# 心身疾病（Psychosomatic Disease）课堂笔记（按老师讲课时间顺序）

## 一、导入与【复习】心理应激：心身疾病与应激机制的关联

【复习】老师提醒：后续“心身疾病”章节与前面“心理应激（psychological stress）”内容高度相关；目前最广泛应用的心身疾病发病理论，很多都建立在**心理应激机制**之上。

【举例】“两只猴子电击实验”（老师用来强调“可控感/责任负担”对健康的影响）

* 两只猴子接受同频率、同电量电击：

  * **伙伴猴**：只能被动接受/不接受 → 虽然挨同样电击，但“活得健康”。
  * **执行猴**：要负责“按按钮/做决定” → 压力巨大 → 出现**溃疡（ulcer）**，在实验不同阶段死亡。
* 结论：**额外责任/负担带来的压力**可能造成**心身损害**；当压力超过个体代偿能力 → 可能发展为心身疾病。

老师交代本周+下周学习目标：

* 认识心身疾病概念：**狭义 vs 广义**如何界定。
* 学完常见心身疾病后，总结其共同特征。
* 重点：心身疾病主要机制基于心理应激，同时也会介绍其他学派理论。
* 按疾病类别逐个讲临床常见心身疾病，并强调诊疗中需要遵循的原则/注意点。

## 二、什么是心身疾病：不是“某一类专门疾病”，而是“心理社会因素显著参与的疾病过程”

老师先强调：心身疾病里包含的病名都很熟悉：

* 原发性高血压、冠心病、消化性溃疡……以及内外妇儿等多学科疾病都可能“属于心身疾病”。

### 1）狭义心身疾病（narrowly defined psychosomatic disease）

核心：**心理社会因素（psychosocial factors）在疾病发生发展中起重要作用**，且存在**明确的器质性病变（organic lesion）**。

* 必须能找到：

  * 明确的病理生理过程（pathophysiological process）
  * 病理学改变/生理生化指标变化（biomarkers）
  * 有医学循证证据（evidence-based evidence）
* 这类可称为狭义心身疾病。

补充：常伴随情绪变化（情绪与症状可先后出现或并行）。
涉及系统：主要牵涉

* 神经系统（nervous system）
* 内分泌系统（endocrine system）
* 免疫系统（immune system）

### 2）广义心身疾病（broadly defined psychosomatic disease）

在狭义基础上进一步扩展：

* 除器质性病变外，还包括**躯体功能性障碍（functional disorder）**：只要心理社会因素起重要作用，也可归入心身疾病。
* 总结：广义心身疾病 ≈ **狭义心身疾病 + 心身障碍（psychosomatic disorder）**
* 重点仍是：心理社会因素在病程中的重要作用；不论是否有明确器质性损害，都“可能属于心身疾病”。

## 三、疾病谱系位置与常见疾病举例：介于纯心理病与纯躯体病之间

老师指出：在疾病谱系（spectrum）中，心身疾病处在

* **单纯心理疾病** ↔ **纯粹躯体疾病**之间，横跨两端，具有“过渡性”。

【举例】内科更常见，但各科均可见：

* 心血管：原发性高血压、低血压、冠心病
* 消化：胃/十二指肠溃疡
* 呼吸：支气管哮喘
* 神经：偏头痛（migraine）、紧张性头痛（tension-type headache）
* 皮肤：神经性皮炎（neurodermatitis）
* 小科也有：口腔、耳鼻喉等

【复习/举例】过度换气综合征（hyperventilation syndrome）

* 紧张时“纸袋呼吸”帮助回吸 CO₂
* 过度呼出 CO₂ → 易致**呼吸性碱中毒（respiratory alkalosis）**

老师强调：**并非某病一发生就必定是心身疾病**；只有当心理社会因素在该患者病程中起重要作用时，才可归入心身疾病。

---

## 四、“无病不心身”：医学模式改变带来的临床思维重点

老师提出临床说法：**“无病不心身”**（并非要死抠分类边界）。

* 因为医学模式已从**生物医学模式（biomedical model）**转向**生物-心理-社会医学模式（biopsychosocial model）**。
* 结论：与其纠结“是不是心身疾病”，更重要的是建立临床思维：

  * 面对患者是“活生生的人”：有情绪、应激、人格、生活事件
  * 心理社会因素往往对“看似躯体症状”的疾病过程有影响
  * 当单纯躯体治疗效果不好/找不到明确躯体病因时，要及时转换思路，主动寻找心理社会因素。

## 五、心身疾病的病因分析框架：心理 + 社会 + 生物（3方面入手）

老师说：分析心身疾病病因通常从三方面着手：

1. **心理因素（psychological factors）**
2. **社会因素（social factors）**
3. **生物学因素（biological factors）**（同样不可缺）

### （一）心理因素：应激、情绪、人格

【复习】应激过程基本逻辑：

* 应激源（stressor）→ 心理/生理反应 → 打破平衡
* 机体努力代偿恢复平衡：

  * 代偿成功 → 恢复平静
  * 代偿失败 → 心身损害/心身紊乱 → 心身疾病

【复习】社会再适应量表：LCU 值（Life Change Unit）

* LCU 值最高事件：**丧偶**（与情感/依恋连接相关的丧失事件冲击最大）
* 老师提醒：经历重大丧失事件后要关注后续健康。

老师提到“研究数据”提示：**中年丧偶**人群某些疾病风险显著高于同龄非丧偶人群（老师举例提到脑血管病、冠心病及其他问题）。

> 课堂要点：重大生活事件 → 应激反应更强 → 更需随访关注。

**人格（personality）**更稳定持久：

* 影响对生活事件的**认知评价（cognitive appraisal）**（老师强调：认知评价是应激过程首要条件）
* 影响应对方式（coping）
* 影响社会支持质量（social support quality）

### （二）社会支持：心理“缓冲器”

【复习】社会支持（social support）具有缓冲作用：

* 社会支持好 → 不易出现精神心理问题，也不易罹患心身疾病
* 支持差 → 风险更高
  （老师强调：不是绝对因果，但有关联，可作临床参考）

### （三）疾病—人格特质的“相关性提示”（非必要、非绝对）

老师展示“不同疾病对应的人格特征”并提醒主要看“蓝字重点”：共同点很突出——**压抑、拧巴、负性情绪难表达**。

* 消化性溃疡：压抑、愤怒/负性情绪；认真负责、有进取心、竞争性强
* 结肠炎：压抑、愤怒；对负性情绪掩盖
* 原发性高血压：童年（主动/被动）压抑不满；渴望认可；压抑愤怒
* 偏头痛：刻板、拘泥细节、完美主义倾向；**超我（superego）**强，达不到目标会自我惩罚
* 哮喘：可理解为“诉求/被压抑的哭泣”
* 神经性皮炎：敌对与依赖冲突；负性情绪难表达；自我监管严格

【举例】神经性皮炎作为“情绪晴雨表”

* 研究生因导师情绪不稳而紧张，不敢沟通；精神科门诊医生建议：观察导师后颈红斑（神经性皮炎）轻重

  * 疹子轻时去谈 → 更顺利
  * 犯得重时别去 → 容易挨骂
* 用来说明：压力大时皮炎加重、压力缓解则减轻 → 心理社会因素影响躯体表现。

### （四）社会因素：生活节奏、文化背景、工业化程度

* 工业化程度高/城市生活节奏快 → 压力更大 → 一些心身疾病（如高血压、冠心病）发病率可能更高。
* 老师补充现代特点：信息铺天盖地，被迫接收信息也会增加心身负担。

### （五）生物学因素：器官“脆弱性/易感性”

老师提出概念（语音识别为“生理史积”，课堂含义明确）：

* 可理解为**生理素质/器官脆弱性（physiological diathesis / organ vulnerability）**：个体在患病前就具有的、与发病相关的身体特点。
* 解释“应激的个体差异”：

  * 同一应激情境，有的人能适应，有的人出问题
  * 出问题的系统也不同：有人心血管、有人成呼吸系统 → 因为“薄弱点”不同
* 临床意义：明确易感后可更有意识地预防、体检监测。

老师举例（作为“生理易感性提示”）：

* 胃蛋白酶原（pepsinogen）水平高 → 胃溃疡风险提示
* 高甘油三酯血症（hypertriglyceridemia）→ 冠心病风险提示
* 高尿酸血症（hyperuricemia）→ 痛风风险提示
  -（老师还举了与甲亢相关的某指标例子，提示“体检异常→遇压力更需警惕对应系统”）

## 六、心身疾病发病机制：不同学派观点 + 现代应激假说

### 1）心理动力学派（psychodynamic）/精神分析（psychoanalysis）

特点：**往回找**——成人问题追溯童年。

* 观点：未解决心理冲突多源自童年，被压抑进潜意识；未来情境触发 → 在器官易感性背景下，引发症状。
* 自主神经系统（autonomic nervous system, ANS）过度活动参与：交感/副交感系统（sympathetic/parasympathetic）。
* 【复习】防御机制“转换（conversion）”：情绪无法以情绪形式表达 → 通过身体“走出来”形成躯体症状。

  * 【举例】“心理性瘫痪”的检查矛盾：主诉肌力=0，但肌张力正常、反射对称；分散注意力后肌力可恢复 → 提示心理因素相关。
* 可解释：哮喘、溃疡、原发性高血压、甲亢等可能与“复现的心理冲突 + ANS激活”有关。

【老师评价/局限】精神分析理论常被争议：**难以证实也难以证伪**，科学性受质疑，更多依赖主观报告，可能有偏差。

### 2）心理生理学途径（psychophysiological approach）：更“实验科学”

老师强调其科学基础：动物实验支撑（小白鼠/狗/鸽子等）。

* 相关人物：

  * Walter Cannon（坎农）
  * Hans Selye（塞里）——一般适应综合征（General Adaptation Syndrome, GAS）
  * Ivan Pavlov（巴甫洛夫）

核心：心理社会因素可引发生理应激反应：

* 交感-肾上腺髓质系统（SAM system, sympathetic-adrenomedullary）激活
* 下丘脑-垂体-肾上腺皮质轴（HPA axis, hypothalamic–pituitary–adrenal）激活

  * 糖皮质激素（glucocorticoids）→ 免疫抑制/干扰
  * 相关生理后果：

    * 心率加快、血压升高
    * 盐皮质激素（mineralocorticoids）→ 水钠潴留 → 与血压升高/冠心病相关
    * 胃蛋白酶原升高/胃酸相关改变 → 与溃疡相关
    * 免疫抑制 → 肿瘤发病率可能增高
    * 免疫-炎症与冠心病粥样斑块形成相关（斑块形成是炎症过程）

### 3）行为主义途径（behaviorism）

关注外显行为，不深究内在冲突；治疗重在**矫正行为、再学习**。
理论基础：两类条件反射

* 经典条件反射（classical conditioning, Pavlov）
* 操作条件反射（operant conditioning, Skinner）

【举例】斯金纳“踏板—食物奖励”实验：

* 动物偶然按踏板 → 食物滚出 → 食物是奖赏（reward）
* 奖赏强化（reinforcement）按踏板行为 → 动物不断按踏板

【举例】儿童“神经性哮喘”行为主义解释：

* 父母在场时发作更频繁/更重；父母赶不来时反而少/缓
* 不是孩子“故意装”，但“父母及时陪伴与关注”可能成为奖赏，长期强化“发作模式”
* 老师再次强调：哮喘可被理解为一种“诉求/内在哭泣”的表达方式。

### 4）【考点】现代假说：基于心理应激机制的心身疾病发生模型（4个关键环节）

老师强调：**书上要求记住**，图里有“四环节”。

1. 心理社会因素 = 应激源（stressor）
2. 应激源作用机体 → 产生一系列心身反应（psychophysiological responses）
3. 反应作用于“脆弱/易感”的器官系统（vulnerable organ/system）
4. 超过代偿 → 心身紊乱 → 心身疾病（psychosomatic disease）

课本另一种叙述（与上同义）：

* 心理社会刺激传入中枢 → 大脑皮质整合/信息加工 → 传出信号 → 引发生理反应 → 心身疾病发生。
  并指出：过程中受躯体/心理中间因素及理化、生物因素影响；超过代偿则从反应走向紊乱与疾病。

## 七、心身疾病的诊断与防治原则

### （一）诊断线索：注意“先后/并行关系”

老师提示两种常见模式：

* **先后关系**：应激期可能扛得住，事件过后开始生病（平时不犯的病开始犯）→ 提示心身因素参与
* **并行关系**：应激源持续时症状持续；应激源消失后症状逐渐减轻/消失 → 提示心理社会因素作用

并强调：

* 症状可表现为器质性病变或功能性障碍——只要心理社会因素重要参与，都可能属于心身疾病。
* 诊断时要排除单纯精神心理问题以及单纯躯体病因。

### （二）诊断信息收集：病史 + 体检 + 心理测量 + 动态随访

1. 病史采集（history taking）：要**有意识询问心理社会资料**

* 近期发生什么事？如何应对？情绪变化？事件后是否出现不适？
* 老师预告：后面会用病例示范“怎么问、怎么抓线索”。

2. 体格检查（physical examination）：不只看躯体，也观察心理行为反应

* 【举例】患者在检查中回避接触、过度敏感、抗拒体检 → 暗示其应激反应可能更强，与躯体症状相关。

3. 心理测量（psychological assessment）：量表等提供依据。

4. 【考点】动态随访（dynamic follow-up）：

* 心身疾病与心理因素相关，而心理会变化 → 诊断与评估需要持续观察、随时调整。

### （三）干预目标与治疗总原则

心理干预目标：

* 消除/减弱应激源
* 改善情绪状态
* 提高依从性（adherence）、改善生活质量（quality of life）
* 帮助建立/利用社会支持
* 提升功能与适应性（function & adaptation）

【考点】治疗总原则：**心身同治（treat both mind and body）**，并分轻重缓急：

* 急性期/危急躯体症状：以躯体对症/抢救为主 + 简单支持性心理干预

  * 【举例】急性心梗：支架/溶栓等抢救优先；心理方面以陪伴、倾听、安抚紧张为主，不可能做完整心理咨询。
* 康复期/慢性期：在躯体治疗同时，更侧重心理治疗与长期管理

  * 【举例】更年期、慢性消化性溃疡、糖尿病等。

老师再次强调临床“主次”：

* 重视心理社会因素，但大前提是**先排除高风险躯体因素**，避免顾此失彼。

## 八、临床常见心身疾病（一）：原发性高血压（Primary Hypertension）

老师先区分：

* 原发性（primary/essential） vs 继发性（secondary）高血压
* 心身因素在原发性高血压中更常见（应激中心血管系统首当其冲）。

### 1）病因三方面

**生物学因素**

* 遗传/家族史：不可忽视（冠心病、高血压、糖尿病等常有遗传基础）
* 摄盐量：老师讨论指南推荐**每日食盐摄入量约 5–6 g**（课堂回忆式表达），且现实中难控制（外食易超标；看似不咸的食物如话梅含盐也可能很高）
* 肥胖等生理基础问题也增加风险

> 老师结论：生物学因素无法解释所有人，仍需看心理社会因素。

**心理社会因素**
【举例】诊所高血压/白大衣高血压（white coat hypertension）

* 平时正常，一到医院见医生测血压就飙高（甚至 200+），回家又正常。
* 解释：情绪/紧张/应激，或医院相关创伤记忆触发。
* 老师强调：虽然是“一过性”，但**是警示**：提示心血管调节系统可能存在缺陷；长期应激 + 年龄增长 + 生活方式叠加，可能演变为持续性原发性高血压 → 应早期预防。

其他相关：

* 生活事件越多 → 发病率越高
* 城市 > 农村；脑力劳动者 > 体力劳动者（应激强度差异）
* 职业应激：长期保持警觉、高标准严要求、付出高回报低等环境更风险

  * 【举例】机场岗位：问卷调查显示压力最大常是**地勤/空管（air traffic control）**而非机长；因为长时间高度集中、持续警觉、突发情况需快速反应。

### 2）人格与心理特征（老师提醒勿轻易对号入座）

* 可能相关：A 型行为模式（Type A behavior pattern）、焦虑抑郁状态、应对能力差等
* 不是“有这些特质就必得病”，但提示应激管理重要。

### 3）患病后的心理表现

* 认知层面：紧张、易怒、记忆力下降、注意力不集中
* 长期高血压可能影响脑供血 → 智能/认知水平可能低于非患者（老师从机制角度解释）
* 焦虑抑郁可致自主神经功能紊乱，睡眠问题（失眠、睡眠不足）
* 严重情况：高血压危象（hypertensive crisis）、高血压脑病（hypertensive encephalopathy）（老师提及为极端/特殊）

### 4）心理与行为干预：核心是“学会放松 + 行为矫正”

【学习建议】放松训练（relaxation training）——行为主义疗法的一种

* 渐进性肌肉放松（progressive muscle relaxation, PMR）：

  * 让不同部位肌肉先紧绷→保持→再放松
  * 用放松的舒适感对抗紧张（交互抑制/拮抗原理：同一时间难以既紧张又放松）

【学习建议】深呼吸（deep breathing）与正念（mindfulness meditation）

* 重点不只是“供氧”，更重要是：注意力几乎全部集中在呼吸上 → 杂念减少
* 杂念回来不必强驱赶：把注意力温和拉回呼吸，顺其自然。

【学习建议】行为矫正：控盐、运动、减少久坐/宅

* 养成运动习惯可用“阳性强化法（positive reinforcement）”：

  * 奖赏要**及时**，延后奖励效果弱
  * 老师用早教 APP 举例：孩子答对立刻夸奖 → 强化更有效
  * 自我习惯养成也可设计“即时正反馈”。

【注意】运动疗法对高血压有利，但：

* 中重度高血压不适合过于激烈或强竞争性项目 → **适度运动更好**。

### 5）插入科普视频要点（老师播放）

* 高血压诊断：同一天测 3 次，收缩压 ≥140 mmHg 和/或舒张压 ≥90 mmHg → 提示高血压
* 正确测血压：休息 5 分钟后测 3 次取均值；上臂与心脏同水平；手腕测需抬到心脏水平；不要撸袖子勒上臂（会测得偏低）
* 年轻人：锻炼/减肥/低盐/戒烟减酒，3 个月内控住可不吃药（视频观点）
* 合并糖尿病、肾功不全、脑血管病者：目标血压更严格（视频提到 130/80 mmHg 以下）
* 服药后血压正常不能随意停药；长期服用一般不产生“耐药”（视频解释“控不住多因病进展需联合”）
* 降压药方案：控制良好且无不良反应无需频繁更换；控制不良或不良反应及时就医
* 运动：游泳、骑车、慢跑等适量运动有利降压。

## 九、临床常见心身疾病（二）：冠心病（Coronary Heart Disease, CHD）

老师定义要点：

* 冠状动脉粥样硬化斑块（coronary atherosclerotic plaque）增多 → 管腔狭窄/阻塞。

### 1）病因：生物学基础 + 心理社会因素

* 生物学：遗传；高血压、高血脂等基础病理状态
* 心理社会：慢性压力、社会支持缺乏（social support as buffer）
* 情绪紧张 → 儿茶酚胺（catecholamines）分泌↑ → 血管收缩、血压↑，心脏负担↑
* 焦虑/抑郁：

  * 老师指出抑郁可促发炎症反应；斑块形成是炎症过程 → 易诱发冠心病
  * 焦虑严重可致心律失常（arrhythmia）
  * 急性焦虑/惊恐发作（panic attack）可模拟心绞痛/心梗：心前区痛、左上臂放射、濒死感等 → 临床需鉴别。
* 生活事件越多：发生/复发/死亡率更高；与 LCU 值越高相关。
* 不良生活方式：吸烟、缺乏运动、暴饮暴食等。

### 2）【复习/考点】A 型行为模式（Type A）与冠心病的关联

老师强调：A 型行为模式与冠心病关联已基本确证（常识级）。

* A 型核心：**时间紧迫感 + 竞争 + 敌意**
* 优势：高标准严要求，可能更“优秀/有成就”
* 代价：慢性愤怒（chronic anger）、人际关系紧张、压力大 → 健康风险高
* B 型：更放松，把生活当享受，健康风险相对低；但可能不守时、略散漫。
* 人群多为混合型：以某型为主。

老师给出 A 型行为清单式特征（用于自我观察）：

* 说话有明显重音；替别人说完后半句
* 走路/吃饭快，行动迅速，强势争辩要“最后一句”
* 阅读缺耐心、追求倍速/摘要
* 易怒：排队慢、路怒等
* 难发现生活小美好（太“赶”）
* 多任务并行；只做一件事会觉得浪费
* 休息躺平会内疚（超我强）
* 倾向用量化指标评价自我价值
* 紧张姿态/动作：磨牙、攥拳等
* 计划排得满；计划外事件会暴躁；控制感强
* 容易给自己增加额外责任（类比“执行猴”）

老师总结建议：**慢一点、冷静一点**，对健康与人际关系都有改善。

### 3）冠心病患者患病后的心理特征

* 情绪：恐惧、焦虑、抑郁常见；情绪触发 ANS 紊乱 → 交感兴奋 → 反过来加重心血管负担（恶性循环）
* 认知/防御：常见防御机制是**否认（denial）**

  * 【举例】心梗就诊发现陈旧梗死灶；追问才知几个月前不适但归因“吃撑了/不是心脏/年轻不会得” → 否认导致延误。
* 药物影响：老师提到洋地黄类（digitalis/cardiac glycosides）可能诱发焦虑抑郁或意识状态紊乱，从而出现精神症状。

### 4）心理干预：分急性期与康复期

【考点】急性期：支持性心理治疗（supportive psychotherapy）为主

* 不是某一种专门疗法，而是多种疗法共有的基础成分：

  * 倾听、陪伴、积极鼓励、积极暗示
  * 简单医学教育/科普
* 老师强调：医护多数无专业心理背景，也能较快学会并应用，临床“好用”。

【举例】病例线索：找到“心结/根源”

* 男性：从小被家庭关注且身体较弱 → 对身体变化极敏感，易把正常变化当症状
* 1 年前岳父因冠心病离世且只有他在场 → 创伤性体验
* 之后总担心自己得严重心脏病，害怕发病时身边没人、孤独死去 → 疑病倾向（hypochondriasis）
* 老师强调：疑病患者不是装，是真相信自己有病；阴性结果也难打消担忧，本质是焦虑。

康复期：更“专门”的心理干预可介入

* 健康教育
* 关注并及时处理抑郁：生病是“健康的丧失事件”，抑郁可能持续；严重可发展为抑郁症并带来自伤/自杀风险
* 需医护密切关注，也要提醒家属提供心理支持
* 积极适度锻炼；矫正 A 型行为模式；戒烟减酒等。

## 十、【病例】心身疾病患者摘要：像“破案”一样抓线索

老师提示：下节课还会练习让大家找线索。

病例要点（老师逐条提示“提示性线索”）：

* 身份：干部
* 主诉：四肢酸痛，无明显诱因；早期可缓解

  * 【诊断提示】查不出生理原因时要考虑心身因素/躯体化（somatization）
* 3 年前退休后加重，性格改变：不爱说话、自我封闭

  * 【心理社会事件】退休对不同人影响不同：有人轻松，有人（岗位重要/落差大）失落严重，成为负性应激事件
* 既往史：神经性皮炎、原发性高血压（提示“多系统心身问题”）
* 家族史：姐姐糖尿病（对患者也是“焦虑暗示”）
* 心理社会因素：敏感多疑、外向急躁、疑病倾向、易躯体化；合并抑郁症状
* 近期事件：炒股赔 100 多万 + 住院后丢豪车

  * 患者口头称“影响不大”（还有房子出租）
  * 老师点评：能说得很具体，说明未必真“云淡风轻”，可能有“嘴硬”，事件叠加仍可能造成心理冲击
* 心理测查：汉密尔顿焦虑量表 HAMA 22（明显焦虑）；汉密尔顿抑郁量表 HAMD 21（中度抑郁）

综合诊断思路（老师总结逻辑）：

* 找心理社会因素 + 找生物学背景 + 识别躯体化 + 用量表支持焦虑抑郁证据
* 诊断：冠心病 + 原发性高血压，伴焦虑抑郁状态及躯体化表现。

## 十一、临床常见心身疾病（三）：消化性溃疡（Peptic Ulcer Disease, PUD）

范围：胃溃疡（gastric ulcer）、十二指肠溃疡（duodenal ulcer）。
机制核心：胃黏膜屏障（gastric mucosal barrier）防御与侵袭因素平衡被打破 → 溃疡发生。

老师强调：生物学因素不足以完全解释时，要看心理社会因素：

* 【考点/举例】应激水平高时溃疡发生/复发增加

  * 老师提到：高校学生尤其医学生，在**考试前后几周**溃疡发生率与复发率明显增加（备考压力 + 消极应对）
* 焦虑抑郁既可能是对疾病的反应，也会反过来加重溃疡（循环）。
* 溃疡本身也有“治愈—复发—再治愈”的循环特点，应激一来更容易发作。

## 十二、插入视频要点：胃溃疡形态、分层进展、饮食节律与情绪影响

【举例/影像】胃溃疡外观：平坦黏膜上出现圆形凹陷，底部白苔样。老师类比“像口腔溃疡”。

【考点】分层进展概念：

* 黏膜炎症刺激破溃 → **糜烂（erosion）**
* 糜烂继续向下突破黏膜肌层到黏膜下层 → **溃疡（ulcer）**
* 溃疡继续发展穿透浆膜层 → **穿孔（perforation）** → 胃内容物入腹腔 → 急腹症，需抢救，危及生命。

【学习建议/视频内容】胃的“生物钟/节律”

* 人体有生物钟（biological clock / circadian rhythm），胃酸分泌也有节律
* 定时定量进餐形成条件反射（conditioned reflex）：到点/见食物 → 胃酸分泌
* 饮食不规律：到点胃酸照样分泌，但无食物中和 → 胃酸损伤黏膜 → 溃疡风险增加
* “多年不吃某顿是否不要紧？”视频观点：人可能适应自己的节律，但关键是要有稳定规律。

【举例/演示】用“盐酸”模拟胃酸：pH 可接近分泌期胃酸酸度；直接作用黏膜可致变性坏死、糜烂，进一步腐蚀可穿孔（演示强调破坏力）。

【考点/临床关联】情绪对胃肠道影响

* 焦虑、紧张、压力大（如学生备考）常见：胃痛、便血就诊
* 机制（视频表达）：强烈刺激→植物神经（ANS）受刺激→胃酸分泌增多→溃疡发生（甚至“没到饭点也分泌”）

（视频最后抛出互动：紧张时胃不舒服的体验）
