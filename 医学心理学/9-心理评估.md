# 课堂笔记（按老师讲课时间线整理）

## 一、从“身高体重血压血糖”引出：心理能不能测量？

* 生活中大量测量：身高、体重、血压、血糖等，**看得见摸得着**，感觉“客观、外显”。
* 由此提出核心困惑：**心理（psychology）是内隐的、看不见摸不着**，那它到底**能不能测量/评估**？

  * 生活俗语：**人心难测、人心叵测**，“女人心海底针”等 → 说明大家直觉上觉得“心理难猜”。

**结论（老师给的明确答案）**：心理当然可以测量、可以评估；只是需要理论与方法支撑。

## 二、心理可测量的理论基础（古今中外的“背书”）

### 1）中国古代思想的证据

* 【引用/复习式引入】孟子名言（老师用来论证“心也可度量”）

  * “**权**然后知轻重，**度**然后知长短，物皆然，**心为甚**。”
  * 解释：权衡可知轻重、度量可知长短，万物如此，人的“心”更需要度量与评估。

* 儒家孔子：**因材施教** → 必须先“评估人的才能/智力差异”

  * 名言：“**中人以下，不可以语上也**”（智力中等以下者不宜讲太高深复杂的道理，因为听不懂）
  * 这实际上指向：**智力测量（intelligence testing）/心理评估（assessment）** 的必要性。

### 2）西方心理测量学的经典表述

* 美国“教育测量之父”桑代克（Thorndike）：

  * “凡客观存在的事物，都有其数量。”
* 测量学者麦科尔（McCall，老师口述）：

  * “凡有数量的东西，都可以测量。”
* 推论回到医学基础：**心理是大脑（brain）的功能**，是大脑对外界事物的**客观反应** → 因而可通过科学方法加以测量。

## 四、核心概念1：心理评估（psychological assessment）

### 1）定义（老师给的标准表述）

* **心理评估（psychological assessment）**：依据心理学的**理论与方法**，对人的心理品质与水平做出**鉴定/判断**。

  * 类比临床：门诊接诊 → 病史采集、症状程度、起病时间等；心理评估也是“收集信息→下判断”。

### 2）它不等于“玄学相术”

* 老师提问：心相学/手相学/面相学/颅相学/骨相学算不算心理评估？

  * 结论：**不算**。因为它们**不依据心理学理论与方法**，且多为**伪科学**。

### 3）心理评估 vs 心理诊断（psychological diagnosis）

* **心理诊断（diagnosis）**更贴近“临床诊断”语境：针对精神/心理障碍（如精神分裂症、抑郁症、焦虑症、强迫症等）进行诊断。
* **心理评估（assessment）更广义**：不仅对“病人”，也可对健康人做智力、人格等评估（例如评估智商、人格特质）。

## 五、核心问题：怎么评估/测量心理？（方法学时间线）

> 老师依次讲了：观察法 → 访谈法 → 调查法 →（强调不高效）→ 测验/量表法（重点）

### 1）观察法（observation）

* 类比临床与中医：患者进诊室先“看一眼”；中医“望闻问切”中的**望诊**。

* 两类观察：

  1. **自然情境观察**：学校、操场、逛街等真实环境。
  2. **特定情境观察**：实验室/特定布置场景 + 录像/监控记录行为。

* 观察的关键抓手：**非言语信息（nonverbal information）**

  * 老师提到研究：人际信息传递中，**60%以上依靠非言语信息**（语气、姿势、表情等）。
  * 经典说法：**“真相在脸上”** → 面部表情是洞悉内心的重要窗口。
  * 临床场景：抑郁/焦虑/恐惧不一定用语言说，可能从**步态、神态、动作激越或迟滞、表情呆板**等看出来。

* 【举例】美剧 *Lie to Me*（别对我说谎/千方百计）：通过捕捉面部表情识别说谎与内心状态，用于刑侦/审讯线索。

* 情绪与表情（老师从中医“七情六欲”引到基本情绪）

  * 中医“七情”：喜、怒、哀、乐、忧、思、恐（老师口述）
  * 老师列的基本情绪（结合面部表情识别）：

    * 快乐（happiness）
    * 悲伤（sadness）
    * 愤怒（anger）
    * 恐惧（fear）
    * 厌恶（disgust）
    * 惊讶（surprise）
    * 轻蔑（contempt）
  * 【举例】“笑”的文化差异：真笑/苦笑/假笑/坏笑/笑里藏刀 → 说明仅凭“看见笑”不等于“高兴”，需要更细的表情线索。

* 【AI/前沿应用】面部表情解码 + 人工智能

  * 摄像头实时捕捉面部信息 → 算法输出情绪类别与比例（如“80%高兴、20%惊讶”）。
  * 理论来源：保罗·艾克曼（Paul Ekman）长期研究情绪与面部表情，跨文化研究（含少数部落），并用于反恐/情报培训等（老师口述）。

* 【局限/误区】观察易受观察者影响（刻板印象/“爱屋及乌”/恋爱脑被花言巧语蒙蔽）

  * 所以不能只靠“听其言”，还要结合更多证据（老师用来引出后续方法）。

---

### 2）访谈法（interview）

* 类比临床：医生与患者**一对一问诊**。
* 两种访谈：

  * **自由访谈（unstructured interview）**
  * **结构化访谈（structured interview）**
* 目的：通过提问收集信息，对心理状态/问题做推断（像病史采集一样：何时出现、严重程度、用药史等）。

---

### 3）调查法（survey / informant report）

* 适用场景：当被评估者**表达能力有限**或**信息不可靠**时。

* 【举例/临床关联】儿科：婴幼儿语言功能弱 → 医生更多问家长（体温、腹泻、大小便、起病时间等）。

* 心理学同理：可问被试周围人（老师、父母、同学、配偶等）。

* 【临床关联】重性精神障碍常见特点：**缺乏自知力（insight）**

  * 例：精神分裂症患者可能否认自己有病 → 需要问家属获取“自言自语、大吼大叫、疑似幻听幻觉、妄想”等信息。

* 【局限】观察/访谈/调查：都可能**费时、效率低** → 引出“更高效的标准化工具”。

---

### 4）测验法/量表法（psychological test / scale）（老师强调“接下来重点”）

* 定义：用**标准化（standardized）、客观（objective）的工具**，对心理现象与行为进行**数量化（quantification）测量**。

* 类比西医仪器优势：血常规、尿常规、CT、MRI等都输出指标；心理测验也输出分数/指标，便于比较与解释。

* 基本原理：心理内隐，但**行为外显**

  * 通过外显行为推测内隐心理。
  * 行为太多 → 需选取**有代表性的行为样本**。
  * 【举例】外向/内向：

    * 外向：爱社交、主动组织、喜欢成为焦点、表达欲强
    * 内向：偏独处、回避活动、不愿成焦点、安静待着
    * 测验通过典型行为样本推断人格特质。

## 六、【考点】如何评价一个测验“好不好”？三大指标：信度、效度、常模

> 老师强调“考试常考：量表质量评价”

### 1）信度（reliability）

* 含义：同一对象多次测量结果是否**一致、稳定、可靠**。
* 类比血压计：今天130、明天180、后天90 → 波动过大就怀疑仪器信度差。

### 2）效度（validity）（老师强调：心理测验最在意）

* 含义：测验是否**真的测到了它宣称要测的东西**。
* 类比血压计：低血压的人被测成180 → 说明效度差。

### 3）常模（norm）

* 含义：解释分数必须有参照系；原始分本身可能没意义，需要与常模比较（平均水平、标准差等）。
* 【举例】小明考90分是否“好”？要看班级分布：若95人100分、4人95分 → 90分反而最差 → 说明常模用于**解释分数的相对位置**。

## 七、【考点/易错】典型陷阱题：身高测智商——“可信但无效”

* 题干：用一个人的**身高**去评估一个成人的**智商**，结果是否可信？是否有效？
* 正确结论（老师强调很多人答错）：

  * **信度高（可信）**：身高反复测量相对稳定。
  * **效度低（无效）**：身高与智商相关很弱，并非稳定正相关；举例：

    * 有人矮但智商高；也可能矮且智商受影响（老师提到“呆小症”等情况）
  * 所以答案是：**可信但无效**（high reliability, low validity）。

## 八、网络流行测验的两个坑：MBTI 与巴纳姆效应（Barnum effect）

### 1）【例子】MBTI（Myers–Briggs Type Indicator）

* 老师指出现象：有的人隔一段时间再测，四字母类型会变 → 但人格一般相对稳定
  → 暗示其**信度可能不高**。

### 2）【例子】“描述谁都像你”的话术：巴纳姆效应（Barnum effect）

* 模糊描述：既外向亲和又内向谨慎沉默……很多同学会觉得“很像我”。
* 解释：这类描述把两面都说全，类似算命话术，**无法真正区分个体人格** → 体现测量表述的无效性。

## 九、心理评估的用途（回到临床逻辑）

* 心理评估为**心理干预/心理治疗（intervention/therapy）**提供基础：

  * 先评估 → 确认问题类型（焦虑/抑郁/强迫等）与严重程度 → 决定治疗策略。
* 还能用于**疗效评价**：

  * 干预前抑郁高 → 干预后抑郁显著下降 → 说明干预有效。
  * 类比临床：发热用药后退热 → 药有效。

## 十一、从“学校人物与碘缺乏”谈智力评估的公共卫生价值（老师插入的案例段）

* 老师以学校老校长/团队研究为例，讲“碘缺乏（iodine deficiency）影响智力”：

  * 过去（70–80年代口述背景）部分地区盐未加碘 → 内陆地区更易碘缺乏。
  * 研究团队做调研：碘摄入与儿童智力（IQ）关系。
  * 老师口述关键时间点：**1994年**向国务院提出食盐加碘建议；之后复测显示部分地区儿童智商提高**10–15分**（老师口述数据）。
* 结论指向：心理测量/智力评估不仅是“测着玩”，也服务于**政策与公共卫生决策**。

## 十二、智力（intelligence）的内涵：功能—机制—结构

### 1）功能角度

* 学习知识、掌握技能、解决临床疑难问题（diagnostic thinking / clinical reasoning）都依赖智力。

### 2）机制角度

* 智力是**高级认知功能（higher cognitive function）**：不是单一的感觉/知觉/注意/记忆/思维，而是综合体，复杂度最高。

### 3）结构角度（老师结合学生回答）

* 包括但不限于：记忆力（memory）、思维/推理（thinking/reasoning）、创造力（creativity）、解决问题能力（problem solving）等。

### 4）概念性定义（老师口述总结）

* 智力：能够进行**有目的的行动**、**合理思维**并**有效应对环境**的一组能力集合。

## 十三、智商（IQ, intelligence quotient）：两种“单位体系”

### 1）比例智商（ratio IQ）

* 公式：**IQ =（智力年龄 MA / 生理年龄 CA）× 100**

  * MA：mental age（智力年龄）
  * CA：chronological age（生理/实际年龄）
* 【算题例（老师给的典型考法）】三个孩子CA=10岁：

  * A：MA=13 → IQ=130
  * B：MA=10 → IQ=100
  * C：MA=7 → IQ=70
* 【致命缺陷（老师强调）】用于成人不合理：

  * 成人CA持续增长，但MA相对稳定 → 公式会导致“年龄越大IQ越低”，不符合事实。

### 2）离差智商（deviation IQ）（老师说“全球目前最通用”）

* 公式（老师口述结构）：

  * **IQ = 100 + 15 ×（原始分 X − 常模平均 M）/ 常模标准差 SD**

* 常见解释区间：

  * **85–115**：一般水平（约±1 SD）

* 【课堂互动】爱因斯坦 IQ：老师口述“**160以上**”。

  * 还讲到与医学相关的“爱因斯坦大脑”故事：临终遗嘱与后续被保存研究（老师口述故事线）。

* 【影视例子】《阿甘正传》：老师口述阿甘IQ约**70–80**（偏低但可生活自理）。

* 进一步引出“智力残疾”的临床意义：

  * 有人躯体无明显缺陷，但因智力严重受损导致不能自理 → 需要智力评估决定照护与适应支持。

## 十四、经典智力测验1：韦氏智力量表（Wechsler）

* 老师定位：全球最经典、常用、质量高；想评估IQ做韦氏很合适（老师口述）。
* 三个版本（按年龄）：

  * 成人版：**16岁以上**
  * 儿童版：**6–16岁**
  * 学龄前/幼儿版：学龄前（幼儿园小中大班阶段）
* 结构：

  * **11个分测验（subtests）**

    * 言语（verbal）6个
    * 操作/表现（performance）5个
* 输出分数：

  * 总IQ（Full Scale IQ, **FIQ/FSIQ**）
  * 言语IQ（Verbal IQ, **VIQ**）
  * 操作IQ（Performance IQ, **PIQ**）

### 【举例】典型分测验体验

1）相似性（Similarities）

* 题目从易到难，按回答给0/1/2分。
* 易错点：问“相似性”不要答“差异性”。

  * 老师例：北方 vs 西方 → 答“一个在北一个在西”是差异，得0分。

2）数字广度（Digit Span）：顺背与倒背

* 规则：一般“一秒一个数字”；每个系列两道题，答对继续，连续错则停止。
* 顺背例：5位 42731；11位 4163246359（老师口述示例）
* 倒背例：3位 629→912；更长位数倒背更难
* 老师借此联系：过目不忘、倒背如流（钱钟书例子）→ 记忆能力差异与智力测量相关。

3）数字符号（Digit Symbol / Coding）

* 1–9对应不同符号 → 把一串数字快速翻译成符号，强调“又快又准”，体现加工速度/反应速度。

4）操作性测验举例：拼图、积木/图片拼凑等（如木块图、图片排列、图形拼凑等）

* 需要一对一施测，类似“测评工具箱”。

### 结果解释（老师强调韦氏不只给“高低”，还能给“优势-短板”）

* 既判断总体智力水平，也能看**言语优势**还是**操作优势**，据此用于“扬长避短/因材施教”。
* 类比临床：检查不仅告诉你“有病没病”，还提示“类型、程度、下一步治疗方向”。

## 十五、经典智力测验2：比奈—西蒙量表（Binet–Simon，1905）

* 编制者：法国学者比奈（Binet）及助手西蒙（Simon）。
* 历史典故（老师讲的“为什么要做智测”）：

  * 法国教育部长发现小学里总有少数孩子跟不上进度 → 提问：如何筛出这些孩子做特殊教育？
  * 比奈提出：可能与智力较低有关 → 编制智力量表筛查 → 成功。
* 教学落点：心理测量/智力测验服务于教育与临床实践。

### 斯坦福—比奈量表（Stanford–Binet, **SB**）

* 美国斯坦福大学特曼（Terman）修订比奈—西蒙量表，形成更著名的SB量表（老师强调“升级版、更强更准”）。
* 国内也有修订版本（老师概括提及）。

## 十六、经典智力测验3：瑞文推理测验（Raven / Raven’s Progressive Matrices）

* 为什么需要它（老师提出的“公平与效率”问题）：

  1. 文字性测验受语言影响：移民、外语不熟者、文盲等不一定智力差，但文字题会不公平。
  2. 个体施测效率低：能不能一次测50/100人？
* 瑞文的特点（老师强调）：

  * **非文字载体**（图形矩阵推理）→ 跨文化更公平
  * 可**团体施测** → 高效
* 版本（老师口述四种）：

  * 标准版
  * 彩色版（偏低智商儿童更适用）
  * 高级版（高智商人群）
  * 组合型
* 题目结构：

  * A、B、C、D、E 五个系列
  * 每系列12题，共60题
  * 难度递增：系列间 A→E 越来越难；系列内 1→12 也逐步变难
  * 从6选1到8选1等（老师用课堂样题说明）
