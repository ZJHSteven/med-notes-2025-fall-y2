## 2. 人体不同体液 pH 为何不一样（先建立“正常范围感”）

### 2.1 动脉血 pH

* 正常：**7.35–7.45**
* <7.35：酸中毒；>7.45：碱中毒
* 范围很窄 → **偏一点就伤细胞功能**

### 2.2 静脉血 pH（老师引导你推理）

* **比动脉血更偏酸**（含更多代谢产物）

### 2.3 脑脊液（CSF, cerebrospinal fluid）pH

* 约 **7.4**（变化范围极窄）
* **几乎不允许偏移** → 偏酸/偏碱都损伤神经细胞

### 2.4 尿液 pH（范围很宽）

* 约 **4.6–8.0**（老师强调：范围大是因为肾调酸碱）
* 酸中毒 → 肾排酸尿；碱中毒 → 肾排碱性尿
* 但尿过酸（老师提到 <4.5）可能损伤肾小管（提示“过度偏酸也危险”）

### 2.5 消化道 pH

* 胃液：**pH ~1–3（很酸）**
* 肠液：**偏碱**（胰液+胆汁进入肠道）

## 4. 体内酸、碱的来源

### 4.1 酸的来源（两大类）

**A. 挥发性酸（呼吸性酸）——碳酸系统**

* 三大营养物彻底氧化 → CO₂ + H₂O
* CO₂ + H₂O ⇌ H₂CO₃（碳酸，碳酸酐酶参与）
* H₂CO₃ ⇌ H⁺ + HCO₃⁻
* 能变成气体 CO₂ 被呼出 → 所以叫“挥发性酸”，也叫**呼吸性酸**

**B. 非挥发性酸（固定酸 / 代谢性酸）**

* 含硫/含磷氨基酸代谢 → 硫酸/磷酸等
* 嘌呤代谢 → **尿酸**（尿酸高→痛风）
* 缺氧/休克/心衰等严重低灌注 → **乳酸堆积**（乳酸酸中毒）
* 碳水不足/饥饿/糖尿病胰岛素缺乏 → 脂肪酸分解↑ → **酮体↑**（酮症酸中毒）

> 老师的“现实提醒”：短暂运动乳酸会被肝代谢；但严重缺氧/休克才会乳酸爆表。

### 4.2 碱的来源

* 水果蔬菜中的有机酸盐代谢 → 释放 **HCO₃⁻**
* 所谓“碱性食物/酸性食物”来自代谢后“净产酸/净产碱”不同
* 老师强调：**不用天天算配比**，因为机体有强大的自动调节系统。

## 5. 酸碱调节的“四大机制”（核心框架）

1. **血液缓冲系统（快，但容量有限）**
2. **呼吸系统（快，调 CO₂）**
3. **肾脏（强而持久，但慢：小时到几天）**
4. **细胞内外离子交换（快，但会带来电解质紊乱）**

### 5.1 缓冲系统重点

* 细胞外液最重要缓冲对：**HCO₃⁻ / H₂CO₃（碳酸氢根-碳酸缓冲对）**

  * 主要缓冲：**固定酸 + 碱**
  * 老师强调：它**不能直接缓冲“呼吸性酸（CO₂/碳酸）”**，呼吸性酸更依赖 **Hb 缓冲对**
* 红细胞内：**Hb 缓冲对**处理 CO₂ 带来的 H⁺
* 细胞内：**磷酸盐缓冲对**等；血浆蛋白也参与缓冲

### 5.2 呼吸调节（老师用“憋气实验”讲机制）

* CO₂潴留 → 直接刺激呼吸中枢 → 呼吸加深加快 → CO₂排出
* 代谢性酸（H⁺↑）也能通过外周化学感受器（颈动脉体/主动脉体）→ 刺激呼吸中枢 → **过度通气**
* 关键思想：**代谢酸↑ → 通过“呼出更多CO₂”来抵消总酸负担（代偿）**

### 5.3 肾调节（排酸保碱）

* 排酸：分泌 H⁺、泌氨等
* 保碱：重吸收 HCO₃⁻
* 特点：**慢，但“最强、最持久”**

### 5.4 细胞内外交换（老师特别强调的考点）

* **酸中毒：H⁺入细胞 ↔ K⁺出细胞 → 高钾血症**
* 这是“救急式缓冲”，但会造成电解质紊乱（因此排在第4机制）

## 6. 血气分析：指标、正常值、各代表什么（老师反复强调“别只背，要会推理”）

### 6.1 抽血要点

* **动脉血**（常用桡动脉），压力高，穿刺后需**压迫至少5分钟**止血
* 需尽量**隔绝空气**（避免影响 PaO₂/PaCO₂）

### 6.2 三大核心指标（老师课上“三件套”）

#### ① pH（综合指标）

* pH 正常不等于没病，可能有三种情况：

  1. 真正常（无紊乱）
  2. **完全代偿**（病在，但被拉回正常）
  3. **混合紊乱**（酸中毒+碱中毒同时存在，互相“抵消”掉 pH）

> 老师点名：这三条很像“考试暗示”。

#### ② PaCO₂（动脉血二氧化碳分压，呼吸性指标）

* 正常约：**33–46 mmHg**，平均 **40 mmHg**
* 通气不足 → PaCO₂↑
* 通气过度 → PaCO₂↓
* 注意：代谢因素也可“间接”改变 PaCO₂（通过代偿性呼吸变化）

#### ③ HCO₃⁻（碳酸氢根，代谢性指标）

* **标准碳酸氢根（SB, standard bicarbonate）**：把血调到标准状态（如 PaCO₂=40 等）再测

  * 正常 **22–27 mmol/L**，平均 **24 mmol/L**
* **实际碳酸氢根（AB, actual bicarbonate）**：病人当下真实状态测得

**老师的经典推理结论：**

* **AB > SB ⇒ CO₂潴留（PaCO₂偏高）**
* **AB < SB ⇒ 过度通气（PaCO₂偏低）**
* “SB不受呼吸因素影响”要理解成：**因为它测量时强行把 PaCO₂校正回40**，所以“相对”不受呼吸影响。

### 6.3 其他常见指标

* **BE（Base Excess, 碱剩余）**：正常约 **-3 ~ +3**，平均 **0**（反映碱储备）
* **CO₂结合力**：多用静脉血估算碳酸氢根/碱储备；便于反复复查
* **AG（Anion Gap, 阴离子间隙）**：

  * 定义：未测定阴离子与未测定阳离子差值
  * 公式（老师版）：**AG = Na⁺ − (Cl⁻ + HCO₃⁻)**
  * 正常 **10–14 mmol/L**（老师给的范围）
  * 老师强调：**AG主要用于“代谢性酸中毒”的病因分析**（别乱用）

## 7. 四种原发性酸碱紊乱：用“谁先变”来定义（老师最想让你掌握的逻辑）

把系统简化成两件事：

* **HCO₃⁻：代谢性（肾调）**
* **H₂CO₃/CO₂：呼吸性（肺调）**

于是：

* **代谢性酸中毒**：原发 **HCO₃⁻↓** → pH↓
* **代谢性碱中毒**：原发 **HCO₃⁻↑** → pH↑
* **呼吸性酸中毒**：原发 **CO₂↑** → pH↓
* **呼吸性碱中毒**：原发 **CO₂↓** → pH↑

> 老师反复强调：这套是“推出来的”，不是死背。

---

## 8. 代谢性酸中毒（最常见、最爱考）

### 8.1 概念（老师原意）

* 细胞外液 **H⁺增多** 和/或 **HCO₃⁻减少**
* 关键是：**HCO₃⁻原发性降低** → pH↓

### 8.2 按 AG 分型（老师主线）

**A. 高AG型（“储酸型/固定酸增加型”）**

* 典型原因（老师列举）：

  * **乳酸酸中毒**：休克、心衰、严重缺氧/缺血、严重贫血等
  * **酮症酸中毒**：糖尿病控制差（胰岛素缺乏/作用障碍 → 细胞用不了糖 → 脂肪分解 → 酮体↑）
  * 肾衰（排酸能力下降）
  * 药物/酸性物质：阿司匹林、氯化铵等（老师强调“药物也可能带酸负荷”）

**B. 正常AG型（“失碱型/高氯性代酸”）**

* 核心机制：**HCO₃⁻丢失**
* 常见原因（老师列举）：

  * **腹泻**（丢碱性肠液）
  * 肾丢碱：如**Ⅱ型肾小管酸中毒（近端小管回吸收HCO₃⁻障碍）**

**老师给的“配套观察”：**

* **正常AG代酸常伴 Cl⁻↑（高氯性）**
* **高AG代酸 Cl⁻多接近正常**

### 8.3 代偿（还是四大机制，但要说清“谁干了什么”）

* 缓冲：主要靠 **HCO₃⁻/H₂CO₃缓冲对**消耗H⁺
* 呼吸代偿：H⁺刺激外周化学感受器 → **过度通气（库斯莫呼吸 Kussmaul）** → PaCO₂↓
* 肾代偿：排酸保碱（若肾本身坏了则代偿失败）
* 离子交换：**酸中毒 → 高钾血症（K⁺外移）**

### 8.4 血气特点（老师要求你会“顺着链条推”）

* pH：下降（若完全代偿可回到正常范围）
* HCO₃⁻（SB/AB/BE等碱储备指标）：**下降**（原发改变）
* PaCO₂：**下降**（呼吸代偿导致过度通气）

### 8.5 对机体危害（老师重点讲了心脑 + 呼吸）

**心血管：**

* 心肌收缩力↓：H⁺影响兴奋-收缩耦联（老师讲“H⁺竞争性影响肌钙蛋白-钙作用”这一层意思）
* 常合并高钾 → 心律失常甚至停跳
* 外周血管对儿茶酚胺反应性↓ → 血管扩张 → **休克**
* 凝血/血栓风险（老师提到酸性环境可促凝/血栓倾向）

**中枢神经：**

* 酸性环境抑制中枢：抑制性递质（老师提到GABA）相对增强 + ATP生成减少
* 表现：嗜睡 → 昏睡 → 昏迷

**呼吸：**

* **库斯莫呼吸**（深大、快的过度通气）

**慢性代酸：**

* 骨脱钙、骨质疏松/软化等（老师用来提醒“长期极端戒碳水→酮体↑→酸负荷↑”的风险）

### 8.6 治疗原则（老师强调“先治原发病”）

* 控制病因：如纠正休克/缺氧、控制糖尿病、处理肾衰等
* 碳酸氢钠纠酸需谨慎：避免“纠酸过度 → 转成代谢性碱中毒”（老师在代碱部分也反复提醒）

## 9. 回扣病例：这例到底是什么紊乱？（按老师的推理走）

已知：pH 7.13；PaCO₂↓；HCO₃⁻ 10.1（明显低）；血糖25（极高）

推理：

1. pH↓ → 酸中毒
2. PaCO₂↓ 解释不了酸中毒（CO₂少反而偏碱） → 不是呼吸性酸中毒
3. HCO₃⁻显著↓ → 能解释 pH↓ → **代谢性酸中毒（原发HCO₃⁻下降）**
4. PaCO₂↓ = 呼吸代偿（库斯莫样过度通气）
5. 结合“糖尿病控制差 + 高血糖 + 昏迷” → **高度提示高AG型代酸：酮症酸中毒（DKA）可能性大**

### 老师留的“钾题”

* 化验K⁺=5.1（表面在参考范围内），但老师提示“肯定有潜在钾紊乱”。
* 更贴近临床的解释：**酸中毒/胰岛素不足会让K⁺从细胞内移到细胞外**，所以血钾看起来可“正常或偏高”；但同时因渗透性利尿/呕吐等，**总钾往往在体内是亏的**，一旦治疗（尤其补胰岛素、纠酸），K⁺回到细胞内，**血钾可能迅速下降 → 潜在低钾风险**。
* 所以这题的“潜在紊乱”通常指向：**总钾缺乏/治疗后低钾风险**（表面数值迷惑人）。

## 10. 代谢性碱中毒（代碱）

### 10.1 概念

* 细胞外液 **HCO₃⁻增多** 或 **H⁺丢失过多**
* 本质：**HCO₃⁻原发性升高 → pH↑**

### 10.2 常见原因（老师按“丢H⁺/得HCO₃⁻”分类）

**A. H⁺丢失过多**

* 消化道：**呕吐、胃肠减压、肠梗阻严重呕吐**（丢胃酸）

  * 常合并：低Cl⁻、低K⁺（胃液里有Cl⁻、K⁺）
* 肾：

  * **醛固酮增多**（促进排H⁺、回吸收HCO₃⁻）
  * 利尿药（老师提到噻嗪/袢利尿药一类可能促进排H⁺、并常伴低K）

**B. HCO₃⁻摄入/储备过多**

* 纠酸过度（补碳酸氢钠过猛，没等肾代偿“慢慢接手”）
* 大量服用含碳酸氢根的制酸药（胃病止痛长期过量）
* 大量输库存血：抗凝剂多为**枸橼酸钠（citrate）**，代谢后产生碱负荷（老师用“强碱弱酸盐→偏碱”来帮助记忆）

**C. 低钾与代碱（老师专门点了“反常性酸性尿”的坑）**

* 低K可促H⁺进入细胞/肾排H⁺等机制 → 加重代碱
* 若“原发病是低钾”，即使整体代碱，尿也可能出现**反常性酸性尿**（老师强调：继发改变往往“打不过”原发驱动）。

### 10.3 临床分型：盐水反应性 vs 盐水抵抗性（老师用来指导治疗）

* **盐水反应性代碱**：多为“呕吐/利尿剂”等导致的**容量不足+低氯**，补**生理盐水（NaCl）**常有效
* **盐水抵抗性代碱**：多与**醛固酮增多**等矿皮激素过多相关，补盐水效果差

### 10.4 代偿与血气特点（按老师框架）

* pH：升高（完全代偿可回正常）
* HCO₃⁻：升高（原发改变）
* 呼吸代偿：碱抑制呼吸中枢 → 通气下降 → **PaCO₂↑（潴留酸以对冲碱）**
* 一旦PaCO₂变了，AB与SB就会拉开差距（回扣前面“实际/标准”概念）

## 12. 老师式“考试问法”速答模板（你背这几句就很顶）

1. **pH正常**三种可能：无紊乱 / 完全代偿 / 混合紊乱
2. 判断原发：看 **HCO₃⁻（代谢）**还是 **PaCO₂（呼吸）**谁先变
3. 代酸：HCO₃⁻↓，常见呼吸代偿 PaCO₂↓（库斯莫）
4. 代酸分型：看AG（高AG=储酸；正常AG=失碱/高氯）
5. 代碱：HCO₃⁻↑，常见呼吸代偿 PaCO₂↑（通气下降）
6. AB/SB：AB更“受PaCO₂影响”；SB把PaCO₂校正回40再测
