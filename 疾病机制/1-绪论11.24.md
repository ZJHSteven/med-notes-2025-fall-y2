# 11.24课上录音
## 一、开场：课程定位与整体框架（整合课“疾病机制”是什么）

* 本学期少数“**整合课程**”之一；先用很短时间介绍课程，再讲绪论内容。
* 整合课的思路：以后更多会以“**某类疾病**”为线索把知识串起来；本课属于整合课中**较早**的一门。

### 1）本课主要围绕三块“共性规律”

* **疾病形态学改变规律**（偏病理学）
* **疾病功能学改变规律**（偏病理生理学）
* **疾病治疗相关规律**（偏药理学）

> 强调：本课**不讲某个器官系统特别具体的疾病**，主要解决“疾病的共性规律”。
> 具体到八大系统的整合课：会在下学期及大三上继续学。

### 2）病例/PBL的“通用拆解框架”（老师用消化系统感染举例）

【举例】消化系统感染 → 出现症状 → 进一步发展为酸碱平衡失调 → 入院后正确诊断与治疗 → 痊愈。

* 从任何病例里通常能看到几块信息：

  1. 现病史、症状、体征、实验室检查 → 对应**病理学 + 病理生理学**
  2. 诊断后治疗 → 对应本课后半部分的**药理学**

> 目标：理解“共性发病机制/规律” → 才能对应机制找到**诊断与治疗靶点**，梳理治疗原则（对因/对症）。

## 六、进入绪论概念：什么是“疾病”、什么是“健康/亚健康/全健康”

### 1）疾病（Disease）的概念（老师强调“多理解，不是死背”）

疾病：在一定病因作用下，机体出现**内稳态调节紊乱**，导致异常生命活动，并出现功能/代谢/形态结构改变。

由概念推出的三个“特点”：

1. **一定有病因**

   * “原发性”只是“病因不明”，不等于“没有病因”。
   * 病因不清 → 只能更多做**对症治疗**；病因明确 → 才能做**对因治疗**。
   * 老师顺带强调：许多疾病预后变好，与发病机制研究有关。
2. **内稳态调节紊乱**（稳态机制被打破）
3. **功能/代谢/形态结构改变**

   * 从诊断学角度：对应为症状、体征、实验室检查异常
   * 【复习】症状 vs 体征

     * 症状：患者**主观**感觉
     * 体征：医务工作者通过**查体**发现的客观情况

### 2）疾病按病程（老师举英文词）

* 急性（acute）
* 慢性（chronic）
* 亚急性（subacute）
  【学习建议】临床工作中常接触急难重症，但从健康管理角度也更应关注亚急性/慢性进展与机制。

### 3）健康（Health）的概念：从“躯体”到“生理-心理-社会”

* 早期：健康 = **躯体完好状态**
* 现代：健康 = **生理 + 心理 + 社会适应** 三维度的完好状态
* 三维度相互影响：

  * 慢性躯体病 → 可能影响精神/心理适应
  * 精神/心理问题 → 也可能诱发躯体病（老师举“内分泌等”方向）

### 4）全健康（One Health）

One Health：把**人-动物-环境**的健康作为整体来考虑。关注点：

* 人兽共患病
* 气候对机体影响
* 抗生素耐药
* 食品安全等

【举例】从 One Health 看“抗生素耐药”

* 不只是在医患用药层面，还与：医院/药厂/社区、家禽动物饲养场、以及废水处理等“残留排放”有关 → 可能促进耐药问题。

【举例】天津本地案例（老师提到的科研简报）

* 提到“缺血性脑卒中发病与气候高度相关”的研究；并说获得天津市科技进步特等奖；天气预报发布时可能提示脑血管病高发风险与此研究相关。
  （此处为老师课堂举例，用于说明 One Health/气候与健康的联系。）

### 5）亚健康（Sub-health）

* 亚健康：介于健康与疾病之间的“**非完美健康状态**”。
* 老师提到：人群中约 **75%** 处于亚健康（强调这是很普遍的情况）。
* 关键：健康 ↔ 亚健康 ↔ 疾病 **可相互转化**

  * 有效控制亚健康 → 可能回到健康
  * 不重视预防 → 可能转为疾病

【学习建议】疾病管理理念：

* “治未病”、**关口前移**：早发现、早诊断、早治疗 → 解决亚健康向疾病转化的问题（老师后面说心血管/中枢神经系统疾病常强调这一点）。

## 七、病因学（Etiology）：病因 vs 条件、诱因、危险因素

### 1）病因学研究两个点

1. 疾病发生的**原因**
2. 疾病发生的**条件**

### 2）病因（cause）的定义（老师给出的关键点）

病因：引起疾病**必不可少**的因素；赋予疾病**特征性/特异性**，决定疾病特异性的因素。

### 3）致病条件（conditions）的定义

条件：促进或减缓疾病发生的因素，可包括：

* 机体状态
* 自然环境
* 心理社会因素等
  特点：本身**不直接引起**疾病，但会影响病因对机体的作用。

【名词】诱因（trigger）

* 在致病条件中，能**加强病因作用**的因素称为诱因。
  【举例】甲流/流感：着凉不是病因，但可降低抵抗力 → 成为诱因。

【重要理解】原因与条件可相互转化（因疾病而异）
【举例】营养不良

* 对缺铁性贫血等：营养不良可作为**病因**
* 对某些感染性疾病：营养不良使抵抗力差 → 成为**条件**（易感人群）

【补充概念】危险因素（risk factor）

* 在后续系统学习中会遇到：如心血管病的高糖高脂、运动少、腹型肥胖等。

## 八、病因的分类（老师列“七类”并逐一展开）

> 老师提醒：你们在“病原与免疫”里至少学过其中两类：感染、免疫。

### 1）感染性生物因素

**① 致病微生物 + 寄生虫**

* 重要特点（老师按病原致病学思路回顾）：

  1. 有**入侵门户**：口、呼吸道、血行等 → 预防方式不同（洗手/戴口罩/避免体液传播）

     * 【学习建议】理解入侵门户后，对疾病不必“莫名恐慌”；堵住门户可显著预防。
  2. 病原体与宿主个体之间要发生**相互作用**才致病

     * 【举例】人兽共患病：动物（猫狗等）可通过合理途径感染人
     * 也有只在动物间传播、不感染人的情况 → 不必过度担心
  3. 作用于机体后会触发**免疫反应**，并参与疾病发生发展

* 相互作用的结果之一：**耐药性/抗药性（resistance）**

  * 病原体接触药物/环境后发生改变 → 对后续药物不敏感。

**② 共生微生物（肠道菌群等）**

* 肠道菌群在体内正常存在；比例合适不致病。
* 菌群失调可与多类疾病有关（老师提到：感染性疾病、心血管、阿尔茨海默病研究等领域都在关注）。
* 【易错/提醒】经常使用**广谱抗生素** → 容易导致菌群失调 → 可诱发多种问题（机会致病菌相关）。

### 2）物理与化学因素（老师建议更关注化学）

* 化学因素：如药物导致的疾病、化学致癌物等

  * 影响：对疾病**发生 + 发展**都可能有影响
  * 潜伏期：可很长（引出药物毒性反应中的“长期/慢性毒性”）
  * 选择性：不同化学物质可选择性损害肝肾/造血/内分泌等系统
* 物理因素：更偏影响“发生”，对“发展”影响相对小；潜伏期通常较短（如高温高压等）

### 3）遗传因素

* 包括：染色体畸变、基因异常、表观遗传因素等
* 可直接导致遗传病：老师提到“分子病”概念

  * 单基因病：机制清楚时，可能有机会通过基因治疗改善/治愈
  * 多基因病：如糖尿病、阿尔茨海默病

    * 【理解点】多基因病用“单靶点/单基因”治疗往往效果不理想 → 需要更多综合策略
* 遗传易感性：遗传因素与环境因素相互作用 → 诱发疾病

【举例】安吉丽娜·朱莉（老师说作示例）

* 因家族乳腺癌史做基因检测，提示 **BRCA1（老师口述成 brt one）** 突变；乳腺癌/卵巢癌风险显著升高 → 采取预防性手术（乳腺切除、卵巢输卵管切除）以降低风险。
  （课堂用来说明“遗传易感性 + 预防策略”。）

### 4）先天因素（congenital factors，老师强调讲义定义不够完整）

先天因素不仅包括：

* 妊娠期接触某些物质/感染 → 导致先天性疾病
  也包括：
* 父母携带的基因异常 → 导致先天性疾病（其中部分可遗传）

【区分要点】“先天性”不等于“遗传性”

* 可遗传的先天性疾病：与基因/染色体有关（老师举血友病等）
* 不遗传的先天性疾病：如先天性弓形虫病、先天梅毒等

  * 【举例】妊娠期频繁接触猫可能涉及弓形虫风险；可做抗体检测排查
  * 关键逻辑：遗传强调基因/染色体问题；若基因染色体无异常，则“先天但不遗传”。

### 5）免疫因素

* 免疫增强或免疫抑制都可致病（老师说你们已学完“病原与免疫”，此处略）。

### 6）营养因素

* 营养不足或过量都可致病
* 【举例】叶酸摄入不足 → 可能导致神经系统发育相关障碍（老师提到方向性例子）。

### 7）心理与社会因素

* 与“疾病/健康”本身的生理-心理-社会属性一致，老师提示应重点关注。

## 九、发病学（Pathogenesis）：疾病发生的一般规律（老师列 4 条）

### 1）内稳态失衡

【复习】以内分泌轴举例：下丘脑-垂体-甲状腺轴（HPT axis）

* 甲亢：T3/T4 升高；TSH 等指标出现相应异常变化 → 体现“一个器官出问题，相关环节也会改变”。

### 2）损伤与抗损伤的失衡

* 损伤与抗损伤是相对的。
* 【举例】炎症：

  * 初始可为保护（杀灭病原微生物）
  * 异常/过度炎症 → 转为损伤因素 → 失衡致病

### 3）因果交替

* 临床上要警惕“因果交替”，否则容易看不懂病情为什么恶化、该怎么打断恶性循环。

### 4）局部与整体

【举例】糖尿病足

* 全身性疾病（糖尿病）→ 局部问题（皮肤感染、溃烂/坏疽，严重可截肢）
* 局部感染若不治 → 可进展为全身感染
  【理解点】治疗时要同时评估：
* 全身病能否导致局部问题
* 局部病不治会不会拖成全身性恶化

## 十一、疾病的转归 vs 预后（prognosis）（老师重点澄清概念差异）

### 1）转归（outcome）：疾病最终结果

主要两大结局：

* **康复**（理想结局）

  * 但不少疾病（尤其慢病）可出现**不完全康复**
  * 不完全康复 → 可能出现**后遗症**（sequelae，老师口述成“squcreen”）

    * 可能表现为组织损伤、功能障碍
    * 应尽量减少后遗症发生
* **死亡**（疾病不可逆时可能走向死亡）

### 2）预后（prognosis）：对转归的“预测”

* 预后 = 对疾病转归的预测
* 转归 = 疾病实际结果
  （老师说很多同学容易把两者混为一谈。）

> 讲到“死亡标准的认定（最早的……）”时，这段录音在此处结束，后续应会继续展开。
