## 一、绪论：为什么会有“局部血循环障碍”

* 正常循环：**心脏 + 动脉/静脉系统**构成闭合回路；靠**神经-体液调节**维持动态平衡。
* 微循环里，血管内外一直在交换，核心是两股力的平衡（Starling 力）：

  * **毛细血管流体静压（hydrostatic pressure）**：把水“往外推”
  * **血浆胶体渗透压（主要靠白蛋白）**：把水“往回拉”
* 临床串联：**低蛋白血症（严重营养不良）→ 胶体渗透压下降 → 水从血管漏到组织间隙 → 浮肿/水肿**。

---

## 二、本章总纲（老师给的“分类框架”）

局部血液循环障碍 = **血液改变** + **血管壁改变**

### 1）血液改变

* **血量改变**

  * 血多：**充血（hyperemia）**
  * 血少：**缺血（ischemia）**
* **血质改变**

  * 凝固性增高 → **血栓形成（thrombosis）**
  * 血中出现“异物”（空气/脂滴/肿瘤细胞等） → **栓塞（embolism）**
  * 进一步可导致：**缺血性梗死（infarction）**

### 2）血管壁改变

* **完整性没破坏**、但**通透性↑**
  → 水外渗：**水肿**；红细胞外渗：**漏出性出血**
* **完整性破坏（血管壁破了）**
  → **破裂性出血**

## 三、第一节 充血（Hyperemia）——“血多了”

### 1）词根小抄（老师强调）

* **hyper-**：多 / 过度
* **-emia**：血（各种“血症”常用结尾：高糖血症、高尿酸血症等）

### 2）充血定义

* **局部组织器官血管内血液含量增多** = 充血

### 3）动脉性充血（arterial hyperemia）

**概念**：动脉输入血量增多 → 充血
**机制要点**：血管舒张 → 微循环灌注量↑

**常见原因/例子（老师举例）**

* 炎症早期：局部发红
* 生理性：情绪激动（脸红脖子粗）、运动（肌肉供血↑）、进食后胃肠供血↑
* **减压后充血（反射性扩张）**：比如胸/腹腔积液一次抽太多，原来被压瘪的血管突然“放松”，血大量灌注 → 易出现头晕甚至更严重后果（老师强调“要慢、要观察”）

**肉眼：大红热**

* 体积轻度增大
* 颜色鲜红（氧合血红蛋白多）
* 代谢增强、局部温度升高

**镜下**

* 小动脉、毛细血管扩张充血

**结局**

* 多数**去除病因可完全恢复**
* 特殊风险：若合并**高血压/动脉硬化**，情绪激动可诱发**破裂性出血（如脑出血）**

---

### 4）静脉性充血 = 淤血（congestion）

**概念**：静脉回流受阻 → 血液淤积于小静脉/毛细血管

**原因（老师按逻辑讲）**

1. **静脉内堵了**：血栓/栓塞（且无侧支循环“代偿”时更严重）
2. **静脉外被压**：肿瘤压迫、绷带过紧等
3. **心衰**：右心衰→肝淤血；左心衰→肺淤血；严重可全身淤血

**肉眼：大紫凉**

* 体积增大（血多）
* 暗红/紫（还原血红蛋白多，提示缺氧）
* 发凉：血流淤滞、散热增加

**镜下**

* 细静脉、毛细血管扩张；管腔内红细胞多

**后果（比动脉性更“狠”）**

* 缺氧 → 实质细胞**萎缩、变性，甚至坏死**
* 间质纤维组织增生 → **淤血性硬化**
* 静脉压↑ + 代谢废物堆积 → 血管壁通透性↑
  → **水肿**，严重可出现**漏出性出血**

## 四、重点器官病变：肺淤血与肝淤血（老师明确“要掌握”）

### 1）慢性肺淤血（chronic pulmonary congestion）

**原因**：多见于**左心衰竭**
逻辑链：左室泵血差 → 左房压↑ → 肺静脉回流受阻 → 肺淤血

**大体**

* 肺体积增大、暗红
* 切开可见**泡沫样液体**（空气 + 水肿液）

**镜下**

* 肺泡隔增宽/肺泡壁增厚（毛细血管扩张充血）
* 肺泡腔内：淡粉色**蛋白水肿液**（血浆蛋白外渗）
* 重者：红细胞外渗（漏出性出血）
* **心衰细胞（重点名词）**
  = 肺泡腔巨噬细胞吞噬红细胞后，血红蛋白降解形成**含铁血黄素**，胞浆可见黄褐色颗粒

**临床关联**

* 气促、缺氧、呼吸困难，重者**端坐呼吸**
* 长期可致肺组织纤维化 → **肺褐色硬化**（肺“越来越硬、越来越废”）

---

### 2）慢性肝淤血（chronic congestion of liver）

**原因**：多见于**右心衰竭**（如肺心病等）
逻辑链：右心回流/泵血障碍 → 下腔静脉压力↑ → 肝静脉回流受阻 → 肝淤血

**大体（槟榔肝：重点）**

* 肝大、重量增加、包膜紧张
* 切面**红黄相间**，似槟榔横切面 → **槟榔肝（nutmeg liver）**

  * 红：淤血区
  * 黄：脂肪变性区（缺氧导致）

**镜下**

* 小叶中央静脉、肝窦扩张充血
* 扩张的肝窦压迫肝细胞索 → **萎缩、甚至坏死消失**
* 小叶周边缺氧 → **脂肪变性**

**临床**

* 肝大、肝区压痛、肝功能下降

**结局**

* 长期 → 间质纤维化 → **淤血性肝硬化**

## 五、第二节 出血（hemorrhage）——老师说“相对非重点，但要会分类”

**定义**：血液从血管/心腔内溢出

### 1）按机制

* **破裂性出血**：血管壁/心壁破裂
  例：外伤、动脉瘤破裂、心肌梗死后室壁破裂；结核/肿瘤侵蚀血管；溃疡侵蚀血管等
* **漏出性出血**：血管壁完整，但通透性↑
  常见：静脉压↑、血管壁损伤、血小板/凝血因子异常等

### 2）按部位/形式（临床别叫错）

* 内出血：心包积血、胸腔/腹腔积血；组织内积血=血肿（如硬膜下血肿）
* 外出血：与外界相通
* 命名：**咯血**（呼吸道） vs **呕血**（上消化道） vs **血尿**（泌尿） vs **血便**（下消化道）

### 3）结局

* 少量：可自行止血/吸收/机化
* 重要器官：脑出血、眼底出血、心包填塞等可致严重后果
* 大量：失血性休克/死亡

## 六、第三节 血栓形成（Thrombosis）——老师明确“重点”

### 1）概念

* **活体**心血管内，血液成分析出凝集成固体块的过程 = 血栓形成
* 形成的固体块 = **血栓**
* **死后**形成的是**血凝块**（不叫血栓）

### 2）“天平模型”：凝血系统 vs 抗凝/纤溶系统

* 凝血：破口时快速封堵止血
* 抗凝/纤溶：保证血液总体保持流动，防止乱栓

### 3）血栓形成三大条件（Virchow 三要素）

1. **心血管内膜（内皮）损伤**（最重要、最常见）
2. 血流状态改变：**血流缓慢、涡流**
3. 血液高凝状态：血小板/凝血因子↑或纤溶↓

   * 遗传：如**Factor V Leiden**等导致抗凝途径失效
   * 获得性：手术、创伤、妊娠/分娩、恶性肿瘤等

### 4）形成过程（按老师讲法）

* 血小板粘附裸露胶原 → 激活、脱颗粒（ADP、5-HT、TXA₂等）→ 聚集成“血小板堆”（早期可逆）
* 凝血级联启动 → 纤维蛋白网形成 → 固着不可逆
* 血栓结构形成：**头（白）—体（混合）—尾（红）**

### 5）血栓类型与形态（重点）

* **白色血栓**：多见**动脉/心瓣膜**；灰白、粗糙、与壁粘牢；主要是血小板+少量纤维蛋白
* **红色血栓**：多见**静脉**；常为延续性血栓的尾部；纤维蛋白网+大量红细胞
* **混合血栓**：灰红相间，层状/波纹状（白红交替）
* **透明血栓**：毛细血管内；多见 **DIC**；主要纤维蛋白

### 6）结局

* 溶解吸收
* **机化**（肉芽组织长入）± **再通**
* 钙化（静脉石）
* 脱落 → 栓子 → 栓塞 → 梗死
* DIC：早期广泛微血栓消耗凝血物质 → 后期反而**广泛出血**

### 7）血栓 vs 死后血凝块（老师用“血豆腐”比喻）

* 血栓：干燥、易碎；常与血管壁粘连；色泽混杂、有灰白条纹
* 死后血凝块：湿润、有弹性（像血豆腐 Q 弹）；不与血管壁粘连；颜色较均一

## 七、第四节 栓塞（Embolism）——老师也强调“概念+途径要记牢”

### 1）概念

* **随血流运行的异物**阻塞血管 = 栓塞
* 异物本身 = **栓子**（可为固/液/气）

### 2）栓子运行 5 条途径（重点）

1. **静脉系统/右心 → 肺动脉栓塞**
2. **动脉系统/左心 → 体循环动脉栓塞**
3. **门静脉系统 → 肝内门静脉分支栓塞**
4. **交叉（反常）栓塞**：先心病（房/室间隔缺损等）使栓子跨到另一侧循环
5. **逆行栓塞**：罕见；在特殊压力变化等情况下栓子“倒着走”

### 3）常见类型与影响

**① 肺动脉血栓栓塞（最常见）**

* 95% 以上栓子来自**下肢膝以上深静脉**
* 主干/大分支栓塞 → 可**猝死**

  * 机制：肺动脉阻力骤增 → **急性右心衰**
  * 反射：迷走神经反射可致肺动脉/冠脉/支气管痉挛 → 窒息 + 右心衰（死得很快）

**② 体循环动脉栓塞**

* 约 80% 栓子来自**左心**
  常见：感染性心内膜炎赘生物、二尖瓣病变左房血栓、心肌梗死附壁血栓等

**③ 脂肪栓塞（老师专门讲了）**

* 多见于**长骨骨折/脂肪组织严重挫伤**
* 直径 >20 μm 多堵在肺循环；更小者可入体循环造成多器官栓塞
* 少量可被清除；大量（老师提到“>75% 肺循环受阻”）→ 窒息 + 右心衰死亡
  （尸检可用苏丹染色证明脂滴）

**④ 气体/空气栓塞 + 减压病**

* 高压环境 → 气体溶解度高；快速减压 → 气体析出成气泡 → 栓塞
* 大量空气入静脉到右心：心脏搅拌形成泡沫样血液 → 阻碍回流与输出 → 循环崩溃

**⑤ 羊水栓塞**

* 分娩过程中羊水挤入子宫静脉窦 → 肺/体循环栓塞
* 可致过敏性休克、DIC，严重可母婴死亡
* 诊断证据：肺小血管内见羊水成分（胎毛、胎脂、胎粪、鳞状上皮等）

**⑥ 其他**

* 肿瘤细胞栓塞、细菌/菌团栓塞（可致败血性梗死、脓肿）、寄生虫/虫卵栓塞等

## 八、梗死（Infarction）——“堵死了 → 缺血坏死”

### 1）概念（老师的意思）

* 多因**动脉阻塞**且**侧支循环未及时建立** → 局部缺血缺氧 → **缺血性坏死（梗死）**
* 典型：冠心病 → 心肌梗死（支架/搭桥就是在“补侧支/通路”）

### 2）原因与条件

* 原因：血栓、栓塞、外压（绷带过紧）、血管痉挛
* 条件（决定“容不容易梗死”）：

  * 供血血管类型：**单一供血（终末动脉）**更易梗死；双重供血相对不易
  * 组织对缺血敏感性：

    * **神经元最差**：约 **8 分钟**可出现不可逆损伤（老师明确）
    * 其次心肌，再其次骨骼肌等

### 3）形态学特征

* 多见于有“门”的实质器官（脾、肾、肺等）：常呈**楔形/锥体形**
  **尖端指向器官门部**
* 心肌梗死：常呈**地图状不规则**（对应冠脉走行不规则）
* 肠梗死：常呈**节段性/截断性**（由肠系膜供血分区决定）
* 显微镜：多为凝固性坏死（脑组织例外偏液化性坏死）→ 后期肉芽组织替代、形成瘢痕

### 4）梗死类型

* **贫血性（白色）梗死**：多见心、肾、脾等“实质器官/侧支差”
* **出血性（红色）梗死**：多见肺、肠等（组织疏松、双重供血且常伴淤血时更易出血性）
* **败血性梗死**：栓子携带细菌 → 梗死区形成脓肿（更凶险）

## 九、本章老师“点名式考点”速记

* **大红热**：动脉性充血
* **大紫凉**：静脉性充血/淤血
* **心衰细胞**：慢性肺淤血时肺泡巨噬细胞吞红细胞 → 含铁血黄素
* **槟榔肝**：慢性肝淤血（右心衰）切面红黄相间
* **血栓形成三要素**：内皮损伤（最重要）+ 血流异常（慢/涡流）+ 高凝
* **白/红/混合/透明血栓**：部位+成分要对得上
* **栓塞五条途径**：右心/静脉→肺；左心/动脉→体循环；门静脉→肝；交叉（先心病）；逆行（罕见）
* 出血这一节老师说“相对非重点”，但**分类别叫错（咯血/呕血等）**
