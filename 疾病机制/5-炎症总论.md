# 病理学总论｜炎症（Inflammation）课堂笔记

## 0. 这一章为什么重要

* **几乎没有哪个组织器官不发生炎症**；临床常见病、多发病里，炎症占比极高（和肿瘤并列常见）。
* 疾病名里带“炎”的很直观：肝炎、肺炎、脑炎、胃炎、肠炎、胆囊炎……
* **名字不带“炎”，本质也可能是炎症**：

  * 烫伤/冻伤（高温、低温都能致炎）
  * 机械摩擦起水泡（运动/走路久）
  * 毛囊炎/疖肿/脓肿（皮肤、肺脓肿、肝脓肿）
  * 急性阑尾炎（典型腹痛体征）
* **临床表现差异很大**，原因是：**致炎因素不同 → 炎症性质不同**。

---

## 1. 什么是炎症（定义与核心点）

### 1.1 定义（老师强调版）

**炎症 = 具有血管系统的活体，对各种损伤因子所发生的一种防御性反应。**

老师反复强调三个关键词：

1. **活体**：死组织没有典型炎症反应（没有血流/渗出环节）。
2. **具有血管系统**：炎症反应以**血管反应和渗出**为中心；没血管就谈不上典型“渗出性炎症反应”。
3. **由损伤因子诱发**：任何能引起组织细胞损伤的因素，都可能致炎。

> 课堂口号：**哪里有损伤（在活体血管组织中），哪里就可能有炎症。**

### 1.2 炎症是好是坏？

* **本质上是“防御系统”**：没有炎症，动物/人类很难活下来。
* 日常说“吃消炎药”，老师指出很多时候其实是指**抗菌药**（去除病原体），并不是“把炎症这套防御系统消灭掉”。

---

## 2. 炎症的本质、结局与意义

### 2.1 炎症的本质（一句话背诵）

**炎症的本质 = 致炎因子对机体的损伤  vs  机体抗损伤反应 的矛盾斗争过程。**

结局取决于两股力量谁占上风。

### 2.2 炎症的结局（老师的三分法）

1. **抗损伤 > 损伤** → 逐步**痊愈**

   * **完全性痊愈**：结构/功能基本恢复
   * **不完全性痊愈**：留下瘢痕/后遗改变（老师举例：脸上留疤也算“痊愈了”）
2. **损伤 > 抗损伤** → **蔓延、扩散、加重**

   * 可出现：菌血症、毒血症、败血症、脓毒败血症等（全身播散）
3. **损伤 ≈ 抗损伤** → **迁延反复不愈** → **慢性炎症**（常见：慢性咽炎、慢性肠炎、慢性胆囊炎、慢性宫颈炎等）

### 2.3 炎症的意义：有利 + 不利

**有利：抗损伤 + 修复**

* **渗出**带来：抗体、补体、免疫球蛋白、白细胞等 → 局限病灶、杀灭病原体
* **增生**促进修复：同种细胞增生/肉芽组织增生 → 填补缺损、保护创面

**不利：过度反应也会致命/致残**

* **渗出过多**：

  * 喉头水肿（窒息风险）
  * 脑炎/脑水肿 → 颅内压升高、脑疝
  * 胸腔/腹腔积液 → 压迫肺组织（肺不张等）
* **机化/纤维化**：粘连、狭窄（如食管狭窄、器官粘连）
* **发热过高**：超过一定阈值可造成代谢紊乱、脑损伤风险（老师提到高热需要退热控制）

---

## 3. 致炎因子（炎症原因）

**引起组织细胞损伤并诱发炎症反应的因素 = 致炎因子**

常见类别：

* **生物性**（最常见）：细菌、病毒、真菌、立克次体、衣原体、支原体、螺旋体、寄生虫等
* **物理性**：高温（烫伤）、低温（冻伤/液氮）、放射线、紫外线、机械性损伤（切割/撞击/挤压）
* **化学性**：强酸强碱、毒物、体内某些分解产物等
* **免疫性**：Ⅰ～Ⅳ型超敏反应等
* **遗传/先天相关因素**：少见但存在

---

## 4. 炎症的基本病变（三大核心）

老师按“三条”讲：

### 4.1 变质（alteration）

* **组织细胞变性、坏死**统称变质
* 可发生在**实质细胞**（心、肝、肾等）和**间质细胞**
* **不是炎症特有**（肿瘤等也可见变性坏死）

### 4.2 渗出（exudation）——炎症的“特征性改变”

* **血管内液体和细胞成分 → 通过血管壁 → 到达血管外**
* 渗出液 + 白细胞渗出（炎症细胞浸润）是防御反应的关键环节

### 4.3 增生（proliferation）

* 与修复密切相关：同种细胞增生、肉芽组织增生、纤维化等

---

## 5. 血管反应与渗出：血流动力学改变（顺序要会）

炎症局部血流动力学改变的典型过程：

1. **小动脉短暂收缩（痉挛）**
2. **血管扩张、血流加速 → 充血（红、热）**
3. **血流速度减慢/淤滞（stasis）**

   * 血管腔变宽、血液黏稠度↑
   * 白细胞更容易靠边，为后面游出做准备

老师用“水泵/喷口”比喻血管口径与流速变化：扩张早期流量变化和阻力变化会带来加速，但进一步扩张+渗出后血液浓缩、流速会逐渐变慢，进入淤滞阶段。

---

## 6. 血管通透性升高的机制（高频考点）

老师按“几种主要机制”讲（掌握核心逻辑即可）：

1. **小静脉内皮细胞收缩**（常由组胺、缓激肽、白三烯等介质触发）
   → 细胞间隙增宽（像“瓷砖之间裂缝变大”）
2. **内皮细胞骨架重排**（如 IL-1、TNF 等细胞因子相关）
   → 细胞形态改变、通透性↑
3. **穿胞作用（transcytosis）**
   → 内皮细胞胞浆内囊泡连接形成“穿胞通道”
4. **内皮细胞直接损伤**（烧伤、高强度损伤、化脓性感染等）
   → 通透性显著升高且可持续较久
5. **白细胞介导的内皮损伤**
   → 白细胞活化释放 ROS、蛋白酶等，“救火队也可能砸坏门窗”
6. **新生毛细血管高通透性**（肉芽组织）
   → 新生血管分化不成熟、连接不牢 → 易渗出（新鲜创面常“湿润肿胀”）

---

## 7. 渗出液的意义 + 渗出液 vs 漏出液（表格题必考）

### 7.1 渗出液（exudate）的意义

**有利：**

* 稀释毒素/有害物质
* 带来抗体、补体、白细胞等 → 抗感染、防御

**不利：**

* 渗出过多 → 炎性水肿/积液压迫（喉头/脑/胸腹腔等）
* 渗出物吸收困难 → 肉芽组织长入 → **机化** → 瘢痕/粘连/狭窄

### 7.2 渗出液 vs 漏出液（老师给的关键鉴别点）

* **原因**

  * 渗出液：炎症（通透性↑）
  * 漏出液：非炎症，多与**静水压↑**或**低蛋白血症（胶体渗透压↓）**有关
* **蛋白**

  * 渗出液：**>30 g/L**
  * 漏出液：**<30 g/L**
* **比重**

  * 渗出液：**>1.018**
  * 漏出液：**<1.018**
* **有核细胞数**

  * 渗出液：多（白细胞为主）
  * 漏出液：少
* **Rivalta（李凡他）试验**

  * 渗出液：阳性
  * 漏出液：阴性
* **是否自凝、外观**

  * 渗出液：可自凝、混浊（蛋白/细胞多）
  * 漏出液：不自凝、澄清（以水为主）

老师用“卤水点豆腐”比喻：**要能“点成块”，前提得有蛋白**；没蛋白的清水点不出豆腐 → 对应漏出液不自凝。

---

## 8. 白细胞渗出（游出）与趋化：步骤链条要背

### 8.1 白细胞渗出的全过程

1. **边集/靠边（margination）**：血流变慢、轴流变宽 → 白细胞从中间挪到边缘
2. **滚动（rolling）**
3. **粘附（adhesion，复壁）**：牢固粘住内皮细胞（“定居联姻”）
4. **穿越内皮（diapedesis）**：伸出尾足穿过内皮间隙
5. **穿过基底膜**：分泌胶原酶等降解基底膜
6. **趋化（chemotaxis）**：沿化学因子浓度梯度定向移动到病灶

### 8.2 趋化（chemotaxis）的理解（老师的“闻味儿”比喻）

* 病灶处可溶性化学物质形成**浓度梯度**（近高远低）
* 白细胞沿梯度移动（像狗闻着炖肉味走过去）
* 趋化因子：

  * **内源性**：补体成分、白三烯、趋化性细胞因子等
  * **外源性**：**可溶性**细菌产物（强调“可溶”才有梯度）

## 9. 吞噬作用：步骤 + 杀菌系统（重点）

### 9.1 吞噬作用定义

炎症灶聚集的白细胞**吞入并杀伤/降解**病原体与组织碎片的过程。

### 9.2 吞噬步骤（四段式）

1. **识别与粘附**
2. **吞入**形成吞噬体
3. 与溶酶体融合 → **吞噬溶酶体**
4. **杀伤与降解**

### 9.3 调理素化（opsonization，老师叫“接头暗号”）

* 病原体表面被补体/抗体“标记”（如 **C3b、IgG 的 Fc 片段**）
* 吞噬细胞表面有相应受体 → 更容易识别、粘附、吞入

### 9.4 杀菌机制（老师强调“最强杀菌系统”）

* 吞噬时耗氧量激增（呼吸爆发）
* 产生 **超氧阴离子 O₂•⁻ → 过氧化氢 H₂O₂**
* 在**髓过氧化物酶（MPO）+ 卤素离子（如 Cl⁻）**存在下生成 **次氯酸 HOCl**

  * HOCl 是强氧化剂（自来水消毒的核心之一）
  * 该系统杀菌力远强于单独 H₂O₂
* 作用方式：破坏细菌细胞膜、使关键酶失活、干扰 DNA 复制等

## 10. 炎症细胞：形态与“出场顺序”感觉

### 10.1 中性粒细胞（急性炎症先锋）

* 外周血比例高（约 50%～70%）
* 直径约 10～12 μm
* 核：杆状或 2～5 分叶
* 胞浆中性颗粒（HE 下粉染）→ 含多种杀菌/水解酶

### 10.2 单核细胞 → 巨噬细胞（“大将”）

* 单核细胞进组织后体积增大、活性增强 → 巨噬细胞
* 直径约 12～24 μm
* 核：肾形/不规则扭曲折叠
* 溶酶体、线粒体、吞饮小泡丰富 → 吞噬/降解更强
* 还能**处理抗原并递呈**，激活 T/B 淋巴细胞（连接固有免疫与适应性免疫）

### 10.3 嗜酸性粒细胞

* 多见于寄生虫感染、过敏相关炎症
* 胞浆粗大红染颗粒，核常双叶

### 10.4 淋巴细胞与浆细胞（免疫反应）

* B 细胞受刺激 → 浆细胞：胞浆丰富、核偏位、染色质呈“车轮状”

### 10.5 “友军误伤”提醒

白细胞在吞噬/激活过程中释放：溶酶体酶、ROS、白三烯、前列腺素、免疫复合物等
→ 既能杀敌，也可能**损伤内皮和周围组织**。

## 11. 炎症介质（Inflammatory mediators）

### 11.1 概念

**致炎因子引起局部细胞或体液产生/释放的、参与炎症反应的化学活性物质。**

### 11.2 来源与激活方式

* **细胞来源**：可储存在颗粒内，刺激后释放；或刺激后新合成再释放
* **血浆来源**：常以**无活性的“前体（precursor）”形式**存在

  * 必须经**蛋白水解裂解**，暴露活性位点后才被激活（老师用“封印解除”比喻）

### 11.3 一般特点（老师为什么强调“半衰期短”）

* 多数通过与靶细胞受体结合发挥效应；少数本身就是酶
* 可诱导产生“第二级介质”（级联放大/相互调控）
* 多效性：一个介质可作用多种靶细胞、产生多种效应
* **半衰期短是优势**：介质往往有潜在组织损伤性，“招之即来、挥之即去”才能避免反应失控

## 12. 上节课补账：梗死与“败血性梗死”联系到炎症

* 梗死分类：贫血性梗死、出血性梗死、**败血性梗死（septic infarct）**
* 败血性梗死要点：脓毒败血症时细菌团栓塞 → 组织缺血坏死 + 局部细菌繁殖 → 易形成脓肿，形态更不规则、可扩散
* 梗死对机体影响取决于：**器官/部位重要性 + 梗死范围**

  * 心肌/脑干等关键部位，小范围也致命
  * 心梗范围大（老师提到心肌受累比例越大越危险）→ 泵衰/休克/致命并发症
* 梗死结局（老师用“俘虏/监狱/封死”比喻）

  * 小：溶解吸收
  * 大且能与外界相通：分离排出
  * 不能排出：机化（肉芽组织长入纤维化/瘢痕），或包裹、钙化

# 本节课“考试向”高频抓手（按老师强调整理）

* 炎症定义：**活体 + 血管系统 + 防御反应**
* 炎症三大基本病变：**变质、渗出、增生**（渗出是特征性）
* 血流动力学改变顺序：短暂收缩 → 扩张充血 → 流速减慢/淤滞 → 白细胞靠边
* 通透性升高机制：内皮收缩/骨架重排/穿胞/直接损伤/白细胞介导损伤/新生血管高通透
* 渗出液 vs 漏出液：**蛋白 30 g/L、比重 1.018、有核细胞数、Rivalta、自凝、外观**
* 白细胞游出步骤：**边集-滚动-粘附-穿越-趋化**
* 吞噬四步：识别粘附-吞入-吞噬溶酶体-杀伤降解
* 最强杀菌系统：**H₂O₂ + MPO + Cl⁻ → HOCl（次氯酸）**
