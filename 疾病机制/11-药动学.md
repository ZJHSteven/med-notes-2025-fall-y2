## 二、回顾：药效学（PD）与引入：药动学（PK）

### 1）上一节：药效学（Pharmacodynamics, PD）

* 药物对机体的作用、作用机制
* 不仅有治疗效应，也包括不良反应（ADR）

### 2）本节：药动学（Pharmacokinetics, PK）

* 定义：**机体对药物的影响**（药进入人体后，人体如何“处理”药）
* PD/PK：药理研究里常写 **PD-PK**（或 PK/PD）

### 3）药动学为什么有用（老师用腹泻病例串起来）

* 病人：腹泻→脱水、电解质紊乱、酸碱失衡
* 治疗链条：

  1. 补液（补盐/补糖的选择会影响病人状态）
  2. 纠正酸碱与电解质
  3. 抗感染（对因治疗）
  4. 止泻（对症治疗）
* 典型“药动学相互作用”例子：

  * **蒙脱石散（思密达）+ 抗生素**
  * 老师强调：一般应**分开服用**；合用时思密达可能有效，但抗生素可能被“吸附”而效果变差（体现药动学层面的相互作用）。

## 三、药物体内过程 ADME（框架）

老师按教材把药动学分两块：

1. **药物体内过程（ADME）**
2. 用定量模型描述这些过程 → 参数（半衰期等）

### ADME 对应

* **A** absorption：吸收
* **D** distribution：分布
* **M** metabolism：代谢/生物转化
* **E** excretion：排泄

> 注：老师口误把 E 说成 expression，标准是 **excretion**。

## 四、跨膜转运（贯穿吸收/分布/排泄的“共同底层”）

老师强调：常见考法看似问“影响吸收/分布/排泄因素”，本质都在问：

> **影响药物跨膜转运的因素是什么？**

### 1）被动转运（Passive transport）

核心：**顺浓度梯度**（downhill transport）

* 不耗能
* 不需要载体
* 一般**无饱和现象**
* 两种形式：

  1. **滤过（filtration）**：多见于水溶性物质，经水性通道；多数组织孔隙小，不是主要途径；肾小球孔大是例外
  2. **简单扩散（simple diffusion）**：脂溶性高者为主（老师也称“脂溶扩散”）

     * 所以影响口服吸收的重要因素之一：**脂溶性**（越高越易吸收）

### 2）载体介导转运（Carrier-mediated transport）

老师区分：载体 ≠ 受体（受体结合后触发效应；载体负责运输）
共同特征：

* **选择性**
* **饱和性**（位点有限）
* **竞争性**（两个底物抢同一载体 → 速度都下降）
* **特异性**：结构特异性、部位特异性

两种典型形式：

1. **主动转运（active transport）**：逆浓度梯度 → **耗能**
2. **易化扩散（facilitated diffusion）**：顺梯度 → **不耗能但需载体**

### 3）膜动转运（Vesicular / Membrane transport）

* **胞吞/内吞（endocytosis）**：入胞、包饮
* **胞吐/外排（exocytosis）**：囊泡与膜融合释放内容物
  老师提到与药物相关的现实意义：
* 大分子药物难以靠前两类转运进入细胞 → 可借助**包裹/偶联（如抗原/靶向分子）**，通过内吞实现“靶向治疗”的设计思路
* 也提到肿瘤细胞产生外排转运蛋白把化疗药“泵出细胞”→ 耐药机制之一（P-gp 类思路）

## 五、影响跨膜转运/吸收的关键因素（老师列点）

### 1）药物解离度（离子型 vs 非离子型）

* 药在体内常以两种形式存在：

  * **离子型/解离型（带电）**：一般**不易跨膜**
  * **非离子型/非解离型（不带电）**：更易跨膜
* 用 **pKa** 描述药物解离特性（pKa 是 Ka 的负对数，药物自身常数）
* 通过改变环境 **pH** 来改变“离子/非离子比例”：

  * 老师的考试导向：常考“弱酸/弱碱药在不同 pH 下解离度变化 → 影响跨膜/排泄/毒性”
* 中毒处理思路（老师反复提）：

  * **调 pH → 改解离度 → 影响跨膜与排泄**
  * 例：酸性药物中毒，碱化尿液（如碳酸氢钠）→ 解离度↑ → 重吸收↓ → 排泄↑

### 2）浓度差（膜两侧浓度梯度）

* 梯度越大，扩散驱动力越强，转运越快。

### 3）膜通透性、表面积、厚度

* 老师用肺泡举例：表面积大、屏障薄、血运丰富 → 吸入给药可很快起效。

### 4）转运蛋白数量/功能

* 载体多 → 转运快；肿瘤外排泵表达↑ → 化疗药效下降（耐药）

## 六、吸收（Absorption）

### 1）定义（老师强调考点）

* 吸收：**药物从给药部位进入血液循环的过程**
* 重要提醒：**血管内给药（如静脉注射）没有“吸收”过程**

### 2）为什么要学吸收

* 不同给药途径 → 吸收速度/程度不同

  * 速度影响：**起效快慢**
  * 程度影响：**效应强弱**

### 3）口服吸收（老师说：重点）

影响口服吸收因素（按老师顺序整理）：

1. **食物/内容物影响**（饭前/饭后；有的药因刺激性要求饭后）
2. **胃肠蠕动与排空**（排空慢→吸收时间更长，可能吸收更多；腹泻时连水都难吸收，药也难吸收）
3. **胃肠道 pH 改变**（如消化性溃疡抑酸治疗 → 胃 pH 改变 → 原本吸收好的药可能受影响）
4. **药物颗粒大小与溶出速率（dissolution rate）**

   * 片剂需先崩解成小颗粒再溶解成溶液才易吸收
   * 不同厂家同剂量药，溶出不同 → 吸收可差很多
5. **理化相互作用**（例如四环素与金属离子结合；吃药配牛奶等可能不合适）
6. **胃酸/胃蛋白酶破坏**（不耐酸药 → 不适合普通片剂；可用肠溶、胶囊等制剂思路）
7. **肠道菌群差异**（长期/滥用抗生素者菌群不同；部分药物代谢与菌群相关）

### 4）首过消除 / 首过效应（First-pass effect）

* 定义（老师讲的版本）：口服药吸收后进入全身循环前，可能被

  * 胃酸/酶破坏
  * 肝门静脉入肝后被肝代谢
    → 导致进入体循环的有效药量减少
* 意义：首过明显 → 药物**不适合口服**或需改给药途径
* 老师举例：

  * **硝酸甘油**：舌下含服（避免首过）
  * **胰岛素**：多肽类易被胃酸破坏 → 不能口服

### 5）常见给药途径与曲线特点（老师画曲线那段）

* **静脉注射（IV）**：血药浓度最高出现在给药当下 → 起效最快但风险高（可能瞬间超过中毒浓度）
* **肌内注射（IM）**：吸收较快（血运较丰富）
* **皮下注射（SC）**：吸收较慢（血运少）→ 可做长效方案（老师提到“周制剂减肥药”等思路）
* **口服（PO）**：吸收更慢，持续时间可更长
* 临床思路：有时先静脉快速控制症状 + 同时口服维持更久

### 6）吸入给药（Inhalation）

* 关键影响因素：**颗粒大小**

  * <2 μm：更易到肺泡并进入全身（全身治疗）
  * 3–10 μm：主要到支气管
  * > 10 μm：多停留口咽/鼻咽
    > （老师还类比了 PM2.5、PM10）

### 7）直肠给药（Rectal administration）

* 适用：昏迷、惊厥、不配合等不能安全口服者（老师也提到小儿）
* 优势：直肠**中下段**血流回流可部分绕开门静脉 → **减少首过效应**
* 对比：直肠上段仍可能经门静脉 → 仍有首过

### 8）舌下给药（Sublingual）

* 舌下静脉粗、回流快、**绕过首过**
* 特别适用于需要快速起效的心血管急症（老师强调缺血性心脏病）

## 七、分布（Distribution）

### 1）定义

* 药物由血液循环到达各组织器官的过程
* 不同组织浓度不一样（不是“全身同浓度”）；平衡是“成比例平衡”。

### 2）影响分布的因素（老师顺序）

1. **血流量**

   * 多：心、肺、肝、（脑受血脑屏障限制）
   * 少：骨、前列腺、皮肤、脂肪等 → 浓度低
2. **血浆蛋白结合（高频考点）**

   * 两种形式：游离型（free drug） vs 结合型
   * 结合型一般不能跨膜；**真正发挥药效/产生毒性的主要是游离型浓度**
   * 动态平衡：游离↓时结合型可释放补上
   * 竞争性置换（药物相互作用）：

     * 老师举例：**华法林（结合率~99%）+ 保泰松**

       * 被置换后游离比例 1% → 4%
       * 这不是“+3%”，而是**游离浓度变成 4 倍（400%）** → 出血风险大增
   * 特殊人群/状态：

     * 低蛋白血症（如肾病综合征）→ 游离比例↑ → 毒性风险↑
     * 新生儿蛋白水平低 → 按成人剂量折算仍可能风险（游离比例偏高）
3. **组织特异性结合**

   * 碘聚集甲状腺（可用于功能检测思路）
   * 四环素与骨/牙结合 → 四环素牙、影响骨生长（老师也提“反过来可利用这个特性做骨科靶向偶联”）
4. **体液 pH**

   * 弱酸药在酸性环境：解离度↓ → 更易跨膜分布
   * 弱酸药在碱性环境：解离度↑ → 不易跨膜
5. **特殊屏障**

   * **血脑屏障（BBB）**：脂溶性低/分子大 → 难进中枢；必要时可改给药途径（如鞘内注射）绕开
   * **胎盘屏障**：老师强调“几乎没什么屏障意义”→ 药物可能入胎儿；致畸风险（尤其妊娠前3个月器官分化期尽量避免用药；明确致畸证据者禁用）
   * **血眼屏障**：眼部药浓度低 → 眼科常用局部滴眼或球后/局部注射提高浓度

## 八、代谢（Metabolism / Biotransformation）

### 1）定义

* 药物在酶作用下发生**化学结构变化**
* 有些药可原形排出（无代谢），对肝功能不全者可能更安全（老师观点：不代谢不一定是坏事）

### 2）代谢的意义（老师举例）

1. 多数代谢后：**灭活（inactivation）** → 作用减弱/消失
2. **前药（prodrug）**：体内代谢后变活性物质才起效

   * 肝功能不全 → 不能生成活性代谢物 → 药可能无效
   * 老师举例：可的松需转化为氢化可的松才起效（肝功能不全者慎/禁用思路）
3. **毒性代谢产物**

   * 对乙酰氨基酚（扑热息痛）可产生肝毒性代谢产物；剂量/频次过大 → 肝坏死风险↑（老师提每天次数不超过4次的理由）

### 3）I 相 / II 相代谢

* **I 相**：氧化/还原/水解 → 极性↑、水溶性↑，利于排泄
* **II 相**：结合反应（与体内某些物质结合）→ 水溶性进一步↑
* 特例：磺胺类乙酰化代谢后水溶性反而↓ → 尿中易结晶 → 泌尿系统毒性（老师强调点）

### 4）CYP450（细胞色素 P450）系统（重点酶系）

* 多种同工酶；老师强调：

  * **CYP3A4 代谢约“接近一半药物”**（说明底物广）
  * 不同酶代谢底物不同（如华法林与 CYP2C9 相关；酶缺陷者风险高）
* **酶诱导剂 / 酶抑制剂** → 药物相互作用来源

  * 老师例：利福平（Rifampin）是诱导剂 → 使某些药血药浓度下降、疗效减弱
  * 食物/草本例子：

    * 银杏/白果：可能诱导某些 CYP（老师举例提到与奥美拉唑疗效变化有关的思路）
    * 葡萄柚：抑制代谢 → 血药浓度↑ → 毒性风险↑
  * 双硫仑样反应：头孢类或甲硝唑可抑制乙醛脱氢酶 → 饮酒后乙醛堆积 → 醉酒样反应（老师提醒跨年喝酒风险）

### 5）影响代谢的因素（老师列的“像主观题”）

1. 遗传多态性（快/慢代谢型）

   * 老师例：异烟肼（Isoniazid）快代谢/慢代谢与不良反应谱差异（肝毒性 vs 神经毒性倾向）
2. 酶诱导/抑制（药物、食物、草本）
3. 肝血流量变化（血流↑代谢可能↑；血流↓代谢↓）
4. 环境因素、昼夜节律等

## 九、排泄（Excretion）

### 1）定义

* 药物以原形或代谢产物从体内排出体外
* 未被吸收的口服药谈不上“体内排泄”（老师强调概念边界）

### 2）主要排泄途径

* **肾（泌尿）**、**胆汁-消化道**
* 其他：呼吸（酒精检测）、唾液等（检测手段足够敏感时可替代频繁抽血）

### 3）肾排泄三环节（对应尿生成）

1. 肾小球滤过
2. 肾小管主动分泌
3. 肾小管重吸收

任一环节变化都会影响药物排泄：

* 利尿/滤过改变：茶/茶碱利尿 → 排泄可能加快（老师举例：吃药别同时喝茶的逻辑之一）
* 主动分泌竞争：

  * 利尿剂（如呋塞米、噻嗪类）与尿酸共享有机酸转运通道 → 尿酸排泄↓ → 高尿酸血症/痛风风险↑（老师举“啤酒+海鲜+利尿剂”诱发痛风）
* pH 与重吸收：调尿 pH 改解离度 → 改重吸收 → 改排泄（与中毒解救强相关）

### 4）胆汁排泄与肝肠循环（Enterohepatic circulation）

* 胆汁排到十二指肠后，部分药又被重吸收回体内 → 排泄变慢、作用时间延长
* 若治疗肝胆系统感染，可能反而有利（老师提到头孢曲松/头孢哌酮等在肝胆系统的应用思路）

## 十、定量化：房室模型、消除动力学、常用参数

### 1）药代实验流程（老师描述）

* 招募健康志愿者 → 留置针 → 给药
* 按时间点采血（分钟级到小时级，甚至 24h/数天）→ 测血药浓度 → 得到浓度-时间曲线
* 根据曲线选模型（房室模型）→ 计算 PK 参数 → 评价药物

### 2）房室模型（了解即可）

* 1 室模型：假设体内迅速均匀分布（理想化）
* 2 室模型：

  * 中央室：血流丰富组织
  * 周边室：血流少组织
  * 曲线常出现：**分布相（快）+ 消除相（慢）**

### 3）一级 vs 零级消除动力学（期末重点记忆）

**一级消除（first-order kinetics）**

* 单位时间消除“恒定比例”（恒比消除）
* 半衰期 **恒定**
* lnC-时间（或 logC-时间）关系呈直线 → 也称“线性动力学”
* 多数安全药、OTC 常见

**零级消除（zero-order kinetics）**

* 单位时间消除“恒定数量”（你给再多也只能按固定量清除）
* 半衰期 **不恒定**，剂量越大越容易蓄积
* 中毒风险更高，需要监测血药浓度、调方案

**混合消除**

* 小剂量：一级；大剂量：零级
* 老师例：阿司匹林（小剂量抗血小板相对安全；大剂量解热镇痛/抗风湿更易不良反应）

### 4）曲线读参数（老师讲到的几个）

* **Cmax**：峰浓度（达峰浓度）→ 吸收程度/暴露强度相关
* **Tmax**：达峰时间 → 吸收速度相关
* **AUC**（area under the curve，曲线下面积）→ 体内总暴露量/相对进入体循环的“总量”相关

### 5）生物利用度（Bioavailability）（录音此处中断，我补一个标准定义方便你对照）

老师讲到：血管外给药时，进入体循环的**相对量与速度**。
**补充（标准教材表述，用于你做题/背名解）：**

* **绝对生物利用度 F**（absolute bioavailability）：

  * 与静脉给药相比：
  * ( F = \dfrac{AUC_{extravascular}}{AUC_{IV}} \times \dfrac{Dose_{IV}}{Dose_{extravascular}} )
* **相对生物利用度**：同一给药途径下，不同制剂/厂家之间用 AUC 等比较。

* 选择题（尤其 A1/B1）：

  1. 跨膜转运三大类的特点：是否耗能、是否载体、是否饱和/竞争
  2. 影响口服吸收因素（尤其首过效应、溶出速率、食物/金属离子、pH 改变）
  3. 血浆蛋白结合：游离型才有效/致毒；竞争性置换的风险计算思路（“1%→4%是4倍”）
  4. 酶诱导/抑制导致的相互作用（利福平、葡萄柚等例子）
  5. 一级/零级消除动力学的差异（半衰期是否恒定、是否易蓄积）

## 十二、药动学英文术语表（纠错版，便于做题）

* Pharmacokinetics（PK）：药代动力学/药动学
* Pharmacodynamics（PD）：药效学
* ADME：Absorption / Distribution / Metabolism / Excretion
* Passive transport：被动转运
* Downhill transport：顺浓度梯度转运
* Filtration：滤过
* Simple diffusion：简单扩散
* Carrier-mediated transport：载体介导转运
* Active transport：主动转运（耗能、逆梯度）
* Facilitated diffusion：易化扩散（不耗能、顺梯度、需载体）
* Vesicular transport：膜动转运
* Endocytosis / Exocytosis：胞吞（内吞）/ 胞吐（外排）
* Ionized / Unionized：离子型（解离型）/ 非离子型（非解离型）
* pKa：酸解离常数的负对数（反映解离倾向）
* First-pass effect：首过效应/首过消除
* IV / IM / SC / PO：静脉 / 肌内 / 皮下 / 口服
* Rectal administration：直肠给药
* Sublingual administration：舌下给药
* Blood-brain barrier（BBB）：血脑屏障
* Plasma protein binding：血浆蛋白结合
* Free drug：游离型药物
* CYP450 (Cytochrome P450)：细胞色素P450 酶系
* Enzyme inducer / inhibitor：酶诱导剂 / 酶抑制剂
* Enterohepatic circulation：肝肠循环
* First-order / Zero-order kinetics：一级/零级消除动力学
* Half-life（t1/2）：半衰期
* Cmax / Tmax / AUC：峰浓度 / 达峰时间 / 曲线下面积
* Bioavailability：生物利用度
