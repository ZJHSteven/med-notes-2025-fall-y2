# 三、生理基础回顾（老师强调：这部分是理解病生的“地基”）

## 1）体液（Body fluid）与分布

* 体液 = **水 + 溶质**（溶质包含电解质、蛋白等）
* 体液分区：

  * **细胞内液（ICF）**：约占体液 **2/3**
  * **细胞外液（ECF）**：约占体液 **1/3**

    * 对血细胞：ECF 在血管内叫 **血浆**
    * 对组织细胞：ECF 在组织间隙叫 **组织液**
  * **跨/穿细胞液（Transcellular fluid）**：位于特殊腔隙（脑室/腹腔/胸腔/关节腔/肠腔等），量不大但临床很关注（如关节液润滑）。
  * 课堂问答补充：有的教材把跨细胞液归入细胞外液，但无论怎样**它不属于细胞内液**。

## 2）“内环境”这句经典话怎么理解

* **细胞外液是细胞赖以生存的内环境**：听着矛盾但不矛盾——对“细胞”而言，它的“体内环境”就在细胞外液里。
* 因此 ECF 的**容量与浓度**轻微改变都会影响细胞功能。

## 3）隔膜通透性差异：细胞膜 vs 毛细血管壁

* **细胞膜**：主要允许**水自由通过**；电解质跨膜需要通道/泵（如 Na⁺/K⁺-ATPase）。

  * ECF 主要阳离子：**Na⁺**
  * ICF 主要阳离子：**K⁺**
* **毛细血管壁**：孔隙更大，允许**水 + 小分子电解质自由通过**；但**蛋白质（尤其白蛋白）不易自由通过**
  → 结果：血浆蛋白含量明显高于组织液，这是形成胶体渗透压差的关键。

## 4）体液占体重比例与人群差异

* 成年人体液约占体重 **60%**（例：100 kg 体重 → 体液约 60 kg）。
* 年龄：婴幼儿含水比例更高，随年龄增长下降。
* 体成分：肌肉含水多、脂肪含水少
  → **肥胖者耐受缺水更差**
  → 一般同等条件下男性肌肉比例更高，**男性含水量往往高于女性**，耐受缺水相对更强。

# 四、渗透压与“为什么老测血钠”

## 1）渗透压组成

* 总渗透压 = **晶体渗透压（电解质等小分子）** + **胶体渗透压（蛋白）**
* 总渗透压主要由**晶体渗透压**决定，所以电解质变化（尤其 ECF 的 Na⁺）对渗透压影响很大。

## 2）三处渗透压“正常应相同”

* **细胞内液、组织液、血浆**：正常情况下渗透压应大体一致（老师给范围：**约 280–310**）。
* 临床上最好测谁？

  * 组织液/细胞内液难取
  * **血浆易取（抽血离心）**
    → 因此用**血浆渗透压/血钠**来间接代表体液渗透状态最现实。

## 3）细胞放在不同渗环境会发生什么（用来理解“高渗/低渗为什么重要”）

* **等渗（0.9% NaCl）**：细胞形态功能基本不变
* **低渗**：水入细胞 → **细胞肿胀甚至破裂**
* **高渗**：水出细胞 → **细胞皱缩/脱水**

# 五、水的出入与调节机制（病生推理的“发动机”）

## 1）水摄入（入量）

* 饮水：约 **1000–1300 mL/天**（生理需要）
* 食物含水：一部分来源
* **代谢水（内生水）**：三大营养物质氧化生成水，约 **300 mL/天**（不含电解质）

## 2）水排出（出量）

* 尿：约 **1000–1500 mL/天**（个体可调）
* 粪便：少量
* 不显性失水（易被忽略）：

  * 皮肤蒸发约 **500 mL/天**
  * 呼吸道蒸发约 **400 mL/天**
  * 合计约 **900 mL/天**
  * 这部分多为**低渗水**（主要丢水，丢钠少）

## 3）调节系统（核心四件套）

* **口渴中枢**

  * 兴奋因素：①**血容量下降** ②**细胞外液渗透压增高（高渗）**
  * 例：吃咸 → Na⁺先进血浆（ECF）→ 渗透压升高 → 口渴 → 喝淡水 → 稀释回归正常
* **抗利尿激素（ADH）**

  * 刺激因素同口渴：①血容量下降 ②ECF 高渗
  * 作用：促肾小管重吸收水 → 尿少 → 保水
* **醛固酮（RAAS 末端）**

  * 刺激因素：①血容量下降 ②（与 ADH 不同）**ECF 低渗/低钠倾向**会促其分泌（老师强调：它是“保钠排钾”）
  * 作用：保钠→带保水 → 钠水潴留
* **心房钠尿肽（ANP）**

  * 作用：**利钠利水**（拮抗 RAAS、拮抗 ADH/醛固酮效应）
  * 典型：心衰时心房牵张↑ → ANP↑ → 利钠利水 → 在一定程度减轻心脏负荷（保护性）

# 六、脱水：按渗透性质分型（高渗 / 低渗 / 等渗）

## 0）脱水总定义

* **脱水 = 体液容量减少**（不是“只丢水”，而是体液中水/钠等一起丢，只是比例不同）
* 脱水首先丢的是：**细胞外液（±跨细胞液）**
  → 只有在组织/细胞大面积损伤时才会“直接丢细胞内液”。

---

## A. 高渗性脱水（Hypertonic dehydration）

### 1）特点与诊断要点（老师给的“金标准思路”）

* **失水 > 失钠** → ECF 被浓缩 → **血钠升高、血浆渗透压升高**
* 老师给指标：

  * 血钠 **>150 mmol/L**
  * 血浆渗透压 **>310**
* 机制关键词：**细胞内向细胞外移水**，并且“**以细胞内脱水更明显**”
* 又称：**低血容量性高钠血症**

### 2）常见原因（按路径）

* 摄入不足：缺水环境、不能自主饮水（昏迷等）+ 生理不显性失水持续存在
* 丢失增多：

  * 肾：尿崩、浓缩功能障碍、渗透性利尿等 → 排出低渗尿（丢水多）
  * 消化道：腹泻早期多为等渗性丢失，但时间久 + 发热/呼吸加快 → 不显性失水↑ → 可转为高渗性脱水
  * 皮肤/呼吸：发热、环境干燥/风大 → 蒸发↑（低渗水丢失）

### 3）体液转移与“谁最吃亏”

* 初始丢 ECF，但 ECF 高渗后 **从 ICF 抢水** → ICF 下降明显（细胞内最吃亏）
* 血浆因浓缩吸水能力增强，还会 **从组织液再“抢水”** → 组织液也降，但血浆相对“占便宜”
* 结果：早期休克症状可能不典型（但晚期一定会休克，或丢失太猛一开始就休克）

### 4）临床表现与危险点

* **口渴明显**：两个刺激因素（血容量下降 + ECF 高渗）同时存在
* **尿少**：ADH 早期就上；醛固酮早期不一定明显，晚期因血容量下降可升高（尿钠随之下降）
* **最致命：脑细胞脱水**

  * 脑组织萎缩牵拉静脉 → 可能破裂出血 → 昏迷/危及生命
* **脱水热（婴幼儿）**：高渗影响汗腺分泌 + 婴幼儿体温调节差 → 无感染也可发热（成人不典型）

---

## B. 低渗性脱水（Hypotonic dehydration）

### 1）特点

* **失钠 > 失水** → ECF 低渗 → 水向细胞内移 → **细胞外液量减少更明显**
* 老师给指标：

  * 血钠 **<130 mmol/L**
  * 血浆渗透压 **<280**
* 又称：**低血容量性低钠血症**

### 2）常见原因（老师强调：最常见是“治疗不当”）

* **只补水、不补钠**：如大量输 **5%–10% 葡萄糖**（很快代谢成“无钠的水”）而不补生理盐水 → ECF 被稀释成低渗
* 肾性失钠：

  * 排钠利尿药长期使用
  * 肾小管重吸收钠障碍
  * 醛固酮下降（保钠能力差）
  * 肾小管酸中毒：钠-氢交换受影响 → 失钠↑

### 3）体液转移与“谁最吃亏”

* 脱水先丢 ECF，但因 ECF 低渗 → **水进入细胞** → ECF 进一步下降
  → **组织液下降最明显**（皮肤黏膜“塌”、弹性差、婴幼儿囟门凹陷等）
* 细胞内“看似占便宜”其实危险：**细胞水肿**，最致命是 **脑水肿/颅高压/昏迷**。

### 4）临床表现要点（注意“书上写不明显”的参照对象）

* **休克更早、更明显**：因为 ECF 下降更厉害 + 水入细胞进一步抽空 ECF + ADH 刺激因素少一个（缺少“高渗刺激”）
* **口渴**：相对高渗性脱水“不那么明显”（这是和高渗比，不是和正常人比；严重时也会口渴）
* **尿量**：早期尿少不如高渗明显；但因低渗对醛固酮是刺激 → **尿钠从一开始就更倾向下降**

---

## C. 等渗性脱水（Isotonic dehydration）

* **水和钠等比例丢失**
* 血钠、渗透压可在正常范围
* 细胞内外水分转移不明显（细胞泡在等渗环境形态不变）
* 临床最常见；但紧急情况下若血钠结果未出，需要结合病史体征先做初步判断（老师提醒：补液策略随类型不同而不同）

# 七、水肿：两大机制 + 钠水潴留如何推动水肿

## 1）水肿发生的两大机制（老师总结）

1. **组织液生成 > 回流**（血管内外液体交换失衡：静水压/胶体渗透压/通透性/淋巴回流等因素）
2. **钠水潴留**（体内“水钠出入”失衡，水钠回收到血中）

> 二者有关联：钠水潴留 → 血容量/静水压↑，血液被稀释 → 胶体渗透压↓ → 最终仍推动“组织液生成 > 回流”。

---

## 2）钠水潴留：肾缺血是高频“总开关”

### A）肾小球滤过率（GFR）下降

* 肾小球本身损伤（如肾炎等）
* 肾缺血：没有足够灌注 → 滤过减少 → 尿少 → 易水肿
  （解释：休克、心衰常见尿少）

### B）近曲小管重吸收增强：滤过分数（FF）↑ 的推理链

* FF = GFR / 肾血流量
* 肾缺血时：GFR↓，但肾血流量↓↓更明显 → **FF 上升**
* 肾缺血交感兴奋 → 血管收缩；且**出球小动脉收缩更明显**
  → 肾小球内静水压↑ → 滤出“无蛋白滤液”↑
  → 血浆蛋白被浓缩 → **血浆胶体渗透压↑**
  → 近曲小管周围毛细血管回吸能力↑ → **近曲小管重吸收水钠↑**

### C）肾血流重新分布

* 正常：约 **90% 血供皮质**（肾小球多，产尿关键），约 **10% 髓质**
* 缺血：皮质供血下降，更多血流转向髓质（小管为主）
  → **小管重吸收增强** → 尿少 → 钠水潴留

### D）远曲小管：激素控制（醛固酮 + ADH）

* 肾缺血/血容量下降 → **醛固酮↑、ADH↑**
  → 远曲/集合管重吸收水钠↑ → 钠水潴留
* 课堂补充：两者在**肝脏灭活**；肝功能下降 → 灭活障碍 → 激素水平高 → 也可尿少/水肿（不一定是“生成增多”）。

### E）ANP 与“利水利钠”

* ANP 抑制近曲小管重吸收（利水利钠）；当其作用减弱（如缺血/缺氧时分泌下降）→ 更倾向钠水潴留。

# 八、水肿液：渗出液 vs 漏出液（抽液化验的临床意义）

* **渗出液**（炎症/肿瘤等 → 微血管通透性↑）

  * 蛋白含量高、细胞多（常见中性粒细胞等）、**比重高**
* **漏出液**（低蛋白血症等 → 胶体渗透压↓，通透性本身无明显问题）

  * 蛋白低、细胞少、比重低
* 意义：帮助判断水肿主要机制 → 指导治疗

  * 低蛋白 → 补蛋白/纠正原因
  * 通透性↑ → 抗炎/降低通透性等

# 九、水肿分类（老师给例子）

* 按范围：**局部性水肿** vs **全身性水肿**

  * 局部例：眼睑肿、下肢局部、蚊虫叮咬、局部感染肿胀等
* 按病因系统：**心性、肾性、肝性**水肿（机制各有侧重）
* 按体征：**凹陷性** vs **非凹陷性**水肿

  * “一按一个坑” → 多见凹陷性
  * 甲状腺功能减退：**黏液性水肿**（与黏蛋白结合）→ 肿但不易按出坑
