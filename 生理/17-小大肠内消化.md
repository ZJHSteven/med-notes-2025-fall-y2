## 一、小肠内消化（Digestion in Small Intestine）

1. **地位**

   * 小肠阶段是整个消化过程中**最重要的阶段**。
   * 小肠是**已消化营养成分吸收的主要部位**，所以“消化+吸收”两件事都在这里达到高峰。

2. **为什么重要**

   * 来自胰腺、肝胆、小肠腺的消化液在此汇合；
   * pH 被调到适合多种消化酶作用的**弱碱性**；
   * 小肠停留时间长（3～8 h），利于消化产物充分接触肠黏膜。

## 二、胰液的分泌与作用（Pancreatic Secretion）

### 1. 胰液概述

* 胰液是胰腺的**外分泌产物**，是**消化力最强、谱面最全**的消化液。
* **日分泌量**：约 1～2 L。
* **外观与性质**：无色无味、碱性液体，pH 7.8～8.4，渗透压≈血浆。碱性主要靠 HCO₃⁻。
* **主要分泌来源**：

  * **腺泡细胞（acinar cells）**：分泌各种**酶蛋白**；
  * **管壁细胞（duct cells）**：分泌**HCO₃⁻和水**，用来中和胃酸、提供酶的最适 pH。

### 2. 胰液的主要成分与作用

| 分泌细胞/成分 | 主要内容                                 | 作用                                            | 备注                                   |
| ------------- | ---------------------------------------- | ----------------------------------------------- | -------------------------------------- |
| 管壁细胞      | HCO₃⁻、水                                | 中和胃酸；保护肠黏膜；为胰酶提供最适 pH（7～8） | 进入十二指肠的胃酸必须被中和           |
| 腺泡细胞      | 胰淀粉酶 (pancreatic amylase)            | 水解淀粉→麦芽糖                                 | 最适 pH 6.7～7.0                       |
| 腺泡细胞      | 胰脂肪酶 (pancreatic lipase)             | 脂肪→脂肪酸+甘油/甘油一酯                       | 最适 pH 7.5～8.5，需要胆盐和辅脂酶配合 |
| 腺泡细胞      | 胰蛋白酶原 (trypsinogen)                 | 被肠致活酶激活→胰蛋白酶→分解蛋白质/多肽         | 分泌时是**酶原**                       |
| 腺泡细胞      | 糜蛋白酶原 (chymotrypsinogen)            | 由胰蛋白酶激活→糜蛋白酶                         | 分解蛋白质                             |
| 腺泡细胞      | 羧基肽酶原 (procarboxypeptidase)         | 多肽→氨基酸                                     | 属外肽酶                               |
| 腺泡细胞      | 核酸酶 (ribonuclease, deoxyribonuclease) | RNA/DNA→单核苷酸                                | ——                                     |
| 腺泡细胞      | 胆固醇酯酶、磷脂酶A₂                     | 分解胆固醇酯、卵磷脂                            | 与脂类消化有关                         |
| 腺泡细胞      | 胰蛋白酶抑制因子 (trypsin inhibitor)     | 1:1 结合胰蛋白酶，使其失活                      | 防止胰腺自我消化                       |

**特点**：胰腺分泌的**蛋白水解酶全部为无活性的酶原**，在肠腔内被激活，能避免在胰腺内提前消化自身蛋白。若大量异常激活，易出现**急性胰腺炎**。

### 3. 胰腺分泌 NaHCO₃⁻ 的机制

* 基底膜侧：有 **Na⁺-H⁺ 交换**、CO₂ 扩散入细胞；
* 顶端膜：HCO₃⁻ 主动分泌入管腔，同时 Na⁺ 扩散，形成富含碳酸氢盐的碱性胰液；
* 作用：①中和胃酸；②给胰酶提供弱碱环境。

### 4. 胰液分泌的调节（Regulation）

胰液调节方式和胃液很像，也分为**头期、胃期、肠期**，但以**肠期、体液调节**最重要。

1. **神经性调节**

   * 迷走神经→ACh→促胰液分泌；
   * 作用特点：**酶多、水和HCO₃⁻少**。

2. **体液性调节**（肠激素为主）：

   * 小肠黏膜 **S 细胞** → 分泌**促胰液素（secretin）**：使胰管细胞分泌大量**H₂O、HCO₃⁻**，用于中和酸；
   * 小肠黏膜 **I 细胞** → 分泌**缩胆囊素/胆囊收缩素（CCK）**：使腺泡细胞释放**大量酶**，水和HCO₃⁻相对较少；
   * 胃窦 **G 细胞** → 促胃液素（gastrin）也能轻度促胰液；
   * 这几种激素的组合使胰液成分“可调配”，既能中和酸，又能提供酶。

3. **反馈性调节**

   * 当肠腔内胰酶够用或蛋白分解产物减少时，会**抑制胰酶再分泌**，防止过度分泌和自身消化。

### 5. 临床相关：急性胰腺炎

* 多有**暴饮暴食或胆道疾病史**；
* 胰酶在腺体内大量激活→自身消化；
* 血、尿淀粉酶测定有助诊断；
* 出血坏死型少见但凶险、死亡率高。

## 三、胆汁的分泌与排出（Bile Secretion and Excretion）

### 1. 来源与日量

* 肝细胞持续生成肝胆汁，约 **800～1000 mL/d**；
* 一部分进入胆囊被**浓缩和贮存**，需要时排出十二指肠。

### 2. 性质与成分

* **肝胆汁**：因含胆红素和NaHCO₃ 呈金黄色或桔棕色，pH≈7.4（弱碱）。
* **胆囊胆汁**：水和HCO₃⁻被吸收后**颜色加深**呈棕黄色，因HCO₃⁻被吸收，pH≈6.8（弱酸）。
* **成分特点**：**不含消化酶**！主要为水、胆色素、胆盐、胆固醇、脂肪酸、卵磷脂及各种无机盐（Na⁺、K⁺、Ca²⁺、Cl⁻、HCO₃⁻）。

### 3. 胆汁酸 / 胆盐（Bile acids / Bile salts）

1. **概念**：胆汁酸是胆烷酸的一大类，在胆汁中多以 **钠盐或钾盐**形式存在，即**胆盐**。
2. **按结构**：

   * 游离胆汁酸 (free bile acid)
   * 结合胆汁酸 (conjugated bile acid)：与甘氨酸或牛磺酸按 3:1 结合。
3. **按来源**：

   * **初级胆汁酸 (primary bile acid)**：肝细胞以胆固醇为原料直接合成（胆酸、鹅脱氧胆酸及其结合型），限速酶是 **7α-羟化酶**。
   * **次级胆汁酸 (secondary bile acid)**：初级胆汁酸进入肠道后被**肠道细菌脱 7α-羟基**生成（脱氧胆酸、石胆酸）。
4. **肠肝循环 (enterohepatic circulation)**：

   * 排入肠道的胆盐约 **95%以上被重吸收**，经门静脉回肝再利用；
   * 这是节约胆盐、维持胆盐池容量、维持胆固醇溶解状态的重要机制。

### 4. 胆汁的生理作用

1. **助消化**：胆盐有**表面活性**，能乳化脂肪、形成微胶粒，**显著增强胰脂肪酶作用**。
2. **助吸收**：有助于脂肪分解产物及**脂溶性维生素**（A、D、E、K）的吸收。
3. **利胆作用**：胆盐本身又能促胆汁分泌。
4. **防止胆固醇沉积**：胆盐、胆固醇、卵磷脂保持一定比例，才能维持胆固醇在胆汁中溶解，不然容易形成**胆结石**。
5. **中和胃酸**：胆汁含一定量 HCO₃⁻。
6. **排泄作用**：将胆红素等代谢产物排入肠道。

### 5. 胆汁分泌和排出的调节

* **神经**：迷走神经可促肝、胆囊轻度分泌和排出；
* **体液**：

  * 促胃液素（gastrin）→促肝、胆囊；
  * **促胰液素（secretin）** → 主要刺激胆管系统分泌富 HCO₃⁻ 的胆汁；
  * **缩胆囊素（CCK）** → 收缩胆囊、使 Oddi 括约肌松弛，胆汁排入十二指肠；
  * 肠-肝循环中的胆盐也能**正反馈样**地促进胆汁分泌。

### 6. 胆囊炎和胆结石

* 胆道中有结石（胆囊或胆管）即可称胆结石；
* 结石长期刺激可致急/慢性胆囊炎，少数可发展为胆囊癌（1%～2%）；
* 易感因素：喜静少动、肥胖、不吃早餐、餐后久坐、肝硬化、遗传等。

## 四、胆色素的代谢与黄疸（Metabolism of Bile Pigment and Jaundice）

1. **胆色素**：是体内铁卟啉化合物的主要分解产物，包括**胆红素、胆绿素、胆素原、胆素**等。
2. **胆红素的运输**：生成的非结合胆红素（游离胆红素、间接胆红素）先与白蛋白结合运至肝细胞，在肝内与葡萄糖醛酸结合成为**结合胆红素（直接胆红素）**，此时水溶性↑，可经胆汁排入肠道。
3. **两种胆红素比较**：

| 项目                 | 游离/间接胆红素 (unconjugated) | 结合/直接胆红素 (conjugated) |
| -------------------- | ------------------------------ | ---------------------------- |
| 是否与葡萄糖醛酸结合 | 否                             | 是                           |
| 与重氮试剂反应       | 间接、慢                       | 直接、快                     |
| 水溶性               | 小                             | 大                           |
| 尿中排泄             | 不能                           | 能                           |
| 透膜性与毒性         | 能透过细胞膜，对脑有毒性       | 基本无                       |

4. **黄疸**：血清胆红素升高→巩膜、皮肤、黏膜发黄的症状与体征。

   * **溶血性黄疸**：生成过多，肝处理不过来，血中主要↑间接胆红素；
   * **肝细胞性黄疸**：肝细胞摄取、结合、排泄任何一环出问题；
   * **胆汁淤积性黄疸（阻塞性黄疸）**：胆汁排不出去，血中直接胆红素明显升高。

## 五、小肠液（Small Intestinal Juice）

1. **来源**：十二指肠腺（Brunner gland）+ 小肠腺（Liberkühn crypt）。
2. **性质**：碱性，pH ≈ 7.6；等渗；日量 1～3 L。
3. **成分**：黏液、碳酸氢盐、少量酶；以**稀释、保护、调pH**为主。
4. **分泌调节**：

   * 以**壁内神经丛局部反射**为主（食糜刺激即分泌）；
   * 促胃液素、促胰液素、VIP 等也可促进分泌；
   * 有“经常性分泌”，但量可因刺激而大幅波动。

## 六、小肠运动（Movement of the Small Intestine）

1. **紧张性收缩 (tonic contraction)**：

   * 使小肠平滑肌保持一定张力；
   * 保持腔内压，有利于混合、转运和吸收。

2. **分节运动 (segmental motility)**：

   * 食糜诱发、以环行肌舒缩为主、有节律；
   * 作用：①使食糜与消化液充分混合；②使食糜和肠壁紧密接触便于吸收；③挤压肠壁有利于血液和淋巴回流。

3. **蠕动 (peristalsis)**：

   * 环行肌收缩＋纵行肌舒张→食糜向大肠方向推进；
   * 作用：把已经分节好的食糜送到下一段肠道，再进行新的分节运动。

4. **回盲括约肌 (ileocecal sphincter)**：

   * 回肠末端环行肌增厚而成；
   * 作用：

     1. 防止回肠内容物过快进入大肠，**延长小肠停留时间**；
     2. 阻止大肠内容物逆流。
   * 调节：食物入胃→胃-肠反射→回盲括约肌舒张→约 4 mL 食糜入结肠；若盲肠受机械刺激→回盲括约肌收缩。

5. **调节因素**：

   * 副交感神经、肠腔内容物、ACh、5-HT、P 物质、促胃液素、CCK → **促进肠运动**；
   * 交感神经、促胰液素、肾上腺素、胰高血糖素 → **抑制肠运动**。

## 七、大肠的功能与运动（Large Intestine）

### 1. 主要功能

1. 分泌大肠液（黏液 + HCO₃⁻）→保护黏膜、润滑粪便；
2. 合成并吸收维生素（大肠菌群能合成 Vit B 族和 Vit K）；
3. 加工残渣、形成并暂存粪便；
4. 吸收水分和电解质（大肠仍有一定吸收能力）。

### 2. 大肠液

* 由柱状上皮细胞和杯状细胞分泌，成分以黏液和 HCO₃⁻ 为主；
* 作用：润滑+碱性保护。

### 3. 大肠的运动形式

1. **袋状往返运动**：环行肌不规则收缩，使内容物短距离往返，空腹和安静时常见；
2. **分节/多袋推进运动**：一个结肠袋收缩，把内容物推到下一段；
3. **蠕动**：向前推进；
4. **集团蠕动 (mass movement)**：速度快、范围大、收缩强，可一次把内容物推到降结肠或乙状结肠——多在进餐后由胃结肠反射引起，是排便前的重要运动形式。

### 4. 排便反射（Defecation）

* **感受器**：直肠内粪便→直肠壁牵张感受器；
* **反射中枢**：脊髓腰骶段；
* **传出**：

  * 盆神经 → 降结肠、乙状结肠、直肠收缩；肛门内括约肌舒张；
  * 阴部神经 → 外括约肌受意志控制，可抑制或协同；
  * 同时膈肌、腹肌收缩↑腹内压帮助排便；
* 大脑皮质可对外括约肌、部分反射进行控制，所以从反射弧可以分析**便潴留/便失禁**是哪一段受损。

### 5. 大肠内的细菌活动

* 粪便中细菌可达 20%～30% 重量；
* 细菌能利用肠内残存物质合成 Vit B 族和 Vit K；
* 对人体有营养价值。

### 6. 食物中纤维素的影响

* 纤维素与水结合成凝胶 → 限制水分过度吸收 → 肠内容物体积增大；
* 刺激肠运动，**缩短粪便在肠内停留时间**，增加粪便体积；
* 可降低食物中热量比率，有助于纠正肥胖；
* 常见富含食物：杂粮、根菜类、海藻类。

## 八、吸收（Absorption）

### 1. 各段吸收能力概览

* **口腔**：可快速吸收部分药物（如硝酸甘油、吗啡）；
* **胃**：吸收少量水和酒精；
* **小肠**：吸收能力最强、种类最多，是**营养物质吸收的主要部位**；
* **大肠**：水和无机盐的再吸收，也可吸收葡萄糖和一些药物。

### 2. 小肠是吸收主要部位的原因

1. 吸收面积大：有环形襞、绒毛和微绒毛；
2. 绒毛内血管、淋巴管丰富，转运快；
3. 食物在此已被消化成小分子，易透过；
4. 停留时间长（3～8 h）。

### 3. 水和无机盐的吸收

* Na⁺ 主动转运，常与葡萄糖、氨基酸、阴离子同向转运；
* 水的吸收是**被动的**，跟随溶质移动；
* 铁：以 Fe²⁺ 形式，与转铁蛋白结合后吸收；
* 钙：刷状缘膜上的 Ca²⁺ 通道入细胞→基底膜 Ca²⁺ 泵或 Na⁺/Ca²⁺ 交换出细胞入血。

### 4. 糖的吸收（Sugar absorption）

* **以单糖形式吸收入血**；
* 葡萄糖、半乳糖：与 Na⁺ **同向继发性主动转运**入肠上皮细胞→基底侧以**易化扩散**入血；
* 果糖：以**易化扩散**方式吸收。

### 5. 蛋白质的吸收

* 主要以**氨基酸形式**吸收，机制类似葡萄糖——与 Na⁺ 同向转运；
* 少量短肽可被吸收后在细胞内再水解。

### 6. 脂肪的吸收

* 消化产物以**脂肪酸、甘油一酯、胆固醇、溶血卵磷脂**等小分子与胆盐形成微胶粒→以**单纯扩散**入肠上皮细胞；
* 在细胞内重新酯化、包装成乳糜微粒，经淋巴回流入血，所以脂肪多走**淋巴途径**而不是门静脉。
