# 血管生理学总论（Vascular Physiology）

## 一、血管的结构与功能分类

* **循环通道**：动脉、静脉、毛细血管与淋巴管共同与心脏构成密闭循环系统，保证供血与物质交换。
* **功能分工**

  1. **弹力贮器血管（Windkessel vessels）**：主动脉、肺动脉主干及其最大分支；可扩张、弹性大，起“压力缓冲/辅助泵”作用。
  2. **分配血管（Distribution vessels）**：中动脉；负责向器官**分配与调节**血流。
  3. **阻力血管（Resistance vessels）**：小动脉、微动脉（毛细血管前阻力）；毛细血管前括约肌；微静脉（毛细血管后阻力）。决定外周阻力，维持动脉压与器官灌注。
  4. **交换血管（Exchange vessels）**：真毛细血管网；单层内皮、薄壁、高通透。
  5. **短路血管（Shunt vessels）**：动-静脉吻合支；与体温调节、应急分流有关。
  6. **容量血管（Capacitance vessels）**：静脉系统；管壁薄、口径大、顺应性强，**储血**能力大。

**易错点/提示**：毛细血管虽“细”，但**总横截面积最大**，阻力不一定最大；全身阻力主在**小/微动脉**。

**英文要点**：Windkessel、distribution artery、resistance vessel、precapillary sphincter、true capillary、arteriovenous anastomosis、capacitance vessel.

## 二、血流动力学（Hemodynamics）

### 1. 基本关系与定义

* 公式：**Q = ΔP / R**
* **血流量 Q（blood flow）**：单位时间流经某截面的血量（mL/min、L/min）；在密闭系统各处**总血流量相同 = 心输出量**。
* **血流速度 V（velocity）**：质点线速度（cm/s）；**V ∝ Q / A**（A：该段**总**横截面积）。

  * 主动脉：约 **20–40 cm/s**
  * 毛细血管：约 **0.05 cm/s**（最慢，利于交换）

### 2. 泊肃叶定律（Poiseuille law）

* **Q ∝ ΔP · r⁴ / (η · L)**；R = 8ηL / (π r⁴)

  * 与**半径四次方**成正比（最敏感）
  * 与**黏度、长度**成反比/正比如上

### 3. 血流形式与雷诺数

* **层流（laminar）**：ΔQ ∝ ΔP
* **湍流（turbulent）**：ΔQ ∝ √ΔP；出现条件可用**雷诺数 Re = V·D·ρ / η**；**Re > 2000**倾向湍流（杂音/杂音性血流）。

### 4. 阻力的分布与调控

* 全身外周阻力主要由**小/微动脉**决定；**调口径**是机体调阻力与血流量的**首要方式**。
* **思考**：毛细血管阻力**低于**小微动脉，因**并联数巨大、总横截面积大且单位段长度短**。

**英文要点**：flow (Q)、pressure gradient (ΔP)、resistance (R)、velocity (V)、Poiseuille’s law、viscosity (η)、laminar/turbulent flow、Reynolds number.

## 三、血压与动脉脉搏（Arterial Pressure & Pulse）

### 1. 血压定义与单位

* **血压**：血流对单位面积血管壁的**侧压力**；
* 单位换算：**1 mmHg = 0.133 kPa = 133 Pa = 1.36 cmH₂O**。
* 临床所称“血压”多指**动脉血压**。

### 2. 动脉血压的形成条件

* **充盈前提**：循环血量/血管容积比（有效循环血量）；**体循环平均充盈压（MCFP）**≈ **7 mmHg**（实验：心室颤动停泵后全系统压平衡值）。
* **原动力**：心室射血（心输出量）。
* **压力缓冲**：大动脉**弹性贮器**作用（收缩期扩张储能；舒张期回缩维持流出）。
* **维持因素**：外周阻力（口径、黏度）。

### 3. 正常值与平均动脉压（MAP）

* **收缩压**：100–120 mmHg（13.3–16.0 kPa）
* **舒张压**：60–80 mmHg（8.0–10.6 kPa）
* **脉压（PP）**：30–40 mmHg（4.0–5.3 kPa）
* **平均动脉压**：≈ **DBP + 1/3·PP**（精确计算需对压力-时间曲线积分）
* 生理变动：**性别/年龄差异、昼夜节律、年周期**。

### 4. 影响动脉压的因素（单因素分析时其余视为不变）

* **心脏射血（搏出量↑、心率↑）**：

  * 搏出量↑ → **收缩压↑更显著**，PP↑
  * 心率↑ → **舒张期缩短**，**舒张压↑更显著**
* **外周阻力↑**：舒张期外流减少 → **舒张压↑更显著**，PP↓
* **大动脉弹性↓**：缓冲差 → **收缩压↑、舒张压↓**，**脉压↑**（如动脉硬化）
* **有效循环血量↓**（或毛细血管大量开放→“血池化”）：“泵前不足” → **收缩压下降更明显**

### 5. 测压方法

* **直接法**：动物动脉插管测压（经典：Hales 1733年测马血压）。
* **间接法**：袖带+柯氏音原理（课件示意“间接法原理”）。

### 6. 动脉脉搏

* **形成**：心脏间断射血 + 弹性贮器 + 外周阻力。
* **波形**：

  * **升支**（快速射血期）：反映射血速度、每搏量、射血阻力
  * **降支前段**（缓慢射血+动脉回缩）
  * **降中峡/切迹**（主动脉瓣关闭反冲）—反映外周阻力
* **脉搏波传播速度（PWV）**（与顺应性**成反比**，**大于**血流速度）：

  * 主动脉 **3–5 m/s**；大动脉 **7–10 m/s**；小动脉 **15–35 m/s**
* **影响因素举例**：搏出量↑（脉大）、平均动脉压↑（PWV↑）、**主动脉弹性↓**（硬化→PWV↑，脉压增宽）、**主动脉瓣关闭不全**（脉压明显增宽，“水锤脉”倾向）。

**英文要点**：systolic/diastolic pressure、pulse pressure、mean arterial pressure (MAP)、Windkessel effect、Korotkoff sounds、dicrotic notch、pulse wave velocity (PWV)、arterial compliance.

## 四、静脉血压与回流（Venous Pressure & Return）

### 1. 静脉的一般特性

* **压力低、容量大、顺应性强**；为组织微循环血液回流通道。

### 2. 静脉血压

* **外周静脉压（PVP）**：受体位影响明显。
* **中心静脉压（CVP）**：右心房/胸内大静脉压力，**4–12 cmH₂O**；反映心泵能力与静脉回流平衡，常用于输液监测。
* **重力/静水压**：对静脉影响尤大（壁薄易受压）；
* **跨壁压**（血管内压−外压）：↑则静脉扩张储血，↓则静脉易塌陷。

  * 例：**体位性低血压**：站立→下肢静脉容量↑、回心血量↓。

### 3. 回心血量的决定因素

* **体循环平均充盈压（MCFP）**：循环血量越多→MCFP↑→回流↑。
* **心室收缩力（心泵）**：心缩强→舒张末室内压更低→回流↑；右心衰→体静脉淤血；左心衰→肺淤血/水肿。
* **骨骼肌“泵”**：收缩挤压静脉+静脉瓣，促进回流；瓣功能不全可致**静脉曲张**。
* **呼吸“泵”**：吸气胸内负压↑，大静脉扩张，回流↑；动脉压可见随呼吸的周期性波动。
* **体位/重力**：平卧→回流↑；站立→回流↓。

**英文要点**：peripheral venous pressure、central venous pressure、transmural pressure、orthostatic hypotension、skeletal muscle pump、respiratory pump、varicose veins、mean circulatory filling pressure.

## 五、微循环（Microcirculation）

### 1. 基本概念与组成

* **定义**：微动脉—微静脉之间（毛细血管床）的循环；维持内环境稳态与细胞代谢的基本结构。
* **组成**：

  * **微动脉**（α受体、神经支配，平滑肌完整）
  * **后微动脉**（平滑肌不完整，体液调节为主）
  * **毛细血管前括约肌**（受局部体液因素影响）
  * **真毛细血管网**（单层内皮）
  * **微静脉**（平滑肌完整，神经支配）
  * **动-静脉吻合支**（β受体、神经支配）
  * **通血毛细血管**（直捷通道的一部分）

### 2. 三类血流通路

* **营养/迂回通路**：微动脉→后微动脉→**毛细血管前括约肌**→**真毛细血管网**→微静脉（肠、肝、肾多；**慢、广、强交换**，**轮流开放**约每10 s/次）
* **直捷通路（thoroughfare channel）**：微动脉→后微动脉→**通血毛细血管**→微静脉（骨骼肌常见；**常开放、流速快、交换少**）
* **动静脉短路（AV shunt）**：微动脉→**动-静脉吻合支**→微静脉（内脏、皮肤；必要时开放→**快速分流**、参与**体温调节**）

### 3. 微循环血流量的总体特征

* **低压**（均压约 **~20 mmHg**）、**低速**（~0.5 mm/s）、**薄层血液**（利于交换）、**交替开放**（全身约20–25%开放）、**潜在容量大**（约占总血量~10%；大量开放可致有效循环量↓）。

### 4. 调控机制

* **神经性/体液性**：

  * 交感缩血管神经↑、儿茶酚胺（肾上腺素/去甲肾上腺素）、**血管紧张素Ⅱ**（缩）、**缓激肽/前列腺素/组胺**（多舒）等。
* **局部代谢产物**（多为舒血管）：**CO₂、H⁺、腺苷、乳酸、K⁺**等——**代谢匹配**的核心。

**英文要点**：metarteriole、precapillary sphincter、thoroughfare channel、arteriovenous shunt、local metabolic regulation、angiotensin II、bradykinin、prostaglandins、histamine.

## 六、血液—组织液交换与水肿（Capillary Exchange & Edema）

### 1. 交换方式

* **扩散**：小分子被动扩散（主要方式）；慢流+大面积+高通透有利于扩散。
* **滤过与重吸收**：由**Starling力**决定。
* **吞饮（胞饮）**：大分子跨内皮的主动过程。
* **相对通透性**（水=1 参照）：**葡萄糖≈0.6**；**白蛋白 < 0.0001**（几乎不透）。

### 2. 组织液生成与回流

* **组织液**：组织间隙的液体，以胶质为主，少量可流动成分。
* **有效滤过压（EFP）**
  \[
  \text{EFP} = (P_c + \pi_i) - (\pi_c + P_i)
  \]

  * 动脉端（示例）：(30 + 15) − (10 + 25) = **+10 mmHg** → **滤出**
  * 静脉端（示例）：(12 + 15) − (10 + 25) = **−8 mmHg** → **重吸收**
  * 约**10%**滤出液进入**淋巴**回流血循环。

### 3. 影响组织液与水肿的因素

* **毛细血管压（$P_c$）**：

  * **前阻力↓** → 前支扩张 → **充血** → **滤过↑**
  * **后阻力↑** → 出口受限 → **瘀血** → **重吸收↓**
* **血浆胶体渗透压（$π_c$）↓**：如低蛋白血症 → **重吸收↓** → 水肿
* **毛细血管通透性↑**：蛋白外漏 → **$π_c$↓ 与 $π_i$↑** → 重吸收↓ → 水肿
* **淋巴回流↓**：回收受阻 → **非指凹性水肿（淋巴水肿）**，如**象皮病**。

**英文要点**：diffusion、filtration、reabsorption、pinocytosis、Starling forces、effective filtration pressure (EFP)、interstitial fluid、lymphatic drainage、non-pitting edema、elephantiasis.

# 公式/数值速记（考试/作业高频）

* **Q = ΔP / R；R = 8ηL / (π r⁴)；Q ∝ r⁴**
* **V ∝ Q / A**（总横截面积大处流速慢）
* **层流/湍流**：Re = V·D·ρ / η；Re > 2000 倾向**湍流**
* **单位**：1 mmHg = 0.133 kPa = 133 Pa = 1.36 cmH₂O
* **正常**：SBP 100–120，DBP 60–80，PP 30–40（mmHg）
* **MAP ≈ DBP + 1/3·PP**
* **CVP**：4–12 cmH₂O
* **MCFP**：≈ 7 mmHg
* **PWV**：主动脉 3–5 m/s；大动脉 7–10 m/s；小动脉 15–35 m/s
* **EFP** 示例：动脉端 +10 mmHg；静脉端 −8 mmHg；**~10%**入淋巴

# 临床联系与易混点

* **脉压增宽**：动脉硬化（顺应性↓）、主动脉瓣关闭不全（射血反流）
* **体位改变**：站立→静脉容量↑→回心血量↓→可能体位性低血压
* **水肿分类**：

  * **指凹性**：静脉压↑、低蛋白血症等
  * **非指凹性**：**淋巴回流障碍**（象皮肿）
* **“毛细血管阻力为何低于小微动脉”**：**并联众多、总截面积最大、单位长度阻力小**
* **测压要点**：袖带宽度合适、袖带与心脏同高、静息至少5分钟、避免咖啡因/吸烟/运动后立即测量
