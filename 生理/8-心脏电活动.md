# 一、心肌细胞类型与特殊传导系统

* **心肌细胞功能分类**

  * **工作细胞（working cell）**：心房肌、心室肌，直径约 8–12 μm。负责**机械收缩**。
  * **自律细胞（autorhythmic/pacemaker cell）**：分布于**窦房结（SA）**、**房室结（AV）**、**房室束（His）**、**蒲肯野纤维（Purkinje）**等，负责**节律发放与传导**。
* **特殊传导系统作用**：由自律细胞构成，保证心脏**顺序、自动、节律**性活动。
* **临床应用举例**：动态心电图（Holter）用于长期检测心电活动变化趋势。

# 二、心肌生物电的基础

* 形成基础：**膜两侧离子分布不均 + 通透性（电导）动态变化**。
* 关键跨膜转运：

  * **Na⁺/K⁺ 泵**：3 Na⁺外排 / 2 K⁺内流（生电性，维持负静息电位）。
  * **Na⁺/Ca²⁺ 交换（NCX）**：1 Ca²⁺外排 / 3 Na⁺内流（以 Na⁺化学梯度为驱动）。

# 三、工作细胞（快反应细胞）的动作电位（AP）

* **静息电位（RP）**：≈ −90 mV；主要由 **IK1（内向整流 K⁺ 通道）**维持，伴少量 Na⁺内流与 Na⁺/K⁺ 泵活动。
* **动作电位五期（0–4期）与离子机制**

  * **0期（快速去极化）**：INa 开放，膜电位 −90→+30 mV；**TTX（河豚毒）可阻断 INa**。
  * **1期（快速初期复极）**：Ito（瞬时外向 K⁺）激活，电位 +30→0 mV。
  * **2期（平台期）**：ICa-L（慢通道 Ca²⁺内流）与各类 K⁺外流电流平衡，电位滞于 ≈0 mV。
  * **3期（快速复极）**：IK（延迟整流 K⁺）外流占主导，回到 −90 mV。
  * **4期（静息期）**：IK1 主导维持稳定负电位。
* **与神经细胞 AP 对比**：心室肌 AP **形态复杂、时程长、升降支不对称**，具有**平台期**（考试高频）。
* **L 型 Ca²⁺通道特性**：阈电位约 **−40 mV**；**慢激活/失活/再激活**；可被 **Verapamil**、**Mn²⁺**等阻断。

# 四、自律细胞的跨膜电位与 AP（慢反应/快反应）

* **关键特征**：存在**最大复极电位（MRP）**与**4期自动除极（phase 4）**。
* **4期自动除极的本质**：
  **内向电流进行性增强**（If、ICa-T、INa/Ca） + **外向 IK 逐步衰减** → 膜电位上升至阈值（触发 0 期）。
* **自律细胞类型与离子电流差异**

  * **窦房结 P 细胞（慢反应）**：

    * **0期去极化**由 **ICa-L**主导；**3期复极**由 **K⁺ 外流**主导。
    * **If（funny 电流）**主要由 Na⁺携带，阈约 **−60 mV**；**ICa-T**阈约 **−50～−60 mV**。
  * **蒲肯野纤维（快反应自律细胞）**：

    * **If 增强为主**（在 3 期约 −60 mV 激活，−100 mV 最强，至 0 期 −50 mV 关闭）；IK 衰减为辅。
* **快/慢反应细胞定义**：

  * **快反应**（INa 主导）：工作细胞、His-Purkinje。
  * **慢反应**（ICa 主导）：SA 结、AV 结（房结区、结区、结希区）。

# 五、心肌四大生理特性

1. **兴奋性（Excitability）**

   * 指标：**阈刺激强度**，受**静息电位与阈电位差值**影响。差值↑ → 阈↑ → 兴奋性↓。
   * **Na⁺通道三态**：备用（≈ −90 mV）、激活（≈ −70 mV）、失活（≈ +30 mV）；**失活态不可直接再开放**（需复极到约 −60 mV“复活”）。
   * **[Ca²⁺]o 影响阈电位**（Ca²⁺对 Na⁺通透的膜屏障作用）。
   * **兴奋性的周期性变化**（对照 AP/机械曲线）：

     * **有效不应期（ERP=ARP+局部反应期）**：0 期至 3 期约 −55～−60 mV，**200–300 ms**（保证不发生强直收缩）。
     * **相对不应期（RRP）**：3 期 −60→−80 mV，阈上强刺激可再兴奋。
     * **超常期（SNP）**：3 期 −80→−90 mV，阈下刺激亦可兴奋。
   * **高血钾对兴奋性**：轻度 ↑；重度 ↓ 乃至丧失，可致**舒张性停搏**（复极不足→Na⁺通道难复位）。
2. **自律性（Autorhythmicity）**

   * 评价：频率（次/分）、规整度。决定因素：**从 MRP 去极至阈电位的时程**。
   * **起搏点等级（由 4 期斜率决定）**：**SA 结 > 房内通路 > AV 结 > His-Purkinje**。

     * **内在频率**：SA≈**100/min**，AV 区≈**50/min**，Purkinje≈**25/min**；**实际窦性心率 60–100/min**。
   * **正常起搏点**：SA 结（窦性节律）。
   * **潜在/异位起搏点**：交界性逸搏、室性逸搏等（“高→低 70→20 次/分 递减”）。
   * **SA 对下级起搏点的控制机制**

     * **抢先占领（Preoccupation）**：上级冲动先至，使下级来不及自发去极化。
     * **超速驱动抑制（Overdrive suppression）**：上级高频驱动→**Na⁺/K⁺泵活化↑**→膜**超极化**→**下级自律恢复需停搏短暂期**。
     * **临床提示**：置换人工起搏器时应**缓慢下调频率**以避免节律骤停。
   * **降低自律性的因素**：MRP 更负、阈上移、4 期斜率变缓（如**迷走兴奋→K⁺外流↑**）。
3. **传导性（Conductivity）**

   * 结构基础：**闰盘（缝隙连接）**形成功能合胞体，电耦联直接传递。
   * **心内各部位传导速度**（约值）
     SA 结 **<0.05** m/s → 心房肌 **0.4** → 房室优势通路 **1–1.2** → **AV 交界 <0.03**（最慢，形成**房室延搁 ≈0.10 s**） → 房室束/左右束枝 **2.0** → **Purkinje 3.0**（最快） → 心室肌 **1.0**。
     **房室延搁意义**：保证心房先收缩完成充盈，再由心室收缩（避免同搏失效泵血）。
   * **影响传导性的因素**

     * **结构**：纤维**直径粗**、闰盘**密度高** → 传导↑。
     * **生理**：

       1. **0期去极速度与幅度**越大 → 局部电流更强 → 传导更快（受**静息电位水平**影响：越负→0 期越快）。
       2. **邻近未兴奋区兴奋性**高 → 传导快；低/丧失 → 传导慢/阻滞。
       3. **舒张期（DI）缩短** → 传导减慢。
     * **膜反应性曲线**（RP 与 0 期最大去极速关系）：
       **苯妥英钠**↑膜反应性、**加速房室传导、抑制异位节律**；**奎尼丁**↓膜反应性、**减慢传导**（治房扑/房颤等快速性心律失常）。
       *注意：超常期虽兴奋性↑，但**传导速度反而可能减慢**（易考理解题）。
4. **收缩性（Contractility）**

   * **同步收缩**（功能合胞体，“全或无”）；**T 管发达**（兴奋-收缩耦联部位）。
   * 对**细胞外 Ca²⁺**依赖高（肌浆网少、Ca²⁺内储量低）；**收缩时程长（>300 ms）**；**活动潜力大**（初长度储备足）；**延展性小**（胶原骨架限制）。
   * **低血钙**：收缩性↓；兴奋性↑；传导性总体↑（**快反应↑、慢反应↓**）；**慢反应成分减弱**（对 L-型 Ca²⁺依赖）。

# 六、节律/传导异常与临床词汇

* **期前收缩（extrasystole）**与**代偿间歇（compensatory pause）**：兴奋性周期性变化所致的常见节律现象。
* **早搏（premature contraction）**按起源：窦性、房性、房室交界性、室性（最常见心律失常类型之一）。
* **离子失衡的综合影响（提要）**

  * **高钾血症**：兴奋性先↑后↓；自律性↓；传导性↓；收缩性↓。
  * **低钾血症**：兴奋性↑；自律性↑；传导性↓；收缩性↑。
  * **高钙血症**：兴奋性↓；自律性（慢反应↑、快反应↓）；传导性↓；收缩性↑。
  * **低钙血症**：兴奋性↑；自律性（同左）；传导性（快↑、慢↓）；收缩性↓。
  * **高钠/低钠**：分别趋向传导性与收缩性**同向变化**（表格结论性记忆）。

# 七、心电图（ECG）基础

* **定义**：体表记录的**心肌电活动合力（综合向量）**变化。
* **导联系统**

  * **标准肢体导联（双极）**：
    Ⅰ：RA(−)–LA(+)；Ⅱ：RA(−)–LL(+)；Ⅲ：LA(−)–LL(+)
  * **加压单极肢导联（增幅）**：aVR（右臂）、aVL（左臂）、aVF（左腿）。
  * **单极胸导联（V1–V6）定位**：
    V1 右胸骨缘第4肋间；V2 左胸骨缘第4肋间；V3 在 V2–V4 中点；
    V4 左锁骨中线第5肋间；V5 左腋前线与 V4 同平；V6 腋中线与 V4 同平。
* **心电轴（平均电轴）**：额面最大综合向量与水平轴夹角，反映**除极/复极平均方向**。
* **波段与间期**

  * **P 波**：**心房去极化**；P-R 段/间期反映房室传导。
  * **QRS**：**心室去极化**（时限、振幅与传导、心肌肥厚等相关）。
  * **ST 段**：心室**等电位期**（对缺血/损伤敏感）。
  * **T 波**：**心室复极**。
* **Ⅱ导联常作代表图例**；**ECG-细胞电变化**可一一对应（房与室相分离的电生理基础）。

# 八、易考/易混要点快记

* 心室肌 AP 的**最具特征性**：**平台期**（而非 0 期是否快/慢）。
* **快反应 vs 慢反应**的关键差异：**0 期去极化速度**（INa 快 vs ICa 慢）。
* **L 型 Ca²⁺通道**：阈值约 −40 mV；**Verapamil 可阻断**；**TTX 无效**（TTX阻断 Na⁺）。
* **SA 为正常起搏点**的直接理由：**4 期自动除极速率最快**（而非 RP 或 3 期速度等）。
* **AV 交界最慢传导 + 0.10 s 延搁**→ 保证心房先收缩再心室；Purkinje 传导最快（≈3.0 m/s）。
* **ERP（200–300 ms）**让心肌**不发生强直收缩**，维持收缩-舒张交替。
* **超速驱动抑制机制**= Na⁺/K⁺泵驱动的**超极化**（换起搏器要慢降频）。
* **迷走兴奋**：K⁺ 外流↑ → **自律性与传导性下降**。
* **电解质记忆法**：
  高钾“先兴后抑、致停舒”；高钙“阈↑缩↑传↓”；低钙“缩↓而兴↑”。

# 九、课后自测（与课件同型选择点）

1. 心室肌 AP 最具特征：**平台期（2期）**。
2. 快/慢反应主要差别：**0 期去极速度**。
3. 心室肌 Na⁺通道：**电压门控、激活/失活很快、−40 mV 已非阈、阿托品无效、TTX有效**。
4. 心肌 Ca²⁺通道错误说法：**“TTX 可阻断”**（×，应为 Na⁺通道阻断）。
5. 影响心室肌**兴奋性**的主要因素：**RP 与阈电位的距离**。
6. SA 结为正常起搏点的根因：**4 期自动除极最快**。

# 十、重点英文单词（按主题归类）

**细胞与结构**

* 工作细胞 working cell；自律细胞 autorhythmic cell / pacemaker cell
* 闰盘 intercalated disk；缝隙连接 gap junction；功能合胞体 functional syncytium
* 肌浆网 sarcoplasmic reticulum；横管 T-tubule

**膜电与动作电位**

* 静息电位 resting potential (RP)
* 阈电位 threshold potential
* 动作电位 action potential (AP)
* 去极化 depolarization；复极 repolarization；平台期 plateau phase
* 0/1/2/3/4 期 phase 0/1/2/3/4
* 有效不应期 effective refractory period (ERP)
* 绝对/相对不应期 absolute/relative refractory period (ARP/RRP)
* 超常期 supernormal period (SNP)
* 最大复极电位 maximal repolarization potential (MRP)
* 4 期自动除极 phase-4 spontaneous depolarization
* 膜反应性曲线 membrane responsiveness

**离子通道/转运**

* INa（快钠电流）、IK1（内向整流 K⁺）、Ito（瞬时外向 K⁺）
* ICa-L（L-型 Ca²⁺通道）、ICa-T（T-型 Ca²⁺通道）
* If（funny current, 超极化激活阳离子通道 HCN）
* Na⁺/K⁺-ATPase（Na⁺/K⁺ 泵）；Na⁺/Ca²⁺ exchanger (NCX)
* 河豚毒 tetrodotoxin (TTX)；维拉帕米 Verapamil；锰离子 Mn²⁺

**传导系统/节律**

* 窦房结 sinoatrial node (SA node)；房室结 atrioventricular node (AV node)
* 房室束 AV bundle / His bundle；蒲肯野纤维 Purkinje fibers
* 房室延搁 atrioventricular delay
* 逸搏 escape beat；异位起搏点 ectopic pacemaker
* 抢先占领 preoccupation；超速驱动抑制 overdrive suppression

**心电图**

* 心电图 electrocardiogram (ECG)
* 标准导联 standard limb leads (I, II, III)
* 加压单极肢导联 augmented limb leads (aVR, aVL, aVF)
* 单极胸导联 precordial leads (V1–V6)
* P 波、QRS 波群、ST 段、T 波（P wave, QRS complex, ST segment, T wave）
* 心电轴 electrical axis / mean electrical axis

**临床相关**

* 动态心电图 Holter monitoring
* 期前收缩 extrasystole；早搏 premature contraction
* 代偿间歇 compensatory pause
* 窦性心动过速/过缓 sinus tachycardia / bradycardia
* 房颤 atrial fibrillation；房扑 atrial flutter
* 人工心脏起搏器 cardiac pacemaker
