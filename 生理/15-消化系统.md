# 一、消化系统总论（Overview / Introduction）

1. **组成（Components of the digestive system）**

   * **消化道 Alimentary tract / alimentary canal / gastrointestinal tract (GI tract)**
     口腔 oral cavity
     食管 esophagus
     胃 stomach
     小肠 small intestine
     大肠 large intestine
   * **附属消化腺 Accessory organs / accessory digestive glands**
     唾液腺 salivary glands
     肝脏 liver
     胆囊 gallbladder
     胰腺 pancreas

2. **消化系统的主要功能**

   * **消化 digestion**：把“大分子、复杂食物”分解成可吸收的小分子。

     * 机械性消化 mechanical digestion：咀嚼、蠕动、分段运动等，把食物粉碎、搅拌、与消化液混合。
     * 化学性消化 chemical digestion：各种消化液中的酶，在合适的pH下水解营养物。
   * **吸收 absorption**：将消化后的产物、水、无机盐、维生素从消化道腔面转运到血液或淋巴。
   * **排出 elimination / excretion**：不能消化吸收的残渣排出体外。
   * 特别指出：**水、维生素和无机盐可直接吸收**，不需要复杂消化步骤。

3. **三大营养物质的消化对象**

   * **碳水化合物 carbohydrates**
   * **蛋白质 proteins**
   * **脂肪 fats / lipids**

4. **消化液的作用**

   * 分解食物；
   * 调节腔内容物pH，为酶提供最适环境；
   * 稀释、润滑，利于吸收；
   * 保护黏膜，避免物理/化学损伤。
   * 成人每天各种消化腺总分泌量约 **6~8 L**，最终大部分会被再吸收。
     （digestive glands secretion → 6–8 L/day）

# 二、胃肠道平滑肌的生理特性

（Physiological characteristics of gastrointestinal smooth muscle）

1. **基本结构回顾**

   * 消化道壁一般为：黏膜 mucosa → 黏膜下层 submucosa → 肌层 muscularis（内环形肌 inner circular muscle、外纵行肌 outer longitudinal muscle）→ 浆膜 serosa。
   * 胃有**三层**平滑肌：纵行肌 longitudinal、环形肌 circular、斜肌 oblique → 有利于强力搅拌。
     （stomach: longitudinal, circular, oblique）
   * 小肠黏膜有皱襞 folds、绒毛 villi → 扩大吸收面积。

2. **一般特性（General characteristics）**

   * **兴奋性低，收缩缓慢**：low excitability, slow contraction
   * **具有节律性**：rhythmicity
   * **具有紧张性 tonus**：即使无明显动作电位也有一定基本张力
   * **富有伸展性**：distensibility
   * **对不同刺激的敏感性不同**：对机械、化学、神经性刺激反应不一样

3. **电生理特性（Electrophysiological characteristics）**

   * **静息电位 Resting potential**：约 **-50 ~ -60 mV**，内负外正，且**不稳定、波动大**。
     受K⁺外流、Na⁺/Cl⁻/Ca²⁺通透性及Na⁺-K⁺泵影响。
   * **动作电位 Action potential**：

     * 阈值约 **-40 mV**
     * 持续 **10~20 ms**
     * 幅度 **60~70 mV**
     * **Ca²⁺为主、少量Na⁺内流**形成上升支，K⁺外流为复极有关
       → 所以称为 **钙型动作电位 Ca²⁺-dependent AP**
   * **基本电节律 BER / slow wave 慢波**：

     * 又叫 **basal electric rhythm**，是起搏样的慢波，幅度一般 **10~15 mV**，持续数秒到十几秒
     * 产生部位：**胃肠纵行肌和环形肌之间的Cajal间质细胞（interstitial cells of Cajal, ICC）**
     * 性质：**肌源性 myogenic**，不是每次都引起真正的收缩，只是周期性去极化，为后面的动作电位“打节拍”
     * 机制：生电Na⁺泵活动周期性减弱或暂停 → 膜电位周期性变化

4. **ICC（Cajal间质细胞）**

   * 兼具成纤维细胞和平滑肌细胞特性
   * 通过缝隙连接 gap junction 与平滑肌相连
   * 是消化道的**起搏点/起搏细胞**，决定慢波的**方向、频率和传导速度**
   * 被称为**胃肠道的起搏系统**

5. **动作电位与慢波的关系**

   * 慢波（slow wave）本身 **不一定**触发收缩，它是“电位平台”或“起步电位”
   * 当慢波的峰值 **超过电阈值 electrical threshold (~ -40 mV)** → 叠加动作电位 → **有效收缩**
   * 还有一个**机械阈 mechanical threshold**，即引起真正张力变化的阈值
   * 所以：**通过改变慢波水平，就能调节动作电位的产生频率与收缩强度** → 这是肠道节律运动的基础

# 三、胃肠神经调节系统（Nervous control of GI tract）

1. **双重神经支配**

   * **外来神经系统 external / extrinsic ANS**：交感 sympathetic、 副交感 parasympathetic

     * 交感：**多抑制**消化道活动
     * 副交感（迷走神经 vagus、盆神经）：**多兴奋**消化道（分泌↑、蠕动↑），少部分抑制性纤维
   * **内在神经系统 intrinsic / enteric nervous system, ENS**：肠壁内神经丛，可独立完成局部反射

2. **肠壁内神经丛 enteric nerve plexus**

   * **黏膜下神经丛 submucosal plexus / Meissner plexus**
     主要调节分泌、局部血流、黏膜活动
   * **肌间神经丛 myenteric plexus / Auerbach plexus**
     主要支配平滑肌 → 蠕动、肌张力、运动强度
   * 神经元类型：感觉 neurons, interneurons, motor neurons
   * 神经递质十分丰富：Ach, NE, VIP, 5-HT, NO, CCK, ATP, GABA…
     → 是一个“第二大脑”/ **gut brain**，与中枢存在“脑—肠轴 brain-gut axis”

3. **两套神经的关系**

   * 肠神经系统能**独立**完成局部反射，如进食→肠段性运动、分泌增加
   * 但在正常情况下仍受外来神经（尤其副交感）的调节或当作中继站

4. **情绪与肠道**

   * 情绪、精神因素可影响胃肠功能 → 临床上见到的“紧张→腹泻/便秘”
   * 肠道微生物也能影响中枢和肠脑 → 肠—脑轴（gut-brain axis）

# 四、胃肠激素（Gastrointestinal hormones）

1. **来源**

   * 胃肠黏膜内散在的内分泌细胞（APUD细胞，amine precursor uptake and decarboxylation cells）
   * 同一激素常在中枢和肠道**双重分布**，称为脑—肠肽 brain–gut peptides

2. **主要激素及分泌细胞/部位**

   * **促胃液素 gastrin**：G细胞，主要在**胃窦 antrum**、十二指肠

     * 促释放因素：迷走神经兴奋（Ach）、胃扩张、蛋白消化产物
     * 作用：①强烈促胃酸分泌；②促胃、肠、胰液等分泌；③增强胃窦、胆囊运动，延缓胃排空；④营养作用（胃黏膜生长）；⑤促胰岛素释放
   * **促胰液素 secretin**：S细胞，十二指肠、空肠

     * 促释放因素：酸性胃液进入小肠（HCl）、脂肪酸
     * 作用：①促胰液和胆汁的水、HCO₃⁻分泌↑；②抑制胃酸分泌和胃运动
   * **胆囊收缩素 CCK / cholecystokinin**：I细胞，十二指肠、空肠

     * 促释放因素：脂肪酸、蛋白产物
     * 作用：①促胆囊收缩、Oddi括约肌松弛→胆汁排放；②强烈促胰酶分泌；③抑制胃排空、抑制胃分泌；④促胰外分泌组织生长
   * **抑胃肽 GIP / gastric inhibitory peptide / glucose-dependent insulinotropic peptide**：K细胞，十二指肠、空肠

     * 促释放因素：葡萄糖、脂肪酸、氨基酸
     * 作用：①促胰岛素分泌（肠促胰岛素效应 incretin effect）；②抑胃酸和胃蛋白酶分泌；③抑制胃排空
   * **胃动素 motilin**：胃、小肠、结肠的某些细胞

     * 作用：消化间期促进胃肠道的移行性复合运动（MMC）
   * **生长抑素 somatostatin**：D细胞，胃、肠、胰

     * 作用：广泛抑制多种激素和消化液分泌，抑制胃肠运动

3. **总体作用**

   * 协调消化腺分泌与消化道运动
   * 互相调节其他激素释放
   * 对消化道黏膜具有营养与生长促进作用
   * 有一定免疫调节意义

# 五、口腔内的消化（Digestion in oral cavity）

1. **特点**

   * 是整条消化道消化的起始部位
   * 停留时间很短（约15~20 s）→ 只能做**初步的**机械和化学处理
   * 更多意义在于：**启动后续消化器官的活动（反射性增强胃、胰、肝、胆分泌与运动）**

2. **消化方式**

   * **机械性**：咀嚼 mastication → 食物粉碎、与唾液混合成食团 bolus；吞咽 deglutition → 把食团送入口咽、食管
   * **化学性**：唾液中的酶（最主要是唾液淀粉酶 salivary amylase）开始水解淀粉 → 麦芽糖 maltose；还有舌脂酶 lingual lipase 开始少量脂类水解

# 六、唾液及其分泌调节（Saliva & salivary secretion）

1. **唾液腺**

   * 腮腺 parotid gland
   * 颌下腺 submandibular gland
   * 舌下腺 sublingual gland
   * 还有散在小唾液腺
   * 每天分泌量约 **1~1.5 L**，**近中性、低渗（pH 6.6–7.1）**，渗透压随分泌率变化。

2. **成分特点**

   * 水占99%
   * **有机成分**：黏蛋白 mucin、唾液淀粉酶 salivary amylase、溶菌酶 lysozyme、舌脂酶 lingual lipase、Ig、氨基酸、尿素、尿酸
   * **无机成分**：Na⁺、K⁺、Cl⁻、HCO₃⁻、SCN⁻(硫氰酸盐)、NH₃等
   * 和血浆相比：**Na⁺、Cl⁻低，K⁺、HCO₃⁻高**（但具体要看流速）

3. **生理作用**

   * 湿润口腔，利于说话、吞咽
   * 溶解食物 → 刺激味觉（味觉需要溶解）
   * 清洁口腔、杀菌（溶菌酶、SCN⁻）、保护黏膜、预防龋齿
   * 初步消化淀粉
   * 有排泄功能：可排出碘、汞、铅等（临床上可见铅线）

4. **分泌的调节**

   * **完全受神经支配（几乎无激素性调节）**
   * **副交感神经为主**：VII（面神经）、IX（舌咽神经）→ 分泌量↑、水样、稀薄
   * **交感神经也能促分泌，但与情绪有关**，常使唾液较黏稠
   * **反射形式**：

     * **非条件反射**：食物直接刺激口腔、舌、咽部感受器 → 延髓唾液中枢 → 唾液腺
     * **条件反射**：食物的视觉、嗅觉、声音等高级中枢信号 → 延髓 → 唾液腺
   * 所以见到美食就流口水，是**大脑→延髓→唾液腺**的条件反射通路

# 七、咀嚼（Mastication）

1. **性质**

   * 咀嚼肌是骨骼肌 → 可以随意
   * 但典型进食时，多是**反射性节律咀嚼**：食物在口内的机械刺激→口腔感受器→中枢→节律性开闭口

2. **作用**

   * 切碎、研磨、混合、润滑食物
   * 食物与唾液充分混合形成**食团 bolus**，利于化学消化、也利于顺利吞咽
   * 通过反射**促进胃、胰、肝、胆的消化准备活动**

---

# 八、吞咽（Deglutition / swallowing）

1. **定义**

   * 液体或固体食团从口腔进入胃的全过程

2. **分期**

   * **第一期：口腔期（随意期）**
     食团被舌推送到口咽部，是**受意识控制**的阶段
   * **第二期：咽期（不随意/反射期）**
     由**吞咽中枢（延髓）**发出指令，引起一系列保护性动作：

     * 软腭上抬 → 封闭鼻咽
     * 会厌下降、声门关闭 → 封闭喉入口，防止呛咳
     * 食管入口开放
       → 这是一个**快速而协调的反射过程**
   * **第三期：食管期**

     * 食团进入食管后，被食管的**蠕动 peristalsis**向下推进至胃
     * 食管上段为骨骼肌，下段为平滑肌，中下段蠕动主要由壁内神经丛和迷走神经调节

3. **食管蠕动**

   * 原发性蠕动：吞咽诱发的顺序收缩波
   * 若有残留，可出现继发性蠕动

# 九、食管—胃连接处的括约肌与反流（LES & reflux）

1. **食管-胃括约肌（esophageal-gastric sphincter）/ 食管下括约肌 LES**

   * 位于食管与胃贲门交界处以上的高压带，长约 **4–6 cm**
   * 静息压一般较胃高出 **5–10 mmHg**，具有**屏障作用**，防止胃内容物逆流入食管
   * 属于**功能性括约肌**，不是一个非常明显的解剖性环肌

2. **功能不全的后果**

   * 括约肌松弛或压力不足 → 胃酸、胃内容物可逆流至食管
   * 食管黏膜不耐酸，易被胃酸/胃蛋白酶腐蚀 → **反流性食管炎 reflux esophagitis**
   * 典型症状：

     * 胸骨后烧灼感 heartburn（向颈部放散）
     * 反流 regurgitation
     * 胸痛 chest pain
     * 多见于**饱餐后、夜间平卧时**，症状加重可影响睡眠
   * 危险因素/高发人群：**中老年、肥胖、吸烟、饮酒、精神压力大**等 → 这些因素可能降低LES张力或增加腹压
