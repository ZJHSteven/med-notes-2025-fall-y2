## 一、氧的运输（O₂ Transport）

### 1. 运输形式与比例

* **物理溶解（dissolved O₂）**：约 **1.5%**。
* **化学结合（chemically bound to Hb）**：约 **98.5%**，以**血红蛋白（Hb）与氧可逆结合**的形式存在。

### 2. Hb–O₂ 可逆结合与T/R构象

* 在**肺**（**PO₂ 高**）侧重**结合**：
  **Hb + O₂ ⇌ HbO₂**（氧合、红色）。
* 在**组织**（**PO₂ 低**）侧重**解离**：释放O₂（还原、紫蓝色）。
* 结合/解离时伴随**盐键（salt bridges）**变化：

  * **结合O₂ → 盐键断裂 → R型（疏松型）→ 亲和力高**
  * **解离O₂ → 盐键形成 → T型（紧密型）→ 亲和力低** 

### 3. 结合特点与定量指标

* **可逆性**、**非酶促**、反应**迅速**，受 **PO₂** 显著影响。
* **价态不变**：O₂与Hb的**亚铁离子（Fe²⁺）**结合，不改变价态，称**“氧合（oxygenation）”**而非氧化。
* **一个Hb分子最多结合4个O₂**（示意：Hb₄O₈）；
  **1 g Hb 可结合约 1.34–1.39 ml O₂**（常用 **1.34 ml O₂/g**）。

#### 三个常用量化概念

* **Hb氧容量（oxygen capacity of Hb）**：指定容条件下，**每100 ml血**中Hb**最大可结合O₂**的量。

  * 正常：Hb ≈ **15 g/100 ml 血**，以 **1.34 ml O₂/g** 计，**氧容量 ≈ 20 ml/100 ml**。
* **Hb氧含量（oxygen content of Hb）**：Hb**实际**已结合的O₂量。

  * **动脉血 ≈ 20 ml/100 ml**；**静脉血 ≈ 15 ml/100 ml**。
* **Hb氧饱和度（oxygen saturation, SaO₂/SvO₂）**：氧含量/氧容量×100%。

  * **动脉血 ≈ 100%**；**静脉血 ≈ 75%**。

### 4. 氧解离曲线（Oxygen Dissociation Curve, ODC）

* 含义：**血氧分压（PO₂）** 与 **Hb氧饱和度（SO₂）** 的关系曲线，呈**S形**（协同/变构效应）。

#### 曲线三段的生理意义（配安全系数/供氧调配）

* **上段（PO₂ ≈ 60–100 mmHg，即 7.98–13.33 kPa）**：
  PO₂ 变化大而SO₂变化小 → **肺侧高亲和**，**缓冲吸入氧不足**，提供**较大安全系数**。
* **中段（PO₂ ≈ 40–60 mmHg，即 5.34–7.88 kPa）**：
  SO₂随PO₂**明显改变**：

  * 在**肺**：PO₂上升 → 结合能力↑ → 维持足够血PO₂；
  * 在**组织**：PO₂下降 → 解离↑ → **释放O₂**以匹配代谢。
* **下段（PO₂ ≈ 15–40 mmHg，即 1.95–5.34 kPa）**：
  **斜率最大**，SO₂ **75%→22%**，提示**组织端能大量释放O₂**以满足**更高代谢需求**。

#### P50 与曲线移位

* **P50**：Hb**饱和度=50%** 时所需的 **PO₂**；反映Hb对O₂的**亲和力**。

  * **正常 ≈ 26.5 mmHg（3.5 kPa）**。
  * **P50↑ → 亲和力↓ → 曲线右移 → 更易释放O₂**；
  * **P50↓ → 亲和力↑ → 曲线左移 → 更易结合O₂**。

### 5. 影响氧解离曲线（ODC）的因素

1. **pH/PCO₂（Bohr效应）**

* **PCO₂↑、[H⁺]↑（pH↓）→ Hb对O₂亲和力↓ → 曲线右移 → 有利组织端释氧**；反之左移（不利释氧）。
* 反映与组织**代谢强度相适应**的调节。称**Bohr效应**（pH与PCO₂对Hb的变构效应）。

2. **温度（Temperature）**

* **组织代谢↑ → 温度↑ → 右移 → 释氧↑**；反之不易解离。同样体现与代谢相匹配。

3. **2,3-二磷酸甘油酸（2,3-DPG/2,3-BPG）**

* 红细胞**无氧酵解↑**时生成↑；**与去氧Hb结合**，**稳定T态**，**亲和力↓**，**曲线右移**；反之亦然。

4. **铁的价态与一氧化碳**

* **Fe²⁺→Fe³⁺**（高铁血红蛋白，MetHb）**失去**结合O₂能力。
* **CO中毒**：CO与Hb结合成**碳氧Hb（HbCO）**，**无结合O₂能力**；CO对Hb亲和力为O₂的**约210倍**。

### 6. 缺氧与发绀（Cyanosis）要点

* **发绀出现阈值**：**去氧Hb > 5 g/dL**。
* **贫血**：虽缺氧，但**Hb总量低**，**未必出现发绀**。
* **多红细胞症/高原人**：即使不缺氧，**Hb偏高**也可能出现发绀。

#### 本节英文关键词

* dissolved oxygen；chemically bound oxygen；hemoglobin (Hb)；oxygenation（vs. oxidation）；T-state/R-state；salt bridge；oxygen capacity；oxygen content；oxygen saturation (SaO₂/SvO₂)；oxygen dissociation curve (ODC)；P50；Bohr effect；2,3-BPG (2,3-DPG)；methemoglobin (MetHb)；carboxyhemoglobin (HbCO)；cyanosis。

## 二、二氧化碳的运输（CO₂ Transport）

### 1. 运输形式与比例（总览）

* **物理溶解（dissolved CO₂）**：**≈ 5%**
* **化学形式（≈ 95%）**：

  * **碳酸氢盐（HCO₃⁻）**：**≈ 88%**（主要形式）
  * **氨基甲酰血红蛋白（carbamino-Hb, Hb–NH–COOH）**：**≈ 7%**。

### 2. HCO₃⁻ 形式运输（纲要）

* 课件要点：**CO₂以HCO₃⁻形式运输**占**主要比例**。

> （课件列出“**HCO₃⁻形式的运输**”为要点；该页强调其为主要形式与比例，未展开机制细节，复习以**比例与形式**为主。）

### 3. 氨基甲酰血红蛋白形式运输（Carbamino-Hb）

* **CO₂进入红细胞后与Hb肽链自由氨基结合**，生成**氨基甲酰Hb（Hb–NH–COOH）**。
* **反应迅速、可逆、无需酶**；**运输效率高**：该途径在**肺部CO₂总释放排出量中可占 >15%**。
* **组织端**：有利于**结合**（PCO₂高）；**肺部**：有利于**解离并排出**。

### 4. CO₂解离曲线（CO₂ Dissociation Curve, CDC）

* **含义**：血液中 **PCO₂** 与 **CO₂含量** 的关系曲线。
* **特点**：在机体**正常范围内近似线性**，**无饱和点**。

### 5. 何尔登效应（Haldane Effect）与Bohr效应的配合

* **Haldane效应定义**：**O₂与Hb结合后促使CO₂释放**。

  * **肺部**：**PO₂升高**→ 形成**HbO₂**；**HbO₂酸性更强**、**不易与CO₂结合** → **有利CO₂释放/排出**。
  * **组织**：**PCO₂高**通过**Bohr效应**使Hb对O₂亲和力下降 → **利于O₂释放**供组织利用。
* **要点**：**肺侧以Haldane效应促CO₂排出**，**组织侧以Bohr效应促O₂释放**，两者**相向协作**优化气体交换。

#### 本节英文关键词

* dissolved CO₂；bicarbonate (HCO₃⁻)；carbaminohemoglobin (carbamino-Hb)；carbon dioxide dissociation curve (CDC)；Haldane effect；Bohr effect。

## 三、数据与临床相关速记（整合提要）

* **1 g Hb ≈ 1.34 ml O₂**；**15 g/dl Hb → 氧容量≈20 ml/100 ml**。
* **动脉血O₂含量≈20 ml/100 ml；静脉血≈15 ml/100 ml；SvO₂≈75%**。
* **P50 正常≈26.5 mmHg（3.5 kPa）**。
* **ODC右移**（释氧↑）：**H⁺↑/pH↓、PCO₂↑、温度↑、2,3-BPG↑**。
* **CO亲和力≈O₂的210倍**；**MetHb（Fe³⁺）不携氧**。
* **发绀阈：去氧Hb > 5 g/dL**（警惕贫血/多红细胞症对发绀判断的干扰）。
* **CO₂运输**以**HCO₃⁻（≈88%）**为主；**carbamino-Hb（≈7%）**快而可逆；**溶解≈5%**。
* **Haldane效应**（肺促排CO₂）与 **Bohr效应**（组织促释O₂）**协同**。

## 五、易错点/考点提示

1. **氧合≠氧化**：Hb与O₂结合不改变Fe²⁺价态（氧合）。**Fe³⁺（MetHb）不携氧**。
2. **P50方向**：**P50↑=亲和力↓=曲线右移**（记“P右亲低”）。
3. **静脉端SO₂并非很低**：常考**≈75%**，但在**下段PO₂ 15–40 mmHg**时可降至**≈22%**，体现**大幅释氧能力**。
4. **发绀阈值与血红蛋白浓度**：贫血可**缺氧不发绀**；多红细胞症可**不缺氧而发绀**。
5. **CO₂主要以HCO₃⁻运输**，**carbamino-Hb**虽比例小但**反应快且在肺部排出量中占比>15%**，勿忽视其贡献。
