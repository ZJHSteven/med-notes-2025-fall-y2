## 一、呼吸中枢与呼吸节律的形成

### 1. 概念与定位

* **呼吸中枢（respiratory center）**：位于**中枢神经系统**内，负责**产生与调节**呼吸运动的**神经细胞群**。

### 2. 历史与认识演变（重要人物与实验）

* **1824 Legallois**：破坏进入**延髓**部分的**迷走神经**时，**呼吸停止** → 指出延髓及其传入对呼吸维持的重要性。
* **1842 Flourens**：提出**第四脑室底**灰白质中存在**呼吸中枢**。
* **1859 Budge**：提出**吸气中枢**与**呼气中枢**可能**独立存在**。
* **1923 Lumsden**：**脑干分段横切**实验，提出**三级呼吸中枢学说**（见下）。
* **1939 Pitts**：认为呼吸中枢**不是单一核团**，而是**网状结构**的一部分。

### 3. Lumsden 横切实验与结论（掌握）

| 横切部位           | 观察到的呼吸运动形式 |
| ------------------ | -------------------- |
| **脑桥与中脑之间** | **基本正常**         |
| **脑桥中部**       | **变深变慢**         |
| **脑桥与延髓之间** | **不规则呼吸**       |
| **延髓与脊髓之间** | **呼吸停止**         |

**小结（区域功能）**

* **脑桥上部**：**呼吸调整中枢**（调节呼吸相位与平稳性）。
* **脑桥中下部**：**长吸中枢（apneustic center）**的经典提法**已被否定**（现代多视为网络调制的一部分）。
* **延髓**：**基本呼吸中枢**（节律生成与基元输出）。
* **脊髓**：**初级呼吸中枢**（运动神经元与反射环路的执行层面）。

### 4. 呼吸节律的形成机制

* 课件要点：**“局部神经元回路＋反馈控制学说”**

  * 依赖延髓/脑桥**局部网状神经元网络**的相互抑制/兴奋与**来自外周和中枢化学/机械感受器**的**反馈调节**，共同形成**自主节律**与**对内外环境变化的适应**。

## 二、呼吸的化学感受性调节（Chemosensitive control）

> 总图（框架记忆）：**动脉血气体/酸碱（PCO₂、PO₂、H⁺）→ 化学感受器（外周/中枢）→ 呼吸中枢 → 效应器（呼吸肌）→ 潮气量、呼吸频率改变**。

### 1. 外周化学感受器（Peripheral chemoreceptors）

* **解剖部位**：

  * **颈动脉体（carotid bodies）**
  * **主动脉体（aortic bodies）**
* **敏感刺激**：**动脉血**中**PCO₂↑、PO₂↓、H⁺↑（酸中毒）** → 感受器兴奋。
* **相对作用强度**：**颈动脉体**对呼吸的**刺激作用 ≈ 主动脉体的7倍**（高频考点）。
* **传入通路**：

  * 颈动脉体 → **窦神经（glossopharyngeal branch）**
  * 主动脉体 → **迷走神经（vagus）**
    共同投射至**延髓呼吸中枢**。

### 2. 中枢化学感受器（Central chemoreceptor）

* **定位**：**延髓腹外侧浅表部位**。
* **有效刺激变量**：**脑脊液（CSF）中的 H⁺ 变化**。
* **关键特点**：
  a) **不感受缺氧（低O₂）**的直接刺激；
  b) **血中 H⁺**对其**影响弱**（**血脑屏障**限制H⁺进入）；
  c) **对 CO₂ 更敏感**于外周感受器，但**对动脉 PCO₂ 突变**的**反应潜伏期更长**；
  d) **有效刺激物不是 CO₂ 本身**，而是 CO₂ 进入中枢后经**碳酸酐酶**催化：
  [
  \text{CO}_2 + \text{H}_2\text{O} \xrightleftharpoons[\text{CA}]{ } \text{H}_2\text{CO}_3 \xrightleftharpoons{ } \text{H}^+ + \text{HCO}_3^-
  ]
  —— **H⁺ 增多** → **中枢化学感受器兴奋** → **通气增加**。

## 三、CO₂、O₂ 与 H⁺ 对呼吸运动的影响（体液因素）

### 1. 二氧化碳（CO₂）

* **主导因素**：CO₂ 是呼吸调节中最**重要**的**体液因素**（dominant humoral factor）。
* **两条作用途径**：

  * **间接作用（主要）**：**PCO₂↑** → 通过**中枢化学感受器**引起反应（**动脉 PCO₂ ↑ 约 2 mmHg**即可触发明显通气反应）。
  * **直接作用（次要）**：**PCO₂↑约 10 mmHg**时可**直接**兴奋**外周化学感受器**。
* **敏感性比较**：**中枢化学感受器对 H⁺ 的敏感性 ≈ 外周的 25 倍**。
* **过度通气的后果**：**时间过长的过度通气** → **PCO₂ 过低** → 解除对呼吸中枢的**兴奋驱动** → **呼吸暂停**（高频机制题）。
* **高浓度 CO₂ 的抑制**：当**吸入气/肺泡气 CO₂ > 7%**时，可**直接抑制呼吸中枢**，出现通气反而减弱的**抑制相**。
* **渐进升高的剂量-效应**：随吸入气体 **1% → 4% → 7% CO₂** 递增，**呼吸显著增强**，直至过高浓度发生**中枢抑制**。

### 2. 氧（O₂）

* **作用特点**：
  a) **主要经外周化学感受器**（切断其传入则缺氧的呼吸兴奋作用**消失**）；
  b) 对中枢有**轻度抑制**（直接缺氧对延髓神经元）；
  c) **轻度缺氧（PO₂＞80 mmHg）**对呼吸**影响不明显**。
* **调节通路**：**低 O₂** → **外周化学感受器兴奋** → 促使**呼吸中枢兴奋** → 通气↑。
* **临床相关提示**（来自课件链路）：**CO₂ 潴留**（如慢性高碳酸血症）可使**中枢化学感受器发生适应**，此时**过高浓度吸氧**会**削弱外周低氧驱动**，导致**通气下降**（需警惕临床给氧策略）。

### 3. 氢离子（H⁺）/pH

* **整体效应**：**H⁺↑/pH↓** → **通气加快**（化学感受器有效刺激）。
* **作用途径**：
  a) **血中 H⁺↑**：**主要兴奋外周化学感受器**；
  b) **脑脊液 H⁺↑**：**兴奋中枢化学感受器**。

### 4. 三者（PCO₂、PO₂、H⁺）的相互关系

* **PCO₂ 起主导作用**于**正常呼吸调节**。
* **任一因素改变**可引起**另外两个因素的继发性改变**，并**反过来影响**第一因素的呼吸效应。
* **协同效应**：**缺氧（PO₂↓）**与**酸中毒（H⁺↑）**可**加强**PCO₂ 升高对呼吸的**刺激效应**。

## 四、呼吸运动的反射性调节（Reflex control）

### 1. 肺牵张反射（Pulmonary stretch reflex，**黑–伯反射 / Hering–Breuer**）

* **发现**：**1868 年**，**Breuer** 与 **Hering** 各自发现：

  * **肺叶扩张** → **抑制吸气动作**（**吸气切断机制**），以**迷走神经**为主要传入；
  * **肺叶强烈缩小/萎陷** → **阻止呼气、促使吸气**（“肺萎陷反射/吸气兴奋反射”）。
* **通路概念图**：
  **吸气 → 肺扩张 → 牵张感受器（气道/肺组织） → 迷走神经传入 → 延髓 → 抑制吸气神经元**（限制过度充气，维持节律）。

### 2. 呼吸肌本体感受性反射

* **来自肋间肌、膈肌等**的本体感受器传入，参与**相位调节**与呼吸运动**协同化**。

### 3. 防御性呼吸反射

* **气道/肺部刺激**引起的**快速保护性反应**（如咳、喷嚏等概念范畴）→ **短暂改变呼吸相位/频率/深度**，以**清除刺激**。

### 4. 肺毛细血管感受性反射

* **肺毛细血管（间质）感受器**受刺激时可引发**特征性呼吸改变**（课件列出该命名，掌握其**存在与作用方向**）。

## 五、整合框架与易错点

1. **主轴**：**延髓基本呼吸中枢**（节律发生）＋**脑桥上部调整**（相位/平稳）＋**外周/中枢化学感受器**（体液反馈）＋**机械性反射**（肺牵张等） → **形成稳定而可调的呼吸**。
2. **外周 vs 中枢化学感受器**：

   * **外周**：**PCO₂↑、PO₂↓、H⁺↑**皆可兴奋；**颈动脉体作用强于主动脉体（≈7倍）**。
   * **中枢**：**只对 CSF H⁺ 上升敏感**，**血中 H⁺ 影响小**；对 **CO₂** 变化**敏感**但**反应慢**，**有效刺激=CO₂→H⁺**。
3. **过度通气—呼吸暂停机制**：**PCO₂ 降太低** → 失去 CO₂ 对中枢的**兴奋驱动** → **短暂停呼吸**。
4. **高浓度 CO₂ 抑制**：吸入气 CO₂ **>7%** 时可**直接抑制**呼吸中枢。
5. **缺氧作用路径**：**仅经外周感受器**；**PO₂>80 mmHg**影响小；对中枢 **轻度抑制**。
6. **协同效应**：**低 O₂、酸中毒**均能**增强**CO₂ 对通气的**刺激**。
7. **术语更新**：**“脑桥长吸中枢”已被否定**，以**网络调控**的观点取代（但历史名词仍可能出题）。

## 七、速记板（考点一句话版）

* **PCO₂ 是王者**：正常调控中最重要；**中枢受体对 H⁺ 的敏感 ≈ 外周 ×25**。
* **外周感受器**：对**低 O₂/高 H⁺/高 CO₂**都敏感；**颈动脉体 ≈ 主动脉体 ×7**。
* **中枢感受器**：只认**CSF 里的 H⁺**，**CO₂→H⁺**才是有效刺激；**缺氧不直接刺激**。
* **过度通气** → **PCO₂↓** → **呼吸暂停**；**CO₂ >7%** 反而**抑制**呼吸中枢。
* **肺牵张反射**：**肺扩张抑制吸气**、**肺萎陷促吸气**，**迷走传入**。
