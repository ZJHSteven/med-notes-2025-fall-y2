# 呼吸系统（肺通气）

---

## 一、呼吸的基本概念与全过程

* **外呼吸 external respiration**：机体与外环境之间的气体交换总称，包含：

  1. **肺通气 pulmonary ventilation**：肺与环境空气之间的气体交换；
  2. **肺换气 gas exchange**：肺泡与肺泡毛细血管之间的气体扩散；
  3. **气体运输 gas transport**：O₂/CO₂在血液中的转运。
* **内呼吸 internal respiration**：动脉血与组织/细胞之间的气体交换（含**组织换气**与**细胞内呼吸**）。

---

## 二、肺循环概述与特点

* **双重血供 dual blood supply**：肺循环 + 支气管循环；支气管静脉与肺循环吻合 → **静-动脉血分流 shunt** 约 **1–2%**。
* **低压低阻系统 low-pressure, low-resistance**

  * 肺动脉压：收缩压 **≈22 mmHg**；舒张压 **≈8 mmHg**；平均 **≈13 mmHg**
  * 肺毛细血管压（均压）**≈7 mmHg**；肺静脉压（均压）**≈4 mmHg**
  * 肺血管总阻力：约为体循环的 **1/9–1/8（≈0.12 PRU）**
* **肺血容量大**：约 **450 mL（≈总血量10%）**，可变动 **±200 mL**（贮血库）。
* **组织液生成极少**：维持肺泡“干燥”，利于气体交换。
* **血流分布不均**：受重力明显影响，**上肺 < 下肺**。

## 三、肺通气（Pulmonary Ventilation）

### 1. 肺通气器官与功能

* **呼吸道 airways**：沟通外界与肺泡；**加温 warming、加湿 humidifying、过滤 filtering**，并具防御反射。
* **肺泡 alveoli**：气体交换场所。
* **胸廓 thoracic cage**：通气机械动力来源。

### 2. 通气原理与动力 / 阻力

* **动力**：

  * **呼吸运动 respiratory movement**（吸/呼气肌收缩舒张引起胸廓容积变化）；
  * **肺内压 intrapulmonary (alveolar) pressure**与**大气压**之差是气体流动的直接动力；
  * **胸膜腔内压 intrapleural pressure**（胸内负压）。
* **阻力**：

  * **弹性阻力 elastic resistance**（肺与胸廓弹性）；
  * **非弹性阻力 non-elastic resistance**（气道阻力、惯性/黏滞阻力）。

### 3. 呼吸运动与呼吸肌

* **吸气肌 inspiratory muscles**：**膈肌 diaphragm**（平静呼吸主力，贡献≈**70%**胸廓容积变化）、**肋间外肌 external intercostals**；辅助吸气肌：**斜角肌 scalenes、胸锁乳突肌 SCM**等。
* **呼气肌 expiratory muscles**：**肋间内肌 internal intercostals、腹肌 abdominals**（**平静呼吸**时呼气多为**被动**；**用力呼吸**时呼气转为**主动**）。
* **呼吸型式**：**腹式 abdominal** / **胸式 thoracic**；**平静呼吸 eupnea**（吸气主动、呼气被动）VS **用力呼吸 forced**（吸/呼均主动）。

### 4. 肺内压（Palv）与胸膜腔内压（Ppl）

* **肺内压 Palv**随肺容积周期性变化：

  * 吸气时 **Palv↓**（约 **−2 ~ −1 mmHg**），气体进入；
  * 呼气时 **Palv↑**（约 **+1 ~ +2 mmHg**），气体排出；
  * **强吸气**可至 **−100 ~ −30 mmHg（≈ −13.3 ~ −30 kPa）**；
  * **强呼气**可至 **+60 ~ +140 mmHg（≈ 7.98 ~ 18.62 kPa）**。
* **胸膜腔内压 Ppl**：通常为**负压**

  * 平静呼气末 **≈ −5 ~ −3 mmHg**；平静吸气末 **≈ −10 ~ −5 mmHg**。
  * **形成机制**：肺回缩力（elastic recoil）与肺内压对脏层胸膜的共同作用；胸膜腔为“密闭潜在腔”，浆液**润滑 + 内聚**维持胸膜贴附。
  * **意义**：牵引并维持肺扩张（肺随胸廓运动）；促进胸腔内**静脉与淋巴回流**。
  * **气胸 pneumothorax**：胸膜破损，空气进入胸膜腔 → 负压消失，肺萎陷。

## 四、肺通气阻力与顺应性（Compliance）

### 1. 弹性阻力与顺应性

* **顺应性 compliance, C**：反映容积器官在外力作用下的变形难易，
  **C = ΔV/ΔP（L/kPa） = 1/弹性阻力**。
* **肺弹性阻力来源**：

  1. **肺组织弹力纤维**（约 **1/3**）；
  2. **肺泡表面张力 surface tension**（约 **2/3**）。

### 2. 肺泡表面张力与肺表面活性物质（Surfactant）

* **表面张力**：气-液界面液体分子内聚使肺泡趋于缩小 → 增加吸气所需功。
* **拉普拉斯定律 Laplace**：**P = 2T / R**（P：回缩压；T：表面张力；R：半径）。
* **肺表面活性物质 pulmonary surfactant**

  * 来源：**Ⅱ型肺泡上皮细胞**；
  * **主要成分**：**二软脂酰卵磷脂 DPPC**（双极性分子，单分子层分布，随肺泡张缩密度改变，更新快）；
  * **生理作用**：

    * **显著降低表面张力**（约降至原来的 **1/7**）；
    * **稳定大小肺泡**（调节回缩力、维持肺内压相对稳定）；
    * **减弱毛细血管滤过**，防止组织液生成与**肺水肿 pulmonary edema**。

### 3. 胸廓弹性阻力

* 胸廓自然容积 ≈ **TLC 的 67%**：当实际容积 **< 自然容积** 时，构成**呼气阻力**；当 **> 自然容积** 时，构成**吸气阻力**。

### 4. 非弹性阻力

* **气道阻力 airway resistance**：气体流经呼吸道的摩擦；
* **惯性阻力 inertial**（气流变速/变向）；**黏滞阻力 viscous**（器官移位等）。

## 五、肺容积与肺容量（Pulmonary Volumes & Capacities）

### 1. 基本肺容积（静态指标）

* **潮气量 VT, tidal volume**：平静一次吸/呼出量，成人 **≈0.4–0.6 L**（VT中：膈肌≈**3/4**，肋间肌≈**1/4**）。
* **补吸气量 IRV**：平静吸气末再尽力吸入的量，成人 **≈1.5–2.0 L**（吸气储备）。
* **补呼气量 ERV**：平静呼气末再尽力呼出的量，成人 **≈0.9–1.2 L**（呼气储备）。
* **余气量 RV**：最大呼气末肺内残留量，成人 **≈1.0–1.5 L**（约占TLC **25–32%**）。

### 2. 肺容量（由两种以上容积构成）

* **功能余气量 FRC**：平静呼气末肺内余留气量，成人 **≈2.5 L**。
* **肺活量 VC**：最大深吸后尽力深呼所能呼出的最大量，成人 **≈2.5–4.0 L**。
* **肺总量 TLC**：最大深吸末肺内气体总量，成人 **≈3.5–5.0 L**。
* **用力呼气量 FEV（常指 FEV₁）**：最大深吸后尽力、尽快呼气前几秒内的呼出量；常以占VC的百分比反映**动态气道阻力**与**肺容量**变化。

## 六、通气量与肺泡通气量（Alveolar Ventilation）

* **每分通气量 (\dot V_E)**：**VT × f**（约 **6–8 L·min⁻¹**；VT **400–500 mL**，f **12–18 次·min⁻¹**）。
* **最大通气量 maximal voluntary ventilation, MVV**：**70–120 L·min⁻¹**。
* **无效腔 dead space**

  * **解剖无效腔 anatomical DS**：约 **150 mL**；
  * **肺泡无效腔 alveolar DS**；
  * **生理无效腔 physiological DS = 解剖 + 肺泡**。
* **肺泡通气量 (\dot V_A)**：**(VT − DS) × f**

  * 例（DS 取 150 mL）：

    * **正常安静**：VT 500, f 12 → (\dot V_E = 6000) mL/min，(\dot V_A = 350×12 = 4200) mL/min；
    * **浅快呼吸**：VT 250, f 24 → (\dot V_E = 6000) mL/min，(\dot V_A = 2400) mL/min；
    * **深慢呼吸**：VT 1000, f 6 → (\dot V_E = 6000) mL/min，(\dot V_A = 5100) mL/min。
  * **结论**：在一定频率范围内，**深而慢**比**浅而快**更有效。

## 七、肺换气与组织换气（Gas Exchange）

### 1. 气体扩散原理（Fick 思路）

* **驱动力**：**分压差 ΔP (partial pressure gradient)**；
* **扩散速率 (D)** 受：**ΔP、面积 A、溶解度 s、温度 T、扩散距离 d、分子量的平方根 √MW** 影响。
* **相对扩散**：**D_{CO₂} : D_{O₂} ≈ 20 : 1** → 更易发生 **O₂ 扩散障碍**致缺氧。

### 2. 体内各部位典型分压（kPa / mmHg）

| 部位                                                                         | **P_{O₂}**     | **P_{CO₂}**    |
| ---------------------------------------------------------------------------- | -------------- | -------------- |
| 空气 (Air)                                                                   | **21.2 / 159** | **0.04 / 0.3** |
| 肺泡气 (Alveolar gas)                                                        | **13.9 / 105** | **5.3 / 40**   |
| 混合静脉血 (Mixed venous)                                                    | **5.3 / 40**   | **6.1 / 46**   |
| 动脉血 (Arterial)                                                            | **13.3 / 100** | **5.3 / 40**   |
| 组织 (Tissue)                                                                | **4.0 / 30**   | **6.7 / 50**   |
| **方向**：肺部——O₂：肺泡→血；CO₂：血→肺泡。组织——O₂：血→组织；CO₂：组织→血。 |                |                |

### 3. 影响肺换气的关键因素

* **呼吸膜 thickness（肺泡膜厚度）**：厚度↑ → 扩散↓；
* **呼吸膜面积 area**：面积↓（如肺气肿）→ 扩散↓；
* **通气/血流比 V/Q**：

  * 正常均值约 **0.84**；
  * **V/Q > 0.84**：**肺泡无效腔**↑（通气相对多，灌注少）；
  * **V/Q < 0.84**：**功能性动-静脉短路 shunt-like**（灌注相对多，通气少）→ 未充分氧合的静脉血混入动脉血。
* **通气与血流分布不均**：肺自上而下 **V/Q 差异明显**（受重力）。

### 4. 影响组织换气的因素

* **代谢水平**：组织代谢↑ → 温度↑、O₂消耗↑、CO₂生成↑ → 分压差增大，交换↑；
* **微循环状态**：血流速度/量、毛细血管通透性影响交换；
* **交换距离**：如**水肿 edema** ↑ 组织-毛细血管距离 → 交换受限。

## 八、易错与高频考点小结

* **主动力**是**Palv 与大气压差**，**Ppl为负压**是肺随胸廓运动的重要条件；
* **膈肌**主导平静吸气（≈70%）；
* **表面活性物质**关键成分 **DPPC**，显著降表面张力（≈1/7），并**稳定大小肺泡**；
* **D_{CO₂} ≫ D_{O₂}**（≈20倍），临床更常见的是**O₂扩散受限**问题；
* **V/Q 失衡**双向都可致低氧血症：**V/Q高**→无效腔↑；**V/Q低**→“分流样”效应；
* **深慢呼吸**提升**肺泡通气**效果优于**浅快**。

## 九、重点英文单词（便于复习）

* 呼吸：**Respiration**
* 外/内呼吸：**External / Internal respiration**
* 肺通气：**Pulmonary ventilation**
* 肺换气：**Gas exchange (alveolar-capillary)**
* 气体运输：**Gas transport**
* 膈肌：**Diaphragm**；肋间外/内肌：**External/Internal intercostals**
* 肺内压：**Intrapulmonary (alveolar) pressure, P_alv**
* 胸膜腔内压/胸内负压：**Intrapleural pressure, P_pl**
* 弹性/非弹性阻力：**Elastic / Non-elastic resistance**
* 顺应性：**Compliance (C = ΔV/ΔP)**
* 表面张力：**Surface tension**；拉普拉斯定律：**Laplace law (P = 2T/R)**
* 肺表面活性物质：**Pulmonary surfactant (DPPC)**
* 潮气量/补吸气量/补呼气量/余气量：**VT / IRV / ERV / RV**
* 功能余气量/肺活量/肺总量：**FRC / VC / TLC**
* 用力呼气量：**FEV (commonly FEV₁)**
* 每分通气量/肺泡通气量：**Minute ventilation (\dot V_E) / Alveolar ventilation (\dot V_A)**
* 无效腔：**Dead space (anatomical / alveolar / physiological)**
* 通气-血流比：**V/Q ratio**
* 分压：**Partial pressure**；混合静脉血：**Mixed venous blood**；动脉血：**Arterial blood**；组织：**Tissue**。
