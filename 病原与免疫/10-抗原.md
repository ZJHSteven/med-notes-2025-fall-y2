# 抗原（Antigen, Ag）

## 一、学习目标（来自老师预习大纲）

1. **掌握**：抗原、半抗原、表位的概念；抗原的基本性质；抗原的异物性与特异性。
2. **熟悉**：影响抗原特异性的因素；表位—载体作用。
3. **了解**：共同抗原表位与交叉反应。
4. **熟悉**：影响抗原免疫应答的因素（抗原本身、宿主、免疫途径/剂量/时间、佐剂）。
5. **熟悉**：抗原的分类（按是否依赖Th；与宿主亲缘关系；在APC内来源）。
6. **了解**：非特异性免疫刺激剂（超抗原、丝裂原、佐剂）。 

---

## 二、核心概念与术语

* **抗原（Antigen, Ag）**：能被 **TCR/BCR** 特异识别并结合，诱导 **适应性免疫应答**（激活T/B细胞、抗体产生），且与效应产物（活化T/B细胞或抗体）发生特异性结合的物质。广义上凡能激活并诱导免疫应答者皆可称为抗原。📌相关：**Tolerogen（耐受原）**、**Allergen（变应原）**。
* **免疫原性（Immunogenicity）**：诱导产生适应性免疫应答的能力。
* **免疫反应性/抗原性（Immunoreactivity/Antigenicity）**：与其诱导产生的效应物（活化T/B细胞或抗体）**特异性结合**的能力。
* **完全抗原（Complete antigen）**：同时具备免疫原性与免疫反应性（如**蛋白质、病原体、动物血清**）。
* **半抗原（Hapten）**：仅具免疫反应性，**无免疫原性**；与**载体蛋白**偶联后可获得免疫原性。
* **抗原表位（Epitope/Antigenic determinant）**：决定特异性的最小结构与功能单位；**天然大分子多为多价抗原**，半抗原常为**单价**。
* **共同抗原表位（Common epitope）** 与 **交叉反应（Cross-reaction）**：不同抗原中存在相同/相似表位→已产生的抗体/活化淋巴细胞可与之反应，出现**交叉反应**。
* **TD-Ag（胸腺依赖性抗原）** 与 **TI-Ag（非胸腺依赖性抗原，含TI-1/TI-2）**：是否需要Th辅助。
* **SAg（超抗原，Superantigen）**：极低浓度（1–10 ng/mL）即可**多克隆**激活T细胞库2%~20%，免疫应答强烈、可致严重病理后果。
* **佐剂（Adjuvant）**：与抗原同用或预用，**增强**免疫应答或**改变应答类型**的非特异性增强物质。

**T细胞表位 vs B细胞表位（高频对比）**

| 特性                                     | T细胞表位                                 | B细胞表位                                               |
| ---------------------------------------- | ----------------------------------------- | ------------------------------------------------------- |
| 识别受体                                 | **TCR**                                   | **BCR/抗体**                                            |
| 是否需MHC提呈                            | **必需**（APC加工后呈递）                 | **不需要**                                              |
| 性质                                     | **蛋白多肽（线性）**                      | **多为构象表位**，也可线性；可为蛋白/多糖/脂多糖/核酸等 |
| 大小                                     | **8–10 aa（CD8+）**；**13–17 aa（CD4+）** | **5–15 aa**或**5–7个单糖/核苷酸**                       |
| 位置                                     | 抗原分子**任意部位**                      | 抗原分子**表面**                                        |
| （口诀：**“T要提（呈），B要表（面）”**） |                                           |                                                         |

## 三、抗原的分子基础与性质（Specificity & Molecular basis）

1. **特异性（Specificity）**

* “**锁钥关系**”：抗原与受体/抗体的高度互补性决定免疫诊断与治疗的基础。
* **表位类型**：**线性表位**（顺序片段）与**构象表位**（非线性、空间决定）。B细胞多识别构象表位；T细胞仅识别由APC加工后的**线性肽段**。

2. **半抗原—载体效应（Hapten–carrier effect）**（考点+临床）

* 半抗原则**激活B细胞**；**载体蛋白**提供**CD4+T细胞表位**激活Th→促B细胞**同种型转换/亲和力成熟/记忆形成**。
* **药物过敏机制**：低分子**药物半抗原**与**血细胞膜/血浆蛋白**（载体）结合→获得免疫原性→**溶血性贫血、粒细胞减少、血小板减少性紫癜**等；常见：**青霉素、磺胺、奎尼丁、氯丙嗪、氨基比林、非那西汀**等。

3. **共同表位与交叉反应（Common epitope & Cross-reaction）**

* **实例**：

  * **A族溶血性链球菌**细胞壁 与 **人心肌间质/心瓣膜/肾小球基底膜**存在共同表位→**风湿热、急性肾小球肾炎**。
  * **牛痘—天花**：利用**交叉抗原**进行免疫保护（**Cowpox→Smallpox**）。
* **意义**：

  * 病原体免疫应答可导致**自身组织损伤**（分子模拟）。
  * 诊断/鉴定需**排除交叉反应干扰**。
  * **可用交叉抗原替代**实际抗原制备疫苗。

## 四、影响抗原“免疫原性”的因素（大考点）

### A. 抗原本身的理化与结构性质

* **异物性（Foreignness，本质）**：

  * 来自**异种** ＞ **同种不同个体** ＞ **改变的自身成分** ＞ **胚胎期免疫细胞未接触的自身成分**（隔离抗原）。
* **化学属性**：**蛋白/大分子有机物**最强；**多糖/多肽**次之；**脂类/核酸**通常弱或无，**构象改变/化学修饰**后可获免疫原性。
* **分子量**：一般 **≥10 kDa** 方具较好免疫原性；**分子量越大越强**。
* **结构复杂性**：**芳香族氨基酸（Phe/Trp/Tyr）**越多→免疫原性越强。

  * 反例：**明胶**（100–150 kDa，**重复结构简单**）几乎**无免疫原性**；**胰岛素**（5.7 kDa，**富芳香族aa**）免疫原性反而**较强**。
* **分子构象/易接近性/物理状态**：颗粒性、难降解、可持续刺激者→应答更强。

### B. 抗原进入机体的方式

* **剂量（Dose）**：过低/过高均可致**免疫耐受**（低带/高带耐受）。
* **途径（Route）**（诱导容易程度）：**皮内 id ＞ 皮下 sc ＞ 肌注 im ＞ 静脉 iv ＞ 腹腔 ip ＞ 口服 po**。
* **免疫次数与间隔**、**佐剂应用**：合理加成免疫原性。
* 典型思考：

  1. **日常食物**多经消化与口服耐受机制→**通常不致显著应答**；
  2. **部分药物注射前需皮试**而口服不需；
  3. **疫苗接种**应结合最佳**途径/剂量/佐剂**与**程序**设计。

### C. 宿主因素

* **遗传背景（MHC等位基因）**：决定抗原递呈与T细胞反应能力的**个体差异**。
* **年龄**：青壮年＞幼/老；**新生儿对多糖类抗原应答差**。
* **性别**：雌性更易诱导抗体，**自身免疫病**发生率相对更高。
* **健康状态**：感染、免疫抑制剂使用等均显著影响应答强度与类型。

## 五、抗原的分类

### 1）按诱生抗体是否需要Th细胞参与

* **TD-Ag**：需Th辅助（**外毒素、白喉毒素、病毒血凝素**等）；可诱导**体液+细胞免疫**，产生**IgM/IgG/IgA**，有**免疫记忆**；激活**B2细胞**；**MHC限制性**。
* **TI-Ag**：无需Th辅助，仅**体液免疫**，多产生**IgM**，**无记忆**；激活**B1细胞**；**无MHC限制**。

  * **TI-1**：如**LPS/细菌多糖**，多诱导低亲和力IgM；
  * **TI-2**：**重复表位**显著（如**肺炎链球菌荚膜多糖、沙门菌多聚鞭毛**）。
    **TD vs TI（速记表）**
    | 维度            | TD-Ag                   | TI-Ag             |
    | --------------- | ----------------------- | ----------------- |
    | 结构/表位       | **复杂**，含**T+B表位** | **重复B表位**为主 |
    | T细胞辅助 / MHC | **需要 / 有**           | **不需要 / 无**   |
    | 激活B细胞       | **B2**                  | **B1**            |
    | 应答类型        | **体液+细胞**           | **体液**          |
    | 抗体类型        | **IgM→IgG/IgA**         | **IgM为主**       |
    | 记忆            | **有**                  | **无**            |

> 注：**TD抗原 = 半抗原表位（B细胞表位） + 载体表位（T细胞表位）**，体现“**表位—载体**”协同。

### 2）按与机体的亲缘关系

* **异嗜性抗原（Heterophilic/Forssman Ag）**：**跨物种**共同抗原（人/动物/植物/微生物均可见）；如**大肠埃希菌O14 LPS**与**人结肠黏膜**；**A族溶链菌**与**人心肌/心瓣膜/肾小球基底膜**。
* **异种抗原（Xenogenic）**：来自**其他物种**；如病原体、**外毒素/类毒素/抗毒素**；马抗毒素既是**特异抗体**又是**异种抗原**。
* **同种异型抗原（Allogenic）**：**同种不同个体**；如**ABO、Rh**血型系统，**MHC/HLA**。
* **自身抗原（Autoantigen）**：**改变/修饰的自身成分**或**隔离抗原释放**（如甲状腺球蛋白、精子、晶状体蛋白）；**肿瘤突变新生抗原/新生表位（Neoantigen/Neoepitope）**。

### 3）按在APC内的来源

* **内源性抗原（Endogenous）**：在APC内合成（如**病毒蛋白、肿瘤抗原**），经**胞质加工→MHC I**呈递，供**CD8+ T**识别。
* **外源性抗原（Exogenous）**：来自细胞外（**细菌/蛋白**），经**内吞/溶酶体降解→MHC II**呈递，供**CD4+ T**识别。

## 六、非特异性免疫刺激剂（重点：SAg/佐剂/丝裂原）

### 1）超抗原（Superantigen, SAg）

* **特点**：**极低浓度**、**多克隆激活**（T细胞库**2%–20%**）、**无需抗原加工**、**不受MHC限制**、大量细胞因子释放→**毒素性休克**等。
* **例子**：**金黄色葡萄球菌肠毒素（SEA/SEB）**、**葡萄球菌蛋白A（SPA）**、**链球菌致热外毒素**；**HIV**等可有**内源性超抗原**样作用。
* **生物学意义**：与**T细胞耐受**、**免疫病**（风湿性关节炎、AIDS免疫紊乱等）相关。

### 2）佐剂（Adjuvant）

* **定义**：非特异性增强或改变免疫应答类型。
* **类别**：

  * **生物性**：**卡介苗（BCG）**
  * **无机**：**氢氧化铝 Al(OH)₃**
  * **人工合成**：**poly I:C**、脂质体等
  * **经典**：**弗氏完全佐剂（CFA）/不完全弗氏佐剂（IFA）**
* **机制**：改变抗原**理化性状**、**延缓降解/延长滞留**；增强**APC处理/呈递**；**非特异性促淋巴细胞增殖分化**。

### 3）丝裂原（Mitogen）

* **体外**与T/B受体结合→48–72 h使静息淋巴细胞**转化为母细胞**（增大/增殖）。
* **T细胞丝裂原**：**ConA（刀豆蛋白A）**、**PHA（植物血凝素）**、**PWM（美洲商陆）**
* **B细胞丝裂原**：**LPS（针对小鼠）**、**PWM**、**SPA**
* **实验**：**淋巴母细胞转化试验（LTT）**用于功能评估。

## 七、临床相关与思考

* **链球菌后并发症**：共同表位→**风湿热/急性肾小球肾炎**的免疫学基础（分子模拟/交叉反应）。
* **药物过敏与血细胞减少**：半抗原—载体效应导致**溶血/粒细胞减少/血小板减少性紫癜**。
* **肿瘤免疫学**：多数肿瘤免疫原性弱；策略包括**佐剂优化、递呈增强（如DC疫苗）、多表位/新生表位疫苗、途径/程式优化**等。
* **接种策略**：依据**剂量—耐受曲线**、**途径梯度**、**佐剂**与**宿主因素**制定。

## 八、易考对比/易错点速记

1. **T表位与B表位**：**T要MHC提呈且识别线性肽；B识别表面构象为主**。
2. **TD vs TI**：是否**需Th**、**是否有记忆**、**抗体谱**（TI多IgM）。
3. **免疫原性强弱**：大分子/结构复杂/芳香族aa多/难降解/颗粒性 → **更强**；**明胶**为典型**反例**。
4. **剂量与耐受**：**过低/过高**均可能诱导耐受（低带/高带）。
5. **途径强度**：**id > sc > im > iv > ip > po**。
6. **异嗜性抗原 ≠ 异种抗原**：前者是**跨物种“共同表位”**的概念；后者是**来源于他种**。

## 九、重点英文单词（高频中英对照）

* Antigen（Ag） 抗原；**Immunogenicity** 免疫原性；**Immunoreactivity/Antigenicity** 免疫反应性/抗原性
* **Complete antigen** 完全抗原；**Hapten** 半抗原；**Carrier** 载体
* **Epitope/Antigenic determinant** 表位/抗原决定基；**Common epitope** 共同表位；**Cross-reaction** 交叉反应
* **Thymus-dependent antigen (TD-Ag)** 胸腺依赖性抗原；**Thymus-independent antigen (TI-Ag)** 非胸腺依赖性抗原
* **TI-1/TI-2 antigens** TI-1/TI-2抗原；**B1/B2 cells** B1/B2细胞
* **Endogenous/Exogenous antigen** 内源性/外源性抗原
* **Superantigen (SAg)** 超抗原；**Staphylococcal enterotoxin (SEA/SEB)** 金葡菌肠毒素；**Staphylococcal protein A (SPA)** 葡萄球菌蛋白A
* **Adjuvant** 佐剂；**Complete/Incomplete Freund’s adjuvant (CFA/IFA)** 完全/不完全弗氏佐剂；**Al(OH)₃** 氢氧化铝；**poly I:C** 聚肌胞
* **Mitogen** 丝裂原；**Concanavalin A (ConA)** 刀豆蛋白A；**Phytohemagglutinin (PHA)** 植物血凝素；**Pokeweed mitogen (PWM)** 美洲商陆
* **Major Histocompatibility Complex (MHC)** 主要组织相容性复合体；**HLA** 人类白细胞抗原
* **Neoantigen/Neoepitope** 新生抗原/新生表位；**Molecular mimicry** 分子模拟
* **ADCC** 抗体依赖的细胞介导的细胞毒作用；**Opsonization** 调理作用；**Tolerance** 免疫耐受

## 十、可直接用于背诵的微型总结

* **一句话**：**Ag** = 能被 **TCR/BCR** 识别并诱导应答、且与效应产物特异结合的（多为**大分子蛋白**）物质；**免疫原性**由**异物性、化学性质、分子量、结构复杂性、构象/可及性、物理状态**及**剂量/途径/佐剂/宿主**等共同决定。
* **两组对比**：**T（线性+MHC）vs B（表面构象）**；**TD（需Th、有记忆、多IgG/IgA）vs TI（不需Th、无记忆、IgM）**。
* **三大实例**：**半抗原—载体**（药物血液学不良反应）、**共同表位—交叉反应**（链球菌后并发症，牛痘→天花）、**SAg**（SEA/SEB→细胞因子风暴）。
