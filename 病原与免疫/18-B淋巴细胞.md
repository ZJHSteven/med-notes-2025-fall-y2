# 总览与定位（Innate vs. Adaptive）

* 免疫体系分为**固有免疫（innate immunity）**与**适应性免疫（adaptive immunity）**两大部分。

  * 固有免疫：组织屏障（tissue barriers）、固有免疫分子与细胞（innate immune molecules/cells）。
  * 适应性免疫：**T 细胞**介导的**细胞免疫（cellular immune response）**与**B 细胞**介导的**体液免疫（humoral immune response）**。
* **本章主题**：B 细胞的发生与分化、表面分子、亚群与功能。

## 一、B 细胞的发生（Development of B Lymphocytes）

**发生部位**：骨髓（bone marrow）。
**阶段顺序**：**Pro-B → Pre-B → 未成熟 B（immature B）→ 成熟 B（mature B）**。
**关键结果**：

* **BCR 的生成（generation of BCR）**。
* **自我耐受（self tolerance）**的建立（中心耐受等）。

**表面免疫球蛋白的变化**：

* **未成熟 B 细胞**：膜表**mIgM** 为主。
* **成熟 B 细胞**：**mIgM 与 mIgD 共表达（co-expression）**，是成熟的标志。
* **浆细胞（plasma cell）**：**表面不再表达 mIg**（但分泌可溶性抗体）。

**BCR 与抗体特异性一致**：

* 初始（naïve）→ 活化（active）转变后，B 细胞分泌**抗体**，其**抗原特异性与该细胞表面的 BCR 完全相同**（“分泌版 BCR”）。

> 复习提示：考试常问“成熟 B 细胞的表面 Ig 型式是什么？”答：**mIgM + mIgD 共表达**；“浆细胞是否有表面 Ig？”答：**无**。

## 二、B 细胞表面分子（Surface Molecules of B Lymphocytes）

**四大类**：

1. **B 细胞抗原受体复合物（BCR complex）**
2. **共受体（B-cell coreceptor）**
3. **共刺激分子（costimulatory molecules）**
4. **其他表面分子（other surface molecules）**

### 2.1 BCR Complex

* **抗原结合部分**：膜结合免疫球蛋白 **mIg**（含 **VH + VL** 区域，决定抗原结合特异性）。
* **信号转导部分**：**Ig-α（CD79a）/ Ig-β（CD79b）**异二聚体，胞内带 **ITAM（免疫受体酪氨酸激活基序）**，与 mIg 非共价结合，将受体信号传入细胞内。

> 考点关键词：**mIg + Ig-α/Ig-β + ITAM** = BCR 的**识别 + 传导**两部分。

### 2.2 B 细胞共受体（B-cell coreceptor）

* 组成：**CD19 / CD21 / CD81** 复合物。
* 作用：

  * **增强初始 B 细胞对抗原刺激的敏感性**（可提高 10^2–10^3 倍）。
  * 与 Ig-α/Ig-β **协同传导第一信号**。
* **CD21** 别名与生物学意义：**CR2（C3d 受体）**，也是**EB 病毒受体**。

> 记忆法：CD19 定义 B 细胞身份；CD21“连补体（C3d）与病毒（EBV）”；CD81 作跨膜支架稳定复合体。

### 2.3 B 细胞活化的“双信号”模型

* **第一信号**：**BCR 识别抗原（Ag）**，并由 **CD19/CD21/CD81** 共受体**放大/协同**。
* **第二信号（共刺激）**：

  * **CD40（B 细胞）– CD40L（活化 Th 细胞）**：**B 细胞最重要的第二信号**来源。
  * **B7-1（CD80）/ B7-2（CD86）**（表达于 DC、巨噬细胞、B 细胞等专业 APC；表达可被 **LPS、IFN-γ 或 CD40-CD40L 结合**上调）：

    * 配体：**CD28（初始/活化 T）**促进效应化；**CTLA-4（活化 T）**负向调控。
  * **细胞黏附分子（CAM）**：**ICAM-1（CD54）/ LFA-1（CD11a/CD18）** 介导黏附并**协同刺激**。

> 易混点：B7 家族主要“喂给 T 细胞的第二信号”，但 B 细胞作为 APC 也表达 B7，与 T 细胞 **CD28/CTLA-4** 互作；B 细胞自身“最关键”的共刺激还是 **CD40–CD40L**。

### 2.4 其他重要表面分子（临床/机制）

* **CD19**：B 细胞**特异性标志**；CAR-T/单抗**治疗 B 细胞恶性肿瘤**的重要靶点。
* **CD20**：除浆细胞外几乎贯穿所有分化期 B 细胞；**利妥昔单抗（Rituximab）**治疗 **非霍奇金淋巴瘤、慢性淋巴细胞白血病**等的靶分子。
* **CD22**：胞内含 **ITIM**，**负向**调节 **CD19/CD21/CD81** 信号。
* **CD32（FcγRII）**：**负调节** B 细胞活化与抗体分泌。

> 高频整合图：课件对比了 **B 细胞**（mIg、Ig-α/β、CD19/21/81、CD40）与 **T 细胞**（TCR、CD3、CD4/8、CD28）两套“**第一信号 + 第二信号**”体系，理解类比可快速记忆。

## 三、B 细胞亚群（Subsets of B Lymphocytes）

### 3.1 按活化阶段

* **初始 B 细胞（naïve B cell）**：未遇抗原。
* **效应 B 细胞（effector B cell/浆细胞）**：抗体主要来源，介导体液免疫。
* **记忆 B 细胞（memory B cell）**：再次应答**更快、更强、更特异**。

### 3.2 按反应特异性/免疫属性

* **B1 细胞（innate-like B cell）**

  * 占 B 细胞总数 **5–10%**；**胎肝**起源，具**自我更新**能力。
  * 分布：**腹膜腔、胸膜腔、肠道黏膜固有层**。
  * 识别谱：**窄**（多为 **TI 抗原、自身抗原**）。
  * 功能：

    * 产生**针对细菌多糖**的抗体，**无需 Th 辅助**，**不发生类别转换、无免疫记忆、无再次应答**。
    * 产生**低亲和力、多反应性 IgM**；分泌**天然抗体**（如抗 LPS）。
    * 可被自身抗原刺激产生**致病性自身抗体**，参与自身免疫病。
* **B2 细胞（常规 B 细胞，conventional B cell）**

  * 出现较晚，定位于**外周淋巴器官**。
  * 识别谱：**广**（主要识别 **TD 抗原**）。
  * 功能：在抗原与 **Th 辅助**下分化为浆细胞，产生**以 IgG 为主的高亲和力抗体**；**发生类别转换、体细胞高频突变/亲和力成熟、形成免疫记忆/再次应答**；并能**提呈抗原**、**分泌细胞因子**进行免疫调节。

### 3.3 B1 vs B2 对照记忆表

| 性质           | **B1**                     | **B2**         |
| -------------- | -------------------------- | -------------- |
| 更新方式       | **自我更新**               | **骨髓产生**   |
| 自发 Ig 产生   | **高**                     | **低**         |
| 抗原类型       | **多为碳水化合物（多糖）** | **多为蛋白质** |
| Ig 类别        | **IgM > IgG**              | **IgG > IgM**  |
| 特异性         | **多反应性**               | **高特异性**   |
| 体细胞高频突变 | **低/无**                  | **高**         |
| 免疫记忆       | **少/无**                  | **有**         |

> 速背：**“B1 糖 IgM，B2 蛋白 IgG；B1 先天多反应，B2 适应特异精。”**

## 四、B 细胞的功能（Functions of B Lymphocytes）

1. **产生抗体（production of antibody）**

   * 浆细胞分泌抗体，中和毒素/病毒、调理吞噬、激活补体等。
2. **抗原提呈（antigen presentation to T cells）**

   * B 细胞作为 APC，经受体介导内吞处理抗原，**MHC II** 提呈给 **CD4⁺ T**，并通过 **B7–CD28、CD40–CD40L** 等轴线相互活化。
3. **免疫调节（immune regulation）**

   * 分泌细胞因子，调节免疫反应强度与方向；（拓展）特定亚群如 **Breg（调节性 B 细胞）**在免疫耐受、自身免疫病等中具有重要作用。

> 考点联想：CD20 单抗（利妥昔单抗）去除部分 B 细胞 → 影响抗体产生与抗原提呈 → 与感染风险、疫苗应答相关的临床推断题常见。

# 速记与易错点小结

* **成熟 B 细胞标志**：表面 **mIgM + mIgD 共表达**。
* **B 细胞最关键的第二信号**：**CD40–CD40L**；但 B 细胞也可通过 **B7 → T 细胞的 CD28/CTLA-4** 参与 T 细胞共刺激。
* **CD21 三位一体**：**CR2（C3dR）= EBV 受体**。
* **B1 与 B2**：TI/TD、IgM/IgG、是否记忆与 SHM、抗原类型（糖/蛋白）一一对应。
* **临床延伸**：**CD20** 为单抗治疗热点；**CD19** 为 CAR-T 经典靶点；**CD22/CD32** 为负调节节点。
