# 课堂笔记：疱疹病毒科（Herpesviridae）→逆转录病毒科（Retroviridae）→HIV/AIDS（严格按讲课顺序）

---

## 一、疱疹病毒科总述：有包膜的双链DNA病毒（enveloped dsDNA virus）

### 1）词源与皮损分布特点

* 【词源/举例】**Herpes** 来自希腊语 *herpein*（“爬行”），用来形容疱疹皮损**沿皮肤“爬行式/蔓延式”分布**的趋势；后面讲到**带状疱疹（zoster）**时会更典型。

### 2）【考点】疱疹病毒的“潜伏感染”（latent infection）

* 病毒感染类型复习：除**急性感染（acute infection）**外，还可有**持续性感染（persistent infection）**；持续性感染中一个重要类型是**潜伏感染（latency）**。
* 疱疹病毒是“潜伏感染”的代表：

  1. 病毒侵入机体 → 先有**原发感染（primary infection）**（可隐性/显性）。
  2. 免疫系统/药物**难以彻底清除** → 残留病毒进入特定组织**潜伏**。
  3. 机体与病毒暂时“平衡共处”；当**免疫力下降**或受刺激（感染、淋雨、日晒、经期、焦虑等）→ 病毒**再激活（reactivation）**、再复制 → **复发感染（recurrent infection）**。
  4. 往往表现为“潜伏—复发—再潜伏”的反复过程，**可终生携带**。
* 【应试提示】问“哪些病毒能引起潜伏感染？”优先想到：**疱疹病毒科**相关成员。

### 3）人类疱疹病毒（Human herpesvirus, HHV）

* 疱疹病毒科成员可>100种，但与人类疾病明确相关者主要为 **8种**（统称 **HHV-1 ~ HHV-8**）。
* 常用俗名对应（老师强调前五种要重点掌握）：

  * **HHV-1**：单纯疱疹病毒1型 **HSV-1 (Herpes simplex virus type 1)**
  * **HHV-2**：单纯疱疹病毒2型 **HSV-2**
  * **HHV-3**：水痘-带状疱疹病毒 **VZV (Varicella-zoster virus)**
  * **HHV-4**：EB病毒 **EBV (Epstein–Barr virus)**
  * **HHV-5**：人巨细胞病毒 **CMV / HCMV (Human cytomegalovirus)**
  * **HHV-6/7/8**：多在20世纪80–90年代分离，研究相对少；部分与疾病关系仍在完善

    * 其中 **HHV-6**：按抗原性分 **HHV-6A、HHV-6B**（新版可算“9型”；与疾病更相关的是 **6B**）
    * **HHV-8**：与卡波西肉瘤相关（后述）

### 4）疱疹病毒科的3个亚科（Subfamily）及共同点

* **α疱疹病毒亚科（Alphaherpesvirinae）**

  * 宿主范围广：可感染人及多种动物；体外可感染多种细胞（如人胚肾、人胚肺等）。
  * 复制周期短、起病快；以**溶细胞性感染（lytic infection）**为主，细胞破坏明显。
  * 潜伏部位多在**神经元/神经节（neurons/ganglia）**
  * 代表：**HSV-1、HSV-2、VZV**
* **β疱疹病毒亚科（Betaherpesvirinae）**

  * 宿主范围较窄；复制周期较长。
  * 代表：**HCMV、HHV-6、HHV-7**
  * 【举例】HCMV：可致细胞肿大、核增大、细胞融合 → 多核巨细胞等改变；潜伏于多组织（如唾液腺、肾脏等）
  * HHV-6/7：可见与淋巴细胞增殖相关特点（潜伏多在T细胞），但基因测序归入β亚科
* **γ疱疹病毒亚科（Gammaherpesvirinae）**

  * 成员：**EBV、HHV-8**
  * 病变可致淋巴细胞增生；潜伏与感染靶细胞多为**B细胞（B lymphocyte）**

## 二、疱疹病毒科的共同生物学特征

### 1）形态结构（150–200 nm，中等大小）

* 球形（spherical），**有包膜（enveloped）**。
* 从内到外“四层结构”：

  1. **核酸**：**双链DNA（dsDNA）**，通常为**线性（linear）**；潜伏时可成**环状附加体（circular episome）**
  2. **衣壳（capsid）**：**20面体对称（icosahedral symmetry）**
  3. **内膜/基质层：Tegument（被膜/基质层）**

     * 连接衣壳与包膜，维持结构完整
     * 含多种蛋白（tegument proteins），参与复制调控

       * 【考点】提到 **VP16**：可启动疱疹病毒复制时**α基因（immediate-early/α gene）**转录
  4. **包膜（envelope）**：疱疹病毒相对特殊，包膜来源强调**核膜与高尔基体膜（nuclear membrane & Golgi）**（而非典型“细胞膜来源”）
* 包膜表面有多种**糖蛋白刺突（glycoprotein spikes）**，与吸附、致病、免疫逃逸等相关（后面HSV具体讲）

### 2）复制过程（以HSV为例，了解为主）

* 吸附：病毒与宿主细胞受体结合
* 进入：膜融合（fusion）→ 核衣壳入胞
* 入核：核衣壳与核膜相关过程 → 病毒DNA进入**细胞核（nucleus）**
* 复制/装配定位：

  * **转录、基因组复制、衣壳装配：在细胞核完成**
  * **蛋白翻译：在细胞质完成**
* 基因表达时序（【考点】三类蛋白/基因）：

  * **立即早期蛋白（immediate-early, α proteins / α genes）**：最早转录翻译；多为调控/结合DNA相关蛋白，激活后续基因表达
  * **早期蛋白（early, β proteins / β genes）**：多为酶、转录因子，如**DNA polymerase**，负责基因组复制
  * **晚期蛋白（late, γ proteins / γ genes）**：主要为结构蛋白（capsid/envelope相关），参与装配
* 出芽释放（budding）：装配后获得包膜，经内质网/高尔基体加工糖基化等，最终出芽释放

### 3）感染类型（老师强调常考）

* **急性感染/溶细胞性感染（acute/lytic infection）**
* **潜伏感染（latent infection）**：潜伏期无症状、病毒不复制、难检测；药物/免疫难作用于潜伏病毒
* **先天性感染（congenital infection）**：可经胎盘感染胎儿（如HSV、HCMV等）

  * 【举例/应试】提到孕期**TORCH筛查**思路：

    * **T**：Toxoplasma（弓形虫）
    * **R**：Rubella（风疹）
    * **C**：CMV（巨细胞病毒）/或广义“Cytomegalovirus”
    * **H**：HSV（单纯疱疹病毒）
    * **O**：Others（其他：如HBV、HIV等）

## 三、单纯疱疹病毒（HSV：Herpes simplex virus）

### 1）基本点

* 1922年首次发现；分**两种血清型（serotype）**：**HSV-1、HSV-2**
* 分型依据：基因组序列、限制性内切酶酶切谱等；两者基因组同源性约50%（老师口述）

### 2）α亚科特征与CPE（细胞病变效应，cytopathic effect）

* 复制快、溶细胞性强，CPE明显：细胞肿胀、变圆、脱落等
* 【举例/诊断思路】细胞培养对照可见：

  * 未感染：单层细胞完整、紧密连接
  * 感染后：细胞间隙增大、细胞变圆；可见**细胞融合（syncytium）→ 多核巨细胞（multinucleated giant cell）**
* 临床取病变**基底部**组织可做细胞学诊断（后面微生物学检查再讲）

### 3）包膜糖蛋白（≥11种）功能（【考点】）

* **吸附相关**：如 **gB、gC、gD、gH** 等帮助黏附/进入
* **诱导中和抗体（neutralizing antibody）**：如 **gD** 抗原性强，是疫苗研究候选；并且 **gD** 可用于HSV-1/2分型（抗原性差异较大）
* **免疫逃逸（immune evasion）**：

  * **gC**：作为补体 **C3b receptor**
  * **gE + gI**：形成复合物，充当 **IgG Fc receptor**
    → 与补体/抗体结合后，可阻断其抗病毒作用，帮助病毒逃逸

### 4）致病性：传染源与传播途径

* 传染源：患者 + 无症状排毒者（隐性感染者）
* 传播途径：**水平传播（horizontal）+ 垂直传播（vertical）**

  * HSV-1：多经**密切接触/呼吸道**等（老师表述）
  * HSV-2：多经**生殖道/性接触传播** → 属STD病原体
  * 垂直：两型均可经**胎盘**；经**产道**以HSV-2更常见

    * 【考点/数据】新生儿疱疹约 **75%** 与HSV-2产道传播相关（老师口述）

### 5）感染过程：原发→潜伏→复发（终生反复）

* 原发感染后残留病毒侵入皮肤神经末梢，沿神经纤维**逆行（retrograde transport）**到神经节建立潜伏
* 潜伏期：病毒基因组环状附加体存在，基本不复制 → 无症状、难检测
* 激活诱因（老师举例）：感冒/感染、淋雨、日晒、经期、焦虑等 → 病毒顺神经**下行**到支配皮肤处复发
* 复发特点：因已有体液/细胞免疫基础，通常**症状更轻、病程更短**，但仍会反复终生

### 6）【考点】潜伏部位（老师点名要背）

* **HSV-1**：**三叉神经节（trigeminal ganglion）**、**颈上神经节（superior cervical ganglion）**（老师口述）
* **HSV-2**：**骶神经节（sacral ganglia）**（老师口述）
* （老师强调：HSV-1/2 与后面的VZV潜伏部位都要重点记）

### 7）相关疾病

* HSV-1（腰部以上为主）：

  * 原发：**疱疹性龈口炎（herpetic gingivostomatitis）**
  * 复发：**口唇疱疹（herpes labialis）**（皮肤-黏膜交界常见，如口唇、鼻前庭等）
  * 严重：**疱疹性角膜炎（herpetic keratitis）**（可角膜瘢痕→失明；老师提到仅次于沙眼的重要感染性致盲因素之一）、**疱疹性脑炎（herpetic encephalitis）**（病死率高、儿童后遗症）
* HSV-2（腰部以下为主）：

  * **生殖器疱疹（genital herpes）**（STD）
  * 新生儿疱疹：轻则皮肤/黏膜/眼/口局部，重则脑炎或全身感染
* 先天性感染：可致流产、早产、死胎、先天畸形等

### 8）免疫性（immune response）

* 可诱导**体液免疫**（中和抗体限制扩散）+ **细胞免疫**（CTL杀伤感染细胞）
* 但【考点】两者都**不能清除潜伏病毒**，也不能阻止再激活 → 不能防复发

### 9）微生物学检查（诊断）

* **细胞学检查**：

  * 取病损基底部组织
  * 荧光标记抗体检测抗原（immunofluorescence）
  * 吉姆萨染色（Giemsa stain）观察CPE：如**嗜酸性胞涵体（inclusion body）**、**多核巨细胞/融合细胞**
* **核酸检测**：PCR
* **血清学**：IgM/IgG（IgM早期诊断意义，IgG偏流行病学/既往感染）
* **病毒分离培养**：可行（HSV复制快、CPE明显；2–3天出现病变）

### 10）防治

* 无成熟可用疫苗（有研制中如亚单位/核酸疫苗等）
* 轻型多可自限；重症（角膜炎、脑炎、生殖器疱疹等）需抗病毒：

  * 核苷（酸）类：**Acyclovir（阿昔洛韦）**、**Ganciclovir（更昔洛韦）**等（老师举例）
* 【关键提醒】药物可抑制复制、减轻症状，但**不能清除潜伏病毒**，仍可能复发

## 四、水痘-带状疱疹病毒（VZV：Varicella-zoster virus，HHV-3）

### 1）基本点

* 同属α亚科，生物学性状与HSV相似；但**只有1个血清型**
* 原发与复发对应两种不同疾病：

  * 原发感染 → **水痘（varicella）**
  * 潜伏后再激活 → **带状疱疹（herpes zoster）**

### 2）传播与流行特点

* 主要经**呼吸道传播**；也可因水痘疱液含大量病毒而**密切接触传播**
* 【数据/考点】未免疫易感者接触后约**90%显性感染**（老师口述）
* 因疫苗接种：儿童发病下降；但在某些年龄段（如青少年/青年）出现相对发病增多的情况（老师课堂观察）
* 我国：儿童1岁以上可接种水痘疫苗（老师口述）

### 3）体内过程与临床表现

* 体内可出现**两次病毒血症（viremia）**，第二次病毒血症病毒量高 → 播散全身皮肤黏膜
* 水痘皮疹特点：

  * 潜伏期约2–3周（老师口述）
  * **向心性分布（centripetal distribution）**：躯干多、四肢相对少
  * 皮疹演变：**斑疹→丘疹→水疱→脓疱→结痂→痊愈**
  * 一般不留瘢痕；注意皮肤卫生防继发感染
* 潜伏部位（【考点】）：

  * **背根神经节（dorsal root ganglia）**或**脑神经感觉神经节（sensory ganglia of cranial nerves）**（老师口述）
* 带状疱疹：

  * 多见成人；免疫力低下/细胞免疫下降时激活
  * 皮疹沿感觉神经支配区分布，疱疹融合成“带状”
  * **剧烈疼痛**突出 → 一般需抗病毒治疗
* 复发概率：约**10%–20%**水痘患者成年后可能出现带状疱疹（老师口述）

### 4）免疫与免疫逃逸

* 抗体可中和限制扩散，但对潜伏病毒无效，不能阻止复发
* 细胞免疫促进恢复
* 【考点】免疫逃逸：病毒产物可下调 **MHC I / MHC II** 表达 → 削弱CTL作用

### 5）防治

* 普通水痘多不需治疗；重症水痘/带状疱疹需抗病毒（核苷类：阿昔洛韦等；老师举例含“阿糖胞苷”等）
* **疫苗**：

  * 水痘：减毒活疫苗（live attenuated vaccine），≥1岁儿童
  * 带状疱疹：减毒活疫苗 + 重组蛋白疫苗（recombinant protein vaccine），多用于≥60岁或免疫较低人群
* 【举例/应试】暴露后紧急预防：易感者接触水痘患者，可用**VZV免疫球蛋白（VZV immunoglobulin）**降低发病或减轻症状；但对已经发生的带状疱疹无效（老师强调）

## 五、人巨细胞病毒（HCMV：Human cytomegalovirus，HHV-5）

### 1）【考点】先天性感染的重要病原体

* HCMV 是引起**先天性感染/先天畸形**的常见病毒之一（老师强调要会总结“哪类病原体与先天感染、肿瘤、性病、食物中毒”等）

### 2）生物学特点与CPE

* β亚科：宿主范围较窄；体外培养多感染**人成纤维细胞（human fibroblast）**
* 【诊断线索】核内可见巨大、周围有晕的**嗜酸性胞涵体**，外观像“**鹰眼（owl’s eye inclusion）**”

### 3）传播途径：多途径（老师强调“很广泛”）

* 可存在于血液、体液（唾液、乳汁等）
* 可经：密切接触、性接触、血液/血制品、器官移植、母婴传播等

### 4）与疾病：先天/围生期/儿童成人/免疫缺陷

* **先天性感染（congenital infection）**：经胎盘

  * 多强调孕前3个月感染风险
  * 原发 vs 复发（再激活）对胎儿感染率不同（老师给数字）：

    * 原发：胎儿感染率 **20%–40%**
    * 复发：胎儿感染率 **约0.2%–2.2%（或2%–2.5%）**
  * 在“被感染胎儿”中：仅 **5%–10%** 出现明显症状（老师口述）
  * 表现：**巨细胞包涵体病（cytomegalic inclusion disease）**

    * 肝脾肿大、黄疸、溶血性贫血、紫癜等
    * 可有神经系统损伤
    * 病死率可达 **20%**（老师口述）
    * 存活者可能遗留永久损伤：智力/学习障碍、先天性耳聋等
  * 复发感染所致：虽感染率低且多无症状（约90%–95%无症状），但其中约**~10%** 可能出现**晚期并发症/神经系统后遗症**（出生后数月到数年出现）
* **围生期感染（perinatal infection）**：产道/产后密切接触/哺乳等

  * 通常较轻，多无症状或短暂肝炎/肺炎，预后好、少后遗症
* 儿童/成人原发感染：多隐性感染；少数出现 **CMV单核细胞增多症（CMV mononucleosis）**
* 免疫低下/缺陷：可重症（肝炎、肺炎、视网膜炎等），是AIDS机会性感染重要病原体之一（老师强调“可致死”）

### 5）防治

* 无有效疫苗
* 重症可抗病毒（核苷类抑制复制）
* 近年主张**药物联用**：核苷类 + **抗CMV免疫球蛋白**（老师口述“临床显示效果更好”）

## 六、EB病毒（EBV：Epstein–Barr virus，HHV-4）

### 1）来源与分类

* 1964年由 Epstein 与 Barr 从非洲儿童恶性淋巴瘤（Burkitt淋巴瘤）组织培养细胞中分离 → 命名EBV
* 属 γ亚科：靶细胞/潜伏多在 **B细胞**

### 2）【考点】EBV抗原谱：增殖期 vs 潜伏期

* **增殖期（lytic phase）抗原**

  * **早期抗原（EA, early antigen）**：非结构蛋白，含DNA聚合酶等 → 活跃增殖标志
  * **晚期抗原**：结构蛋白，包括衣壳抗原/膜抗原等；其IgM等可用于感染监测（老师口述）
* **潜伏期（latent phase）抗原**

  * **EB核抗原（EBNA, Epstein–Barr nuclear antigen）**：多型（老师提到6种）

    * **EBNA-1**：DNA结合蛋白，稳定病毒环状附加体，避免随细胞增殖丢失
  * **潜伏膜蛋白（LMP, latent membrane protein）**：3型

    * **LMP-1**：被认为与细胞转化相关的“致癌蛋白”（oncoprotein），与EBV相关肿瘤（如鼻咽癌）有关

### 3）传播与致病过程

* 传播：主要经**唾液**，亦可性接触
* 过程（老师按步骤讲）：

  1. 病毒在咽部/唾液腺上皮细胞增殖
  2. 入血
  3. 侵袭淋巴组织B细胞，在B细胞内再增殖
  4. 再入血播散全身
* 原发感染多隐性
* 致病机制要点（老师口述）：

  * 病毒表达某些“类似白介素的分子”影响免疫（抑制T辅助细胞功能、阻止干扰素释放、抑制T细胞功能等）
  * 促进B细胞增殖
  * 可将基因组整合入宿主染色体（老师表述），细胞转化后在多因素作用下可形成肿瘤

### 4）与疾病的关系

* **传染性单核细胞增多症（Infectious mononucleosis, IM）**

  * 好发青春期；约半数患者出现典型IM（老师口述）
  * 表现：发热、咽痛、乏力、淋巴结肿大、肝脾肿大等
  * 实验室要点：

    * 可见大量**不典型淋巴细胞（atypical lymphocytes）**（与T细胞增殖相关）
    * **嗜异性抗体（heterophile antibody）阳性**

      * 【鉴别点】EBV-IM：嗜异性抗体阳性；**CMV-IM：阴性**（老师强调）
  * 免疫正常者预后好、死亡率低；免疫差者病死率升高
* **Burkitt淋巴瘤（Burkitt lymphoma）**

  * 非洲儿童多见
  * 证据（老师给两条）：

    1. 瘤组织中可检出EBV基因组
    2. 患者血清可检出EBV抗体，且滴度较正常人高
* **鼻咽癌（Nasopharyngeal carcinoma, NPC）**

  * 多见东南亚；我国多见南方
  * 证据：肿瘤组织检出EBV基因组/抗原；患者血清高滴度抗体，且随治疗好转抗体下降
  * 【提醒】肿瘤发生为多因素结果，病毒感染是其中因素之一
* **淋巴组织增生性疾病（lymphoproliferative diseases）**

  * 多见免疫低下人群（如AIDS相关毛状白斑等）
  * 与霍奇金病、非霍奇金淋巴瘤等亦有关（老师口述）

### 5）防治

* 无有效疫苗
* 无特效药物（老师强调）

## 七、HHV-6/7/8（了解）

* **HHV-6（1986分离）**：分 **6A/6B**；与人类疾病更相关的是 **6B**，可致**婴儿急疹（roseola infantum / exanthem subitum）**
* **HHV-7**：与疾病关系尚不完全明确，可能与婴儿急疹有关（老师口述）
* **HHV-8（1994分离）**：从**AIDS患者卡波西肉瘤（Kaposi sarcoma）**组织分离

  * 又称 **KSHV（Kaposi’s sarcoma–associated herpesvirus）**

### 【学习建议】（老师原话思路）

* 建议把常见考法“做总结表”：

  * ①与人类肿瘤相关的病原体
  * ②经常引起先天性感染/畸形的病原体
  * ③性传播疾病（STD）病原体
  * ④食物中毒病原体
  * ⑤按传播途径归类（选择题常考）

## 八、逆转录病毒科（Retroviridae）总述 → 重点：HIV

### 1）逆转录病毒科共同特点（【考点】）

* 有包膜（enveloped），球形，大小约 **80–120 nm**
* 核酸：**两条完全相同的单正链RNA（two identical +ssRNA）**（老师强调“经常考”）
* 含**逆转录酶（reverse transcriptase, RT）**
* 结构基因：**gag / pol / env** 三大基因
* 通过与宿主细胞表面特定受体结合决定组织嗜性（tropism）
* 出芽方式释放（budding）

### 2）与人类疾病相关的两个属（老师口述）

* **慢病毒属（Lentivirus）**：人类免疫缺陷病毒 **HIV**
* **δ逆转录病毒属（Deltaretrovirus）**：人T细胞病毒（HTLV，老师口述“各有两个血清型”）

## 九、人类免疫缺陷病毒（HIV）与AIDS

### 1）基本概念

* 病原体：**HIV（Human immunodeficiency virus）**
* 疾病：**AIDS（Acquired immunodeficiency syndrome，获得性免疫缺陷综合征）**
* 【历史】1981年首次描述；1983年法国巴斯德研究团队分离HIV；团队获2008年诺贝尔生理学或医学奖（老师口述）

### 2）血清型与分布

* **HIV-1**：全球分布，研究重点
* **HIV-2**：主要西非局部流行

### 3）流行病学数据（课堂引用/老师口述“截至2024年底”）

* 全球HIV感染者约 **4080万**；当年 **130万**新发；**63万**死亡
* 2010到2024新发下降约 **40%**（老师结合图示）
* 目标：2025年新发控制到约37万、2030约20万（老师说“差距大，难完成”）
* 中国：截至2024年底感染者约 **135.5万**；2024年新发约 **10万**

  * 主要传播：性接触
  * 地区：四川、广西、重庆、云南、贵州等较多（老师口述）

### 4）形态结构（【考点】关键蛋白/受体）

* 球形有包膜，约 **100–120 nm**
* 核心：两条相同+ssRNA
* 三种关键酶（也是药物靶点）：

  * **Reverse transcriptase（逆转录酶）**
  * **Integrase（整合酶）**
  * **Protease（蛋白酶）**
* 结构蛋白：

  * 衣壳蛋白 **p24（capsid, CA）**
  * 基质蛋白 **p17（matrix, MA）**
* 包膜糖蛋白刺突：

  * **gp120**：受体结合（bind receptor）
  * **gp41**：介导病毒包膜与细胞膜融合（fusion）
* 受体与辅助受体（【考点】）：

  * 主受体：**CD4**
  * 辅助受体：**CCR5、CXCR4**

    * 老师提示：图回去看位置，不再展开

### 5）基因组（老师按功能讲）

* 3个结构基因：**gag / pol / env**

  * **env** → 前体蛋白切割 → **gp120 + gp41**
  * **gag** → 切割 → 衣壳蛋白等（含p24、p17等对应结构）
  * **pol** → 切割 → **RT、Integrase、Protease**
* 另有多个调节基因（regulatory genes），参与复制与转录调控（老师口述）

### 6）复制周期（【考点】步骤+细胞嗜性转变）

* 受体结合：gp120与CD4结合，同时识别辅助受体

  * **CCR5**：多在单核-巨噬细胞表面（macrophage-tropic）
  * **CXCR4**：多在T细胞表面（T-tropic）
* 老师强调“早期→晚期嗜性变化”：

  * 感染早期偏CCR5 → 主要感染巨噬细胞（不一定立刻杀死细胞，形成“病毒库”，利于扩散）
  * 随病程进展可偏CXCR4 → 主要靶向**CD4+ T细胞**
* 进入与逆转录：

  1. gp41构象变化 → 融合 → 核衣壳入胞
  2. 脱壳后在细胞质内：RT以RNA为模板合成cDNA

     * RNA链被RNase H降解
     * 再合成正链DNA → 形成dsDNA
  3. dsDNA在整合酶作用下整合入宿主染色体 → **前病毒（provirus）**
  4. 前病毒可潜伏；在刺激下激活后转录（宿主RNA聚合酶）
  5. RNA去向：

     * 形成mRNA → 翻译病毒蛋白
     * 形成子代基因组RNA
  6. 装配 → 出芽释放（budding）

### 7）抵抗力（老师强调“相对弱”）

* 对氧化剂、乙醚、乙醇等敏感
* 室温放置约10–30分钟可灭活（老师口述）

### 8）致病性：传染源与传播途径（【考点】）

* 传染源：患者 + 无症状携带者
* 病毒主要存在于血液与体液（精液、阴道分泌物、乳汁等）
* 三大传播途径：

  1. **性接触传播**（最主要；含同性/异性）
  2. **血液/血制品传播**（静脉吸毒人群高危等）
  3. **母婴传播**（胎盘/产道/哺乳；老师说对HIV胎盘是重要方式，且可通过抗逆转录病毒治疗显著阻断）

### 9）致病机制：CD4+细胞损伤（老师以T细胞为主讲）

* 靶细胞：**CD4+细胞**（含单核-巨噬细胞、T细胞等；老师还提到NK等）
* 对T细胞损伤：抑制生成、降低功能、直接/间接杀伤
* 杀伤机制（老师列点）：

  1. 被感染细胞表面表达HIV抗原 → 被**CTL**识别杀伤；也可被抗体识别，通过**ADCC**破坏
  2. 感染细胞与未感染细胞融合 → 多核细胞（syncytium）→ 失去分裂能力→死亡
  3. 出芽释放 + 病毒蛋白改变细胞膜 → 通透性增加 → 损伤
  4. 诱导细胞凋亡（apoptosis）

### 10）临床分期（老师按“三期”讲）

* **急性期（acute infection）**

  * 病毒血症（viremia）明显；持续约 **8–12周**（老师口述）
  * 非特异症状：发热、咽痛、盗汗、恶心呕吐、淋巴结肿大、神经系统症状等
  * 症状多持续 **2–3周**后自行缓解
  * 检测窗口：此期血中可检出**病毒核酸**与**抗原p24**；但**抗体通常6–8周后才出现**，因此发病初期往往检不出抗体
* **无症状期/潜伏期（asymptomatic/clinical latency）**

  * 病毒主要潜伏在**淋巴组织**
  * CD4+T细胞：急性期先骤降 → 可短暂恢复 → 随后**缓慢进行性下降**

    * 下降速度：约每年 **25–60 个/μL**（老师口述）
    * 可持续 **4–8年**甚至更久
  * 表现：多无症状或仅持续性淋巴结肿大
  * 检测：血中多检不出病毒（老师表述），但**抗体阳性**
* **AIDS期（AIDS stage）**

  * 当CD4+T细胞 < **200 个/μL** → 免疫功能严重缺陷
  * 继发致死性**机会性感染（opportunistic infection）**或**恶性肿瘤（malignancy）**
  * 未治疗者：进入此期后约2年内死亡（老师口述）
  * 常见：

    * 机会性感染：**肺孢子菌肺炎（Pneumocystis jirovecii pneumonia, PJP）**（老师说“最常见”）
    * 恶性肿瘤：**卡波西肉瘤（Kaposi sarcoma）**（老师说“最常见”）

### 11）免疫学要点

* 可产生中和抗体、CTL等限制病毒载量
* 但病毒攻击的正是免疫关键细胞（CD4+T、巨噬细胞等）→ 体液与细胞免疫最终都受损 → 免疫缺陷加重

### 12）微生物学检查（诊断）

* **血清学**：

  * **ELISA**：初筛（假阳性率较高，老师强调“初筛”）
  * **Western blot**：确认试验（确诊）
* **抗原检测**：主要 **p24**（用于抗体未出现的“窗口期”）
* **核酸检测**：PCR等
* **病毒分离**：少用；培养复杂（需正常人单核细胞与患者单核细胞共培养等，老师口述）

### 13）防控（老师讲到的一般性措施）

* 无有效疫苗（高度变异导致研制困难）
* 以一般预防为主：

  * 健康宣教、明确传播途径；**12月1日世界艾滋病日（World AIDS Day）**
  * 血液管理与献血者严格筛查
  * 感染者监测体系、规范治疗（提到母婴阻断依赖抗逆转录病毒治疗）
