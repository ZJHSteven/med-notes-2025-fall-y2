## 1. 绦虫概论（Introduction to cestode）

### 1.1 共同形态特征（common features）

* **成虫：扁平、带状/丝带样（ribbon-like），乳白色**（像“宽面条/宽粉”）
* **无消化道**（digestive tract absent）
  → **靠体表微绒毛样结构吸收营养**（nutrients absorbed via body surface）
* **头节（scolex）= 固着/附着器官**

  * 可见 **吸盘（suckers）**，部分还有 **小钩（hooks）**
* **颈节（neck）= 生发区（germinative region）**

  * 最细最窄，但**不断“出芽”生成后续节片**
* **链体（strobila）由许多节片（proglottids）组成**

  * **未成熟节片（immature）→ 成熟节片（mature）→ 孕节片（gravid）**
  * 末端孕节片不断脱落，颈节不断新生 → 维持总体长度
* **雌雄同体**（hermaphroditic）
  → 每个成熟节片内有一套雌雄生殖器官

### 1.2 生活史“通用模板”（你做题就套这个）

1. **成虫**寄生在终宿主小肠
2. **孕节片/虫卵**随粪便排出污染环境
3. **中间宿主**摄入虫卵 → 孵出**六钩蚴（oncosphere）**
4. 六钩蚴穿肠壁入血 → 到组织发育成不同类型**幼虫**
5. 终宿主吃了含幼虫的肉/内脏 → 小肠内发育为成虫

## 2. 猪带绦虫 *Taenia solium*（重点：两种病！）

### 2.1 “一虫两病”总纲（先背这一句）

* **吃“囊尾蚴”（米/豆猪肉）→ 小肠长成虫 → 猪带绦虫病（taeniasis）**
* **吃“虫卵” → 组织里长囊虫 → 囊虫病（cysticercosis）**（严重！尤其脑/眼）

### 2.2 形态要点（成虫）

* 长度：约 **2–4 m**
* 节片数：约 **700–1000**
* **头节：4 吸盘 + 顶突/吻有“小钩圈”（有钩 = 重要鉴别点）**
* **孕节片子宫侧支数：每侧约 7–13 支（从“根部”数！只数一侧！）**

  * 临床常用：**墨汁染色（ink injection）**后数侧支鉴别种类

### 2.3 卵与幼虫（囊尾蚴）

* **带绦虫卵（Taenia egg）三者（猪/牛/棘球）形态“很像/难分”**（老师强调：镜下常分不清到物种）

  * 内有**六钩蚴**
  * 有**放射状胚膜/条纹**
  * 外层卵壳易碎、易脱落：粪便中常看不到完整卵壳
* **囊尾蚴（Cysticercus cellulosae）**：

  * 黄豆粒大小、白色半透明囊泡，囊内液体
  * 内含“米粒样头节”，可内翻/外翻
  * 在猪肌肉形成“米猪肉/豆猪肉”

### 2.4 生活史要点（考试最爱问：宿主/感染期/致病期/寄生部位）

* **终宿主（definitive host）**：人
* **中间宿主（intermediate host）**：猪；**人也可误当中间宿主**（囊虫病）
* **寄生部位**：

  * 成虫：人**小肠**
  * 囊尾蚴：猪肌肉；人可在**皮下/肌肉/眼/脑**等
* **感染期（对人）**：

  * 囊尾蚴 → 导致猪带绦虫病
  * 虫卵 → 导致囊虫病
* **感染途径**：经口（吃不熟猪肉/误食虫卵）

### 2.5 囊虫病的 3 种感染方式（名词解释高频）

1. **自体内感染**：体内有成虫，**呕吐/逆蠕动**使虫卵返流入胃再吞入
2. **自体外感染**：排出的虫卵污染手/食物又被本人吃回去
3. **异体感染**：吃到**他人**排出的虫卵污染的食物/水（如家人、厨师等）

### 2.6 致病与临床

* **猪带绦虫病（肠道）**：多不重

  * 可：腹痛、腹泻、腹胀、消化不良、消瘦
  * 多数是**粪便见节片**才发现
  * 诱发：多虫/刺激饮食 → 可能肠梗阻、穿孔、阑尾炎（老师提到）
* **囊虫病（严重）**：按部位分型

  * 皮下/肌肉：黄豆样结节，可游走；多无症状，重者肌肉酸胀
  * 眼囊虫：可见“头节活动”；死亡崩解释放抗原 → 炎症重，甚至失明
  * **脑囊虫（最重）**：三大主征

    1. **癫痫发作**（最常见）
    2. **颅内高压**
    3. **精神症状**

### 2.7 诊断

* **肠道绦虫病**：

  * 排节片史；粪便查卵/节片
  * 节片：**墨汁染色**后数子宫侧支（猪带：7–13/侧）
* **囊虫病**：

  * 皮下/肌肉：切除/病理
  * 脑：CT/MRI（辅助）
  * 眼：眼底镜
  * 血清学试验：辅助

### 2.8 治疗（老师讲得很“操作流”）

* **吡喹酮（Praziquantel）**：有效，但可使虫体在体内崩解，可能看不到完整虫体；有副作用
* **槟榔-南瓜子合剂 + 硫酸镁导泻**（老师强调“找头节！”）

  * 目的：麻痹虫体与头节 → 导泻排出
  * **关键点：必须确认“头节（scolex）排出”才算驱虫成功**
  * 若未排出头节/颈节残留：2–3 个月可再生长成虫

## 3. 牛带绦虫 *Taenia saginata*（对照记忆：像猪带的“简化版”）

### 3.1 核心一句

* **只引起牛带绦虫病（肠道）**
* **虫卵被人吃下去一般不继续发育成组织幼虫**（老师口述：人对其有“天然免疫力/不适宿主”）

### 3.2 形态鉴别（和猪带一起背）

* 长度：**4–8 m**（更长）
* 节片数：**1000–2000**（更多）
* 头节：**4 吸盘，无小钩（无钩=关键）**
* 孕节片子宫侧支：**15–30/侧**（从根部数，一侧）
* 节片脱落与表现：

  * 常**多节脱落**
  * 可**主动爬出肛门** → 肛门/会阴瘙痒；节片在肠内移动可致回盲部痛（老师提到）

### 3.3 生活史要点

* **终宿主**：人
* **中间宿主**：牛
* **感染期（对人）**：牛肉内的幼虫（囊尾蚴）
* **感染途径**：生/半生牛肉（老师举藏区嗜生牛肉例）

### 3.4 诊断/治疗/预防（基本同猪带）

* 诊断：排节片史；粪便查卵；肛门拭子（因可主动排出）
* 治疗：同猪带；**仍强调“必须排出头节”**
* 预防：不吃生牛肉；牛群与人粪隔离；检疫

## 4. 细粒棘球绦虫 *Echinococcus granulosus*（包虫/棘球蚴病，牧区高发）

### 4.1 一句话定位

* **自然界循环：犬科（终宿主）↔ 牛羊等食草动物（中间宿主）**
* **人：偶然误食虫卵成为中间宿主 → 体内长“包虫囊”（棘球蚴/ hydatid cyst）**

### 4.2 成虫特点（为什么叫“犬绦虫”）

* 成虫寄生：**犬/狼小肠**
* 很短：约 **2–7 mm**
* 体节少：**头节+颈节+未成熟/成熟/孕节片（总共就几节，老师强调“每种节片各一节”）**
* 虫卵：**带绦虫卵样**（形态与其他带绦虫卵相似）

### 4.3 幼虫：棘球蚴（包虫囊）结构（考试名词解释大户）

* 形态：圆形囊状体，像“皮球/大包”
* 大小：直径可 **1–40 cm**（与时间、部位、宿主相关）

  * 老师给经验：感染半年约 0.5–1 cm；每年可增 1–5 cm
* 囊壁两层：

  1. **角质层/层板层（外层）**：乳白半透明，保护、渗透吸收
  2. **胚层/生发层（内层）**：贴内面，能向内生长结构
* 囊内：囊液（无色透明，含多蛋白/酶，抗原性强）
* 重要名词：

  * **原头节（protoscolex，老师口述“源头结”）**：未来能发育为成虫的“头节原基”，有吸盘/小钩
  * **生发囊/育囊（brood capsule）**：一堆原头节外包一层生发组织
  * **子囊/孙囊（daughter cyst / granddaughter cyst）**：囊内再长囊，“母-子-孙”级联
  * **棘球蚴沙（hydatid sand）**：囊内漂浮的原头节/生发囊等，离心后像沙粒（老师强调常考名词解释）

### 4.4 生活史（按“犬-羊-犬；人误入”背）

1. 犬/狼小肠成虫 → 粪便排卵污染草地/犬毛
2. 羊/牛等食草动物吃草吞卵 → 六钩蚴穿肠入血 → 肝肺等形成棘球蚴囊
3. 犬/狼吃了感染动物内脏（含棘球蚴囊）→ 囊内原头节在犬小肠发育成虫
4. **人**误食虫卵（摸犬毛/手不洁/食物污染）→ 肝肺脑等长包虫囊（但人一般不再回到犬体内完成循环）

### 4.5 致病机制与临床

* **生长慢**：常感染后 **5–20 年**才明显（老师口述：多“童年感染，成年发病”）
* 三类主要危害：

1. **机械压迫**（囊越长越大）：轻痛、坠胀；肝最多（老师口述约 80%），其次肺（约 13–15%），其他脑/眼/骨/腹腔等
2. **毒性/过敏反应**：囊液外溢（抗原性强）→ 荨麻疹、血管性水肿；囊破裂可致**过敏性休克/死亡**（老师举“司机撞破腹腔包虫→休克”案例）
3. **继发问题**：

   * 囊破入腹腔 → 弥漫性腹膜炎 + **继发性多发包虫**（囊液播散）
   * 破入胆道 → 炎症/胆绞痛
   * 肝肺囊破入支气管 → 剧咳，可咳出子囊/囊壁碎片样物

### 4.6 诊断（强调：病史 + 影像 + 免疫；确诊看虫体）

* **病史**：牧区居住/到访史；犬及皮毛接触史（可追溯到“早年”）
* **影像**：B 超、CT、X 光（看囊性占位/特征性改变）
* **免疫学**：**卡松尼试验（Casoni test，皮试）**：辅助，特异性相对高（老师口述）
* **病原学确诊**：

  * 手术取出棘球蚴囊
  * 或在腹水/胸水/痰等查到**原头节/棘球蚴沙**
* **诊断性穿刺**：老师强调“过去教材严禁；现在可在超声引导下谨慎做”，核心风险：**囊液外溢 → 过敏性休克 + 播散导致继发多发包虫**

### 4.7 治疗与手术原则（老师反复强调“别让它播散”）

* 以**手术**为主（取内囊为关键）
* 手术关键两条：

  1. **完整清除内囊/内容物**
  2. **严格防止囊液外溢，必须杀灭原头节**（否则腹腔播散可再长新包虫囊）
* 老师提到的操作思路：先抽囊液、再注入杀灭液（提到甲醛等），保护视野、再剥离内囊（你按老师课件流程复习即可）

## 5. 三者对照速记表（做选择题/填空题用）

### 5.1 猪带 vs 牛带（最常考鉴别点）

* 头节：

  * **猪带：有钩 + 4 吸盘**
  * **牛带：无钩 + 4 吸盘**
* 长度/节片数：

  * 猪带：2–4 m；700–1000 节
  * 牛带：4–8 m；1000–2000 节
* 孕节片子宫侧支（**一侧、从根部数**）：

  * **猪带：7–13**
  * **牛带：15–30**
* 节片排出：

  * 猪带：多被动、常单节
  * 牛带：多节、可主动爬出 → 肛门瘙痒
* 致病：

  * 猪带：肠道绦虫病 + **囊虫病（脑/眼重）**
  * 牛带：只肠道绦虫病

### 5.2 棘球绦虫的“一眼识别”

* 成虫：犬/狼小肠，**短（2–7 mm）+ 少节**
* 人得病阶段：**棘球蚴/包虫囊（hydatid cyst）**
* 风险：囊破 → **休克 + 播散继发多发包虫**

## 7. 录音里出现的“操作流程”我给你单列（你之前很在意这种可执行步骤）

* **绦虫孕节片鉴别**：
  1）取孕节片 → 2）盐水浸泡 → 3）**墨汁从一侧注入** → 4）**从根部数一侧子宫侧支数**（猪带 7–13；牛带 15–30）
* **驱虫后判定是否成功（猪带/牛带通用）**：
  1）导泻后**全程用盆接粪** → 2）用筷子/工具**仔细找头节（scolex）** → 3）**见头节 = 成功；不见 = 可能复发**
* **槟榔-南瓜子合剂大致逻辑**：
  南瓜子+槟榔麻痹虫体/头节 → 约 2 小时后 → 硫酸镁导泻 → 排出虫体并找头节
* **包虫手术核心原则**：
  取内囊 + **防外溢** + **杀原头节**（否则播散继发多发包虫）
