## 1）课前测/统计与逐题讲评（老师原意梳理）

### 第1题：BCR/TCR 多样性相关（正确率约70%上下）

* 老师说：这题多数同学会做，所以后面讲“多样性（diversity）”可以快一点。
* **强调纠错点**：

  * **克隆清除（clonal deletion）**不是“多样性产生机制”，它是**结局/筛选结果（耐受形成的一部分）**。
  * 多样性机制讲的是“怎么产生不同受体”，不是“产生后怎么处理掉不合格克隆”。

### 第2题：**T 细胞阳性选择（positive selection）的意义**（正确率约31%）

老师重点补讲（你这段里信息量最大的一题）：

* 很多人被“阳性/阴性”字面误导：

  * **阳性选择**＝把“能**适度**识别**自身 MHC**”的克隆**留下**（positive = keep）。
  * **阴性选择**＝把“对自身抗原反应太强”的克隆**删掉**（negative = delete）。
* 阳性选择核心意义（老师逐条讲的）：

  1. **获得自身 MHC 限制性（self-MHC restriction）**：

     * 能和自身 MHC **结合得上**（但不是特别强）→ 才“合格”。
     * 完全不能结合 → **凋亡**（“死掉”）。
  2. **双阳性（CD4⁺CD8⁺, DP）→ 单阳性（SP）分化**：

     * DP 若与 **MHC II**结合更合适 → **CD4 保留、CD8 下调** → CD4⁺ T
     * DP 若与 **MHC I**结合更合适 → **CD8 保留、CD4 下调** → CD8⁺ T
* 选项陷阱（老师点名）：

  * “发育为成熟 T 细胞”这个说法容易被选，但老师强调：**阳性选择后还要阴性选择**，完成阴性选择后才算“成熟并出胸腺”。

### 第3题：**ITAM / ITIM**（正确率约63%，老师说“送分题”）

* 老师把它从“信号通路细节（磷酸化级联）”里抽离出来：

  * 免疫学考试重点：你只要知道

    * **ITAM（immunoreceptor tyrosine-based activation motif）**：**激活信号**
    * **ITIM（…inhibition motif）**：**抑制信号**
* 典型定位（老师原话意思）：

  * 需要“激活”的受体复合体里常见 **ITAM**
  * “抑制性受体/抑制性共受体”常见 **ITIM**

### 第4题：B 细胞共受体（正确率约76.8%）

* 老师说：整体还不错，但仍有人混。

### 第5题：T 细胞共受体（正确率约67%）

* 共受体＝**CD4、CD8**（老师强调“非常非常重要”）
* 为什么用 CD4/CD8 区分两类功能 T 细胞：因为它们是识别 MHC 的关键“辅助抓手”。

### 第7题：初始 B 细胞表面分子（正确率偏低）

* 老师纠错：“初始 B（naive B）”不是“未成熟 B”。

  * **naive B 已经发育成熟**，只是**还没遇到抗原**。
  * 因此表面应有成熟 B 的典型分子组合（后面笔记里会整理）。

### 课堂提示：CD 分子速记题（老师举例）

* **CD2：T 细胞**
* **CD19：B 细胞**
* **CD28：T 细胞**
* **CD40：B 细胞（同时也在其他 APC 上）**
* **CD40L（CD154）：活化 T 细胞**

## 2）从固有免疫过渡到适应性免疫：老师的“总框架图”

老师反复强调的逻辑链（你这段里出现很多次）：

1. **固有免疫（innate immunity）**

   * 由**固有免疫细胞 + 固有免疫分子**构成

2. **DC（树突状细胞）是桥梁**

   * 没有 DC，很难“进入/启动”适应性免疫
   * 老师强调一句：**DC 是唯一能激活初始 T 细胞（naive T）的 APC**（课堂常考表述）

3. **抗原分类与呈递规则必须像记名字一样记住**（老师语气很重）

   * **内源性抗原（endogenous）→ MHC I → CD8⁺ T**
   * **外源性抗原（exogenous）→ MHC II → CD4⁺ T**
     （这段老师说是理解“细胞免疫 vs 体液免疫”的钥匙）

4. APC 的“狭义 vs 广义”

* 老师提问并解释：

  * 广义：几乎所有有核细胞都表达 **MHC I**，都能呈递内源性抗原（所以“广义上都可算 APC”）。
  * 但课堂默认“APC（不加说明）”通常指**专业 APC**：**DC、巨噬细胞、B 细胞**（其中 DC 最关键）。
  * 肿瘤细胞呈递突变抗原时，课堂常称为“靶细胞”，也可从“广义 APC”角度理解。

## 3）B 细胞（B cell）——老师讲的主线（发育→BCR→多样性→耐受→表面分子→功能）

### 3.1 为什么叫 B 细胞 / 在体内怎么“巡逻”

* **B = Bone marrow（骨髓）** 成熟
* 成熟后定居/循环于外周免疫器官（淋巴结等）：

  * 血液 → 淋巴液 → 淋巴结 → **高内皮微静脉（HEV）** 回到血液 → 再进淋巴结
* 老师提到淋巴结数量：大约“几百个（如 600–800 左右）”（这句更像课堂口径，不必当精确数字背）。

### 3.2 B 细胞发育分期（骨髓内：抗原非依赖期；外周：抗原依赖期）

* 骨髓内：从造血干细胞 → 淋巴系祖细胞 →（pro-B / pre-B / immature B 等）
* 老师说**两件“标志性事件”决定它是否合格**：

  1. **BCR 生成（BCR generation / rearrangement）**
  2. **自身耐受形成（tolerance）**（等价于“B 细胞的阴性选择”）

### 3.3 BCR 基因重排（老师讲得很细：重点、轻链、同种型转换的底层）

> 你这段里老师一直用“重链/轻链”举例解释，很像考试会点的内容。

**（1）重链（Heavy chain）可变区：VDJ 重排**

* 重链可变区由 **V、D、J** 三段片段拼接而成：

  * 先 **D-J**，再 **V-DJ**
* 每类片段都有很多“备选片段”，随机抽取组合 → 巨量多样性

**（2）轻链（Light chain）可变区：VJ 重排**

* 轻链没有 D 段：只做 **V-J** 重排
* 轻链有 **κ（kappa）/ λ（lambda）** 两套基因座（老师说“不同染色体上”）

**（3）恒定区决定抗体类别（IgM/IgG/IgA/IgE/IgD）**

* 老师用“Cμ 在最前面”解释：

  * 初始表达先是 **Cμ → IgM**
  * 之后在细胞因子等影响下发生**类别转换（class switching）**：本质是“换用不同恒定区（如 Cγ → IgG）”

### 3.4 两个“排斥原则”（保证一个 B 细胞只做“一种特异性”）

* **等位基因排斥（allelic exclusion）**：

  * 父源/母源两条染色体中，只要一条成功重排出功能性受体，另一条停止
  * 结果：**一个 B 细胞只表达一种特异性 BCR**
* **同种型排斥（isotypic exclusion）**（老师讲 κ/λ）：

  * κ 成功 → λ 不再重排（反之亦然）
  * 结果：一个 B 细胞只用 κ 或 λ 之一

### 3.5 多样性（diversity）产生的 4 个机制（对应你们测验题）

1. **组合多样性（combinatorial diversity）**：V/D/J 片段组合 + 重链/轻链配对
2. **连接多样性（junctional diversity）**：拼接处核苷酸缺失/插入 → 读码框改变 → 巨大差异
3. **受体编辑（receptor editing）**：如果新生成 BCR 识别自身抗原 → 给一次“重排改过自新”的机会（主要发生在轻链）
4. **体细胞高频突变（somatic hypermutation, SHM）**：外周免疫应答中可变区高频点突变，提升亲和力（老师强调频率远高于一般体细胞突变）

### 3.6 B 细胞“阴性选择”= 自身耐受的形成（clonal deletion/无能等结局）

老师讲了三种结局（按亲和力强弱）：

* **强结合自身抗原** → 直接删除（clonal deletion）
* **中等/可修正** → **受体编辑**再试一次
* **很弱结合** → 下调 BCR（或进入无能状态），带着“低风险”进入外周

## 4）B 细胞表面分子：考试核心（老师明确说“这些都要掌握”）

### 4.1 BCR 复合物（第一信号的基础）

* **BCR 负责结合抗原**
* 胞内尾太短，传不了信号 → 需要伴侣：

  * **Igα / Igβ（CD79a/CD79b）**
  * 胞内含 **ITAM** → 传递激活信号

### 4.2 B 细胞共受体（帮助放大第一信号）

* 复合物：**CD19 + CD21（CR2）+ CD81**
* 关键点（老师用补体讲得很清楚）：

  * 抗原表面若被补体片段（如 **C3d**）“装饰”
  * **CD21（CR2）** 结合 C3d，把抗原“拉近”
  * **CD19**放大激活信号，**CD81**稳定复合物
* 课堂补充：

  * **EBV（EB 病毒）利用 CD21 作为受体**感染 B 细胞（老师提到）

### 4.3 B 细胞共刺激分子（第二信号）

* 对 B 细胞最关键的一对：

  * **CD40（B 细胞）— CD40L/CD154（活化 T 细胞）**
* 老师反复强调：**没有 CD40-CD40L，B 细胞难以充分活化（尤其是 T 依赖性应答）**

### 4.4 B7 分子（CD80/CD86）—给 T 细胞第二信号

* B 细胞/DC/巨噬细胞表面：**CD80、CD86（统称 B7）**
* 与 T 细胞 **CD28**结合 → **激活（第二信号）**
* 与 **CTLA-4（CD152）** 结合 → **抑制**（老师说亲和力比 CD28 强很多，像“刹车”）

### 4.5 粘附分子（像胶水一样让细胞“贴住”）

* 重点一对：**ICAM-1 — LFA-1**

  * 让 T-B / T-APC 贴紧，便于信号交换
  * 也可辅助共刺激，但老师说“重要性不如 CD40 或 CD28-B7”

### 4.6 常见 B 细胞标志分子（老师点名）

* **CD19：B 细胞标志**
* **CD20：B 细胞标志**（老师还提到抗 CD20 单抗用于淋巴瘤治疗，作为“单抗时代先驱”例子）
* **CD22 / CD32**：老师提到“调控/抑制 B 细胞活化”的方向（你们题里常考“哪个是抑制性/含 ITIM”会联动到这里）

## 5）B 细胞分类与功能（老师的“比较简单但要背”部分）

### 分类

1. 按阶段：**naive B（初始）→ effector B（效应，如浆细胞）→ memory B（记忆）**
2. 按反应特性：**B-1 vs B-2**

   * B-1 更偏“天然抗体/低特异性/先天样”
   * B-2 是你们本节重点（典型 VDJ、多信号、类别转换、免疫记忆等）

### 功能（3 条）

1. **产生抗体（抗体介导的效应几乎覆盖 B 细胞主要功能）**
2. **抗原呈递（MHC II + 共刺激）给 CD4⁺ T**
3. **免疫调节**：分泌调节性细胞因子（老师点名）

   * **IL-10、TGF-β、IL-35**（出现“reg/调节”通常就是抑制方向）

## 6）T 细胞（T cell）——老师讲到的要点（发育、选择、表面分子、免疫检查点）

### 6.1 T 细胞发育三阶段（胸腺内）

* **DN（double negative，CD4⁻CD8⁻）**
* **DP（double positive，CD4⁺CD8⁺）**
* **SP（single positive，CD4⁺ 或 CD8⁺）**

### 6.2 TCR 重排（老师用“像 BCR 一样”帮助理解）

* **αβ T 细胞**是适应性细胞免疫主力
* **γδ T 细胞**更偏“固有样/先天样”方向（老师提到“固有免疫细胞”语境）
* 基因片段规则（老师的类比非常明确）：

  * **β 链：VDJ**（像重链）
  * **α 链：VJ**（像轻链）

### 6.3 阳性选择（positive selection）：获得 **MHC 限制性 + CD4/CD8 谱系决定**

* 发生在：**胸腺皮质上皮细胞（thymic cortical epithelial cell）** 介导
* 逻辑（老师讲得很考试向）：

  * DP 若**完全不能识别自身 MHC** → 死
  * 若能“适度识别”：

    * 适配 **MHC II** → 保留 CD4 → CD4⁺
    * 适配 **MHC I** → 保留 CD8 → CD8⁺
  * 若“两边都很强/都识别得太好”→ 也会被淘汰（你转写里出现“两个都识别的死掉”这种课堂化表达）

### 6.4 阴性选择（negative selection）：获得 **中枢耐受（central tolerance）**

* 逻辑同 B 细胞：

  * 如果 TCR 对“自身抗原肽-自身 MHC”反应太强 → 删除 → 防止自身免疫病

## 7）T 细胞表面分子：与 B 细胞一一对应（老师强调“对应着记就简单了”）

### 7.1 TCR-CD3 复合物（第一信号基础）

* **TCR 识别：抗原肽-MHC 复合物**（老师让同学回答的那句）
* **CD3**负责信号传导（胞内含 **ITAM**）

### 7.2 共受体：CD4 / CD8（放大第一信号）

* **CD4 ↔ MHC II**
* **CD8 ↔ MHC I**（老师提到结合 MHC I 的特定结构域）
* 功能：显著放大 TCR 触发信号（类比 B 细胞 CD19/CD21/CD81 放大第一信号）

### 7.3 共刺激（第二信号）：T 细胞最重要的是 **CD28-B7**

* **CD28（T）— CD80/CD86（B7，APC）**：激活
* 抑制/检查点（老师用“油门/刹车”类比，讲得很长）：

  * **CTLA-4（CD152）**：与 B7 结合，抑制（“亲和力比 CD28 强很多”）
  * **PD-1**：与 **PD-L1/PD-L2**结合，抑制
* 老师补充：

  * 这两套是“免疫检查点”，阻断它们可增强抗肿瘤免疫（他用“把刹车拆掉”解释免疫治疗原理）

### 7.4 其他：CD2-LFA-3（E-rosette 经典实验）

* 老师提到旧实验：

  * **绵羊红细胞（SRBC）** 与 T 细胞形成“玫瑰花环（rosette）”
  * 原理：**CD2（T 细胞）— LFA-3（配体）**黏附结合
* 仍然要掌握的意义：这对分子像“胶水”，帮助细胞紧密接触并辅助信号。

# 8）老师反复强调的“必背对照表”（我帮你压成最像考题的形式）

* **内源性抗原 → MHC I → CD8⁺ T（细胞免疫/杀伤相关）**
* **外源性抗原 → MHC II → CD4⁺ T（辅助为主，推动体液应答）**
* **B 细胞活化第二信号：CD40（B）— CD40L（T）**
* **T 细胞活化第二信号：CD28（T）— B7/CD80/86（APC）**
* **ITAM = 激活；ITIM = 抑制**
* **BCR：重链 VDJ、轻链 VJ；TCR：β VDJ、α VJ**
* **阳性选择：留下“能适度识别自身 MHC”的；阴性选择：删掉“强自身反应”的**
