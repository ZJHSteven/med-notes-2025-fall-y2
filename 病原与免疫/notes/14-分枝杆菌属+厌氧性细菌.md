# 第一章 分枝杆菌属

## 分枝杆菌属概述

* 形态：**细长、略弯曲杆菌**；常**黏连成分支状**（因此得名“分枝”）
* 与人类疾病相关按致病特点分三类
  1）**结核分枝杆菌复合群**：结核病

  * 人结核：**结核分枝杆菌**
  * 人兽共患：**牛分枝杆菌**
    2）**麻风分枝杆菌**：麻风病
    3）**非结核分枝杆菌 NTM**：多为条件致病

## 分枝杆菌属共同特点

【重点】细胞壁**脂质含量极高**（非常关键，牵着一串考点）

* 因此：不易着色 → 常用**抗酸染色**（延长时间、加温、助染）
* 一旦染上色：可抵抗**酸-酒精脱色** → 称**抗酸杆菌**
* 生长慢：代时约 **18–24 h/代**；固体培养往往 **3–4 周**才见菌落
* 结构：不产芽孢、无鞭毛；可形成**微荚膜**
* 致病性：一般**无外毒素、无内毒素**（无LPS），主要靠**菌体成分** → 慢性过程、常见**肉芽肿**改变

# 结核分枝杆菌

## 发现与流行背景

* 1882年3月24日：德国细菌学家**科赫（Koch）** 宣布结核分枝杆菌为结核病病原体
* 3月24日：**世界防治结核病日**（老师提到WHO于1995年将此日作为纪念日）
* 历史：新石器时代骨骼、埃及木乃伊、我国古医书均有结核相关证据/描述（如淋巴结结核等）

## 生物学性状

### 形态与结构

* 形态：细长略弯曲杆菌
* 【重中之重】细胞壁结构（从内到外可简化为三层）
  1）**肽聚糖（peptidoglycan）**
  2）**阿拉伯半乳聚糖（arabinogalactan）**
  3）外层类似“外膜”的**脂质双层**

  * 内层：**分枝菌酸（mycolic acids）**
  * 外层：多种**糖脂/脂蛋白**
* 细胞壁还嵌有一些重要糖脂成分（与致病相关）

  * **磷脂酰肌醇甘露糖苷（PIM）**
  * **脂阿拉伯甘露聚糖（LAM）** 等（老师口述为“伸向细胞表面的一端”）

### 脂质含量高带来的连锁后果

【考点串联】脂质高 →
1）**抗酸性**（抗酸染色阳性）
2）形成**疏水屏障** → 水溶性营养吸收差 → **生长慢**
3）菌落：干燥、粗糙、颗粒状 → **菜花状菌落**
4）对外界抵抗力增强（抗干燥等）
5）与**致病性**有关（多种糖脂/脂质是致病物质）
6）与**耐药性**相关：屏障使部分常规抗生素不敏感 → 需要特异抗结核药

### 培养特性

* **专性需氧菌**

  * 液体培养：多在表面形成**菌膜**
* 【易错词】营养要求高：**fastidious**（苛养、挑剔）
* 常用：**罗氏培养基（Löwenstein–Jensen）**（老师描述：甘油、蛋黄、马铃薯，加入**孔雀绿**抑制杂菌）
* 最适 pH：约 **6.5–6.8**
* 生长慢：固体培养常需 **3–4周或更久**

### 抵抗力

老师用“**三抗三敏感**”概括：

* 三抗：
  1）抗干燥（痰中可存活很久，老师提到可达数月）
  2）对酸/碱有一定耐受（实验前处理可用酸/碱去杂菌）
  3）抗碱性染料（如培养基里的孔雀绿）
* 三敏感：
  1）对**湿热**敏感（老师举例：62℃ 15min 可灭活）
  2）对**紫外线**敏感
  3）对常用消毒剂敏感（酒精等，数分钟可灭活；日光照射数小时可灭活）

### 变异性

* 形态变异：细杆状 → 串珠状/颗粒状
* 可失去细胞壁 → **L型**
* 菌落变异：粗糙型 ↔ 光滑型
* 【重点】耐药性变异

  * 单耐药、多耐药
  * **耐多药 MDR**：至少同时耐 **异烟肼 + 利福平**（老师强调这点）
  * 广泛耐药 XDR：在MDR基础上进一步耐部分二线药（老师举例氟喹诺酮、二线注射类等）

### 毒力变异与卡介苗

【考点】**卡介苗 BCG**

* 全称来自两位科学家：Calmette–Guérin（老师口述“BCG”来源）
* 来源：将**有毒牛分枝杆菌**在含胆汁/甘油等培养基中长期传代（老师：约230代、历时13年）→ **减毒活疫苗**
* 作用：对**儿童**保护较好，对**成人**保护有限
* 也是“**毒力变异**”的经典例子：毒力强 → 毒力弱

## 致病性

### 总原则

* 不产生外毒素、无内毒素、无典型侵袭性酶
* 主要靠**菌体成分**：
  1）帮助逃避免疫/在细胞内存活
  2）诱发迟发型超敏反应导致组织损伤

### 主要致病物质

* **分枝菌酸**：与肉芽肿形成相关（老师提到教材未必展开）
* **索状因子 cord factor**

  * 化学本质：**海藻糖-6,6′-二分枝菌酸（Trehalose 6,6′-dimycolate, TDM）**
  * 现象：液体培养中菌体沿长轴黏连成“索状/束状”
  * 作用：抑制中性粒细胞游走、促进细胞因子释放 → 促肉芽肿形成
* **磷脂**

  * 促进单核细胞增生
  * 促进巨噬细胞→上皮样细胞转化 → 与结核结节形成有关
  * 抑制蛋白酶对组织溶解 → 促**干酪样坏死**
* **硫酸脑苷脂（sulfatide）**

  * 抑制吞噬体与溶酶体融合 → 结核杆菌可在吞噬细胞内存活增殖
* **蛋白质 + 蜡质D（wax D）复合物**

  * 可诱导**迟发型超敏反应**

## 传播途径与临床类型

### 传播途径

* 多途径，但最常见：**呼吸道** → 肺结核
* 也可：肠道（肠结核/腹膜炎）、破损皮肤（皮肤结核）

### 疾病谱

* 肺结核最常见
* 肺外结核：骨、关节、脑膜、生殖泌尿等
* 免疫极低下者可出现：**粟粒性结核（全身播散）**

### 原发感染与继发感染

【原发感染】（多见儿童）

* 临床：常轻微或无症状
* 病理与影像学：原发灶 + 淋巴管炎 + 肺门淋巴结肿大 → **原发综合征（Ghon综合征）**
* 约3–6周建立细胞免疫，同时也出现超敏反应
* 90%以上纤维化/钙化 → 自愈；但可残留少量菌潜伏

【继发感染】（多见成人、免疫低下）

* 两种来源：

  * **内源性再激活**：潜伏菌复燃
  * **外源性再感染**：再次吸入新菌
* 特点：病灶较局限但局部破坏更重，易见干酪坏死、空洞
* 侵犯支气管可排菌 → **开放性肺结核**（传染性强）

---

## 临床表现要点

* 全身：午后低热、盗汗、消瘦乏力、食欲减退、面色苍白
* 肺结核：咳嗽咳痰、咯血等（病例题常用）

---

## 免疫特点

【考点两句话】
1）以**细胞免疫**为主（兼性胞内菌）
2）细胞免疫建立的同时伴随**迟发型超敏反应**（保护与损伤并存）

老师补充：

* 刺激迟发超敏的抗原：偏**蛋白质+蜡质D复合物**
* 刺激细胞免疫的成分：老师提到“核糖体RNA”等（意思是与菌体某些成分有关）
* 两者参与T细胞亚群、细胞因子等不同；功能上：免疫保护 vs 组织损伤

## 结核菌素试验

【考点】PPD / TST

* 操作：**前臂皮内注射**纯蛋白衍生物 PPD
* 观察：**48–96小时**看红肿硬结
* 判读（按老师口述）：

  * <5 mm：阴性
  * ≥5 mm：阳性（可能既往感染或BCG接种）
  * ≥15 mm：强阳性（提示可能活动性结核，需进一步检查）
* 假阴性考虑：感染早期、老年、免疫抑制/免疫缺陷等
* 用途：

  * 评估疫苗接种效果
  * 婴幼儿辅助诊断
  * 评价细胞免疫水平
  * 流行病学调查
* 区分“既往感染 vs BCG接种”：老师提到可用**差异蛋白**的替代试验思路（用于区分）

## 微生物学检查与防治

### 标本处理

* 痰/粪便等污染标本：酸/碱/硫酸等预处理以去杂菌（老师举例3%盐酸、4%NaOH、6%硫酸）
* 尿液：含菌量低可离心浓缩

### 检测方法

* 直接涂片 + **抗酸染色**：见红色细长杆菌

  * 报告：**抗酸杆菌阳性/分枝杆菌阳性**
  * 不能仅凭抗酸阳性就直接报“结核分枝杆菌”
* 培养：慢，可用快速培养系统缩短时间
* 核酸检测：PCR等
* 免疫学：结核菌素试验、干扰素释放试验等（老师提到）

### 防治原则

* 预防：BCG（儿童接种为主）
* 治疗原则（老师强调）：**早期、适量、联合、规律、全程**
* DOTS：督导短程化疗策略（面对面督导服药、免费供药、提高治愈率、减少耐药）
* 药物：一线药（异烟肼、利福平等；老师还提链霉素、吡嗪酰胺等），耐药后用二线药（氟喹诺酮等）

# 麻风分枝杆菌

* 抗酸菌、兼性胞内菌
* 目前**人工培养困难/尚未解决**（老师强调）
* 鉴别点：感染细胞可出现**泡沫细胞/麻风细胞**
* 传播：呼吸道为主，密切接触
* 临床类型（老师讲两型）

  * **瘤型（lepromatous）**：重，狮面样外观，病灶菌多，细胞免疫缺陷 → 麻风菌素试验阴性
  * **结核样型（tuberculoid）**：相对轻，可自限，病灶菌少，细胞免疫正常 → 试验阳性
  * 另有“中间型/界限类”作为过渡

---

# 非结核分枝杆菌

* 自然界广泛存在，可为机会致病菌
* 免疫低下者（如AIDS）易感染，且可与结核分枝杆菌**混合感染**
* 对部分抗结核药**天然耐药** → 治疗更难
* 老师举例：**鸟分枝杆菌复合体**常见于AIDS相关感染

# 第二章 厌氧性细菌

## 厌氧菌概念

* 只能在无氧或低氧条件下生长，通过**无氧呼吸/发酵**获取能量的细菌总称

## 按是否产芽孢分两类

1）**有芽孢厌氧菌**

* 主要来自**梭菌属**
* 教材更新：原“艰难梭菌”现多称**艰难拟梭菌**（从梭菌属分出）
* 多为**外源性感染**，常靠**外毒素**致病

2）**无芽孢厌氧菌**

* 多为人体正常菌群重要成员（优势菌群）
* 多引起**内源性感染**

---

## 梭菌属共同特点

* 厌氧（严格程度不同）
* **革兰阳性大杆菌**
* 能形成芽孢 → 外界抵抗力强，常以芽孢形式在土壤存在
* 多外源侵入后出芽繁殖、产毒致病
* 多有鞭毛、不形成荚膜

  * 【例外】**产气荚膜梭菌**：有荚膜、无鞭毛（老师特别强调）

---

# 破伤风梭菌

## 生物学性状要点

* 芽孢：**终末、正圆、直径比菌体宽** → “**鼓槌状**”
* **周身鞭毛**
* 生化反应：不活泼（用于与产气荚膜梭菌对比记忆）

## 病例分析框架

* 来源：锈钉来自土壤 → 带芽孢
* 感染关键条件：**厌氧微环境**

  * 窄而深的伤口 + 包扎 + 未消毒
  * 其他可形成厌氧环境：坏死组织多、混合感染（需氧菌耗氧）等

## 致病机制

【考点】破伤风痉挛毒素 tetanospasmin

* 传播路径：毒素产生后经血/淋巴 → 神经肌接头 → **沿轴突逆行上行** → 脊髓前角/脑干
* 作用靶点：抑制性中间神经元，老师强调**Renshaw细胞**
* 机制核心：阻断抑制性递质（GABA、甘氨酸）释放

  * 通过裂解**SNARE蛋白**（囊泡与膜融合所需）→ 囊泡不能释放递质
* 结果：运动神经元失去抑制 → **屈肌与伸肌同时强直收缩** → 强直性痉挛

  * 面肌/咀嚼肌：牙关紧闭、苦笑面容
  * 背肌：角弓反张
  * 重者：累及呼吸肌/自主神经 → 呼吸受限、血压脉搏紊乱等

## 临床类型

* 局限型（轻）
* 全身型（重，进展到呼吸肌/自主神经）
* 新生儿破伤风：脐带残端消毒不严，常在7天内发病 → “七日风”（我国现较少）

## 免疫特点

* 感染后免疫**不牢固**
* 原因：毒素致死量极低（老师举例 <1 μg），感染量不足以激发有效免疫
* 获得保护需靠**类毒素疫苗**诱导抗毒素

## 防治

【预防】
1）正确处理伤口：清创/扩创、去除坏死组织、避免包扎造成厌氧环境
2）主动免疫：破伤风类毒素（我国儿童百白破含破伤风成分，按程序+加强针）
3）高危且无基础免疫、污染重：加被动免疫

* 马血清抗毒素或**人抗破伤风免疫球蛋白**

【治疗三原则】
1）尽早足量中和毒素（抗毒素/免疫球蛋白）
2）清除细菌（青霉素/甲硝唑等）
3）对症支持（镇静解痉、保持气道通畅等）

# 产气荚膜梭菌

## 生物学性状与培养特征

* 芽孢：**次端**，且芽孢宽度比菌体小
* 有荚膜、无鞭毛
* 生长快：代时可短至约**8分钟**（老师强调“非常快”）
* 生化反应活泼：分解糖/蛋白，产酸产气

【血平板】双层溶血环

* 内层：θ毒素相关的完全溶血（老师口述）
* 外层：α毒素相关的不完全溶血

【蛋黄平板】卵磷脂酶作用

* 产生白色浑浊圈
* 加入抗毒素浑浊圈消失：**Nagler反应（奈格勒反应）**

【牛奶包肉培养基】

* 产酸使酪蛋白凝固 + 产大量气体把凝块冲成蜂窝状，甚至顶开封口
* 称“**汹涌发酵**”

## 毒素与分型

* 可产多种毒素，按毒素型分型
* 对人主要：**A型、C型、F型**

  * A型：气性坏疽相关
  * C型：坏死性肠炎相关
  * F型：食物中毒相关

## 关键致病物质

* 【考点】α毒素 = **磷脂酶C**

  * 破坏细胞膜磷脂 → 通透性↑ → 溶血、组织坏死、出血、水肿等
* 肠毒素（F型）：老师刚讲到“作用于肠上皮细胞膜”，录音到这里截断（后半段若你还有录音我可以继续无缝补全）。

## 本节课反复出现的高频考点清单

* 分枝杆菌属共同特征：**细胞壁脂质多 → 抗酸、慢生长、肉芽肿**
* 结核分枝杆菌

  * 细胞壁结构三层与脂质高的“连锁后果”
  * 培养：专性需氧 + fastidious + 罗氏培养基 + 慢生长 + 菜花状菌落
  * 抵抗力：三抗三敏感
  * 变异：耐药分型、BCG来源
  * 致病物质：索状因子、硫酸脑苷脂、磷脂、蛋白+蜡质D
  * 原发 vs 继发感染、开放性肺结核
  * 结核菌素试验：原理、时间窗、判读、假阴性
  * 治疗原则：早期适量联合规律全程、DOTS
* 梭菌属：有芽孢厌氧菌多外源感染、常靠外毒素致病
* 破伤风梭菌：鼓槌状终末芽孢、痉挛毒素逆行入中枢、裂解SNARE阻断抑制性递质释放
* 产气荚膜梭菌：双层溶血、Nagler反应、汹涌发酵、α毒素磷脂酶C

## 课堂里提到的关键操作流程复述

1）结核菌素试验：前臂**皮内注射PPD** → **48–96小时**观察红肿硬结 → 按mm判读。
2）结核标本预处理：痰/粪便等污染标本先用酸/碱/硫酸等**去杂菌去杂质**；尿液可**离心浓缩**后再检。
3）破伤风暴露后的预防：**清创扩创、避免包扎造成厌氧环境**；按免疫史决定**类毒素主动免疫**，污染重且无基础免疫者加**抗毒素/免疫球蛋白被动免疫**。
4）破伤风治疗三原则：**早期足量中和毒素** + **抗生素清除细菌** + **解痉镇静与气道管理等支持治疗**。
