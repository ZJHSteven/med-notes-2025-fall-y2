## 0）这段录音里最常见的“错词纠正”（很关键，不然你会越背越歪）

* “**种论/总论**”✅：总论（general introduction）
* “**各论**”✅：各论（specific parasites）
* “**精虫**”✅：寄生虫（parasite）
* “**猿虫**”✅：原虫（protozoa）
* “**鸡虫**”✅：吸虫（trematode）
* “**抛虫/涛虫**”✅：绦虫（cestode）
* “**trimental / tommento**”✅：Trematoda / trematode（吸虫纲/吸虫）
* “**colon…senances**”✅：**Clonorchis sinensis**（华支睾吸虫）
* “**syisposmjpnicm**”✅：**Schistosoma japonicum**（日本血吸虫）
* “**bioduck**”✅：bile duct（胆管）
* 幼虫阶段常被识别乱：
  **毛蚴**（miracidium）/ **胞蚴**（sporocyst）/ **雷蚴**（redia）/ **尾蚴**（cercaria）/ **囊蚴**（metacercaria）

## 1）寄生虫总框架（老师反复强调：这是“毕业后还能记住”的骨架）

### 1.1 寄生虫（Parasites）三大块

1. **蠕虫（Helminths）**✅（重点学）
2. **原虫（Protozoa）**（下周老师讲）
3. **节肢动物（Arthropods）**（蚊、蝇等，多数课上略讲或不讲）

### 1.2 蠕虫再分三类（考试最爱从这儿下手）

* **吸虫（Trematodes）**：叶状/舌状、**不分节**、有吸盘
* **绦虫（Cestodes）**：**分节**（一节一节的）
* **线虫（Nematodes）**：线状圆柱形（“像面条”）

---

## 2）吸虫（Trematodes）概论：形态 + 生活史（先有“识别力”，再背虫种）

### 2.1 形态学特征（看到虫体大概就能“归类”）

* **体形**：多为**叶状/舌状**，背腹扁平，**左右对称**
* **分节**：**不分节（unsegmented）**
* **吸盘**：通常有 **2 个吸盘**

  * **口吸盘（oral sucker）**
  * **腹吸盘（ventral sucker）**
* **消化道**：**不完全消化道**（盲端、无肛门，残渣多经口排出）
* **生殖**：多数为**雌雄同体（hermaphroditic）**

  * **例外：血吸虫（Schistosoma）为雌雄异体（dioecious）**

### 2.2 生活史通则（“水 + 螺”是吸虫的灵魂）

* **必须有水环境**（卵入水，毛蚴孵化）
* **第一中间宿主必为淡水螺**（不同虫种对应不同螺）
* 幼虫发育多为无性增殖：
  **毛蚴 → 胞蚴 →（雷蚴）→ 尾蚴 →（囊蚴）**
* **感染期（infective stage）**两大类：

  * 多数吸虫：**囊蚴（metacercaria）感染**（靠“吃进去”）
  * 血吸虫：**尾蚴（cercaria）感染**（靠“钻皮肤”）

> 你可以把吸虫生活史背成一句话：
> **“卵入水 → 毛蚴找螺 → 螺里无性扩增 → 尾蚴出水 → 要么变囊蚴被吃，要么直接钻皮”**

## 3）华支睾吸虫（肝吸虫）Clonorchis sinensis（老师讲得非常“临床向”）

### 3.1 名称与寄生部位

* 学名：**Clonorchis sinensis**
* 常用名：**肝吸虫 / 华支睾吸虫**
* **成虫寄生部位**：**肝内胆管/胆管系统（bile ducts）**
* 可有多种**保虫宿主**：人、猫、狗、猪等（老师强调：这是防治难点）

### 3.2 形态（考试常考：成虫像瓜子、卵像芝麻）

**成虫（adult）**

* 体形：狭长、前窄后宽，像**葵花籽/瓜子**
* 大小：约 **1–2.5 cm 长**，宽约 **3–5 mm**（老师口述范围）
* 生殖：雌雄同体；“华支睾”之名来自**睾丸呈树枝样分支**

**虫卵（egg）**

* 外观：黄棕色、椭圆形，**有卵盖（operculum）**
* **极小（老师强调：最小 → 容易漏诊）**
* 结构点：卵盖与卵壳交界处可见“小肩样突起”；卵盖对侧可见小突

> 老师给的临床提醒非常实用：
> **肝吸虫卵小 → 一次粪检阴性不保险 → 可重复取样/做沉淀浓缩再查**

### 3.3 生活史要点（必背“八件套”）

* **终宿主（definitive host）**：人（也可猫、狗、猪等）
* **寄生部位**：胆管系统
* **诊断期（diagnostic stage）**：**虫卵（粪便/引流液中）**
* **第一中间宿主**：淡水螺（老师点名：豆螺/沼螺/含螺等，考试可能要写“具体螺”）
* **第二中间宿主**：**淡水鱼/虾**（重点是鱼）
* **感染期（infective stage）**：**囊蚴（metacercaria）**
* **感染方式**：生食/半生食淡水鱼虾；或刀具/案板交叉污染
* **致病期（pathogenic stage）**：主要是**成虫**

> 老师课堂提问你可以直接背成判断题：
> **“吃螺会得肝吸虫吗？”——通常不作为感染方式（感染期在鱼的囊蚴）。**
> 但现实生活里“生吃螺”本身并不安全（只是就肝吸虫这条链来说不是关键环节）。

### 3.4 致病机制（理解题/病例题最爱）

核心：**机械刺激 + 化学损伤 + 胆道阻塞 + 继发感染**

* 成虫寄生胆管 → 慢性炎症
* 胆管上皮增生/脱落 → 管壁增厚、管腔狭窄
* 虫体、虫卵碎片可参与阻塞 → 胆汁淤积
* 易合并细菌感染 → 胆管炎/胆囊炎
* 长期可致：**胆结石、胆管纤维化、肝硬化**
* 老师还强调：可诱发**胆管癌/肝胆系统肿瘤风险**（考试常作为“远期并发症”考点）

### 3.5 临床、诊断、流行、防治（老师讲得很“问诊导向”）

* **问诊关键词**：是否来自/去过流行区；是否吃鱼生/鱼生粥/醉虾醉蟹等
* **病原学诊断**：粪检找卵（必要时浓缩/沉淀）；十二指肠引流液/胆汁中找卵
* **流行与习惯强相关**：吃生鱼是核心驱动因素
* **防治**：粪便管理、灭螺、饮食卫生（生熟分开、刀板分开）、不喂猫狗生鱼等

## 4）日本血吸虫 Schistosoma japonicum（这段信息量爆炸，建议你按“生活史要点”抓住）

### 4.1 血吸虫的“总概念”（先别被各国名字吓到）

* 血吸虫是“血管寄生”的吸虫（blood flukes）
* 人体常见血吸虫有多种（老师提到日本、曼氏、埃及等）
* **我国本土流行的是：日本血吸虫（S. japonicum）**

### 4.2 形态学特征（最重要：它是吸虫里的“异类”）

**成虫（adult）**

* **雌雄异体**（吸虫中少见）
* 雄虫：短粗，有**抱雌沟（gynecophoral canal）**
* 雌虫：细长，常“住”在雄虫抱雌沟中
* 老师给的记忆法：**“一夫一妻，合抱终生直到死亡”**

**虫卵（egg）**

* 中等大小（老师用“约 10 个红细胞大小”帮助你估量）
* **无卵盖**
* 具**小侧刺/侧棘（lateral spine/knob）**（考试常作为鉴别点）
* **关键机制点：卵壳有微孔（你显微镜看不见，但功能上必须记住）**

  * 卵内分泌物（可溶性虫卵抗原等）外渗 → 诱发强烈炎症/肉芽肿
  * 目的：帮助虫卵穿过组织进入肠腔排出体外（否则生活史断掉）

**尾蚴（cercaria）**

* **感染期**
* 有叉状尾（forked tail），头部有腺体分泌蛋白酶样物质 → **10 秒左右可钻皮**

### 4.3 生活史（你必须能解释：它在血管里，为什么卵能从粪便排出来？）

* **终宿主**：人（及多种保虫宿主，老师强调自然界控制难）
* **寄生部位**：肠系膜静脉/门静脉系统相关静脉丛
* 成虫产卵 → 卵进入组织（肠壁/肝）
* 卵释放抗原 → **虫卵肉芽肿 + 溃疡** → 在压力/蠕动作用下破溃入肠腔
* **虫卵随粪便排出 → 入水孵化毛蚴**
* **唯一中间宿主**：**钉螺（Oncomelania，老师口述“钉螺”）**
* 螺内发育：毛蚴 → 胞蚴（母/子胞蚴）→ 尾蚴（**无雷蚴阶段**，老师反复点）
* 尾蚴出水 → **钻入皮肤** → 同虫移行（血/淋巴）→ 心肺 → 再到肠系膜静脉发育为成虫

### 4.4 血吸虫“哪个阶段致病？”（高频选择题）

老师给你的标准答案是：
**尾蚴、同虫、成虫、虫卵都能致病，但以虫卵最重。**

* **尾蚴**：侵入皮肤 → **尾蚴性皮炎/“游泳者瘙痒”**（偏 I 型超敏相关）
* **同虫移行**：经肺循环 → 肺部炎症表现（咳嗽、发热等）
* **成虫**：血管内膜炎等损伤（相对不是最“毁灭性”）
* **虫卵**（最重）：沉积肝/肠 → **肉芽肿（IV 型超敏）→ 纤维化 → 门脉高压/肝硬化/腹水**

### 4.5 临床分期（老师的时间轴是 4–8 周）

* **急性期（约感染后 4–8 周）**：发热、腹痛/腹泻、血便、肝脾肿大、嗜酸粒细胞增多等
* **慢性期**：反复接触疫水/多次感染 → 以消化道症状、营养/发育影响为主
* **晚期（终末期）**：肝硬化、腹水、门脉高压、上消化道出血、肝性脑病等（病死率高）

### 4.6 异位血吸虫病（老师说：这考验“医生水平”）

* 大量感染时，成虫/虫卵可出现在非常规部位
* **脑型血吸虫病**：容易被当成肿瘤，甚至误上“开颅”
* 老师给的临床教训：**多问疫水接触史 + 粪检/免疫学检查**，能避免很多“硬创伤误诊”

### 4.7 诊断（老师强调“病史 + 病原学”）

* **最基础**：粪便找卵（直接涂片/浓缩沉淀）
* **毛蚴孵化法**：孵化后放大镜观察（过去缺显微镜时很实用）
* **直肠黏膜活检**：慢性/晚期排卵少时，可看沉积死卵
* **免疫学**：老师点名必背 —— **环卵沉淀试验 COPT（circumoval precipitin test）**

### 4.8 免疫学现象（老师讲到但录音尾部截断）

* **伴随免疫（concomitant immunity）**：体内已有成虫时，对新入侵幼虫有一定杀伤/阻挡；成虫死后该保护减弱
* **免疫逃逸（immune evasion）**：成虫可长期在血管内躲过免疫清除（体表结构/抗原伪装等是研究热点）

## 5）两虫对比速背表（你考前 5 分钟就靠它撑着）

**肝吸虫（华支睾吸虫）**

* 寄生部位：**胆管**
* 中间宿主：**螺 + 淡水鱼**（第二宿主是鱼）
* 感染期：**囊蚴（吃进去）**
* 诊断：**粪便卵**（卵很小易漏）
* 致病主因：**成虫**（胆管炎/阻塞/纤维化/结石/胆管癌风险）

**日本血吸虫**

* 寄生部位：**肠系膜静脉/门脉系统**
* 中间宿主：**仅钉螺**（没有第二中间宿主）
* 感染期：**尾蚴（钻皮肤）**
* 诊断：**粪便卵** + **COPT** +（必要时直肠活检）
* 致病主因：**虫卵最重**（肉芽肿→纤维化→门脉高压/肝硬化/腹水）

## 6）直接可做 Anki 的高频问答卡（按老师出题习惯写的）

1. **吸虫三件套识别点？**
   叶/舌状、不分节、口腹两吸盘（多为雌雄同体）

2. **吸虫生活史的“必有”条件？**
   水环境 + 第一中间宿主淡水螺 + 螺内无性增殖阶段

3. **肝吸虫感染期是什么？怎么感染？**
   囊蚴；生食/半生食含囊蚴淡水鱼（刀板交叉污染也可）

4. **肝吸虫寄生部位与致病期？**
   胆管系统；致病期主要是成虫

5. **肝吸虫卵的关键考点？**
   最小、黄棕色、有卵盖、易漏诊（必要时浓缩/多次检查）

6. **日本血吸虫为什么叫“血吸虫”？**
   成虫寄生血管（肠系膜静脉/门脉系统），不是“吸血”为主概念

7. **日本血吸虫中间宿主与感染期？**
   钉螺；感染期尾蚴，钻皮肤感染（必须有疫水）

8. **日本血吸虫生活史里缺哪个幼虫阶段？**
   缺雷蚴（redia）阶段（老师反复强调）

9. **日本血吸虫在血管里寄生，虫卵怎么从粪便出去？**
   卵沉积肠壁 → 卵抗原外渗 → 肉芽肿/溃疡 → 破溃入肠腔 → 随粪便排出

10. **血吸虫病哪一阶段致病最重？**
    虫卵最重（IV 型超敏 → 肉芽肿 → 纤维化）

11. **尾蚴性皮炎属于什么免疫反应倾向？**
    偏 I 型超敏相关（局部皮炎/瘙痒）

12. **血吸虫病免疫学诊断老师点名哪一个？**
    COPT：环卵沉淀试验

13. **异位血吸虫病最容易误诊成什么？**
    肿瘤（尤其脑型），因此病史（疫水接触）极其关键
