# 课堂笔记（按老师讲课时间线）——病毒命名方式 → 肝炎病毒总论 → 甲肝（HAV）→ 乙肝（HBV）

---

## 一、病毒各论：章节为什么这样分（命名/归类逻辑）

老师先强调：病毒在“各论”里被放进某个章节，**归类方法不止一种**——因此“同一章里的病毒”，在分类学上**未必同科同属**。

1. **按传播途径归类**

* 例：按呼吸道、消化道、虫媒等传播途径把病毒放在一起。
* 推论：这些病毒**分类学来源可能不同**，但传播方式相似。

2. **按引起的疾病命名/归类**

* 例：**肝炎病毒**（Hepatitis viruses）、**出血热病毒**、**狂犬病病毒**（Rabies virus）等。
* 推论：同样，**疾病相似 ≠ 同科同属**。

3. **按“科”作为章节（分类学归类）**

* 例：**逆转录病毒**按**逆转录病毒科**（Retroviridae）讲；**疱疹病毒**按**疱疹病毒科**（Herpesviridae）讲。
* 推论：同科病毒往往具有**共同生物学性状/致病特点**。

## 二、回到“肝炎病毒”：定义、范围与“五型”

### 1）肝炎病毒的定义

**肝炎病毒**：指**主要侵犯肝脏**（主要靶器官是肝脏），并引起**病毒性肝炎**（viral hepatitis）的一组病毒。

【概念澄清】为什么某些也伤肝的病毒不叫“肝炎病毒”？

* 例：疱疹病毒科（Herpesviridae）的一些病毒，如**单纯疱疹病毒**（Herpes simplex virus, HSV）、**巨细胞病毒**（Cytomegalovirus, CMV）等也可导致肝损伤，甚至严重。
* 但它们**肝脏不是主要靶器官** → **不归入肝炎病毒**。

【提示】临床上仍存在“病因不明但表现为肝炎”的情况 → 暗示可能还存在**未知病原体**。

### 2）已明确的五型肝炎病毒（A–E）

* **甲肝**（Hepatitis A virus, **HAV**）
* **乙肝**（Hepatitis B virus, **HBV**）
* **丙肝**（Hepatitis C virus, **HCV**）
* **丁肝**（Hepatitis D virus, **HDV**）
* **戊肝**（Hepatitis E virus, **HEV**）

老师说明：因为“肝炎病毒”是按“疾病/主要靶器官”归类，**所以五型来源可不同科不同属** → **生物学特点、致病特点差异明显**，需要比较记忆。

【考点】老师强调：今天重点讲 **甲肝（急性代表）+ 乙肝（慢性代表）**；其余类型回去按表格/要点自学。

## 三、五型肝炎病毒对比（分类、核酸、大小、传播、慢性化、疫苗）

### 1）分类学 + 基因组/大小（老师逐个报参数）

* **HAV**：小RNA病毒科（Picornaviridae）/ 嗜肝病毒属（Hepatovirus）

  * **裸病毒**（non-enveloped）
  * **单正链RNA**（+ssRNA）
  * 直径约 **27–32 nm**
  * 基因组约 **7.5 kb**

* **HBV**：嗜肝DNA病毒科（Hepadnaviridae）

  * 五型里**唯一DNA病毒**
  * **环状、部分双链DNA**（partially double-stranded circular DNA；两条链长度不等）
  * 完整病毒直径约 **42 nm**

* **HCV**：黄病毒科（Flaviviridae）/ 丙肝病毒属（Hepacivirus）

  * **+ssRNA**
  * 约 **50 nm**
  * 基因组约 **9.5 kb**

* **HDV**：三角/δ相关（Deltavirus，老师称“三角病毒科/德耳塔病毒属”）

  * 五型里**唯一单负链RNA**（-ssRNA）
  * 约 **35–37 nm**
  * 基因组约 **1.7 kb**

* **HEV**：戊肝相关分类
  【教材更新】老师提醒：新版教材对HEV分类做了更新（旧版可能没更新），提到 **Paslahepevirus** 等新分类名。
  【备考建议】新版旧版若有冲突：**考试不会因为你写旧版就判错**；电子版新版已上传学习通，可参考。

### 2）传播途径与慢性化趋势（老师按“消化道 vs 肠道外”讲）

* **HAV + HEV：经消化道传播**（fecal–oral route，粪-口途径）

  * 多为**急性肝炎**
  * **很少转慢性**
  * 免疫力极低者可能发展为**重症肝炎**
  * **有疫苗可预防**

* **HBV + HCV：肠道外途径传播**（parenteral transmission）

  * 以**血液传播**为主，也可**性接触传播**
  * 可致急性，也**易转慢性**
  * **HBV：有基因工程疫苗**，效果好
  * **HCV：目前无有效疫苗**（老师强调）

* **HDV：缺陷病毒（defective virus）**

  * 必须在**辅助病毒**帮助下才能形成有感染性的完整颗粒
  * 辅助病毒：**HBV**（提供表面抗原结构，如HBsAg）
  * 因此：

    * 要么与HBV**同时感染**（coinfection）
    * 要么在HBV感染基础上**重叠感染**（superinfection）
  * 预防策略：**预防HBV即可间接预防HDV**

## 四、甲型肝炎病毒（HAV）：发现、流行、结构基因组、致病、免疫、检查、防治

### 1）发现与分类变迁

* **1973年**：首次从急性肝炎患者**粪便**中用电镜观察到HAV。
* 早期曾归入小RNA病毒科的**肠道病毒属**（Enterovirus），后因**生物学性状/基因组序列不同**，重新归入新的属：**嗜肝病毒属**（Hepatovirus）。

### 2）流行特点与【举例】上海1988年暴发

* HAV常见**散发**，也可**暴发流行**（outbreak）。
* 暴发常因**共同污染源**（水源/食物）。
  【举例】**1988年上海**：食用被HAV污染且**未彻底加热**的**毛蚶** → 暴发流行
* 累计患者约 **30万+**
* 死亡约 **40多例（<50）**
  老师强调：总体**预后好、自限性（self-limited）**，重症多见于免疫力低者。

### 3）生物学特性（形态/核酸/颗粒类型）

* **球形**，**27–32 nm**
* **裸病毒**（无包膜）→ 结构为“核酸 + 衣壳”（nucleocapsid-like）
* **20面体对称**（icosahedral symmetry）
* 基因组：**+ssRNA**，约**7.5 kb**
* 电镜下可见两类颗粒：

  * **实心颗粒**：完整成熟、有感染性
  * **空心颗粒**：缺核酸、**无感染性**

【考点】HAV **只有一个血清型（single serotype）**，变异少 → 解释其疫苗预防效果好。

### 4）基因组结构（老师要求“大概了解”）

* 两端：**非编码区**（non-coding region）
* 中间：编码区，只有**一个开放读码框**（open reading frame, **ORF**）
* ORF分三段功能区：**P1 / P2 / P3**

  * **P1区**：编码结构蛋白（衣壳蛋白）

    * VP1、VP2、VP3（主要衣壳成分）
    * VP4：多见于成熟病毒体
  * **P2/P3区**：多为酶类（蛋白酶 protease、解旋酶 helicase、聚合酶 polymerase等）→ 参与复制与蛋白加工

### 5）抵抗力（环境稳定性）与切断传播

* 对**酸/碱/乙醚**耐受力较强：老师举例 **pH≈3 或 >10**仍可存活
* 加热：老师提到 **60°C 12小时**仍可能不灭活；但**煮沸5分钟可灭活**
* 可在**水生贝类**中存活较久（数周到数月）
* 可被**氧化剂、甲醛、含氯消毒剂**灭活；对**紫外线（UV）敏感**

【学习要点】这些稳定性解释了：为什么消化道传播 + 食物/水源管理对HAV极关键。

### 6）致病性（传染源、传播、潜伏期、排毒高峰）

* 传染源：

  * **患者**
  * **隐性感染者**（inapparent infection，常见但无症状）——重要原因：仍可排毒
* 传播：**粪-口途径**（fecal–oral）
* 潜伏期：**15–50天**，平均约**30天**

【考点】排毒与传染性时间窗（老师用图讲）

* 粪便排毒：暴露后约**2周开始**出现，**2–4周（潜伏期后段）排毒量最大、传染性最强**
* 发病（出现症状）后约**2周左右**粪便基本停止排毒（与抗体上升、清除病毒有关）
* 血中可出现短暂**病毒血症（viremia）**，但滴度低、持续短 → 血液传播导致甲肝**罕见**

### 7）发病过程（pathogenesis）与肝损伤机制

老师按路线描述：

1. 入口：经口进入消化道
2. 早期增殖：咽部/唾液腺初步增殖
3. 再增殖：到达肠道相关淋巴组织/淋巴结增殖
4. 入血：短暂病毒血症
5. 靶器官：到达肝脏，在肝细胞内复制
6. 排出：经胆汁 → 肠道 → 粪便排出

【机制】肝细胞损伤主要不是“病毒直接杀伤”，而是**免疫病理损伤（immunopathology）**：

* 清除细胞内病毒需要**细胞免疫**（尤其 **CTL/CD8+ T cell**）杀伤受感染肝细胞
* 感染过程中产生大量**干扰素**（interferon, IFN）→ 上调肝细胞表面 **MHC I** → 增强CTL杀伤
* 结论：免疫反应“清除病毒”的同时不可避免造成肝细胞损伤

### 8）临床表现与病程

* 多为**隐性感染**；少数显性感染
* 显性：急性肝炎（acute hepatitis）

  * **无黄疸型**：发热、乏力、恶心呕吐、食欲差、厌食厌油、转氨酶升高、肝脾肿大等
  * **黄疸型**：在上述基础上出现黄疸（巩膜黄染、尿色加深、粪色改变等）
* 病程：老师提到一般**3–4周**，多为**自限性** → 通常**不需要抗病毒治疗**

### 9）免疫学特点（IgM/IgG）与诊断意义

* **IgM 抗-HAV**：出现早、持续短（老师说约2个月左右下降）

  * 【考点】IgM阳性提示：**急性期/近期感染**（早期诊断）
* **IgG 抗-HAV**：出现晚、持续多年

  * IgG阳性提示：既往感染或疫苗接种后免疫
  * 多用于流行病学调查/免疫状态判断，不直接代表“正在感染”

### 10）微生物学检查（病原学 + 血清学）

* 病原学：分离病毒（临床少做）、抗原检测、核酸检测

  * HAV为RNA病毒 → 常用 **RT-PCR** 检测核酸
  * 也可用 **ELISA/EIA** 做抗原/抗体检测（老师口述“E SA”按语境纠正为ELISA）
* 血清学：IgM/IgG检测（意义见上）

### 11）防治原则

* **一般预防**：卫生管理（粪便、水源、食物）；患者排泄物消毒；切断粪-口传播
* **特异性预防（主动免疫）**：HAV疫苗（我国纳入计划免疫，儿童期免费接种）

  * 疫苗类型：**灭活疫苗（inactivated vaccine）**、**减毒活疫苗（live attenuated vaccine）**（国内均有应用）
  * 【特殊人群】老师提到WHO建议免疫低下/高风险人群（如AIDS、静脉吸毒者等）可考虑接种加强
* **被动免疫**：暴露后紧急预防 → 抗HAV免疫球蛋白（immunoglobulin）
* **治疗**：目前无特效抗病毒药；多为对症支持，因其自限性

## 五、乙型肝炎病毒（HBV）：流行负担、发现史、结构复制、传播致病、免疫机制、两对半解读

### 1）全球负担与公共卫生意义（老师引用统计）

【数据】老师说：据**WHO统计到2022年**：

* 慢性乙肝（chronic hepatitis B）约 **2.5亿**人
* 2022年新发约 **120万**
* 2022年死亡约 **110万**（多与肝硬化、肝癌相关）

老师强调：HBV是全球重要公共卫生问题；我国属于流行较重地区之一。

### 2）发现史：从“澳抗”到HBsAg

* **1965**：Blumberg（布兰伯格）在澳大利亚土著人血清中偶然发现特殊抗原 → **澳大利亚抗原**（Australia antigen，俗称**澳抗**）
* 后证实多见于肝炎患者 → “肝炎相关抗原”
* **1970**：电镜观察到HBV颗粒
* 最终明确：澳抗 = **HBV表面抗原**（HBsAg）
* **1976**：Blumberg因该发现获诺贝尔生理学或医学奖

### 3）血中三种颗粒形态（【考点】丹颗粒/大球形颗粒）

感染者血液里可见三种颗粒：

1. **大球形颗粒（Dane particle，丹颗粒）**

   * 直径约 **42 nm**
   * 【考点】**唯一“完整、有感染性”的HBV颗粒**
2. **小球形颗粒**

   * 直径约 **22 nm**
   * 数量最多；主要由**过剩HBsAg**装配
   * **中空、无核酸 → 无感染性**
3. **管形颗粒（filamentous particle）**

   * 直径约 **22 nm**，长度可 **100–500 nm**
   * 由小球形颗粒聚合而成
   * 主要成分HBsAg；**无核酸 → 无感染性**

### 4）丹颗粒结构（外层包膜 + 内层核衣壳）

* **包膜（envelope）**：来自宿主细胞膜的脂质双层

  * 包膜蛋白三种：**S / M / L 蛋白**

    * **S蛋白**：主要成分为 **HBsAg**
    * **M蛋白**：HBsAg + **preS2抗原**
    * **L蛋白**：HBsAg + preS2 + **preS1抗原**
  * 老师提示：这些与**致病/检测**都密切相关
* **核衣壳（nucleocapsid）**：约 **27 nm**

  * 壳蛋白 = **HBcAg（核心抗原）**
  * 内含：

    * **环状部分双链DNA（rcDNA）**
    * **DNA聚合酶（polymerase）**（后面讲到其多种酶活性）

### 5）基因组四个区（S/C/P/X）与对应蛋白

* **S区**：编码 HBsAg、preS1、preS2 → 形成S/M/L包膜蛋白
* **C区**：含 **preC + C**

  * C基因 → **HBcAg**（核心抗原，结构蛋白）
  * preC+C → 生成 **HBeAg前体**，加工后成为 **HBeAg（e抗原）**
  * 【考点】HBcAg多在肝细胞内，不入血；HBeAg可入血 → 解释“两对半”为什么测HBeAg不测HBcAg
* **P区**：编码聚合酶

  * 【考点】HBV聚合酶具三种关键活性：

    1. **DNA polymerase** 活性
    2. **Reverse transcriptase（RT，逆转录酶）**活性：以RNA为模板合成DNA
    3. **RNase H** 活性：降解RNA链
* **X区**：编码 **HBx蛋白**（转录/信号通路相关的反式激活作用）

  * 老师提示：与HBV相关肝癌发生可能密切相关

### 6）复制过程（老师按步骤走，核心关键词：cccDNA、pgRNA、逆转录）

1. 病毒吸附：认为主要由 **preS1** 与肝细胞受体结合（老师未展开受体名）
2. 入胞：内吞进入；包膜留在细胞膜，进入的是核衣壳
3. 去衣壳 → 核酸入核
4. **rcDNA修补成 cccDNA**

   * 【考点】**cccDNA**：covalently closed circular DNA（共价闭合环状DNA）
5. 宿主 **RNA Pol II** 转录 → 形成四条不同长度mRNA：**3.5 kb、2.4 kb、2.1 kb、0.7 kb**

   * **3.5 kb**：

     * 一部分作为 **pgRNA（pregenomic RNA，前基因组RNA）** → 子代DNA模板
     * 并翻译产生：**聚合酶、HBcAg、HBeAg相关蛋白**
   * **2.4 kb**：编码 **L蛋白**
   * **2.1 kb**：编码 **S蛋白、M蛋白**
   * **0.7 kb**：编码 **X蛋白**
6. 细胞质组装核衣壳：HBcAg包裹 pgRNA + 聚合酶
7. 核衣壳内逆转录：pgRNA → 负链DNA；RNase H降解RNA；再合成不完全正链DNA → 形成“部分双链”
8. 获得包膜（ER/高尔基体加工）→ 形成完整丹颗粒并释放
9. 部分核衣壳可回流入核 → 补充cccDNA库（老师称“回炉”）

### 7）动物模型与细胞培养

* 动物：种属特异性窄

  * 人 + 少数灵长类（如黑猩猩）
  * 可用**鸭乙肝病毒**感染鸭做模型
  * **转基因小鼠**（携带HBV基因）用于研究/药筛
* 细胞：

  * **人原代肝细胞**
  * **肝癌细胞系**（常需转染HBV以形成/释放病毒颗粒用于研究）

### 8）抵抗力与消毒学要点

* 对低温、干燥、紫外线等耐受较强
* 【考点】**70%/75%乙醇对HBV无杀灭作用**（老师强调）
* **煮沸10分钟可灭活**
* 对**氧化剂敏感** → 提示污染物/分泌物处理策略

## 六、乙肝致病性：传染源、传播途径、临床结局、肝癌关联、致病机制（“双刃剑”）

### 1）传染源

* 患者（血液/体液含病毒）
* **无症状携带者（asymptomatic carrier）**比例较大 → 重要传染源

### 2）传播途径（老师总结“三条”）

1. **血液/血制品传播**：输血等
2. **有创操作相关**：外科/牙科、穿刺、各种侵入性检查；静脉吸毒、纹身等
3. **母婴传播（vertical transmission）**：胎盘、产道、哺乳/产后密切接触

   * 【考点】在我国传统上最主要途径是**母婴传播**，其中最主要环节是**产道**
   * 老师给数据：若母亲 **HBsAg+ 且 HBeAg+（双阳）**，传播率可达 **~95%**
   * 现因新生儿阻断（疫苗 + 免疫球蛋白）传播明显下降，阻断率老师提到可达 **~90%**

补充：

* **密切接触传播**：共用牙刷、剃须刀等（可能有血液接触）
* **性接触传播**：我国相对少；西方国家常将HBV列为性传播疾病之一

### 3）感染后的不同结局（与免疫状态/病毒量相关）

* 免疫正常、应答有效 → 快速清除 → **急性感染/痊愈**（成人常见）
* 一次感染病毒量很高 → 强烈免疫清除 → 大量肝细胞坏死 → **重症肝炎（severe hepatitis）**
* 免疫功能低下/耐受 → 无法清除 → 病毒持续存在 → **慢性肝炎/无症状携带**
* 另有：**免疫逃逸（immune escape）**（如表面抗原、e抗原变异）与**免疫耐受（immune tolerance）**（尤其围产期相关）

### 4）与原发性肝细胞癌（HCC）的关系证据（老师列“几条依据”）

* HBV感染者发生肝癌风险较一般人高（老师提到可高出**200倍+**）
* 肝癌患者中**80%+**可检测到HBV相关指标
* 肝癌细胞内可检测到**整合状态HBV DNA**（integration）
* 动物实验：动物肝炎病毒感染可诱发肝癌（老师表述为强证据）

## 七、乙肝致病机制：免疫保护 vs 免疫损伤（老师强调“双刃剑”）

老师核心观点：HBV对肝细胞损伤**主要不是直接细胞溶解**，而是与**免疫反应**密切相关。
同一免疫反应包含两面：**清除病毒（保护）** + **损伤肝细胞（破坏）**。

### A. 免疫保护作用

1. **体液免疫（humoral immunity）**——关键是“哪些抗体是保护性的”

* **抗-HBs（表面抗体，anti-HBs）**：保护性强（疫苗目标）
* **抗-preS抗体（anti-preS，尤其preS1相关）**：可阻断病毒吸附/入侵（老师作为“有一定保护作用”讲）
* **抗-HBe（anti-HBe）**：提示复制下降、恢复趋势，传染性降低（相对“好指标”）
* **抗-HBc（核心抗体，anti-HBc）**：**无保护作用**（老师明确）

2. **细胞免疫（cellular immunity）**

* **CD8+ CTL**：识别MHC I呈递抗原 → 穿孔素/颗粒酶杀伤感染肝细胞，利于清除
* **CD4+ Th**：分泌细胞因子募集免疫细胞；促进CTL增殖分化；参与炎症调控

### B. 免疫损伤作用（同样由体液/细胞免疫介导）

1. 【机制/考点】**III型超敏反应（Type III hypersensitivity）**

* 抗原-抗体复合物（immune complex）形成后随血流沉积
* 可沉积于：关节滑膜、肾小球基底膜、肝内小血管等
* 激活补体（complement）→ 造成组织损伤
* 若在肝内小血管沉积 → 血栓 + 肝细胞大片坏死 → **重症肝炎**

2. **CTL过强导致肝损伤**

* 当受感染肝细胞数量巨大 → CTL杀伤范围扩大 → 大量坏死 → 重症表现

3. 【机制/考点】**II型超敏反应（Type II hypersensitivity）/自身免疫相关损伤**

* 病毒感染改变肝细胞膜结构 → 暴露“原本隐藏的自身抗原”
* 产生自身抗体 → 激活补体/巨噬细胞/NK等 → 肝细胞损伤

4. **免疫耐受 + 免疫逃逸**（老师把它们也算进“致病机制五点”里）

* 耐受：免疫应答弱 → 清除不了 → 慢性/携带
* 逃逸：抗原变异 → 原有免疫无效 → 持续感染与致病

【考点】老师总结“致病机制五点”：
体液免疫相关损伤、细胞免疫相关损伤、自身免疫相关损伤、免疫逃逸、免疫耐受。

## 八、乙肝微生物学检查：两对半（血清学）+ HBV DNA（核酸定量）

### 1）两大类检查

1. **血清学（serology）**：抗原/抗体系统（两对半）
2. **核酸检测**：**HBV DNA定量**（viral load），非常重要

### 2）两对半是什么（【考点】为什么没有“核心抗原”）

* “两对”：

  1. **HBsAg / 抗-HBs（anti-HBs）**
  2. **HBeAg / 抗-HBe（anti-HBe）**
* “半个”：**抗-HBc（anti-HBc）**
* 【考点】没有HBcAg：因为HBcAg主要在肝细胞内，不入血；两对半取血检测，血里检测不到HBcAg。

### 3）各指标意义（老师按“好/不好”讲）

* **HBsAg阳性**：提示**HBV感染者**（不能单凭它判断急慢性/携带）

  * 急性感染通常**1–4个月内消失**
  * 若**持续>6个月不消失** → 【不良提示】可能转慢性

* **抗-HBs阳性**：保护性抗体（好指标）

  * 可能：既往感染已痊愈，或疫苗接种获得
  * 意义：有免疫保护，通常可防再感染

* **HBeAg阳性**：病毒复制活跃、传染性强（与HBV DNA、DNA聚合酶水平相关，老师说“趋势一致”）

  * 持续存在：常提示慢性复制活跃

* **抗-HBe阳性**：复制下降、传染性降低、恢复趋势（较好指标）

* **抗-HBc**：无保护作用

  * **IgM anti-HBc**：提示急性期/近期感染、复制活跃
  * **IgG anti-HBc**：提示既往感染
  * 老师补充：临床上很多时候**不区分IgM/IgG**，只报“抗-HBc阳性”

### 4）急性 vs 慢性：血清学转换与“窗口期”

* **急性乙肝**：HBsAg出现后持续一段时间 → 消失 → 可能出现“窗口期（window period）” → 抗-HBs出现并长期持续
* **慢性乙肝**：HBsAg常持续存在（可多年甚至终生）；HBeAg可持续阳性或转阴；若抗-HBe出现通常提示复制减弱

### 5）两对半的用途（老师总结）

* **筛查血源**（献血者筛查常看HBsAg/澳抗）
* 辅助诊断感染状态
* 判断预后与传染性（尤其HBeAg/抗-HBe）
* 流行病学调查
* 评估疫苗接种效果（看抗-HBs水平）
