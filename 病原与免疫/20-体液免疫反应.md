一、总体框架
本章讲的是“由B淋巴细胞介导的体液免疫反应（humoral immune response）”，重点放在**B细胞遇到不同类型抗原（TD-Ag、TI-Ag）以后是怎么被激活、怎么分化成浆细胞和记忆B细胞、以及抗体产生呈现什么规律**上。

---

## 一、基本概念与分类

1. **免疫总体分两大块**：先天免疫（组织屏障、先天免疫分子、先天免疫细胞）和适应性免疫（T细胞、B细胞）。体液免疫是适应性免疫中由**B细胞→抗体**这一路完成的。
2. **抗原按是否需要T细胞辅助分两类**：

   * **胸腺依赖性抗原（TD-Ag, thymus dependent antigen）**：绝大多数是蛋白抗原，既有B细胞表位又有T细胞表位，B细胞要想真正被激活、增殖、发生类别转换，就得要**Th细胞的帮助**。
   * **胸腺非依赖性抗原（TI-Ag, thymus independent antigen）**：不需要T细胞帮助就能诱导B细胞产生抗体，多数是**脂多糖LPS或有大量重复表位的多糖/荚膜多糖**，本身还常常带**丝裂原性质**。TI-Ag 又分TI-1、TI-2两型。

**重点英文单词**：

* innate immunity
* adaptive immunity
* humoral immune response
* thymus dependent antigen (TD-Ag)
* thymus independent antigen (TI-Ag)
* mitogenic property / mitogen
* capsular polysaccharide

---

## 二、B细胞对胸腺依赖性抗原（TD-Ag）的应答

这是本章最核心的一段。它包含“识别→双信号→与Th细胞互作→生发中心反应→浆细胞和记忆B细胞形成”这条线。

### 1. BCR识别抗原的特点

1. **BCR可直接识别天然抗原**：包括天然蛋白、多肽、核酸、多糖、脂类、小分子化合物，多种形态都能认。
2. **既能认完整构象，也能认降解释放的空间构象表位**——也就是说不是只能认加工后的肽段。
3. **不需要APC加工提呈，也不受MHC限制**，这是和TCR最大的区别。
4. BCR识别到抗原后，抗原会被**内吞**，再走**MHCⅡ类分子途径**处理，把抗原肽-MHCⅡ复合物表达到B细胞表面，给特异性的Th细胞看。

**重点英文单词**：

* B cell receptor (BCR)
* natural antigen
* spatial conformation
* antigen processing and presentation
* MHC class II

### 2. B细胞激活所需的“双信号”

B细胞不像先天免疫那样只要一个刺激就开工，它要**两个信号**。

**第一信号（抗原信号）**

* 由 **BCR识别抗原** 发起；
* BCR旁边的 **Igα/Igβ（CD79a/CD79b）** 负责把信号传进细胞；
* 同时还有 **B细胞共受体复合物 CD19/CD21/CD81** 能和抗原上的C3d结合，增强信号；
* 多价抗原能让好多BCR被**交联（cross-linking）**，这样下游的Src家族酪氨酸激酶（Blk等）就会激活，ITAM被磷酸化，Syk被招募，启动一整串信号转导。

**第二信号（共刺激信号）**

* 来自**已经被激活的Th细胞表面的CD40L**；
* 结合B细胞表面的**CD40**；
* 这是B细胞进一步增殖、分化、类别转换必不可少的信号。
* 同时Th细胞还会分泌细胞因子（IL-4, IL-5, IL-6, IFN-γ等），细胞因子决定B细胞往哪种Ig类去转换。

**重点英文单词**：

* antigen signal / first signal
* costimulatory signal / second signal
* Igα/Igβ (CD79a/CD79b)
* CD19/CD21/CD81 co-receptor
* cross-linking
* CD40 – CD40L
* cytokines (IL-4, IL-5, IL-6, IFN-γ)

### 3. B细胞与Th细胞的相互作用

1. **B细胞给T细胞信号**：B细胞把抗原做成“抗原肽-MHCⅡ复合物”，让Th细胞的**TCR/CD3 + CD4**来识别，这是T细胞的第一信号；B细胞还会上调B7分子，与T细胞的CD28结合，给T细胞第二信号。
2. **T细胞再反过来帮助B细胞**：活化的Th细胞表达CD40L、分泌细胞因子，给B细胞第二信号和分化信号。
3. **T、B识别的不是同一表位，但必须来自同一抗原分子**——这是“半抗原-载体效应”的基础：B细胞靠BCR认“半抗原那一头”，加工后把“载体那一头”的T细胞表位递给Th，这样才能拿到T细胞的帮助。

**重点英文单词**：

* peptide-MHC II complex
* B7 / CD28
* carrier effect
* linked recognition
* Th1 / Th2 help

### 4. 生发中心（germinal center）反应

**生发中心是B细胞对TD抗原应答的主要场所**，发生在次级淋巴滤泡里，分暗区和明区。这里面发生了所有考试喜欢考的“高端操作”：高频突变、亲和力成熟、Ig类别转换、浆细胞和记忆B细胞的形成。

1. **细胞构成和区域**

   * 暗区：大量**中心母细胞（centroblast）**，分裂超快，不表达膜Ig；
   * 明区：**中心细胞（centrocyte）**，分裂慢，体积小，表达膜Ig，在这里和**滤泡树突状细胞（FDC）**、**滤泡辅助性T细胞（Tfh）**作用。
2. **Tfh（follicular helper T cell）**：分泌IL-21、IL-4、IFN-γ，是帮助B细胞应答的关键。
3. **FDC**：不表达MHCⅡ，不做提呈，但能用FcR、CR把Ag-Ab或Ag-Ab-C复合物挂在表面，像串珠一样，给B细胞“筛选”用。

**重点英文单词**：

* germinal center
* dark zone / light zone
* centroblast / centrocyte
* follicular dendritic cell (FDC)
* Tfh cell

### 5. 生发中心里发生的关键事件

1. **体细胞高频突变（somatic hypermutation）**

   * 发生在V区基因上的点突变，突变率极高（≈1/1000）；
   * 必须有抗原诱导 + Tfh辅助；
   * 目的：创造一群亲和力有高有低的BCR，为后面“优胜劣汰”做准备。
2. **亲和力成熟（affinity maturation）**

   * 抗原量变少以后，只有**高亲和力BCR**能从FDC上抢到抗原，就被选择性保留下来，于是整体抗体的平均亲和力越来越高，尤其是在再次免疫后最明显。
3. **Ig的类别转换（Ig class switch / isotype switching）**

   * 可变区（V区）不变，只是C区换了：IgM → IgG/IgA/IgE；
   * 需要T细胞的CD40L信号和相应细胞因子；
   * 转换后抗原特异性不变，但效应功能、分布部位变了。
4. **浆细胞（plasma cell）形成**

   * 不再表达BCR和MHCⅡ，专职高效分泌抗体；
   * 大部分会迁到骨髓，从基质细胞获得生存信号，长期分泌；
   * 异常增生可致**多发性骨髓瘤**。
5. **记忆B细胞（memory B cell）形成**

   * 表达高水平CD27、CD44；
   * 进入再循环，二次遇到同抗原迅速反应，产生高亲和力抗体。

**重点英文单词**：

* somatic hypermutation
* affinity maturation
* Ig class switching / isotype switching
* plasma cell
* memory B cell
* long-lived plasma cell

## 三、B细胞对胸腺非依赖性抗原（TI-Ag）的应答

TI应答整体上是“能快，但不精”；和TD相比，最大特点是**不需要Th细胞，所以不发生高频突变、亲和力成熟、Ig类转换和免疫记忆**。

### 1. TI-1抗原

1. 典型代表：**LPS**；
2. 有**丝裂原作用（B cell mitogen）**，高浓度可多克隆激活B细胞；
3. 低浓度时只激活特异克隆；
4. 单独只能诱导**低亲和力IgM**，不能诱导Ig类转换、不能产生记忆B细胞。

### 2. TI-2抗原

1. 多为**细菌细胞壁或荚膜多糖**，**高度重复结构**；
2. 通过大量重复表位把B细胞mIg广泛交联而激活；
3. 主要激活成熟B细胞，尤其是**B1细胞**；
4. 过度交联会让成熟B细胞进入耐受。

### 3. B1细胞

1. 占B细胞总数5%~10%，来源于胎肝，有自我更新；
2. 主要在腹膜腔、胸膜腔、肠黏膜固有层；
3. 识别谱窄，以TI抗原、自身抗原为主；
4. 无需Th辅助，不发生类转换、无记忆、再次应答不好；
5. 产生低亲和力、多反应性IgM，可作“天然抗体”；
6. 也可因自身抗原刺激产生致病性自身抗体。

### 4. TI应答的总特点

* 不需要Th cells
* 以IgM、低亲和力为主
* 无somatic hypermutation
* 无affinity maturation
* 无class switch
* 无memory B cells formation
* 临床意义：很多细菌的荚膜多糖是TI-2抗原，诱导的抗体能起**调理作用**，帮助吞噬。

**重点英文单词**：

* TI-1 antigen
* TI-2 antigen
* B1 cell
* polyclonal activation
* natural antibody
* opsonization

## 四、抗体产生的规律（primary vs secondary response）

体液免疫的另一个必考点是：**第一次遇到抗原和第二次遇到同一个抗原，抗体反应长得不一样**。这就是疫苗设计、加强免疫的理论基础。

1. **初次应答（primary response）**

   * 有明显的**潜伏期（lag phase）**，要等B细胞识别、T细胞帮助、生发中心反应建立；
   * 抗体量升得慢，平台期低，维持时间短；
   * 产生的抗体以**IgM为主**，亲和力低，不均一；
   * 需要的抗原量多。
2. **再次应答（secondary response, anamnestic response）**

   * 潜伏期很短，升得快；
   * 抗体峰值高，平台高、维持久；
   * 以**IgG为主**，亲和力高而均一，因为记忆B细胞已经“优化”过；
   * 需要的抗原量少。
3. **临床意义**：

   * 证明了适应性免疫有**记忆性（immunological memory）**；
   * 疫苗要“初免+加强”就是为了让机体进入“再次应答状态”；
   * IgM出现早、消失快，可用于疾病早期诊断。

**重点英文单词**：

* primary response
* secondary response
* lag phase
* log phase
* plateau phase
* decline phase
* immunological memory
* booster immunization
