## 1）快速复习：核酸结构与理化性质（老师回顾部分）

### 1.1 核酸组成与“磷恒定”

* 元素组成：**C、H、O、N、P**。
* 核酸有个“化学组成特点”：**磷含量相对恒定（约 9%–10%）**
  → 可用“测磷”来做核酸**定量**（通过 P 推核酸含量）。

### 1.2 核苷 / 核苷酸 / 多聚核苷酸

* 核苷酸 = **碱基 + 戊糖 + 磷酸**
* 核苷 = **碱基 + 戊糖**（不带磷酸）
* 核苷酸可带 **1～3 个磷酸基**（单/二/三磷酸核苷酸）。

### 1.3 键与方向性（非常高频）

* 碱基—糖：**N-糖苷键**

  * 嘌呤：糖的 1’C 连 **N9**
  * 嘧啶：糖的 1’C 连 **N1**
* 糖—磷酸：**磷酸酯键**
* 核苷酸之间聚合：**3’,5’-磷酸二酯键**
* 核酸链方向性：**5’端（游离磷酸）→ 3’端（游离羟基）**

  * **链延长方向：5’→3’**（新核苷酸加到 3’ 端）

### 1.4 DNA 结构层次

* 一级结构：**碱基排列顺序**（遗传信息本质载体）
* 二级结构：**右手双螺旋**

  * 两条链反向平行，绕同一轴右手螺旋
  * 骨架（磷酸+脱氧核糖）在外，碱基在内
  * A=T（2 个氢键），G≡C（3 个氢键）
  * 稳定力：横向氢键；纵向**碱基堆积力（老师强调“更关键”）**
  * 表面形成**大沟/小沟**：转录因子等蛋白结合位点（可稳定/可促解链以启动表达）
* 三级结构：

  * 原核/环状 DNA 常见：**超螺旋**
  * 真核核 DNA：**核小体**

    * 核心：组蛋白八聚体 + DNA 缠绕约 **1 又 3/4 圈**
    * 连接区：核小体间 DNA + **H1**（锁在交叉点，防止 DNA 解开）
  * 更高层盘绕 → 体积更致密，利于装入细胞核并增加稳定性。

### 1.5 三种 RNA（重点是 mRNA/tRNA/rRNA）

* **mRNA**：成熟 mRNA 结构（5’→3’）五部分
  1）5’ cap（帽）
  2）5’UTR
  3）编码区 ORF（开放阅读框）
  4）3’UTR
  5）poly(A) tail（A 尾）

  * 帽和尾：转录后加工加上去；保护 + 与蛋白结合定位/运输
  * UTR：不编码，但调控翻译起始/终止与效率
  * 密码子：每 3 个核苷酸一组；4³=64

    * **61** 个编码氨基酸；**3** 个终止密码子（终止信号）
* **tRNA**：最稳定、相似度高；长度约 **74–95 nt**

  * 二级结构：三叶草；三级结构：L 型
  * 3’端恒为 **CCA**，氨基酸连在末端 A 的 **3’OH**
  * 反密码子环与 mRNA 密码子配对，确保氨基酸放在正确位置
* **rRNA**：核糖体组成与翻译场所

  * 原核：大亚基（23S + 5S），小亚基（16S）
  * 真核：大亚基（28S + 5.8S + 5S），小亚基（18S）
  * 小亚基结合 mRNA，大亚基负责肽键形成与氨酰-tRNA 进入。

### 1.6 核酸紫外吸收、变性与杂交

* 核酸最大吸收：**260 nm**（碱基共轭双键吸收紫外）
* 蛋白最大吸收：**280 nm**
* 纯度判断：常用 **A260/A280** 比值
* DNA 变性：外界因素（加热等）破坏氢键 → 双链解开成单链

  * 变性后 **紫外吸收增强：增色效应（hyperchromic effect）**
  * 熔解曲线：随温度升高吸光度上升；终点对应 **Tm（解链温度）**
* 影响 Tm：
  1）**GC 含量**（3 H bonds，Tm↑）
  2）盐浓度
  3）分子大小（氢键总量更多）
* 复性：去除变性条件后互补配对恢复双链
* 分子杂交：不同来源 DNA-DNA 或 DNA-RNA 在互补条件下形成**杂合双链**（科研/临床用途很多）。

## 2）核苷酸代谢（本节的“核酸代谢收尾”）

### 2.1 总体框架

* 合成两条路：

  * **从头合成（de novo）**：小分子一步步搭建核苷酸
  * **补救合成（salvage）**：利用分解产物（碱基/核苷）快速回收合成
* 大多数组织可 de novo；但部分组织（老师点名：**脑、骨髓**）更依赖补救合成。
* **PRPP** 是关键“枢纽底物”：既参与从头合成，也参与补救合成，并联系嘌呤/嘧啶两条通路。

---

## 2.2 嘌呤核苷酸合成（复习重点）

### A）从头合成特点

* **特点：先在核糖（PRPP）平台上逐步“搭嘌呤环”**，而不是先做环再接糖。

### B）第一阶段：合成 IMP（共同前体）

* 老师要求：**重点记前两个关键反应（也是重要调节位点）**
  1）核糖-5-P → **PRPP**（酶：PRPP 合成酶）
  2）PRPP → 5-磷酸核糖胺（酶：**PRPP 酰胺转移酶 / amidotransferase**）

### C）第二阶段：IMP → AMP 与 GMP（重点背）

* IMP → AMP：多一个 **—NH₂**（涉及天冬氨酸提供氮等步骤），且需要能量（老师强调这块要记忆）
* IMP → GMP：先氧化/再胺化（需要谷氨酰胺提供氨等）
* **交叉调节**：合成 AMP/GMP 会分别消耗不同能量与底物，互相牵制以保持平衡。

### D）第三阶段：单磷酸 → 二磷酸 → 三磷酸

* NMP → NDP → NTP：靠激酶逐步磷酸化完成。

### E）补救合成（重点酶）

* 碱基 + PRPP → NMP

  * **APRT**：腺嘌呤 → AMP
  * **HGPRT**：次黄嘌呤/鸟嘌呤 → IMP/GMP
* 再强调：**PRPP 含量**会同时影响从头与补救。

---

## 2.3 嘧啶核苷酸从头合成（本节新重点）

### A）嘧啶环原子来源（老师要求掌握）

* **C2 来自 CO₂**
* **N3 来自谷氨酰胺（Gln）**
* 其余多来自 **天冬氨酸（Asp）**

### B）嘧啶从头合成的“核心特点”（和嘌呤对比）

* **特点 1：先合成嘧啶环，再与 PRPP 提供的核糖-磷酸结合**

  * 嘌呤：在 PRPP 平台上搭环
  * 嘧啶：先做环再接糖

### C）分阶段（老师用于帮助记忆）

1）嘧啶环合成

* 第一步：CO₂ + Gln + ATP → **氨基甲酰磷酸**（酶：**CPS II**）
* 第二步：+ Asp → 氨基甲酰天冬氨酸（酶：天冬氨酸氨基甲酰转移酶）
* 脱水闭环、再脱氢 → **乳清酸（orotate）**（完成嘧啶环）
  2）乳清酸 + PRPP → 乳清酸核苷酸 → 脱羧 → **UMP**
  3）UMP → UDP → UTP；UTP +（来自 Gln 的氨基）→ **CTP**
  4）胸腺嘧啶核苷酸（dTMP）生成：
* 关键点 1：**“脱氧发生在二磷酸核苷酸水平（NDP）”**
* 关键点 2：dUMP → dTMP 只差一个 **甲基**

  * 甲基供体：**N⁵,N¹⁰-亚甲基四氢叶酸**
  * 酶：**胸腺嘧啶酸合成酶（thymidylate synthase）**

### D）CPS I vs CPS II（老师明确要求区分）

* 共同点：都生成氨基甲酰磷酸
* 不同点（老师逐条讲）：
  1）定位：

  * **CPS I：肝线粒体**（尿素循环）
  * **CPS II：胞质**（嘧啶从头合成）
    2）氮来源：
  * CPS I：游离氨（来自氨基酸分解）
  * CPS II：谷氨酰胺
    3）调控：
  * CPS I 需要 **N-乙酰谷氨酸**作为别构激活剂
  * CPS II 主要受产物反馈抑制（不同生物位点不同：细菌 vs 哺乳动物调控位点不同，老师提醒“别死记混”）
    4）功能归属：
  * CPS I：尿素合成
  * CPS II：嘧啶核苷酸合成

### E）嘧啶补救合成（了解为主）

* 游离嘧啶碱基 + PRPP（提供核糖-磷酸）→ 相应核苷酸
* 再经磷酸化变成 NTP。

## 2.4 脱氧核糖核苷酸合成（DNA 原料来源）

* 规律：**脱氧核苷酸不是从头一步步搭出来，而是由核糖核苷酸“还原”而来**
* 关键点：还原发生在 **NDP（核糖二磷酸核苷酸）** 水平
* 还原体系（老师讲了“氢怎么传递”）：

  * 直接供氢：**硫氧还原蛋白（thioredoxin）**的巯基（—SH）
  * thioredoxin 被氧化成二硫键后，需要再还原
  * 还原它的最终氢源：**NADPH**
  * NADPH →（先给 FAD 形成 FADH₂）→ 再把氢递回 thioredoxin → 继续循环
* 特例：**dTMP** 主要来自 dUMP 甲基化（上面已写）。

## 2.5 抗代谢物（核酸合成抑制剂，临床肿瘤化疗相关）

* 定义：结构类似核苷酸合成原料/中间体 → **竞争性抑制或“以假乱真”**阻断合成
* 分类：嘌呤类似物、嘧啶类似物、氨基酸类似物、叶酸类似物
* 例子（老师举例重点讲 6-MP）：

  * **6-巯基嘌呤（6-MP）**：次黄嘌呤类似物

    * 可反馈抑制从头合成关键步骤
    * 也可干扰补救途径（影响 HGPRT 等）
    * 结果：腺嘌呤/鸟嘌呤核苷酸供应下降 → 核酸合成受阻
* 临床要点：肿瘤细胞核酸合成旺盛，受抑制更明显，但正常增殖细胞也受影响 → **化疗副作用来源**。

## 2.6 核苷酸分解（合成难，分解相对简单）

### A）嘌呤分解 → 尿酸（关键酶：黄嘌呤氧化酶）

* 腺嘌呤/鸟嘌呤等最终都转为次黄嘌呤/黄嘌呤，再到 **尿酸**
* **黄嘌呤氧化酶（xanthine oxidase）**是关键点
* 尿酸溶解度低：生成与排泄失衡 → **痛风**

  * 痛风机制：尿酸盐结晶沉积小关节 → 无菌性炎症（红肿热痛，痛最剧烈）
  * 原因概括：
    1）生成增多：高嘌呤饮食（内脏、烧烤等）、酶异常、细胞大量破坏（周转↑）
    2）排泄减少：肾功能受损
  * 治疗思路之一：抑制生成

    * **别嘌醇（allopurinol）**：黄嘌呤氧化酶抑制剂（老师点到）

### B）嘧啶分解 → 小分子（一般不堆积）

* 产物常为：**CO₂、NH₃、β-丙氨酸、β-氨基异丁酸**等
* 水溶性好，不易在体内堆积，临床症状相对少；部分可再利用。

# 3）新章：物质代谢调节（老师说“总结 + 少量新内容”）

## 3.1 代谢的整体性（途径间相互联系）

* 三大营养物质：糖、脂、蛋白
* 共同归宿：多转成 **乙酰辅酶A（acetyl-CoA）** → 三羧酸循环（TCA）+ 氧化磷酸化
* 特点：途径之间 **相互联系、相互依存、相互支持、相互制约**

  * 某条分解增强，其他往往被抑制（老师举例：糖多 → 脂肪/蛋白分解被抑制）

## 3.2 代谢池与动态平衡

* 代谢池：不同来源的同类物质混在一起共同代谢（如血糖来自食物、肝糖原、糖异生）
* 动态平衡：不是“一条直线不变”，而是偏高就拉回、偏低就补回

  * 血糖例子：

    * 进食↑ → 胰岛素↑ → 组织摄糖↑ + 肝糖原合成↑ → 血糖回落
    * 饥饿↓ → 胰高血糖素↑ → 肝糖原分解↑ → 血糖回升

## 3.3 合成反应的“还原力”：NADPH

* 体内多数合成反应供氢（还原力）来自 **NADPH**
* NADPH 主要来源：**磷酸戊糖途径（PPP/HMP shunt）**

## 3.4 能量代谢中心：ATP + 磷酸肌酸缓冲

* 机体直接可用能量形式：**ATP**（不是长期储存形式）
* 短期缓冲储能：**磷酸肌酸（phosphocreatine）**

  * ATP 高能磷酸转给肌酸形成磷酸肌酸储存
  * ATP 不足时，磷酸肌酸再把能量转回生成 ATP
  * 老师强调：对 **脑组织、肌肉**尤其重要（快速供能缓冲）

## 3.5 三大营养物质的相互转化（考点很爱考“能不能转”）

### A）糖 ↔ 脂肪

* 糖 → 脂肪：葡萄糖分解到乙酰-CoA，过剩可合成脂肪酸→甘油三酯储存
* 脂肪酸 → 糖：**基本不行**（乙酰-CoA 不能净生成草酰乙酸/丙酮酸去做糖异生）

  * 例外：脂肪的 **甘油**部分可进糖异生，但量小常被“忽略不计”（老师原话逻辑）

### B）脂肪氧化与“糖的必要性”（酮体与糖尿病酮症酸中毒）

* 脂肪动员↑ → 乙酰-CoA↑
* 若糖供应不足 → 草酰乙酸不足 → TCA 受限 → 乙酰-CoA 改走 **酮体**途径
* 糖尿病常见并发症：**酮症酸中毒（DKA）**

  * 本质：葡萄糖利用障碍 + 脂肪分解增强 + TCA 受限 → 酮体堆积

### C）糖 ↔ 氨基酸

* 氨基酸脱氨后剩 **α-酮酸**

  * 可变糖/可生酮/兼生（生糖氨基酸、生酮氨基酸、生糖兼生酮）
* 糖代谢中间体可转氨生成部分氨基酸

  * 丙酮酸 + 氨基 → 丙氨酸
  * 草酰乙酸 + 氨基 → 天冬氨酸
  * α-酮戊二酸 + 氨基 → 谷氨酸

### D）氨基酸 ↔ 脂类 / 核苷酸

* 氨基酸可转脂肪（生酮氨基酸贡献大）
* 氨基酸是核苷酸合成原料（Gly、Asp、Gln 等）
* 一碳单位（叶酸系统）也常来源于氨基酸转化
* 糖代谢通过 PPP 提供核糖-磷酸 → 把糖代谢与核酸代谢连起来。

## 3.6 器官联系：肝脏是代谢枢纽（老师讲得很“临床化”）

* **肝脏在糖代谢**：糖原合成/分解、糖异生 → 维持血糖稳态
* **肝脏在脂代谢**：

  * 胆固醇→胆汁酸（影响脂类消化吸收）
  * 内源性 TG/胆固醇/磷脂合成
  * VLDL 合成、HDL 相关代谢
  * 脂肪酸氧化与**酮体生成**（向外输出能量）
* **肝脏在蛋白质代谢**：

  * 血浆蛋白合成（白蛋白：维持胶体渗透压；凝血因子等）
  * 尿素合成（解毒：氨→尿素）
  * 甲胎蛋白（AFP）：胎儿期高，成人低；若升高提示肿瘤风险（需进一步检查）
* **维生素与胆汁酸**：脂溶性维生素 A/D/E/K 的吸收依赖胆汁酸乳化；摄入过多可在体内蓄积（主要在肝）
* **生物转化（灭活）**：激素/药物作用后在肝灭活

  * 肝功能差 → 雌激素灭活差 → **蜘蛛痣、肝掌**（老师用很典型的体征例子提醒大家）

# 4）代谢调节“三个层级”（老师说是本章重点）

## 4.1 细胞水平（最重点：围绕“关键酶”）

### A）关键酶与限速酶

* 关键酶常位于：代谢途径**起始步骤**或**分支点**
* 其中反应最慢、决定通量的：**限速酶（rate-limiting enzyme）**

### B）改变酶结构：两种（必须会区分）

#### ① 变构调节（allosteric regulation）

* 小分子结合在 **活性中心之外** → 引起构象变化 → 活性改变
* 小分子称 **变构效应物**：变构激活剂 / 变构抑制剂
* 特点（老师列了好几条）：

  * 多为多亚基酶（调节亚基 + 催化亚基）
  * 效应物可为底物、产物或其他小分子
  * 不符合典型米氏方程（动力学呈 S 型等概念你后面可再配图理解）
  * 结合/解离不需要 ATP、不需要酶催化（非共价作用）

**老师例子：PKA（蛋白激酶A）**

* 结构：2 调节亚基 + 2 催化亚基
* 变构激活剂：**cAMP**
* cAMP 结合调节亚基 → 调节与催化亚基解离 → 游离催化亚基有活性 → 下游蛋白磷酸化

#### ② 共价修饰调节（covalent modification）

* 在酶催化下，酶蛋白发生**可逆共价修饰**（加/去某化学基团）→ 构象改变
* 常见：磷酸化/去磷酸化（最重要）、乙酰化、甲基化等
* 特点（老师强调的逻辑）：

  * 涉及共价键生成/断裂
  * 通常需要能量（如 ATP 提供磷酸基）
  * 酶常呈“有/无活性”两态切换
  * 常受激素调控，并出现**级联放大效应**

**糖原代谢经典例子（老师复述）**

* 糖原磷酸化酶：磷酸化后活性↑（促进分解）
* 糖原合酶：磷酸化后活性↓（抑制合成）
* 同样是磷酸化，但方向相反——别背串了。

### C）改变酶含量（慢调节，但持续久）

* 通过影响酶蛋白的**合成与降解**实现
* 合成增加：**诱导（induction）**；合成减少：**阻遏（repression）**
* 常见规律：

  * 底物增多 → 往往诱导相关酶合成
  * 产物增多 → 反馈抑制酶合成（阻遏）
  * 激素/药物也常诱导代谢酶（加快生物转化，降低毒性）

### D）蛋白质降解途径（老师补了一段“机制细节”）

* 溶酶体途径：识别特异性相对低
* 蛋白酶体途径：识别特异性高

  * 进入蛋白酶体前常需 **泛素化（ubiquitination）** 标记
  * 调节酶降解速度多靠蛋白酶体途径。

---

## 4.2 激素水平（器官水平）

* 激素定义：由内分泌细胞产生，经血运输，作用于远处靶器官的微量活性物质
* 关键：**必须有受体**才能响应

### 按受体位置分两类

1）**膜受体激素**：受体在细胞膜

* 多为肽类/蛋白类激素（胰岛素、胰高血糖素、肾上腺素、生长激素等）
* 激素不能自由穿膜 → 结合膜受体 → 产生**第二信使** → 触发细胞反应
  2）**胞内受体激素**：受体在细胞内/细胞核
* 多为脂溶性：类固醇激素、甲状腺激素、维生素 D3 等
* 进入细胞→激素-受体复合物结合 DNA → 调控转录（诱导/抑制）→ 改变蛋白表达。

## 4.3 整体水平（中枢整合：饱食/饥饿/应激）

### A）饱食（餐后）——受膳食结构影响

* 混合膳食：胰岛素中等升高；优先利用葡萄糖；多余糖→糖原/脂肪储存
* 高糖：胰岛素明显升高，胰高血糖素降低；大量糖→脂肪合成与储存
* 高蛋白：胰岛素中等升高，胰高血糖素升高；肝糖原分解+糖异生补血糖；氨基酸部分供能、部分转脂
* 高脂：胰岛素降低，胰高血糖素升高；肝糖原分解+糖异生补血糖；脂肪供能增强，酮体生成增加（并强调脑组织不能用脂肪酸，优先糖，其次酮体）

### B）空腹（餐后约 12h 未进食）

* 胰岛素↓，胰高血糖素↑
* 早期：主要靠**肝糖原分解**补血糖
* 糖原耗尽后（老师说大约 8–12h 会接近用完）：**糖异生↑**、脂肪动员↑、酮体生成↑
* 肌肉氨基酸分解↑为糖异生提供原料。

### C）饥饿

* **短期饥饿（1–3 天）**：糖原已耗尽；脂肪酸氧化↑、酮体↑；糖异生明显↑（原料主要来自肌肉蛋白分解）→ 体重下降明显
* **长期饥饿（>3 天）**：为保护生命结构蛋白，蛋白分解↓；脂肪动员进一步↑，酮体大量生成；糖异生相对下降（原料不足）

### D）应激（创伤、剧痛、缺氧、感染、中毒等）

* 交感兴奋：肾上腺素↑；胰高血糖素↑；生长激素↑（皮质醇等也参与）；胰岛素↓
* 总体代谢效应：三大营养物质分解都增强，血糖升高以保证脑供能，同时脂肪、蛋白动员增强以应对刺激。

# 5）本节“背诵/易考清单”（按老师强调整理）

1. 3’,5’-磷酸二酯键；核酸链方向：**5’→3’**
2. DNA 双螺旋稳定力：氢键 vs **碱基堆积力（更关键）**；大沟/小沟意义
3. 核酸 260 nm、蛋白 280 nm；A260/A280；变性 **增色效应**；Tm 影响因素
4. 嘌呤从头合成：**PRPP 合成酶、PRPP 酰胺转移酶**（关键/调节点）；IMP→AMP/GMP 的差异与交叉调节
5. 补救合成关键酶：**APRT、HGPRT**；PRPP 的枢纽意义
6. 嘧啶从头合成：**CPS II**（胞质）+ Asp 相关关键步骤；“先合环后接 PRPP”
7. **CPS I vs CPS II**（定位、氮源、激活剂、功能）
8. 脱氧核苷酸：**由 NDP 还原**；thioredoxin + NADPH（经 FAD）传氢逻辑
9. 抗代谢物概念；6-MP 机制要会讲“结构类似→抑制从头/补救→核苷酸不足”
10. 嘌呤分解：**黄嘌呤氧化酶→尿酸**；痛风机制与别嘌醇
11. 代谢调节：关键酶/限速酶；**变构调节 vs 共价修饰**；级联放大（cAMP-PKA 轴）
12. 激素分类：膜受体 vs 胞内受体；饱食/空腹/饥饿/应激的激素与代谢走向。
