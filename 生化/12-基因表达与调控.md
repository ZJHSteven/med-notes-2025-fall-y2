## 二、基因表达与调控：老师想让你先建立的“总框架”

### 1）基因表达不等于“DNA→RNA→蛋白质”这么简单

* 经典中心法则：**DNA → RNA → Protein**
* 但调控绝不只发生在“转录那一刻”，而是贯穿全流程：

  * DNA 层面（染色质结构、启动子/增强子等）
  * RNA 层面（剪接、加帽加尾、输出核、稳定性、降解、RNA 干扰）
  * 蛋白层面（翻译效率、折叠、修饰、定位转运、泛素化降解）

### 2）“基因只占 5%”这个老师用来提醒你：非编码区很多是“调控信息”

* 以前把大量非编码序列叫“垃圾 DNA”，后来发现很多都参与：

  * **调控序列**（promoter/enhancer/silencer 等）
  * **染色质空间结构**：远端调控如何在空间上靠近启动子（染色质环、结构域；老师提到的“pad”更像在说 **TAD/染色质结构域**这种概念）
  * 核内定位：哪些区域贴近核膜/核内骨架会更倾向沉默
  * **转座子（transposons）**等

### 3）基因表达调控的核心意义：决定“细胞命运”和“细胞表型”

* 人类大约 3 万基因，但不同细胞类型（肝细胞、肾小管、视网膜、皮肤等）之所以不同：

  * 关键在**基因表达谱（expression profile）**不同
* **时空特异性（spatiotemporal specificity）**

  * 时间：发育不同阶段表达不同
  * 空间：不同组织/细胞表达不同
* 组成型表达 vs 适应性/诱导性表达

  * **管家基因（housekeeping genes）**：基本都表达，但也不是“完全不受环境影响”，只是相对稳定
  * **诱导性表达（inducible expression）**：环境刺激来了才开（老师举例：高渗/低渗诱导离子通道；发热/热刺激诱导 **热休克蛋白 HSP** 处理错误折叠蛋白）

## 三、调控的“多层次性”：从 DNA 到蛋白质，每一层都能卡你一道题

老师强调“真核复杂，所以层次多，形成网状调控”。

### 1）转录层面（Transcription）

* 起始（initiation）：RNA 聚合酶如何被招募到启动子
* 延伸（elongation）：聚合酶沿基因“跑”的过程如何被调控
* 暂停（pausing）：起始后不久（老师说大约 +70~+100 附近）可出现暂停
* 终止（termination）

### 2）RNA 加工与命运（RNA processing & fate）

* **加帽（5’ capping）**、**加尾（polyadenylation）**
* **剪接（splicing）**、**可变剪接（alternative splicing）** → 产生不同 isoforms
* 核输出（export）
* 稳定性与降解（stability/decay）：应激时“无关 mRNA”会更快被清掉
* RNA 聚集体/应激颗粒（老师描述的是这类现象）
* **RNA 干扰（RNA interference, miRNA/siRNA）**：小 RNA 与 mRNA 局部配对 → 招募剪切/降解复合体

### 3）翻译与翻译后（Translation & Post-translation）

* 翻译起始调控（translation initiation control）
* 翻译后：折叠（folding）、修饰（PTMs）、定位转运（trafficking）、降解（ubiquitin-proteasome）

## 四、表观遗传调控：DNA 不变，但“开/关门禁系统”变了

老师主线：**DNA 不变 → 通过表观层面决定什么时候开、什么时候关**。

* **DNA 甲基化（DNA methylation）**：常见后果是**转录因子上不去** → RNA 聚合酶也上不去 → 转录被抑制
* **组蛋白修饰（histone modifications）**：乙酰化/甲基化/磷酸化/泛素化等（老师举“histone code / 组蛋白密码”）

  * 影响染色质松紧、可及性（accessibility），从而影响转录
* 常染色质/异染色质（euchromatin/heterochromatin）：

  * 活化（开放）更易转录
  * 致密（关闭）更难转录

## 五、原核转录调控核心：乳糖操纵子（lac operon）——必考“条件推导”

### 1）先记一个老师的“辨别口诀”

* “**什么什么子**”多指 **DNA 序列**（启动子 promoter、增强子 enhancer、沉默子 silencer、操纵序列 operator…）
* “**什么什么因子/因素 factor**”多指 **蛋白质**（转录因子 TF、阻遏蛋白 repressor 等）

### 2）操纵子（operon）的定义（原核转录调控基本单位）

* 多个结构基因串联，共用上游调控区，一起转录成一条多顺反子 mRNA（poly-cistronic mRNA）

### 3）lac operon 结构：4 个基因 + 3 个关键 DNA 位点

* 结构基因：**lacZ、lacY、lacA**（你不需要死背各自酶名，老师说“知道有 3 个结构基因即可”）
* 调控基因：**lacI** → 编码 **阻遏蛋白（repressor）**
* DNA 位点：

  * **P（promoter）**：RNA 聚合酶结合位点
  * **O（operator）**：阻遏蛋白结合位点（“路障”位置）
  * **CAP site（CAP 结合位点）**：CAP-cAMP 复合体结合位点（正调控）

### 4）负调控（Negative control）：lacI 阻遏蛋白 = 路障

* 阻遏蛋白（常以四聚体形式）结合 O → 阻止 RNA 聚合酶有效启动/延伸 → **ZYA 关闭**
* **诱导剂（inducer）= 别乳糖 allolactose**

  * allolactose 与阻遏蛋白结合 → 阻遏蛋白构象改变 → 不能有效结合 O → 路障撤掉 → **具备“可转录”的前提**

### 5）正调控（Positive control）：cAMP–CAP 让转录“开得更大”

* 葡萄糖低 → **cAMP 升高**
* cAMP 与 CAP 结合 → 复合体结合 CAP site → **增强启动子活性** → RNA 聚合酶更容易/更稳定工作
* 葡萄糖高 → cAMP 低 →

  * CAP 复合体难形成 → 正调控弱 → 即使路障撤掉，也只能“低水平表达”

### 6）最重要的 4 种条件结论（考试最爱）

用“乳糖/葡萄糖”两变量推导：

1. **无乳糖 + 有葡萄糖**

* 阻遏蛋白在 O 上（路障在）
* cAMP 低（CAP 不上）
  → **几乎不转录（OFF）**

2. **有乳糖 + 有葡萄糖**

* allolactose 让阻遏蛋白下去（路障撤）
* 但 cAMP 低，CAP 不上
  → **低水平/基础表达（LOW）**（不是全开）

3. **有乳糖 + 无葡萄糖**（最强开关组合）

* 路障撤（有诱导剂）
* cAMP 高，CAP 上（强正调控）
  → **高水平表达（ON / HIGH）**

4. **无乳糖 + 无葡萄糖**

* 路障在（无诱导剂）
* CAP 可能上，但被路障“卡死”
  → **仍旧关（OFF）**

> 一句话背诵版：**“乳糖负责‘解除刹车’，低葡萄糖负责‘加油门’。”**

## 六、真核转录调控：顺式元件 + 反式因子（把概念说清就能拿分）

### 1）顺式作用元件（cis-acting elements）= DNA 序列

* 与目标基因在**同一条 DNA 分子上**
* 可与转录因子结合、影响转录效率
* 典型：**promoter、enhancer、silencer、上游启动子元件**
* 常见启动子元件（老师点名）：**TATA box、CAAT box、GC box**

增强子/沉默子特点（老师强调）：

* **不受方向性、距离影响（常见描述）**
* 通过染色质环化把远端拉近启动子，提高或抑制转录

### 2）反式作用因子（trans-acting factors）= 蛋白质

* 可以直接/间接识别顺式元件
* 分两大类：

  * **通用转录因子（general TFs，TFIIA/B/D/E/F/H 等）**：启动基本转录必需
  * **特异转录因子（specific TFs）**：决定时间/空间特异性表达
* 协同招募 coactivator/mediator 等形成更大复合体，核心目的：**把 RNA 聚合酶稳定住，促使转录起始发生**

### 3）顺式 vs 反式、顺式调节 vs 反式调节（老师举 A 调 B、C 调自己）

* A 基因产物（转录因子）去调控 B：**反式调节（trans regulation）**
* 某基因产物回头调控自己：**顺式（或自我调控/反馈）**（老师用“C 调控 C”讲这个意思）

### 4）转录因子典型结构域（老师要求你“知道它为什么能干这事”）

* **DNA-binding domain（DNA 结合结构域）**：能抓住特定序列
* **Activation domain（转录激活结构域）**：能招募其他蛋白复合体
  -（核受体还会强调 ligand-binding domain 等）

## 七、细胞信号转导（signal transduction）：把“外界刺激”送进细胞核的传令系统

老师的比喻：细胞像城市，细胞核是指挥部；信号转导是“传令兵”链路。

### 1）定义（按老师的话整理）

* 细胞通讯：一个细胞发出信号，另一细胞接收并转变为功能变化
* 信号转导：靶细胞接受外源信息后，细胞内发生一系列生化反应的全过程

### 2）信号转导一般步骤（非常标准，容易考简答）

1. 特定细胞释放信息分子（ligand）
2. 扩散/体液循环到达靶细胞
3. 与靶细胞受体（receptor）特异结合
4. 受体构象改变 → 启动细胞内级联放大
5. 产生效应（代谢改变/基因表达改变等）
6. 终止/负反馈（防止无限激活）

### 3）细胞间通讯方式（老师提到的 2 类）

* **直接接触（juxtacrine / cell-cell contact）**：比如免疫细胞杀伤常需要贴脸接触
* **分泌型（paracrine/endocrine/autocrine）**：分泌信号分子到环境/血液

### 4）受体共同特点（老师列的“背诵点”）

* 高度**特异性**（specificity）
* 高度**亲和力**（affinity）
* **可饱和性**（saturability）
* **可逆性**（reversibility）
* 结合模式“具体问题具体分析”

## 八、三条经典通路（本章最像考题的部分）

### A. GPCR–cAMP–PKA 通路

链路：
**Ligand → GPCR（7TM）→ G protein（GDP→GTP）→ Adenylyl cyclase → cAMP（第二信使）→ PKA → 下游蛋白/转录因子磷酸化 → 生物学效应**

要点：

* cAMP 由 ATP 生成；**PDE（phosphodiesterase）**可把 cAMP 降解回 AMP
* PKA 有 **R（regulatory）**和 **C（catalytic）**亚基：

  * cAMP 结合 R → 释放 C → C 才有激酶活性
* 信号到基因表达：老师举 **CREB**

  * PKA 磷酸化 CREB → CREB 结合 **CRE（cAMP response element）** → 激活相关基因转录
  * 记住：**element（元件）= DNA 序列**

### B. GPCR–PLC–IP3/DAG–PKC 通路

链路：
**Ligand → GPCR → G protein → PLC（phospholipase C）→ PIP2 裂解 → IP3 + DAG → Ca²⁺释放 + PKC 激活 → 下游效应**

要点：

* **PIP2**在膜上，被 PLC 切成：

  * **IP3**：去内质网膜受体 → 促 Ca²⁺释放入胞质
  * **DAG**：留在膜上，和 Ca²⁺/磷脂一起帮助激活 **PKC**
* Ca²⁺还可激活钙调蛋白（calmodulin）等 Ca²⁺响应蛋白（老师点到即可）

### C. RTK–Ras–MAPK 通路（酪氨酸激酶受体）

链路：
**Ligand → RTK 二聚化 → Tyr 自磷酸化 → adaptor（如 Grb2）→ Ras-GEF（如 SOS）→ Ras-GTP → MAPK 级联 → 转录因子磷酸化 → 基因表达**

要点：

* RTK 是**单次跨膜受体**，受体本身具有（或紧密偶联）酶活性
* “自身磷酸化”本质是二聚后**互相磷酸化**
* Ras 类似 G 蛋白开关；若 Ras 不能水解 GTP → 持续激活 → 易导致异常增殖（老师用“癌基因”提醒你这条线的重要性）

## 九、胞内/核内受体（intracellular/nuclear receptors）

* 受体位于胞浆或细胞核
* 配体多为**脂溶性**：类固醇激素、甲状腺激素等，能穿膜进入细胞
* 受体本质上常是**DNA 结合蛋白/转录因子**：配体结合后构象改变 → 入核或在核内直接结合 DNA → 调控转录
