# 氨基酸代谢

#  学习目标
1. **营养必需氨基酸的概念和种类**。
2. **氨基酸代谢中的几个基本概念**：氨基酸在体内的来源与去路（注意这说的是“氨基酸的来源和去路”）。
3. **氨基酸的脱氨基作用**：什么叫脱氨？什么叫转氨？转氨酶+辅酶是什么？什么叫联合脱氨？
4. **体内“氨”的来源与去路**

   * 老师特别提醒：**“氨的来源和去路”跟“氨基酸的来源和去路”是两套背景**，不要混。
5. **尿素在体内的生成与调节**

   * 关键反应要会，整个路径不用一字不漏背，但关键酶、关键点要会。
6. **氨基酸脱羧后能生成的、具有特殊生理活性的物质**

   * 要会谁生成谁、氨基酸和活性物质一一对应。
7. **一碳单位代谢（老师口误说成“低碳酸位代谢”）**

   * 要知道它不是“一碳单位的遗传”，而是它在体内的来源、形式和功能。

## 一、蛋白质与氨基酸代谢的总体意义

1. **蛋白质的生物学意义**

   * 是细胞骨架（cytoskeleton）的主要结构成分，保证细胞和组织的生长、生理更新与修复。
   * 具有多样功能：酶（enzyme）、载体（carrier）、免疫球蛋白（immunoglobulins）、肌肉收缩（muscle contraction）、代谢调节（metabolic regulation）等。
   * 蛋白质/氨基酸可在需要时**供能**（degradation and oxidation of AAs）
2. **氮平衡（nitrogen balance）**

   * 蛋白质中氮约占16%，比较“摄入氮量”与“排出氮量”可判断蛋白质代谢状况。
   * **总氮平衡 total balance**：摄入氮 = 排出氮（正常成年人）。
   * **正氮平衡 positive balance**：摄入氮 > 排出氮，如生长、妊娠、烧伤/大病恢复期。
   * **负氮平衡 negative balance**：摄入氮 < 排出氮，如大手术、恶性肿瘤消耗、营养不良。
   * 关键词：*nitrogen balance, positive balance, negative balance* 
3. **蛋白质需要量**

   * **最低 30–50 g/day**
   * **推荐**成人（65 kg 男）约 **80 g/day**
   * 关键词：*physical protein requirements* 
4. **蛋白质营养价值（nutrition value of proteins）**

   * **必需氨基酸 essential amino acids**：机体不能合成、必须由膳食供给。9种：Val, Ile, Leu, Phe, Met, Trp, Thr, Lys, His（缬、异亮、亮、苯丙、甲硫、色、苏、赖、组）。
   * **半必需氨基酸 semi-essential AAs**：如 Arg，正常成年人自己能合成，但婴儿、儿童、妊娠、哺乳、恢复期病人因为合成量跟不上，就得从食物再补。
   * **蛋白质质量 high/low value**：**营养价值取决于必需氨基酸的种类和含量**，动物蛋白（含全必需AA）→ 完全蛋白 complete protein；植物蛋白多为不完全蛋白 incomplete protein。
   * **互补作用 complementary effect**：豆类富含 lysine、谷物富含 methionine，两者合用可互补。
   * 关键词：*essential AAs, semi-essential, complete protein, incomplete protein, complementary effect*

## 二、蛋白质的消化、吸收与腐败（putrefaction）

1. **消化过程概览**

   * 口腔：机械性粉碎。
   * 胃：HCl + pepsin 开始蛋白化学消化。
   * 小肠：胰腺分泌的蛋白酶原（trypsinogen, chymotrypsinogen, proelastase, procarboxypeptidase）被肠激酶（enterokinase）激活 → 继续将多肽水解为寡肽和AA。
   * 小肠刷状缘寡肽酶（aminopeptidase, dipeptidase）将寡肽完全分解为游离AA，再通过**载体+Na⁺协同转运**（**主动运输**）进入肠上皮。
   * 关键词：*enterokinase, trypsin, chymotrypsin, elastase, carboxypeptidase, brush border peptidases* 
2. **急性胰腺炎（acute pancreatitis）与酶原提前激活**

   * 胰液排出受阻 → 胰腺内酶原提前被激活 → 自身组织被消化 → 剧痛甚至致命。
   * 关键词：*acute pancreatitis, zymogen, premature activation* 
3. **蛋白质腐败（putrefaction of protein）**

   * 未被消化吸收的蛋白/肽在结肠被细菌**脱羧（decarboxylation）**、**脱氨（deamination）**，生成：

     * 有毒胺（amines）、H₂S、indole、phenol、NH₃
     * 还可生成假性递质（false neurotransmitter）如 *octopamine, phenylethanolamine* → 与儿茶酚胺结构类似，可致肝性脑病。
   * 这些有毒的产物**依靠肝脏解毒**，否则进血会影响中枢。
   * 肠道NH₃可被吸收 → 肝再合成尿素。
   * 肠道细菌也生成维生素K，异常可影响凝血
   * 关键词：*putrefaction, amine, indole, phenol, ammonia, false neurotransmitter* 
4. **肠道产生的氨跟pH有关**

   * 肠道腐败会产生**NH₃（氨）**。
   * **酸性环境**：NH₃ + H⁺ → NH₄⁺，溶解度高、吸收差，多随粪便排出，有利于“排氨”。
   * **碱性环境**：大量游离NH₃被肠道吸收进血，会加重高氨。
   * 所以肠道碱化→血氨增高；酸化→利于排氨。

## 三、氨基酸代谢共同途径（common pathway）

这一部分是整章核心，要熟。

### 1. 氨基酸代谢库（metabolic pool of AAs）

* 概念：**所有来源的游离氨基酸汇在一起，变成一个可以随时被用的“池子”**。
* 食物来源AA + 组织蛋白周转（protein turnover）释放AA + 体内可合成的非必需AA → 构成**氨基酸代谢库**，体内游离AA总量不大但周转快。
* 这个池子里氨基酸的量不是固定的，不同器官大小不一样。
* 老师点名了**肌肉**和**肝脏**的氨基酸库最重要，因为：

   * 肌肉是大仓库，尤其运动时要把氮运出去。
   * 肝脏要负责解毒、尿素合成、糖异生，所以它的氨基酸库也活跃
* 蛋白降解有两条大路：

  1. **溶酶体途径**（ATP-independent，长寿命或膜蛋白）：

      * 发生在溶酶体里。
      * 不需要ATP。
      * 降解的对象：外源蛋白、膜蛋白、寿命很长的蛋白。
      * 特点：选择性差，进来就拆。
  2. **泛素-蛋白酶体途径**（ATP-dependent，短寿命/异常蛋白，需泛素ubiquitin标记，26S proteasome降解）：
   
      * 发生在胞质里。
      * 需要ATP。
      * 有明显“要不要降解”的选择，必须先**被泛素标记**。
      * 被标好几串泛素的蛋白送进蛋白酶体，被分段水解成氨基酸。
      * 降解的对象：**异常蛋白**（没折好、突变的）、**短寿命调节蛋白**、很多酶、调节蛋白。
      * 泛素会被回收再用。
* 关键词：*protein turnover, ubiquitin, proteasome, metabolic pool* 

> ### 氨基酸代谢的“大框架”
>
> 1. **氨基酸有两个关键部分**：
>
>    * α-氨基（–NH₂）
>    * α-酮酸骨架（脱了氨之后剩下的那部分）
>
> 2. **在体内代谢时主要做两件事**：
>
>    * 把氨基拆下来：**脱氨基作用**
>    * 把碳骨架送去三羧酸循环、糖异生、生成脂肪/酮体：**碳骨架代谢**
>
> 3. **氨基去哪儿？**
>
>    * 不能在血里乱飘，因为**游离NH₃对中枢尤其是脑有毒**。
>    * 所以要么在肝里变成**尿素**，要么先变成**谷氨酰胺**、**丙氨酸**这类“无毒载体”再运走。
>
> 4. **碳骨架去哪儿？**
>
>    * 变成三羧酸循环中间产物 → 氧化供能
>    * 或者走**糖异生**变葡萄糖
>    * 或者变成**乙酰辅酶A/乙酰乙酸** → 脂肪酸或酮体
>
> 5. 所以不同氨基酸就被分成：
>
>    * **生糖氨基酸**（最后能变成葡萄糖的）
>    * **生酮氨基酸**（最后变成乙酰辅酶A或乙酰乙酸，只能生酮/生脂，不能回头变糖的，典型是赖氨酸和亮氨酸）
>    * **兼性（生糖又生酮）** （苯丙氨酸、酪氨酸、色氨酸、异亮氨酸等）


### 2. 脱氨基作用（deamination）

氨基酸要进入分解，氮必须先下来，总共有**5种途径**：

1. **转氨基作用**（最常见）
2. **L-谷氨酸的氧化脱氨**
3. **联合脱氨（=1+2合起来）——这是体内真正主要的方式**
4. **肌肉里的“丙氨酸-葡萄糖循环”相关的转运/脱氨路线**
5. **氨基酸氧化酶直接脱氨**（这条在人体里不主要）

我们**重点只学前3条**：

1. **转氨作用（transamination）**

   * 含义：AA的氨基 ↔ 相应α-酮酸的氧 → 互换；实质是把各AA的氨先集中到**谷氨酸 Glu**上。
   * 酶：aminotransferase / transaminase（转氨酶）
   * 辅酶：*pyridoxal phosphate, PLP* ← 维生素B₆
   * 可逆；不能转氨的有 Lys, Thr, Pro
   * 三个主要受体酮酸：**pyruvate, α-ketoglutarate, oxaloacetate**
   * 临床重要的两条：

     * ALT (GPT): alanine + α-KG ⇄ pyruvate + Glu
     * AST (GOT): aspartate + α-KG ⇄ oxaloacetate + Glu
   * 肝、心损伤 → ALT/AST入血 ↑，可作诊断指标。
   * 关键词：*transamination, aminotransferase, PLP, ALT/GPT, AST/GOT, α-ketoglutarate* 
2. **氧化脱氨（oxidative deamination）**

   * 关键酶：**L-glutamate dehydrogenase**（谷氨酸脱氢酶），在线粒体基质，主要在肝、肾、脑。
   * 反应：Glu + NAD(P)⁺ + H₂O → α-KG + NH₃ + NAD(P)H
   * 特点：能直接把谷氨酸的氮转成游离NH₃，是“真正放氨”的关键一步。
   * 关键词：*oxidative deamination, glutamate dehydrogenase, NAD⁺/NADP⁺* 
3. **联合脱氨（union deamination）**

   * 实际是“多数AA先转氨到Glu + Gln，再由Glu做氧化脱氨”，前后合起来就像这类AA也完成了脱氨。
   * 关键词：*transamination + oxidative deamination = union deamination* 

### 3. α-酮酸的去路（metabolism of α-keto acids）

* AA 去氮后留下的碳骨架（carbon skeleton）= 相应α-酮酸，可以：

  1. 合成非必需AA；
  2. 进入糖异生 → 葡萄糖；
  3. 转成脂肪酸或酮体 → 能量/储存。
* 据碳骨架进入的代谢产物分：

  * **生糖型 glucogenic AAs**：最终能变成葡萄糖（如进TCA → OAA）。
  * **生酮型 ketogenic AAs**：只能生成乙酰辅酶A或乙酰乙酰CoA → 只能生酮/合脂，不可再糖异生。典型：Leu, Lys。
  * **兼有型 glucogenic & ketogenic**：Ile, Phe, Tyr, Trp, Thr。
  * 关键词：*glucogenic, ketogenic, carbon skeleton*

## 四、氨的来源与转运

1. **内源性来源（endogenous sources）**

   * 各AA脱氨：**主要来源**
   * 含氮化合物（amines 等）分解
   * 肾脏、肠道谷氨酰胺分解
2. **外源性来源（exogenous sources）**

   * 肠道蛋白腐败产氨
   * 肠道细菌分解尿素（urease）产氨
   * 这部分氨吸收入门静脉 → 肝 → 再合成尿素
   * 关键词：*ammonia sources, deamination, intestinal bacteria, urease* 
3. **转运方式**

   * **丙氨酸-葡萄糖循环（alanine-glucose cycle）**：肌肉把氮转到Ala → 入血到肝 → 肝再转成葡萄糖，同时把氮进尿素循环。

     * 肌肉：pyruvate + NH₂ → alanine
     * 肝：alanine → pyruvate → gluconeogenesis；氮进入尿素循环
     * 关键词：*alanine-glucose cycle*
   * **谷氨酰胺（glutamine）运氨**：

     * 组织（脑、肌）用 glutamine synthase 把 Glu + NH₃ → Gln，既解毒又储存；
     * 肝、肾、小肠再用 glutaminase 把 Gln → Glu + NH₃，NH₃可排出或合成尿素；
     * 在肾小管，NH₄⁺还能排酸。
     * 关键词：*glutamine synthase, glutaminase, ammonia transport, acid-base balance* 
4. **氨中毒/高氨血症（hyperammonemia）危险机制**

   * NH₃↑ → 脑内与α-KG结合 → TCA受限 → ATP下降
   * Glu、GABA等神经递质被耗 → 神经症状
   * Gln 过多 → 脑水肿
   * 关键词：*hyperammonemia, cerebral edema, neurotransmitter depletion*

## 五、尿素的生成（urea cycle, ornithine cycle, Krebs-Henseleit cycle）

1. **场所**：肝细胞，既有线粒体步骤，也有胞质步骤。
2. **总体反应**：2 NH₃ + CO₂ + 3 ATP → urea + 2 ADP + AMP + 2 Pi + PPi
3. **四步主要反应**

   1. 线粒体内：NH₃ + CO₂ + 2 ATP → carbamoyl phosphate

      * 酶：**carbamoyl phosphate synthetase I, CPS-I**
      * 绝对需要**N-acetylglutamate**激活
   2. 线粒体内：carbamoyl phosphate + ornithine → citrulline（酶：ornithine transcarbamylase, OTC）
   3. 胞质：citrulline + aspartate + ATP → argininosuccinate（ASS）→ argininosuccinate lyase → arginine + fumarate
   4. 胞质：arginine + H₂O → urea + ornithine（酶：arginase）

   * 关键词：*CPS-I, ornithine, citrulline, argininosuccinate synthetase (ASS), argininosuccinate lyase (ASL), arginase, N-acetylglutamate* 
4. **与三羧酸循环的联系（Krebs bicycle）**

   * 尿素循环产生的 fumarate → malate → OAA → 可再转成 aspartate → 回到尿素循环
   * 这是尿素循环与TCA之间的“天桥”
   * 关键词：*aspartate-argininosuccinate shunt of TCA cycle* 
5. **调节**

   * 高蛋白膳食/饥饿分解蛋白 → 需要排更多氮 → N-acetylglutamate 合成↑ → 激活 CPS-I
   * 关键限速酶常记为：CPS-I、ASS
   * 关键词：*N-acetylglutamate, CPS-I regulation*

## 六、氨基酸的脱羧作用与活性胺

1. **通式**：AA 脱去羧基 → 胺类，需 Vit B₆
2. **重要例子**

   * Glu → GABA (γ-aminobutyric acid)，大脑主要抑制性递质之一
   * His → Histamine，参与过敏反应、胃酸分泌
   * Trp → 5-hydroxytryptamine (5-HT, serotonin)，平滑肌收缩、脑内递质
   * Ornithine → polyamines (putrescine, spermidine, spermine)，与细胞生长、离子通道、凋亡调控有关
   * 关键词：*decarboxylation, GABA, histamine, serotonin, polyamines, putrescine, spermidine, spermine*

## 七、一碳单位代谢（metabolism of one-carbon units）

1. **一碳单位的概念**

   * 指在某些AA分解时产生的、只含一个碳的基团：甲酰（formyl）、亚氨甲基（formimino）、甲烯/methylene、甲基/methyl等。
   * 主要载体：**四氢叶酸 FH₄ / THF**，它的N⁵、N¹⁰位点负责携带这些一碳单位。
   * 关键词：*one-carbon unit, tetrahydrofolate (THF/FH₄), N⁵-methyl-FH₄, N¹⁰-formyl-FH₄* 
2. **一碳单位的来源**

   * Ser → Gly 过程中给FH₄一碳
   * Gly 分解
   * His → FIGLU → 给FH₄
   * Trp → N-formylkynurenine → 给FH₄
   * 关键词：*serine hydroxymethyl transferase, FIGLU, kynurenine* 
3. **一碳单位的转化**

   * 不同氧化水平的一碳单位之间可以互相转（除了N⁵-CH₃-FH₄只往外给）。
4. **生理意义**

   * 合成嘌呤、胸腺嘧啶等核酸成分
   * 参与 Met → SAM → 各种甲基化的“间接供甲基”
   * 磺胺类药物结构似叶酸 → 竞争抑制细菌叶酸合成 → 人体不受影响
   * 缺乏叶酸或Vit B₁₂ → DNA 合成受阻 → 巨幼红细胞性贫血
   * 关键词：*purine synthesis, thymidylate synthesis, sulfonamides, megaloblastic anemia*

## 八、含硫氨基酸与Met循环

1. **主要含硫AA**：Met, Cys, Cystine
2. **Met → S-adenosylmethionine (SAM)**

   * SAM 是体内**最重要的直接供甲基体**，用于合成胆碱、肌酸等。
   * SAM 失去甲基 → S-adenosylhomocysteine → Homocysteine
   * Homocysteine 在 Vit B₁₂ + N⁵-CH₃-FH₄ 作用下可再甲基化成 Met，构成 **Met cycle**
   * 叶酸或Vit B₁₂不足 → Met 循环受阻 → DNA 合成下降 → 巨幼红细胞性贫血
   * 关键词：*methionine, S-adenosylmethionine (SAM), transmethylation, homocysteine, methionine cycle* 
3. **肌酸（creatine）和肌酸磷酸（creatine phosphate, PCr）形成**

   * Arg + Gly → Guanidinoacetate → SAM 供甲基 → Creatine
   * Creatine + ATP ↔ Creatine-P（高能）→ 肌肉短时供能
   * 自发少量转成 creatinine，经尿排出
   * 关键词：*creatine, creatine phosphate, creatinine* 
4. **Cys → PAPS（active sulfate）**

   * PAPS 是体内活化硫酸根的供体，用于多种硫酸化反应
   * 关键词：*PAPS, active sulfate*

## 九、芳香族与支链氨基酸代谢

1. **苯丙氨酸 Phe → 酪氨酸 Tyr**

   * 酶：*phenylalanine hydroxylase*，需四氢生物蝶呤（BH₄）
   * 缺乏 → Phe 不能转 Tyr → 苯丙酮尿症（PKU），表现为中枢神经受损、智力发育障碍，处理方式是膳食限Phe。
   * 关键词：*Phe hydroxylase, BH₄, phenylketonuria (PKU)* 
2. **Tyr 的去路**

   * 合成儿茶酚胺：dopamine → norepinephrine → epinephrine
   * 合成黑色素（melanin）
   * 分解产物可入TCA（fumarate, acetoacetate）
   * 关键词：*tyrosine, catecholamines, dopamine, norepinephrine, epinephrine, melanin* 
3. **支链AA（Val, Leu, Ile）**

   * 共有的第一步是转氨 → 相应α-酮酸 → 氧化脱羧 → Acyl-CoA → 进一步氧化
   * 有的最终生成 succinyl-CoA（可生糖），有的生成 acetoacetate/acetyl-CoA（生酮）
   * 关键词：*branched-chain amino acids, transamination, oxidative decarboxylation*

## 十、需要会说的几个临床/问答点

1. **巨幼红细胞性贫血机制（from AA/一碳单位角度）**

   * 一碳单位主要由AA分解提供 → 需叶酸FH₄携带 → 再通过Vit B₁₂/Met循环参与嘧啶、嘌呤合成
   * 叶酸/Vit B₁₂缺乏 → DNA合成受阻、细胞质发育相对正常 → 巨幼红细胞
2. **谷氨酸、精氨酸治疗肝性脑病**

   * 谷氨酸可与NH₃合成Gln，精氨酸可促进尿素生成，帮助“带走”氨 → 降低血氨
3. **测ALT/AST的意义**

   * 这两种转氨酶主要在肝、心、骨骼肌等，当这些细胞受损时酶释放入血，可用于肝炎、心肌损伤等的诊断和病情判断。
   * 关键词：*hepatic encephalopathy, glutamate, arginine, ALT, AST*

## 三、为什么要学氨基酸代谢 —— 蛋白质和氨基酸在体内的作用

### 1. 蛋白质是生命的基本成分

* 蛋白质是构成细胞、组织的主要结构物质，尤其是**生长旺盛**、**组织修复**的时候更重要，所以病人恢复期会强调“多吃高蛋白”。
* 老师举了一个生化开头常说的例子：曾以为生命体一定要有“蛋白质+核酸”，后来发现有的**类病毒（朊病毒/朊样蛋白一类）只有蛋白质也能传递感染**，说明蛋白质是最核心的。

### 2. 体内大量功能性物质本质上都是蛋白质

* 所有的**酶**本质上都是蛋白质。老师点名问“酶的本质是什么”，答案就是蛋白质。
* 很多**激素**、**神经递质的前体**、**抗体**（免疫球蛋白）、**急性期蛋白（如C反应蛋白）**也都是蛋白质或来源于氨基酸。
* 所以没有蛋白质，所有代谢反应都跑不起来。

### 3. 蛋白质也能供能，但这是次要功能

* 三大营养物质（糖、脂、蛋白）都能供能。
* 但蛋白质的**结构功能**和**特异功能**是糖和脂肪替代不了的，只有在糖脂供能不足时蛋白才“拆了烧”。

## 四、为什么要讲“氮平衡”

老师这里讲了一大段“怎么判断蛋白质是不是够用”，核心就是——**测氮就能推蛋白**，因为蛋白里氮恒定约16%，1 g 氮≈6.25 g 蛋白。

1. **为什么测氮能代表蛋白？**

   * 所有蛋白质含氮量差不多，≈16%，所以测粪便、尿里的氮，就能反推蛋白分解量。
   * 食物里氮＝摄入的蛋白；粪尿里氮＝分解排出的蛋白。

2. **三种氮平衡状态**

   * **氮平衡/氮总平衡**：摄入氮 = 排出氮
     正常成年人就是这样，说明摄入的蛋白够补每天坏掉的细胞。
   * **正氮平衡**：摄入氮 > 排出氮
     出现于：儿童生长、孕妇（要供胎儿）、烧伤/大病恢复期——说明有“新组织在长”。
   * **负氮平衡**：摄入氮 < 排出氮
     出现于：饥饿/禁食、重病晚期、恶性肿瘤消耗、不能进食——说明体内在大量分解自身蛋白。

3. **一天需要吃多少蛋白？**

   * 老师说：75 kg 左右的正常成年人，**最低需要 30~50 g 蛋白**来维持。
   * 但因为食物蛋白吸收率和人体不完全一样，所以营养学上推荐**一天吃到 80 g 左右更保险**。

   * 还有一类常并到里头的为婴幼儿必须的（老师说“又加了一种是九种”大意如此）

## 六、蛋白质的营养价值 & 互补作用

1. **营养价值取决于必需氨基酸的种类和含量**
   同样是蛋白，不同来源氨基酸比例不一样。
2. **动物蛋白普遍营养价值高**，植物蛋白相对低。
3. **蛋白互补**：两种各自“缺一两种必需氨基酸”的低营养蛋白混一起吃，可以互相补足。

   * 豆类：赖氨酸多、含硫氨基酸少
   * 谷类：含硫氨基酸多、赖氨酸少
   * 一起吃就都不缺，所以也解释了“食物多样化”的饮食建议。

## 七、食物蛋白的消化与吸收（老师说这一段要求自学，但关键点说了一遍）

1. **口腔里蛋白基本不消化**，因为没有蛋白酶；只有淀粉在口腔有唾液淀粉酶。

2. **胃里**：有胃酸+停留一段时间，会有**初步消化**。

3. **小肠是主战场**：

   * 小肠有来自胰腺分泌的一整套“蛋白酶原”；
   * 在肠黏膜分泌的**肠激酶**激活后，变成有活性的胰蛋白酶、胰凝乳蛋白酶、弹性蛋白酶、肽酶等；
   * 把大分子蛋白拆成**游离氨基酸+二肽+三肽**；
   * 肠黏膜细胞内还有刷状缘肽酶，把小肽再拆成氨基酸，然后进血。

4. **为什么胰腺分泌的是“酶原”而不是直接是酶？**

   * 因为酶是蛋白酶，如果在胰腺里就变成有活性的，会“自己消化自己”，就成了**急性胰腺炎**。
   * 正常是：胰腺分泌酶原 → 到肠腔被肠激酶激活 → 再去消化食物蛋白。
   * 一旦胰管梗阻或暴饮暴食大量分泌、又排不出去，就可能在胰腺本身被激活，开始消化胰腺组织，出现急性胰腺炎。

5. **吸收方式**

   * 氨基酸进入小肠黏膜细胞需要**载体+Na⁺协同转运**，和葡萄糖差不多。
   * 为了让Na⁺始终从高浓度往低浓度进细胞，把氨基酸一起“拎进来”，细胞基底侧有**Na⁺/K⁺-ATP酶**往外泵Na⁺、往里泵K⁺，这个过程**要消耗ATP**。
   * 所以说“氨基酸吸收是主动运输”。

6. **不能被吸收的那一部分会怎样？——肠道腐败作用**

   * 肠道细菌会把没消化/没吸收掉的蛋白和氨基酸再分解，叫**腐败作用**。
   * 会生成：胺类（如腐胺、尸胺）、吲哚、对人体有害的含硫气体（硫化氢）、也有少量有用的如维生素K、短链脂肪酸。
   * 这些有毒的产物**要靠肝脏再解毒**，否则进血会影响中枢。
   * 这里老师还插了一句：肠道细菌做的维生素K很重要，如果肠道菌群乱了，维生素K少了，会影响凝血。

7. **肠道产生的氨跟pH有关**

   * 肠道腐败会产生**NH₃（氨）**。
   * **酸性环境**：NH₃ + H⁺ → NH₄⁺，溶解度高、吸收差，多随粪便排出，有利于“排氨”。
   * **碱性环境**：大量游离NH₃被肠道吸收进血，会加重高氨。
   * 所以肠道碱化→血氨增高；酸化→利于排氨。

## 八、体内自身蛋白的降解（两个途径）

老师在这儿说的是：不仅食物来的氨基酸，**我们自己细胞里旧蛋白降解出来的氨基酸也要进同一个“池子”**。降解途径有两套：

1. **溶酶体途径（ATP非依赖）**

   * 发生在溶酶体里。
   * 不需要ATP。
   * 降解的对象：外源蛋白、膜蛋白、寿命很长的蛋白。
   * 特点：选择性差，进来就拆。

2. **泛素-蛋白酶体途径（ATP依赖）**

   * 发生在胞质里。
   * 需要ATP。
   * 有明显“要不要降解”的选择，必须先**被泛素标记**。
   * 被标好几串泛素的蛋白送进蛋白酶体，被分段水解成氨基酸。
   * 降解的对象：**异常蛋白**（没折好、突变的）、**短寿命调节蛋白**、很多酶、调节蛋白。
   * 泛素会被回收再用。

这两条线的结果都是：**变成游离氨基酸**，然后跟食物来的混在一起。

---

## 九、氨基酸代谢库（amino acid pool）

1. 概念：**所有来源的游离氨基酸汇在一起，变成一个可以随时被用的“池子”**。

   * 来源包括：食物消化吸收的、体内蛋白降解的、体内能合成的非必需氨基酸。
2. 这个池子里氨基酸的量不是固定的，不同器官大小不一样。
3. 老师点名了**肌肉**和**肝脏**的氨基酸库最重要，因为：

   * 肌肉是大仓库，尤其运动时要把氮运出去。
   * 肝脏要负责解毒、尿素合成、糖异生，所以它的氨基酸库也活跃。

---

## 十、氨基酸代谢的“大框架”

老师在黑板上其实是这么说的（我按文字化给你）：

1. **氨基酸有两个关键部分**：

   * α-氨基（–NH₂）
   * α-酮酸骨架（脱了氨之后剩下的那部分）

2. **在体内代谢时主要做两件事**：

   * 把氨基拆下来：**脱氨基作用**
   * 把碳骨架送去三羧酸循环、糖异生、生成脂肪/酮体：**碳骨架代谢**

3. **氨基去哪儿？**

   * 不能在血里乱飘，因为**游离NH₃对中枢尤其是脑有毒**。
   * 所以要么在肝里变成**尿素**，要么先变成**谷氨酰胺**、**丙氨酸**这类“无毒载体”再运走。

4. **碳骨架去哪儿？**

   * 变成三羧酸循环中间产物 → 氧化供能
   * 或者走**糖异生**变葡萄糖
   * 或者变成**乙酰辅酶A/乙酰乙酸** → 脂肪酸或酮体

5. 所以不同氨基酸就被分成：

   * **生糖氨基酸**（最后能变成葡萄糖的）
   * **生酮氨基酸**（最后变成乙酰辅酶A或乙酰乙酸，只能生酮/生脂，不能回头变糖的，典型是赖氨酸和亮氨酸）
   * **兼性（生糖又生酮）**的那几个（苯丙氨酸、酪氨酸、色氨酸、异亮氨酸等，老师后面有一段口述成了一串，你记住这类是“两头都能走”的）

---

## 十一、氨基酸的“脱氨基”有五条路，但重点三条

老师说体内氨基酸的脱氨有**5种途径**：

1. **转氨基作用**（最常见，也最先讲）
2. **L-谷氨酸的氧化脱氨**
3. **联合脱氨（=1+2合起来）——这是体内真正主要的方式**
4. **肌肉里的“丙氨酸-葡萄糖循环”那条相关的转运/脱氨路线**
5. **氨基酸氧化酶直接脱氨**（这条在人体里不主要）

老师说我们重点只学前3条。

---

### 1. 转氨基作用（Transamination）

**定义**：在转氨酶的作用下，一个氨基酸把它的氨基转给一个酮酸，自己变成酮酸，对方变成新的氨基酸。
**特点**：整个过程中**没有游离NH₃产生**，只是“搬家”。

* 典型受体只有三个：**丙酮酸、α-酮戊二酸、草酰乙酸**。

  * 丙酮酸 + 氨基 → 丙氨酸
  * α-酮戊二酸 + 氨基 → 谷氨酸
  * 草酰乙酸 + 氨基 → 天冬氨酸

* **转氨酶的辅酶一定是磷酸吡哆醛（PLP）**，它来自维生素B₆。PLP在中间先接氨基，再转交给酮酸，起的是“搬运带”的作用。

* 大部分氨基酸都能转氨，**但有三种基本不转**：赖氨酸、苏氨酸、脯氨酸（老师口音里是“赖氨酸磺酸和乳酸酸这是色”，你按标准这几种不能转氨记）。

* 转氨反应是**可逆**的，所以它既能用于分解，也能用于**合成非必需氨基酸**。

---

### 2. L-谷氨酸的氧化脱氨

* 这个是**唯一真正“脱出游离氨”的那一步**。
* 反应：**谷氨酸 ↔ α-酮戊二酸 + NH₃**
  催化酶：**谷氨酸脱氢酶（GDH）**
  特点：这个酶既能用NAD⁺也能用NADP⁺，位置主要在**肝、肾、脑**。

---

### 3. 联合脱氨（Transdeamination）

这是老师最想你记住的句式：
**“别的氨基酸先转到谷氨酸上 → 谷氨酸再一次性脱氨”**
这样所有氨都能通过“先转后脱”走掉，所以这是体内**主要**的脱氨方式。

---

### 4. 临床相关的两种转氨酶

老师专门单拿出来讲了 ALT / AST，就是我们体检单里的**GPT / GOT**：

1. **丙氨酸氨基转移酶（ALT，也叫GPT、谷丙转氨酶）**

   * 主要在**肝脏**。
   * 反应：谷氨酸 ↔ 丙氨酸 + α-酮戊二酸/丙酮酸的互转。

2. **天冬氨酸氨基转移酶（AST，也叫GOT、谷草转氨酶）**

   * 主要在**心肌**，其他组织也有。
   * 反应：谷氨酸 ↔ 天冬氨酸 + α-酮戊二酸/草酰乙酸的互转。

3. **为什么要查它？**

   * 这俩酶原本都在细胞里，不在血里。
   * 一旦肝细胞坏了、心肌坏了，就会漏到血里，血清活性升高，就可以作为**肝损伤/心肌损伤的辅助诊断指标**。

---

## 十二、氨从哪儿来（体内“氨”的来源）

老师说了三大来源，要和“氨基酸的来源”分开记：

1. **氨基酸及其他含氮化合物分解出来的氨**

   * 这是**主要来源**，就是我们刚才说的联合脱氨那一批。

2. **肾脏小管细胞分解谷氨酰胺产生的氨**

   * 肾里有**谷氨酰胺酶**，能把谷氨酰胺拆成谷氨酸 + NH₃。
   * 这些NH₃在酸性尿中会变成NH₄⁺排出去，顺便**把H⁺一起带走**，所以这是肾调酸碱、还“保钠”的一个机制。

3. **肠道产氨**

   * 来自两路：
     ① 肠道细菌腐败分解蛋白/氨基酸
     ② 血里的尿素渗到肠腔，被细菌分解也能出NH₃
   * 这些NH₃大部分要进肝再解毒。

---

## 十三、氨要被怎么运走（两条转运方式）

因为NH₃本身有毒，所以不能直接大把在血里跑，要先“装进盒子里”送去肝或肾，老师讲了两条：

### 1. 丙氨酸－葡萄糖循环（Cahill循环）

* 发生部位：**骨骼肌 → 肝**
* 肌肉里糖酵解会出**丙酮酸**，同时肌肉里氨基酸脱出来的氨先转给丙酮酸，生成**丙氨酸**。
* 丙氨酸进血到肝 → 再转回丙酮酸 + NH₃。
* NH₃进尿素循环；丙酮酸在肝里走糖异生 → 变葡萄糖再送回肌肉用。
* 意义：**既安全地把氮送到肝，又解决了肌肉的能量补给**。

### 2. 谷氨酰胺途径

* 各组织（尤其**脑、肌肉**）把NH₃抓起来，加到谷氨酸上 → 生成**谷氨酰胺**。
* 谷氨酰胺是**无毒的储氮和运氮形式**。
* 谷氨酰胺被送到**肝或肾**，再被谷氨酰胺酶拆开，NH₃在肝里进尿素，在肾里变成NH₄⁺排尿。
* 意义：既能**降低脑内氨浓度**，又能**作为氮的贮备**。

---

## 十四、尿素循环（重点里的重点）

1. **为什么要有尿素？**

   * 因为NH₃有毒，必须在肝里变成无毒的尿素，再经肾排掉。

2. **在哪里发生？**

   * 一部分反应在**线粒体**，一部分在**胞质**。

3. **老师把它拆成了4个主要反应**（我按老师说的顺序写）：

   **(1) 在线粒体：NH₃ + CO₂ + 2ATP → 氨基甲酰磷酸**

   * 酶：**氨基甲酰磷酸合成酶Ⅰ（CPSⅠ）**
   * 这是**限速、关键、必须有N-乙酰谷氨酸激活**的一步。

   **(2) 氨基甲酰磷酸 + 鸟氨酸 → 瓜氨酸**

   * 酶：鸟氨酸氨基甲酰转移酶
   * 瓜氨酸接着出线粒体到胞质。

   **(3) 瓜氨酸 + 天冬氨酸 → 精氨基琥珀酸（又叫精氨酸代琥珀酸）**

   * 这一步是把“第二个氮”加进来，那个氮来自天冬氨酸。
   * 酶：精氨基琥珀酸合成酶
   * 要ATP

   **(4) 精氨基琥珀酸 → 精氨酸 + 延胡索酸**

   * 酶：精氨基琥珀酸裂解酶
   * 延胡索酸回到TCA，精氨酸留着下一步水解。

   **(5) 精氨酸 + H₂O → 尿素 + 鸟氨酸**

   * 酶：精氨酸酶
   * 鸟氨酸再回线粒体，开始下一轮循环。

4. **尿素中两个氮的来源**

   * 一个来自**游离NH₃**（就是脱氨那条线）
   * 一个来自**天冬氨酸**（也就是别的氨基酸转过去的）

5. **尿素循环和三羧酸循环的联系**

   * 第3步里出来的延胡索酸 → 苹果酸 → 草酰乙酸 → 再跟谷氨酸转氨变天冬氨酸
   * 这样就把尿素循环和TCA套成了老师说的“**Krebs两个循环像自行车**”那幅图。

6. **尿素生成的调节因素**

   * **吃高蛋白 → 氨多 → 尿素合成多**
   * **CPSⅠ的激活剂N-乙酰谷氨酸**够不够

     * NAG的生成又受精氨酸、谷氨酸影响
   * **精氨基琥珀酸合成酶**是条限速步，活性变动也会影响整体。

## 十五、肝功能不好会怎样 —— 高氨血症 & 肝性脑病

老师这段说得比较细，我也按他说的点列出来：

1. 肝坏了 → 尿素合成↓ → NH₃在血里升高 → **高氨血症**。
2. NH₃进脑之后会：

   * 和α-酮戊二酸结合生成谷氨酸 → 消耗了α-酮戊二酸 → TCA循环被卡 → **脑供能不足**。
   * 谷氨酸再和NH₃变成谷氨酰胺 → 细胞内渗透压升高 → **脑细胞肿胀**。
   * 谷氨酸原本还要去生成GABA等神经递质，走偏了也会**影响神经活动**。
3. 临床表现：意识改变、昏迷、抽搐，老师说就是**肝性脑病**的那套表现。

## 十六、氨基酸的脱羧作用 → 一系列“特殊生理活性物质”

老师这里说：氨基酸不仅能“脱氨”，还能“脱羧”，脱羧后就变成一整类很重要的活性分子。这个反应的**辅酶也还是维生素B₆（PLP）**。

你要记住“谁脱出来变成了谁”：

1. **谷氨酸 → GABA（γ-氨基丁酸）**

   * 作用：中枢**抑制性**神经递质
   * 多了会嗜睡、镇静、止吐、止痛等

2. **组氨酸 → 组胺**

   * 作用：

     * 毛细血管通透性↑ → 渗出、水肿 → 过敏、炎症
     * 支气管平滑肌收缩 → 和哮喘相关
     * 刺激胃黏膜分泌胃酸

3. **色氨酸 → 5-羟色胺（5-HT，血清素）**

   * 中枢里也是一种递质，调节情绪、睡眠
   * 外周能让平滑肌收缩

4. **多胺（腐胺、亚精胺、精胺）**

   * 是“很多个氨基”的小分子
   * 生长旺盛、肿瘤、细胞增殖时会升高
   * 临床可用来看肿瘤复发、转移

## 十七、一碳单位（C₁单位）代谢

老师这里说得很完整，我按他说的结构写：

1. **什么是一碳单位**

   * 不是一个完整分子，是**一个只带一个碳的化学基团**，要**挂在载体上**才能存在。
   * 主要几种形态：甲基、甲烯基、甲酰基、亚氨甲基等五类。

2. **载体是谁？——四氢叶酸（THF）**

   * 叶酸在体内被还原成四氢叶酸
   * 四氢叶酸分子上的**N⁵和N¹⁰位点**可以接这些一碳基团
   * 所以我们会看到名字像“N⁵-甲基-THF”“N⁵N¹⁰-亚甲基-THF”这样的

3. **一碳单位从哪儿来？——4种氨基酸**

   * 丝氨酸
   * 甘氨酸
   * 组氨酸
   * 色氨酸
   * 各自产生不同形态的一碳基

4. **几种一碳单位之间大部分可以互相转**

   * 甲酰基 ↔ 甲亚基 ↔ 甲烯基 ↔ 甲基
   * **但是“甲烯/甲酰等 → 甲基”可以，甲基要再变回去就难，所以体内一碳单位最后多积在“甲基”上**。

5. **一碳单位的两个大作用**

   * ① 参加**核苷酸、核酸的合成**（所以叶酸类、磺胺类药干这个会影响细菌DNA合成）
   * ② 通过**蛋氨酸（甲硫氨酸）循环**把甲基交给需要的分子（转甲基反应）

6. **为什么叶酸/B₁₂缺乏会导致“大细胞性贫血”**

   * 因为一碳单位不能传递 → 核酸合成跟不上 → 细胞分裂不了，但蛋白还在合成 → 细胞就大但数目少 → 巨幼红细胞性贫血

---

## 十八、含硫氨基酸的代谢（Met、Cys、Cystine）

老师重点讲的是**甲硫氨酸（Met） → S-腺苷甲硫氨酸（SAM） → 转甲基 → 同型半胱氨酸 → 再生成Met**这一圈，也就是常说的**蛋氨酸循环 / 甲硫氨酸循环**。

1. **甲硫氨酸活化**

   * Met + ATP → **S-腺苷甲硫氨酸（SAM）**
   * SAM才是真正的**“通用甲基供体”**

2. **SAM把甲基转出去** → 变成 **S-腺苷同型半胱氨酸** → 脱腺苷 → 变成 **同型半胱氨酸**

3. **同型半胱氨酸要想再变回甲硫氨酸，就得拿到一碳单位给的甲基，而且要有维生素B₁₂参与**

   * 所以：**一碳单位是甲基的“间接供体”**，SAM是“直接供体”。

4. **这一圈转不起来会怎样？**

   * 一碳单位传不出去 → THF被“甲基卡住” → 叶酸功能间接被堵 → 影响DNA合成 → 贫血
   * 同型半胱氨酸降不下去 → 动脉粥样硬化风险 ↑（这个老师没细说，你记住前面那条就行）

5. **从Met还能生成肌酸 → 磷酸肌酸 → 肌酐**

   * 肌酸/磷酸肌酸是短期能量储备
   * 肌酐每天生成量大致恒定 → 用来评估肾功能

6. **半胱氨酸还能去做PAPS（活性硫酸）**

   * PAPS要用来做**生物转化的硫酸化**，也用来合成**硫酸软骨素、硫酸角质素**，这些都和结缔组织、关节腔润滑有关。
   * 还可以生成**牛磺酸**，牛磺酸要和胆酸结合，帮助脂肪消化。

## 十九、芳香族氨基酸的代谢（Phe、Tyr、Trp）里老师重点说了Phe和Tyr这条

1. **正常情况**：苯丙氨酸（Phe）在**苯丙氨酸羟化酶**作用下 → 变成酪氨酸（Tyr）
   然后大家都沿着“酪氨酸的几条路”往下走。

2. **苯丙氨酸羟化酶先天缺乏 → 苯丙酮尿症（PKU）**

   * Phe没法变Tyr，就会走“转氨 → 苯丙酮酸”这条歪路
   * 苯丙酮酸对神经系统有毒，小孩不早治会智力低下
   * 尿里会排出这些酸，所以叫“苯丙酮尿”
   * 治原则：**早发现+饮食限Phe**

3. **酪氨酸往下有四条重要去路**：

   1. **→ 儿茶酚胺**（多巴、去甲肾上腺素、肾上腺素）

      * Tyr → DOPA → Dopamine → NE → E
      * 多巴胺少了会出现**帕金森样**表现（老师这里提到了）
   2. **→ 黑色素**

      * Tyr在酪氨酸酶作用下 → 多巴 → 多巴色素 → 黑色素
      * 酪氨酸酶缺乏 → 白化病 → 皮肤、头发都白 → 对紫外线防护差
   3. **→ 甲状腺激素**（T₃/T₄）
   4. **→ 完全分解**

      * 生成**延胡索酸 + 乙酰乙酸**
      * 中间有一个重要的中间产物叫**尿黑酸（homogentisic acid）**，老师最后一句其实就是要说：
        如果分解这一步的酶缺乏，尿黑酸排到尿里会让尿变黑，这就是**黑尿酸症/尿黑酸症**这一类遗传病。
