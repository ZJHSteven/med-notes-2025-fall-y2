## 1. 核酸总览：DNA vs RNA、中心法则

### 1.1 核酸两大类与分布

* **DNA（脱氧核糖核酸）**

  * 真核：主要在**细胞核**；少量在**线粒体**（环状、小分子）
  * 功能：**遗传信息储存载体**
* **RNA（核糖核酸）**

  * 在核内生成，主要在**细胞质/胞浆**发挥作用
  * 功能：对“以DNA为遗传物质”的生物：**参与遗传信息传递、表达与调控**
  * 对“以RNA为遗传物质”的某些病毒：RNA本身就是遗传信息载体

### 1.2 中心法则与逆转录

* DNA **复制**：实现亲代→子代遗传信息传递
* DNA **转录**→RNA（尤其 mRNA）
* mRNA **翻译**→蛋白质
* 某些病毒：RNA → DNA（**逆转录**）

## 2. 核苷酸的组成：核苷、核苷酸、环化核苷酸

### 2.1 核苷酸三部分

核苷酸 = **磷酸 + 戊糖（核糖/脱氧核糖）+ 含氮碱基（嘌呤/嘧啶）**

* 只有“戊糖+碱基” = **核苷（nucleoside）**
* 核苷 + 磷酸 = **核苷酸（nucleotide）**
* 磷酸可连 1/2/3 个：**NMP / NDP / NTP**（一/二/三磷酸核苷）

### 2.2 碱基分类与DNA/RNA差异

* 嘌呤（两环）：**A 腺嘌呤、G 鸟嘌呤**
* 嘧啶（一环）：**C 胞嘧啶、T 胸腺嘧啶、U 尿嘧啶**
* DNA：A G C **T**
* RNA：A G C **U**
* 共同点：C 参与 DNA/RNA；T 主要DNA；U 主要RNA

### 2.3 稀有碱基（老师强调：识别信号/调控相关）

* 在常规碱基基础上经化学修饰（如甲基化）形成
* 常作为核酸上的**特殊识别信号**，参与基因表达调控等

### 2.4 戊糖差异

* RNA：**核糖**（2’位有 **-OH**）
* DNA：**脱氧核糖**（2’位是 **-H**）
  → 少一个氧，所以叫“脱氧”

### 2.5 三种关键化学键（高频考点）

1. **碱基-戊糖：β-N-糖苷键**

   * 戊糖 **1’碳** ↔ 嘌呤 **N9** / 嘧啶 **N1**
2. **磷酸-戊糖：磷酸酯键**（老师也提“磷酸糖苷键/磷脂键”这类口头叫法）
3. **核苷酸-核苷酸：3’–5’磷酸二酯键**

   * 前一个核苷酸 **3’–OH** 与后一个 **5’磷酸**脱水缩合

### 2.6 核酸链的方向性（与蛋白类比）

* 核酸链两端不同：**5’端（磷酸端）** vs **3’端（羟基端）**
* 书写/读取默认方向：**5’ → 3’**
* 类比蛋白：蛋白一级结构书写是 **N端 → C端**

### 2.7 核酸表达与长度单位

* 常用只写“碱基序列”表示（默认左5’右3’）
* 长度单位：

  * 双链DNA：**bp（碱基对）**，大分子用 **kb**
  * 单链DNA/RNA：常用 **nt（核苷酸数）**
* “寡聚核苷酸” vs “多聚核酸”：本质无区别，仅长度差异

### 2.8 环化核苷酸（不直接入链，但功能很重要）

* **cAMP、cGMP**：细胞内常见**第二信使**

## 3. DNA结构层次：一级/二级/三级（老师重点：B型双螺旋）

### 3.1 一级结构

* 定义：DNA链上 **5’→3’** 的核苷酸排列顺序（碱基序列）
* 稳定因素：**3’–5’磷酸二酯键不断裂**

### 3.2 二级结构：Watson–Crick 右手双螺旋（B-DNA为重点）

#### 3.2.1 双螺旋模型提出的关键基础

* **Chargaff 规律**：A≈T，G≈C，嘌呤≈嘧啶（提示存在1:1配对）
* **X射线晶体衍射**（Franklin等的照片提示螺旋重复结构）

#### 3.2.2 B型双螺旋结构要点（必背）

* **两条链反向平行**：一条 5’→3’，另一条 3’→5’
* 绕同一轴形成**右手双螺旋**
* **磷酸-戊糖骨架在外侧**，**碱基在内侧**
* **互补配对**：A–T 2个氢键；G–C 3个氢键
* 尺寸：

  * 直径约 **2 nm**
  * 螺距约 **3.4 nm**
  * 每圈约 **10 bp**
  * 相邻碱基对上升高度约 **0.34 nm**
* 表面形成**大沟/小沟**：蛋白调控因子识别结合的重要位点

#### 3.2.3 双螺旋稳定因素（老师强调“更重要的是堆积力”）

1. **氢键**（横向“拉链”）
2. **碱基堆积力**（纵向“叠盘子”）——对整体稳定尤其关键

#### 3.2.4 其他螺旋形式（了解）

* **A-DNA**：更紧密、短粗，常见于湿度降低等条件
* **Z-DNA**：与离子强度/盐条件相关（老师说“理强度改变”）
* 还可形成三链、四链结构（端粒处可见G四链等，老师提到“端粒四链结构”）

### 3.3 三级结构：超螺旋与染色质包装

#### 3.3.1 超螺旋（常见于环状DNA）

* 类比电话线：双螺旋再盘绕
* **正超螺旋**：方向同双螺旋；**负超螺旋**：方向相反
* 出现条件：

  * 线性DNA两端需固定，或
  * **环状闭合DNA**（细菌、噬菌体、线粒体DNA等）
* 形成/解开需要 **拓扑异构酶**（切开→重连），并消耗能量（老师提“需要ATP参与”）
* 生理意义：紧密存储；复制/转录时局部解开

#### 3.3.2 核小体与染色体（真核DNA三级结构核心）

* “串珠样结构”：小珠子=**核小体**
* 核小体=核心颗粒+连接区

  * **核心颗粒**：组蛋白八聚体（H2A/H2B/H3/H4 各2个）
  * DNA绕核心约 **1又3/4圈**
  * **H1** 组蛋白像“锁扣”固定交叉处
  * **连接DNA**约60bp左右（老师给了数量级）
* 更高级折叠：10nm串珠链 → 30nm纤维 → 更高级折叠 → **染色体**
* 老师强调：人体DNA若拉直约**2米**，靠层层折叠塞进细胞核；紧密结构也能防止被酶降解，表达时再局部解开

## 4. RNA：分类、结构与三大功能RNA（mRNA/tRNA/rRNA）

### 4.1 RNA总体特点

* 多为**单链**，可局部互补配对形成**茎环/发卡结构**
* 种类多：按是否编码蛋白

  * **编码RNA**：mRNA
  * **非编码RNA**：rRNA、tRNA、以及多种调控RNA（miRNA/siRNA/lncRNA等，老师列举“长链、微小、干扰”等）
* 按表达是否恒定：

  * **组成型RNA**：rRNA、tRNA、部分小RNA
  * **调节型RNA**：特定组织/时段出现，调控为主

### 4.2 mRNA（结构“五件套” + 加工）

成熟mRNA基本结构（老师按5部分讲）：

1. **5’帽子（cap）**：常见为 **7-甲基鸟嘌呤三磷酸结构**（m⁷GpppN）
2. **5’非翻译区（5’UTR）**：影响翻译起始
3. **编码区（ORF）**：真正编码蛋白的区域
4. **3’非翻译区（3’UTR）**：影响翻译终止/稳定性等
5. **poly(A)尾巴**：一串A（后加）

转录后加工（老师点名“后加上去的”）：

* 加帽、加尾
* **剪接**：去除**内含子**，连接**外显子**
* 初级转录本：hnRNA（未成熟，不能直接做翻译模板）

密码子：

* 编码区 **每3个核苷酸=1个密码子（codon）**
* 共64个：61编码氨基酸，3个终止密码子 **UAA/UAG/UGA**
* 真核：**单顺反子**（一条mRNA编码一个蛋白）
* 原核：**多顺反子**（一条mRNA可编码多个蛋白）

### 4.3 tRNA（结构最“统一”的一类）

* 长度约 **74–95 nt**
* 二级结构：**三叶草结构**（实质是多个茎环+一个“臂”）
* **3’末端恒为 CCA**：氨基酸结合位点
* 四个环（老师逐个点）：

  * D环（二氢尿嘧啶环）
  * **反密码子环（anticodon loop）**：中间3个核苷酸=反密码子，识别mRNA密码子
  * 可变环（额外环）
  * TψC环
* 三级结构：**L形**（两端：氨基酸端 vs 反密码端）
* 功能一句话：**识别正确氨基酸 + 送到mRNA正确位置**（保证翻译准确）

### 4.4 rRNA（核糖体骨架 + 翻译场所）

* rRNA与蛋白结合成**核糖体**：蛋白质翻译“机器/场所”
* 小亚基：主要结合mRNA
* 大亚基：氨基酸进入与肽键形成（蛋白合成）

核糖体rRNA种类（老师明确要求记忆）：

* **原核**：16S（小亚基），23S+5S（大亚基）
* **真核**：18S（小亚基），28S+5.8S+5S（大亚基）

## 5. DNA vs RNA：老师列的8条差异（精炼版）

1. 糖：脱氧核糖 vs 核糖
2. 碱基：T（DNA） vs U（RNA）
3. 链：双链 vs 单链
4. Chargaff规律：DNA符合；RNA一般不严格符合
5. 稀有碱基：RNA更多
6. 稳定性：DNA更稳定；RNA更易被降解（实验室提RNA要求更严格）
7. 含量：DNA在细胞内相对恒定；RNA变化大
8. 寿命：DNA长；RNA短（尤其mRNA）

## 6. 核酸理化性质：A260、纯度、变性/复性/杂交、PCR原理

### 6.1 紫外吸收

* 核酸最大吸收峰：**260 nm**（A260）
* 蛋白最大吸收峰：**280 nm**
* 原理：碱基含**共轭双键**吸收UV

### 6.2 用A260估算浓度（老师给了实验室常用换算）

在光程 1 cm 时：

* **双链DNA**：A260=1 → **50 μg/mL**
* **单链DNA 或 RNA**：A260=1 → **40 μg/mL**
* **寡聚核苷酸**：A260=1 → **20 μg/mL**

### 6.3 纯度判断：A260/A280

* dsDNA：约 **1.8** → 较纯

  * 比值下降：**蛋白污染增多**
  * 比值显著>1.8：可能混RNA或DNA部分变性成单链等情况（老师按这个思路讲的）
* RNA：约 **2.0** → 较纯

### 6.4 DNA变性（denaturation）与增色效应

* 变性：双链因**氢键断裂**解开成单链
* **不破坏一级结构**（磷酸二酯键不断）
* 变性后A260升高：**增色效应（hyperchromic effect）**

  * 原因：碱基暴露更多 → 吸收增强

### 6.5 解链温度Tm（melting temperature）

* Tm：使 **50% DNA变性**所需温度
* 影响因素（老师点名三条）：

  1. **GC含量↑ → Tm↑**（3个氢键更稳）
  2. **盐浓度↑ → Tm↑**（稳定双链）
  3. **链更长/分子更大 → Tm↑**

### 6.6 复性/退火（renaturation/annealing）与减色效应

* 复性：去除变性因素后，碱基重新互补配对回到双链
* 复性后A260下降：**减色效应**
* **退火**：特指加热变性后**缓慢降温**重新配对

  * 快速冰浴可保持单链（老师举例：**SSCP**单链构象多态性，用于筛突变）

### 6.7 杂交（hybridization）与应用

* 只要能互补配对，不同来源单链也可配对形成**杂合双链** → 杂交
* 应用：

  * **PCR**：95℃变性 → 降温引物与模板杂交 → 延伸合成 → 循环扩增

    * 引物浓度远高于模板 → 优先与模板结合
  * **探针检测**：带荧光/放射/生物素等标记的探针与目标序列杂交 → 检测是否含目标序列

# 7. 核苷酸代谢总览：功能、来源、核酸酶

## 7.1 核苷酸在体内的生物学功能（老师列了很多）

1. 构成核酸（DNA/RNA基本单位）
2. 能量载体：**ATP/GTP**等
3. 辅酶组成：**NAD/NADP/FAD**等（含核苷酸成分）
4. 活化中间体：

   * **UDP-Glucose**（糖原合成时葡萄糖的活化形式）
   * **CDP-DAG**（磷脂合成/脂代谢相关活化形式）
   * **SAM（S-腺苷甲硫氨酸）**：甲基直接供体（与一碳单位配合）
5. 第二信使：**cAMP/cGMP**

## 7.2 来源：自身合成为主，营养“非必需”

* 食物核酸多以**核蛋白**形式存在
* 胃：酸+胃蛋白酶 → 核酸与蛋白分开
* 小肠：核酸酶/磷酸酶等 → 核酸→核苷酸→核苷+磷酸→碱基+戊糖
* 戊糖可利用；碱基多被分解后排出（老师的总体意思：机体自身合成足够）

## 7.3 核酸酶分类（别和核酶混）

* 核酸酶（nuclease）：**水解核酸的酶，本质是蛋白质**

  * DNase / RNase
  * 外切酶：3’外切、5’外切
  * 内切酶：随机内切 vs **限制性内切酶**
* 限制性内切酶要点：

  * 识别**回文序列**（旋转180°对称）常为6–8bp
  * 可切出**平端**或**粘性末端**
  * 重要用途：**重组DNA技术**
* 核酶（ribozyme）：**以核酸为本质的“酶”**（本质是核酸）

# 8. 嘌呤核苷酸代谢：从头合成 + 补救合成（本段是你这份的核心）

## 8.1 两条合成途径

* **从头合成（de novo）**：小分子原料一步步搭建

  * 步骤多、耗能大
  * 多数组织主要靠它
* **补救合成（salvage）**：回收碱基/核苷再生成核苷酸

  * 步骤少、耗能少
  * 某些组织（老师点名：**脑/中枢神经、骨髓**）更依赖

## 8.2 嘌呤环9个原子的来源（必背表）

* N1：天冬氨酸
* C2、C8：一碳单位（甲酰基）
* N3、N9：谷氨酰胺
* C4、C5、N7：甘氨酸
* C6：CO₂

## 8.3 从头合成三阶段（老师按“三段法”讲）

### 阶段1：由5-磷酸核糖 → IMP（共同中间体）

* 起始：**5-磷酸核糖（来自磷酸戊糖途径）**
* 关键反应1：
  5-磷酸核糖 + ATP → **PRPP**

  * 酶：**PRPP合成酶**
* 关键反应2：
  PRPP + 谷氨酰胺 → **5-磷酸核糖胺**（老师口头叫“磷酸核糖胺”）

  * 酶：**谷氨酰胺-PRPP酰胺转移酶**（酰胺转移酶）
* 后续逐步“在磷酸核糖平台上”把原料一块块加上去，最终形成 **IMP（次黄嘌呤核苷酸）**
* 老师强调的“特点”一句话：
  **嘌呤环不是先合成再接糖，而是在PRPP/核糖平台上逐步搭建出来的。**

### 阶段2：IMP 分支生成 AMP 与 GMP（本段高频考点）

* IMP → AMP：

  * 天冬氨酸“接上再释放延胡索酸”留氨基
  * **能量用GTP**（老师强调“合成AMP用GTP”）
* IMP → GMP：

  * 先 IMP脱氢 → XMP
  * 再由谷氨酰胺提供氨基生成GMP
  * **能量用ATP**（老师强调“合成GMP用ATP”）
* 交叉协调意义：
  AMP合成耗GTP、GMP合成耗ATP → **彼此牵制，维持嘌呤核苷酸平衡**

### 阶段3：NMP → NDP → NTP

* 通过激酶逐步磷酸化（老师总体意思：ATP主要来自氧化磷酸化/底物水平磷酸化；其他NTP多通过互相转磷酸获得）

## 8.4 从头合成调控（老师：底物正反馈 + 产物负反馈 + 分支交叉调控）

* 关键酶（前两步）受底物促进：核糖-5P / PRPP 多 → 合成倾向↑
* 受产物抑制：IMP、AMP、GMP 对关键酶有**反馈抑制**
* 分支点酶也受各自产物抑制；再叠加ATP/GTP交叉供能的“平衡机制”

## 8.5 补救合成（Salvage）与临床关联

### 途径1：碱基 + PRPP → 核苷酸（重点）

* 酶1：**APRT**（腺嘌呤 → AMP）
* 酶2：**HGPRT**（次黄嘌呤 → IMP；鸟嘌呤 → GMP）
* PRPP既是从头合成中间体，也是补救合成底物 → PRPP水平会同时影响两条途径

### 途径2：核苷 + ATP → 核苷酸（了解）

* 给核苷“补一个磷酸”

### 补救合成的生理意义（老师强调）

1. **省步骤、省能量、省氨基酸原料**
2. **某些组织依赖补救合成**（脑/骨髓）

### 遗传病：Lesch–Nyhan（老师中文口头“自毁容貌综合征”）

* **X连锁隐性**，男童多见
* **HGPRT缺陷** → 补救合成障碍 → 神经系统发育受影响 → 典型可见自残倾向等表现
  （你们课一般还会连到“高尿酸/痛风倾向”，但你这段文本里没展开，我就不硬加了）

## 8.6 嘌呤核苷酸相互转变（老师提纲式强调）

* IMP ↔ AMP ↔ GMP 的互转保证平衡
* 你这段里有两句口误/识别错误我帮你“按最可能正确意思”修正一下：

  * **AMP → IMP**：通常是 **AMP脱氨酶（adenylate deaminase）**去氨基
  * **GMP → IMP**：通常是 **GMP还原酶（GMP reductase）**等路径实现（老师那句“尿苷酸还原”更像语音识别跑偏了）
