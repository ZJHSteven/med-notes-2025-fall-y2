## 2. 蛋白质的营养学基础（从蛋白质讲起）

### 2.1 蛋白质在体内的三大作用

* **结构材料**：构成细胞与组织（生长旺盛/组织修复时尤重要）
* **功能分子**：酶（enzyme，本质是蛋白质）、部分激素、神经递质、抗体、C反应蛋白等
* **供能（次要）**：糖/脂供能不足时，蛋白分解供能（但前两项功能不可替代）

### 2.2 用“氮平衡（Nitrogen balance）”评估蛋白质代谢

* 蛋白质含氮量恒定约 **16%**

  * **1 g 氮 ≈ 6.25 g 蛋白质**
* 三种状态：

  * **氮总平衡**：摄入氮 ≈ 排出氮（正常成年人）
  * **正氮平衡**：摄入氮 > 排出氮（孕妇、儿童、生长/修复期、烧伤恢复期等）
  * **负氮平衡**：摄入氮 < 排出氮（饥饿/禁食、晚期恶性肿瘤消耗等）

### 2.3 必需氨基酸与“蛋白质互补”

* **营养必需氨基酸（Essential AAs）**：体内不能合成，必须从食物供给（老师说现在按**9种**记）
* **半必需氨基酸（Conditionally essential）**：平时能合成，但儿童/恢复期需求大时需额外供给（老师举例：**精氨酸**常被提到）
* **蛋白质互补作用**：把两种“必需氨基酸谱不完整”的食物搭配，互相补缺

  * 老师举例：豆类富赖氨酸但含硫氨基酸不足；谷类相反 → 搭配提高营养价值
  * 结论：提倡食物多样性，避免挑食

## 3. 食物蛋白的消化吸收（老师要求自学，但讲了关键点）

### 3.1 消化部位与主要酶

* 口腔：无蛋白消化酶（主要是咀嚼）
* 胃：胃酸 + 初步消化（停留时间相对短）
* **小肠是主要消化吸收部位**：胰腺分泌多种蛋白水解酶

### 3.2 为什么蛋白水解酶要以“酶原（zymogen）”形式分泌？

* **酶原 = 无活性酶前体**
* **酶原激活（zymogen activation）**本质：水解掉一段肽段 → **空间构象正确**、活性中心暴露 → 才有活性
* 目的：防止“自产自销”——蛋白酶若在胰腺内就活化，会**自我消化**

  * 老师联系临床：**急性胰腺炎**常见机制之一是酶原在胰腺内异常活化（暴饮暴食、导管梗阻等诱因）

### 3.3 吸收机制（和葡萄糖吸收相似）

* 氨基酸吸收需载体（carrier）
* 常见形式：与 **Na⁺ 同向转运（co-transport）**
* 通过 **Na⁺/K⁺-ATPase** 把细胞内Na⁺泵出去维持低Na⁺，间接保证氨基酸“逆浓度”吸收
* 因此：吸收是**耗能的主动过程**（ATP主要用于维持离子梯度）

## 4. 肠道腐败作用（Protein putrefaction）与“假性神经递质”

* 未完全消化/吸收的蛋白及氨基酸 → 被肠道细菌分解 = **腐败作用**
* 产物：

  * **有害**：胺类、硫化氢、吲哚等（多入肝脏转化解毒）
  * **有益（少量）**：短链脂肪酸、**维生素K**等（肠菌紊乱可致Vit K不足 → 影响凝血）
* 胺类在肝功能差时可升高，进入脑组织：

  * 因结构类似多巴胺/去甲肾上腺素等，产生竞争干扰 → **假性神经递质（false neurotransmitters）**概念
  * 与肝性脑病（hepatic encephalopathy）的神经症状相关

## 5. 体内蛋白降解两条路（很“考试友好”）

### 5.1 溶酶体途径（Lysosomal degradation）

* **ATP非依赖**
* 特点：特异性差（“随机消化感”）
* 常降解：外源性蛋白（吞噬入内的细菌等）、膜相关蛋白、**长寿命蛋白**

### 5.2 泛素-蛋白酶体途径（Ubiquitin–proteasome system）

* **ATP依赖**
* 特点：选择性强
* 常降解：错误折叠/异常蛋白、**短寿命蛋白**（如许多调控蛋白/部分酶）
* **泛素（ubiquitin）**：小分子蛋白，约76 aa，作为“降解标签”

  * 被多聚泛素化（polyubiquitination）后 → 被蛋白酶体识别
* **蛋白酶体（proteasome）**：核心降解区 + 调控/识别颗粒

  * 泛素可被回收再利用，蛋白被水解为游离氨基酸

## 6. 氨基酸代谢库（Amino acid pool）

* 食物吸收来的 + 体内蛋白降解来的 + 体内合成的（非必需氨基酸）
  → 混在一起形成共同“代谢池”
* 重要库：**骨骼肌**与**肝脏**（老师强调这两者在氨基酸代谢中的地位）

## 7. 氨基酸脱氨基的“重点三件套”

老师说体内脱氨基途径可讲很多，但**主要掌握前三种**：

### 7.1 转氨基作用（Transamination）

* 氨基酸把 **–NH₂** 转给酮酸（keto acid）

  * 自己变成相应的**α-酮酸**
  * 受体酮酸变成新的氨基酸
* 催化酶：**转氨酶/氨基转移酶（aminotransferase）**
* 辅酶：**磷酸吡哆醛 PLP（pyridoxal phosphate）**＝维生素B₆衍生物

  * 作用：暂时携带/转运氨基（PLP ↔ PMP互转）
* 特点：反应通常**可逆**
* “受体酮酸”常考三大件：

  * 丙酮酸（pyruvate）→ 丙氨酸（alanine）
  * α-酮戊二酸（α-ketoglutarate）→ 谷氨酸（glutamate）
  * 草酰乙酸（oxaloacetate）→ 天冬氨酸（aspartate）
* 老师还提到：有少数氨基酸“不走典型转氨基”（你复习时以教材为准，课堂点名了赖氨酸等）

### 7.2 谷氨酸的氧化脱氨（Oxidative deamination of glutamate）

* 关键酶：**谷氨酸脱氢酶（glutamate dehydrogenase, GDH）**
* 谷氨酸 → α-酮戊二酸 + **游离氨（NH₃/NH₄⁺）**
* 特点：可用 **NAD⁺ 或 NADP⁺** 作为辅酶（老师专门强调“它俩都能用”）
* 组织分布：肝、脑、肾等

### 7.3 联合脱氨（Transdeamination / Combined deamination）

* **第一步**：多数氨基酸先转氨基，把氨“汇集”到α-酮戊二酸上 → 生成谷氨酸
* **第二步**：谷氨酸再氧化脱氨 → 放出游离氨
* 结论：这是体内**最常用/最主要**的脱氨方式（老师明确这么说）

## 8. 转氨酶的临床意义：ALT/AST（体检常见）

* **ALT（alanine aminotransferase）= GPT（谷丙转氨酶）**

  * 主要在**肝细胞**内
  * 血中升高：提示肝细胞损伤（辅助指标）
* **AST（aspartate aminotransferase）= GOT（谷草转氨酶）**

  * 多组织都有，课堂强调与**心肌**关系密切
  * 血中升高：提示相关组织（如心肌）损伤的可能性
* 原理：酶正常在细胞内；血中显著升高往往意味着细胞膜/细胞破裂、酶外泄

---

## 9. 碳骨架去路：升糖/生酮分类（必背的“少数派”）

氨基酸脱氨后得到碳骨架（α-酮酸）→ 可进入TCA、糖异生、或生成酮体/脂肪。

* **生酮氨基酸（Ketogenic only）**：最终只生成乙酰CoA/乙酰乙酸 → 酮体/脂肪

  * 课堂强调：**亮氨酸 Leu、赖氨酸 Lys**（两个）
* **升糖兼生酮（Both）**：既可走糖异生也可生酮

  * 课堂点名：异亮氨酸 Ile、苯丙氨酸 Phe、酪氨酸 Tyr、色氨酸 Trp、苏氨酸 Thr
* **升糖氨基酸（Glucogenic）**：其余大多归此类（能转成丙酮酸或TCA中间产物→草酰乙酸→糖异生）

老师还列了“代谢最重要的中间产物”（你复习时可按这套去对照碳骨架去向）：
丙酮酸、乙酰CoA、乙酰乙酸、α-酮戊二酸、琥珀酰CoA、草酰乙酸（等）

## 10. 体内“氨”的来源、去路、转运（第四大重点）

### 10.1 氨的主要来源（老师按三类讲）

1）氨基酸及其他含氮化合物代谢（尤其联合脱氨）
2）肾脏：谷氨酰胺分解产生氨（与尿pH、酸碱平衡相关）
3）肠道：

* 蛋白腐败作用产氨
* 血尿素渗入肠腔，被细菌分解产氨

### 10.2 氨的主要去路（老师给“四条”）

1）**肝脏合成尿素（最主要）**
2）与谷氨酸结合生成**谷氨酰胺（glutamine）**：解毒 + 储存/运输形式
3）以 **NH₄⁺** 形式经尿排出（酸性环境更利于排出）
4）作为原料合成非必需氨基酸等含氮化合物

### 10.3 氨的两种“无毒转运”形式

* **丙氨酸-葡萄糖循环（Alanine–glucose cycle / Cahill cycle）**

  * 肌肉：丙酮酸 + 氨基 → 丙氨酸入血 → 肝
  * 肝：丙氨酸脱氨 → 氨进尿素循环；碳骨架→糖异生→葡萄糖回到肌肉
  * 意义：把肌肉的氨“打包”成无毒丙氨酸运走，同时把葡萄糖补回肌肉供能
* **谷氨酰胺（Glutamine）转运**

  * 脑/肌等组织：氨 + 谷氨酸 → 谷氨酰胺（无毒） → 运到肝/肾
  * 肝：转尿素；肾：可产NH₄⁺随尿排出（也联系酸碱平衡）

## 11. 尿素循环（Urea cycle / Ornithine cycle）：步骤、酶、定位、调节

### 11.1 两个氮从哪来（老师反复强调）

* 尿素的两个 –NH₂：
  1）一个来自**游离氨**
  2）一个来自**天冬氨酸（Asp）**

### 11.2 反应部位（亚细胞定位）

* 课堂强调：有的反应在线粒体（mitochondria），有的在胞液（cytosol）

### 11.3 关键步骤（按老师顺序）

1）**CPS I（carbamoyl phosphate synthetase I）**

* NH₃ + CO₂ + ATP → **氨基甲酰磷酸（carbamoyl phosphate）**
* 发生在**线粒体**
* 重要激活剂：**N-乙酰谷氨酸（N-acetylglutamate, NAG）**（无它酶无活性）
  2）**OTC（ornithine transcarbamylase）**
* 鸟氨酸（ornithine）+ 氨基甲酰磷酸 → **瓜氨酸（citrulline）**
* 瓜氨酸出线粒体入胞液
  3）**ASS（argininosuccinate synthetase）**
* 瓜氨酸 + 天冬氨酸 + ATP → **精氨酸代琥珀酸（argininosuccinate）**
* 老师说它是限速/影响很大的一步（你复习时也注意教材里常把CPS I视为关键调节位点）
  4）**ASL（argininosuccinate lyase）**
* 精氨酸代琥珀酸 → **精氨酸（arginine） + 延胡索酸（fumarate）**
  5）**Arginase（精氨酸酶）**
* 精氨酸 + H₂O → **尿素（urea） + 鸟氨酸**
* 鸟氨酸回到线粒体，循环继续

### 11.4 尿素循环与TCA的连接：天冬氨酸–精氨酸代琥珀酸旁路

* 延胡索酸（fumarate）→ 苹果酸（malate）→ 草酰乙酸（OAA）
* OAA 受氨基生成 Asp → 回到尿素循环继续供第二个氮
* 老师提到“两个循环像自行车”（凯氏发现两个循环的趣味记忆点）

### 11.5 调节因素（老师总结三条）

1）高蛋白饮食 → 产氨多 → 尿素生成增加
2）CPS I 活性受 **NAG** 影响（精氨酸可促进NAG生成）
3）尿素生成过程中的关键/限速相关酶活性变化会显著影响尿素合成

## 12. 高氨血症/肝性脑病：为什么氨会“搞脑子”

老师给了几条机制线索（很适合写简答题）：

* 氨影响体液酸碱/渗透环境 → 细胞功能紊乱
* 解毒时大量消耗 **α-酮戊二酸** 生成谷氨酸/谷氨酰胺 →
  α-酮戊二酸是TCA关键中间体 → TCA受影响 → **能量不足** → 脑功能障碍
* 谷氨酰胺在细胞内增多 → 渗透压上升 → 细胞水肿（脑水肿风险）
* 谷氨酸可转为 **GABA（抑制性递质）** → 抑制神经活动 → 嗜睡、意识障碍等

## 13. 氨基酸脱羧生成的特殊活性物质（“对应关系必考”）

* **谷氨酸 → γ-氨基丁酸 GABA（γ-aminobutyric acid）**

  * 中枢重要抑制性神经递质
* **组氨酸 Histidine → 组胺 Histamine**（你转写里“谷氨酸/乳氨酸”应为口误/识别错，按生化常识应是组氨酸）

  * 扩血管、增通透性 → 炎症/过敏相关；支气管平滑肌收缩（哮喘相关）；促进胃酸分泌
* **色氨酸 Tryptophan → 5-羟色胺 5-HT（serotonin）**

  * 中枢递质；外周可影响平滑肌收缩等
* **多胺 Polyamines（如腐胺putrescine、亚精胺spermidine、精胺spermine）**

  * 与细胞增殖旺盛相关，可作为肿瘤活动/复发监测的辅助指标（老师的临床点）

## 14. 一碳单位（One-carbon units）与叶酸/维B12（重点中的重点）

### 14.1 一碳单位是什么（老师强调“不是完整分子”）

* 是含**1个碳原子**的化学基团（如甲基、甲烯基等），**不能独立存在**
* CO₂ / CO 虽含1个碳，但它们是完整分子 → **不算一碳单位**

### 14.2 载体：四氢叶酸（THF, tetrahydrofolate）

* 由叶酸（folate）经两步还原形成
* THF上两个关键连接位点：**N5 与 N10**（老师点名要记）

### 14.3 一碳单位来源氨基酸（老师要求记“四个”）

* 丝氨酸（Ser）、甘氨酸（Gly）、组氨酸（His）、色氨酸（Trp）
* 一碳单位之间可互相转变，但老师强调：

  * **甲烯基 → 甲基**是单向（常对应体内“最终把一碳推到甲基去用”）

### 14.4 主要生理功能（老师给两大功能）

1）参与**核苷酸/核酸合成**（影响DNA/RNA合成）

* 联系药理：磺胺类结构类似叶酸底物 → 干扰叶酸/THF → 抑制细菌核酸合成 → 抑菌
  2）经**蛋氨酸循环（methionine cycle）**提供甲基，参与转甲基反应

### 14.5 甲硫氨酸循环（Methionine cycle）与SAM

* 甲硫氨酸（Met）先活化为 **S-腺苷甲硫氨酸 SAM（S-adenosylmethionine）** → 才能供甲基
* SAM供甲基后 → SAH → 同型半胱氨酸（homocysteine）
* 同型半胱氨酸再甲基化回甲硫氨酸：

  * 甲基来自 **N5-甲基THF**
  * 需要 **维生素B12**（老师讲到“甲基陷阱”思路：B12缺乏会让甲基THF放不出去）
* 叶酸或B12缺乏 → 核酸合成受影响 → 细胞长大但分裂差 → **巨幼细胞性贫血（megaloblastic anemia）**

## 15. 含硫氨基酸代谢：甲硫氨酸、半胱氨酸等（老师后半段重点）

* 含硫氨基酸：甲硫氨酸（Met）、半胱氨酸（Cys）、胱氨酸（Cystine，二硫键连接的二聚体）

* 甲硫氨酸除供甲基外，还参与：

  * **肌酸（creatine）/磷酸肌酸（phosphocreatine）**：高能磷酸储能形式（骨骼肌、脑组织重要）
  * 最终生成肌酐（creatinine）经肾排出 → 肌酐可作为肾功能指标

* 半胱氨酸相关重要产物：

  * **PAPS（3′-phosphoadenosine-5′-phosphosulfate）**：活性硫酸供体

    * 参与生物转化（硫酸化解毒等）
    * 参与硫酸软骨素等糖胺聚糖合成（结缔组织/关节相关）
  * **牛磺酸（taurine）**：结合胆汁酸，促进脂类消化吸收（胆汁酸乳化作用）

## 16. 芳香族氨基酸代谢与疾病：PKU、儿茶酚胺、黑色素、甲状腺素

### 16.1 苯丙氨酸 → 酪氨酸（关键）

* 正常：苯丙氨酸在**苯丙氨酸羟化酶（phenylalanine hydroxylase）**作用下 → 酪氨酸
* 若该酶先天缺陷/活性不足：

  * 苯丙氨酸改走转氨基 → 苯丙酮酸等积累 → **苯丙酮尿症 PKU（phenylketonuria）**
  * 对神经系统毒性大：婴幼儿若不早治 → 发育迟缓/智力损害
  * 原则：**早发现、早治疗**，并控制膳食苯丙氨酸摄入（老师强调）

### 16.2 酪氨酸的三大“产物方向”（老师点名）

* **儿茶酚胺（catecholamines）**：多巴胺 DA → 去甲肾上腺素 NE → 肾上腺素 Epi

  * 其中“NE → Epi”需要 **SAM供甲基**
  * 多巴胺降低与帕金森病（Parkinson’s disease）相关（老师讲到这儿）
* **黑色素（melanin）**：皮肤/毛发颜色来源；缺乏可见白化病
* **甲状腺激素（thyroid hormones）**：甲状腺细胞相关合成方向
* 也可彻底氧化分解进入能量代谢（生成TCA相关中间体）
