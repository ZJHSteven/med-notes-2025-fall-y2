## 一、血液的生化特异性：成分与基本概念

### 1）血液基本组成

* **血液 = 血浆（液体部分） + 有形成分（细胞成分）**

  * 有形成分：红细胞、白细胞、血小板等（本章重点放在**红细胞**）
  * 血浆：水环境 + 各种离子 + 蛋白质胶体 + 小分子代谢物

### 2）血浆 vs 血清（一定要分清）

* **血清（serum）**：血液在体外**凝固后**析出的淡黄色澄清液体
* **血浆（plasma）**：血液加入**抗凝剂**后离心获得的淡黄色液体
* **关键差别（老师强调）**：

  * **血浆有：纤维蛋白原（fibrinogen）**
  * **血清无：纤维蛋白原**（因为凝固时被消耗掉形成纤维蛋白网）

> 记忆钩子：**“血浆=没凝过（还带凝血家伙），血清=凝过了（纤维蛋白原没了）”**

### 3）血液化学成分（和前面糖/脂/氨基酸/核酸代谢串起来）

* **蛋白质**

  * 总蛋白（TP）：约 60–80 g/L
  * **白蛋白（albumin）**：35–55 g/L（占总蛋白约 60%）
  * 球蛋白：约 20–30 g/L
  * 纤维蛋白原：约 2–4 g/L（血浆特有）
* **含氮非蛋白小分子**（前面章节来的）

  * 尿素氮（氨基酸代谢）、尿酸（核酸代谢）、肌酐等
* **不含氮有机物**

  * 葡萄糖、乳酸、甘油三酯、胆固醇、磷脂、酮体等
* **无机离子**

  * Na⁺、K⁺、Ca²⁺ 等（渗透压、兴奋性、酸碱平衡相关）

### 4）血液的“生化层面”基本功能（老师用总结句讲的）

* 运输：营养物、氧、激素等
* 排泄：把代谢废物运至肾/肝等处理排出
* **维持胶体渗透压**（白蛋白核心贡献）
* 维持酸碱平衡（蛋白缓冲、离子体系）
* 调节神经肌肉兴奋性（离子）

## 二、血浆蛋白：种类、分类方法与高频蛋白功能

### 1）血浆蛋白有很多，但考试抓“高丰度 + 功能代表”

老师说血浆蛋白约 200 种，但重点抓几类。

### 2）分类方法（老师讲了两条线）

**A. 实验分离：电泳（按迁移率）**

* 白蛋白（albumin）
* α₁、α₂ 球蛋白
* β 球蛋白
* γ 球蛋白

**B. 按功能分类（更像“生化意义分类”）**

* **载体蛋白**：白蛋白、脂蛋白、转铁蛋白、铜蓝蛋白等
* **免疫防御蛋白**：IgG/IgM/IgA/IgE、补体等（本章不深入免疫细节）
* **凝血/纤溶系统**：凝血因子、纤溶酶原等
* **酶与酶抑制剂**：各种血浆酶 + 蛋白酶抑制剂（非常重要）

### 3）重点蛋白（老师逐个讲的“必背功能点”）

#### （1）白蛋白 Albumin（“血浆第一大户”）

* 含量最高（约占血浆蛋白 60%），**肝合成**
* **不含糖链**（老师特意说：除白蛋白外，多数血浆蛋白是糖蛋白）
* 主要功能：

  * **维持血浆胶体渗透压**（核心）
  * 载体：转运脂肪酸、激素、金属离子、药物等
  * 缓冲：参与酸碱平衡（蛋白带电基团缓冲 H⁺）
  * 营养储备：营养缺乏时可分解供氨基酸

> 临床串联：肝合成能力下降 → 白蛋白↓、白/球比异常（肝功能的重要提示）

#### （2）结合珠蛋白 Haptoglobin（“抓游离Hb，保肾又保铁”）

* 功能：**结合血浆中“游离血红蛋白”**
* 生化逻辑（老师讲得很清楚）：

  * 红细胞破裂/溶血 → Hb跑到血浆
  * 游离 Hb 分子相对小，可能被肾小球滤过 → 肾小管沉积损伤 + 铁丢失
  * **结合珠蛋白 + Hb → 复合物分子量变大 → 不易滤过**
* 两大意义：

  1. **防肾损伤**（减少Hb进入尿路）
  2. **防铁流失**

#### （3）转铁蛋白 Transferrin（“运铁的船”）

* β₁球蛋白，糖蛋白，肝合成
* 与 Fe³⁺结合运输（**游离铁有毒**）
* 一分子转铁蛋白可结合 **2 个 Fe³⁺**

#### （4）铁蛋白 Ferritin（“储铁的仓库”）

* 24 个亚基组成的大蛋白
* 主要功能：**储存铁**（能装很多铁原子）
* 体内铁分布（老师点了一句“绝大多数在Hb里”）：

  * Hb中的铁最多，其次肌红蛋白/酶，储存在铁蛋白等

#### （5）铜蓝蛋白 Ceruloplasmin（“运铜 + 顺便把Fe²⁺氧化成Fe³⁺”）

* 血浆中约 90% 铜由铜蓝蛋白携带
* 具有铜依赖的氧化酶活性：**Fe²⁺ → Fe³⁺**，促进与转铁蛋白结合
* 老师还“扩展一句”：近年研究的**铜死亡/铁死亡**等与金属代谢相关（了解即可）

#### （6）血浆酶：功能酶 vs 非功能酶（诊断学意义）

* **血浆功能酶**：本来就在血浆里发挥作用
* **非血浆功能酶**：组织细胞内的酶，**组织损伤后入血**

  * 例：转氨酶、LDH 等（用于肝/心肌等损伤提示）

## 三、红细胞的代谢特异性：为什么“只靠糖酵解 + PPP”还能活？

### 1）成熟过程与“能力丢失表”

红细胞分化：有核红细胞 → 网织红细胞 → 成熟红细胞
成熟红细胞的关键点：

* **无核**：无DNA合成/无转录
* **无线粒体**：不能三羧酸循环、不能氧化磷酸化
* 结果：能量主要靠 **糖酵解**；抗氧化靠 **磷酸戊糖途径（PPP）**

### 2）成熟红细胞三件套（老师的主线）

#### （1）糖酵解供ATP：维持“膜泵 + 膜稳定”

* ATP用途（老师列了好几条）：

  * 维持膜上 Na⁺/K⁺泵等离子转运，保持渗透压与形态
  * 维持膜脂与血浆脂蛋白之间的脂质交换
  * 支持谷胱甘肽、NAD等合成相关过程
  * 糖酵解启动本身需要ATP“点火”（葡萄糖磷酸化）

#### （2）2,3-BPG旁路：为“放氧”服务（高频考点）

* 红细胞糖酵解中有旁路：

  * 1,3-BPG → **2,3-BPG** → 3-PG
* **2,3-BPG作用**：降低Hb对氧亲和力，促进氧释放（右移）
* 适应性变化：

  * 高原/缺氧环境：2,3-BPG↑ → 放氧能力↑（老师点名）

> 记忆钩子：**“2,3-BPG=放氧开关”**

#### （3）磷酸戊糖途径 PPP：造NADPH来“抗氧化”

* PPP产物 **NADPH** 的核心任务：

  * 维持 **谷胱甘肽（GSH）** 处于还原态
  * GSH去清除过氧化物/ROS，保护膜蛋白、Hb、酶蛋白不被氧化
* 老师讲的链条就是：

  * PPP → NADPH ↑
  * NADPH 让氧化型GSSG → 还原型GSH
  * GSH 把过氧化物变水，自己被氧化
  * NADPH再把它“充电”回GSH

### 3）红细胞脂质从哪来？（老师特意强调“不能自己合成”）

* 成熟红细胞**不能合成脂类**
* 但膜需要磷脂/胆固醇维持完整性
* 解决方案：与血浆脂蛋白不断进行**脂质交换**（依赖能量/膜系统维持）

## 四、血红素/血红蛋白合成：部位、原料、路线、调控（本章“特异通路”）

### 1）血红蛋白组成

* **Hb = 珠蛋白（globin） + 血红素（heme）**
* 典型成人HbA：α₂β₂（老师提到4亚基）

### 2）血红素合成：组织与亚细胞定位（老师总结成“三句话”）

* 合成组织：**骨髓幼红细胞/网织红细胞**为主；**肝**也能合成
* 成熟红细胞：**不能合成血红素**
* 亚细胞定位：**线粒体 → 胞质（包液）→ 线粒体**

### 3）原料（老师让你“就记这三个”）

* **甘氨酸 Glycine**
* **琥珀酰辅酶A Succinyl-CoA**
* **铁 Fe²⁺/Fe³⁺（最终装到卟啉环中心）**

### 4）第一步最关键（老师明确：只考这个也够你拿分）

* 反应部位：**线粒体**
* 反应：甘氨酸 + 琥珀酰-CoA → **δ-氨基-γ-酮戊酸（ALA）**
* 关键酶：**ALA合酶（ALA synthase）** = 限速酶

### 5）后续路线（掌握“走向”而不是每个结构式）

* ALA 出线粒体 → 胞质多步反应 → 再回线粒体
* 最后一步：**亚铁螯合酶（ferrochelatase）**把铁装上 → 生成血红素
* 血红素 + 珠蛋白组装 → 血红蛋白

### 6）调控（老师讲了“反馈 + 抑制 + 诱导”）

* **血红素反馈抑制 ALA合酶**（血红素多→刹车）
* 重金属等可抑制相关酶（老师提到“血红素/重金属抑制”）
* 某些类固醇激素可诱导相关酶生成（了解）

## 五、肝脏的生化特异性：代谢枢纽 + 解毒工厂（生物转化）

### 1）肝在维生素/激素代谢中的作用（老师先“扫一遍功能”）

* 胆汁酸盐：协助脂溶性维生素吸收
* 贮存：Vit A、E、K、B12 等
* 参与多种维生素代谢过程（老师点名：A原、PP、泛酸、B1、D 等）

### 2）肝的“灭活激素”作用（临床联系老师举例了）

* 类固醇激素、甲状腺素、胰岛素、雌激素等可在肝内灭活
* 肝功能差 → 雌激素灭活下降 → 雌激素相对升高

  * 老师举的表现：蜘蛛痣/相关体征（作为理解串联即可）

## 六、肝的生物转化（Biotransformation）：两相反应总框架（本章大题核心）

### 总定义（老师的原意）

把内源/外源的“非营养物质”（药物、添加剂、毒物、激素、胺类等）
通过一系列化学反应 **变得更极性/更水溶** → 便于经胆汁或尿排出；同时让其活性降低或失活。

> 但老师也提醒：**少数情况下会“越转越毒”**（如某些前致癌物被活化）

---

### Phase I：第一相反应（“加功能团/暴露功能团”）

类型：**氧化、还原、水解**
目标：让分子更极性，或生成可进入第二相的“接头位点”（–OH, –NH₂, –COOH 等）

#### 1）氧化（最常见）——CYP450 单加氧酶系统

* 位置：主要在肝细胞**微粒体（内质网相关）**
* 关键酶系：**细胞色素P450（CYP）**
* 反应特点（老师讲了机理骨架）：

  * 需要 **O₂** 与 **NADPH** 提供还原当量
  * 把一个氧原子“塞”进底物（生成羟基化/环氧化等），另一个氧变水
* 意义：

  * 通常水溶性↑、活性↓
  * 但**环氧化物**等中间体可能很毒、可与DNA结合 → 致突变/致癌风险（老师举多环芳烃）

#### 2）线粒体氧化酶：单胺氧化酶（MAO）

* 催化胺类氧化脱氨 → 生成醛 → 再变酸（极性更强，更好排）

#### 3）还原

* 硝基还原酶、偶氮还原酶等：把硝基/偶氮化合物还原成胺类（为后续代谢做准备）

#### 4）水解

* 酯酶/酰胺酶/糖苷酶等水解反应
* 例：阿司匹林水解成水杨酸等，再进入第二相结合排泄

---

### Phase II：第二相反应（“接大头，提高水溶性，直接送走”）

在第一相产物的 –OH/–NH₂/–COOH 上**接上强极性基团**，显著提高溶解度 → 排出体外。
老师点名“最普遍”的是葡萄糖醛酸化。

重点结合方式（按老师顺序整理）：

1. **葡萄糖醛酸结合（Glucuronidation）**：UDP-葡萄糖醛酸供体，葡萄糖醛酸转移酶
2. **硫酸化（Sulfation）**：PAPS 供体，硫酸转移酶
3. **乙酰化（Acetylation）**：乙酰-CoA供体（如某些磺胺类）
4. **甲基化（Methylation）**：SAM 供体（生成SAH）
5. **谷胱甘肽结合（GSH conjugation）**：GST催化，特别对环氧化物/卤代物等解毒重要
6. **甘氨酸结合（Glycine conjugation）**：线粒体相关酶系，常与含羧基外源物结合

> 记忆钩子（很适合背）：
> **“一相：加/露功能团；二相：接大头（醛酸、硫酸、乙酰、甲基、GSH、甘氨酸）”**

## 七、老师最后的“本章考点清单”（按你录音原话的意思复原成背诵版）

### 血液部分你要会：

1. 血浆/血清/全血概念，差别在**纤维蛋白原**
2. 血浆蛋白：电泳分型（白蛋白、α/β/γ球蛋白）
3. 重点蛋白功能：白蛋白、结合珠蛋白、转铁蛋白、铁蛋白、铜蓝蛋白
4. 红细胞代谢特点：**无核、无线粒体 → 糖酵解 + PPP**
5. 红细胞糖酵解旁路：**2,3-BPG** 促进放氧
6. 红细胞脂质来源：**与血浆脂蛋白交换**
7. 血红素合成：

   * 原料：甘氨酸、琥珀酰-CoA、铁
   * 路线：线粒体→胞质→线粒体
   * **第一步限速酶：ALA合酶**，产物：ALA

### 肝脏部分你要会：

1. 肝：维生素处理（胆汁酸助吸收、储存等）
2. 肝：激素灭活（联系肝功能差的表现理解即可）
3. 肝生物转化：

   * **第一相：氧化/还原/水解（CYP450最关键，NADPH参与）**
   * **第二相：结合（葡糖醛酸最常见，其余硫酸、乙酰、甲基、GSH、甘氨酸）**
   * 目的：水溶性↑ → 经胆汁/尿排出；少数可被活化变更毒
