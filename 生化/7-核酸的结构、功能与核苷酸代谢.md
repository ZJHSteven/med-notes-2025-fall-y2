## 二、核酸概述（Nucleic acids in cells）

1. **两大类：**

   * DNA (deoxyribonucleic acid)：主要在细胞核，少量在线粒体；功能是**遗传信息的储存**。
   * RNA (ribonucleic acid)：主要在细胞质，也在细胞核；功能是**遗传信息的传递和表达**，部分病毒以 RNA 为遗传物质。
2. **中心法则（central dogma）：**
   DNA → (replication) → DNA
   DNA → (transcription) → RNA
   RNA → (translation) → Protein
   有的病毒有 reverse transcription（逆转录）。
3. **元素组成：**C, H, O, N, **P 含量比较恒定（9~10%）**，可用于定量核酸。

**关键词：** DNA, RNA, nucleus, mitochondria, genetic information, central dogma, replication, transcription, translation, reverse transcription

## 三、核苷酸与核苷（Nucleotide & Nucleoside）

### 1. 基本组成

一个**核苷酸 nucleotide**有三部分：

1. 含氮碱基 (nitrogenous base)
2. 戊糖 (pentose) —— D-ribose 或 2′-deoxy-D-ribose
3. 磷酸 (phosphate)

**没有磷酸**的叫**核苷 nucleoside**。

### 2. 含氮碱基（Nitrogenous bases）

* **嘌呤（purines）：**Adenine (A), Guanine (G)
* **嘧啶（pyrimidines）：**Cytosine (C), Thymine (T, DNA 特有), Uracil (U, RNA 特有)
* **少量碱基（minor bases）：**5-methylcytosine, 5-hydroxymethylcytosine, 7-methylguanine, hypoxanthine, xanthine —— 在 DNA/RNA 中作为修饰碱基出现。

### 3. 戊糖（Pentoses）

* DNA：2′-deoxy-D-ribose
* RNA：D-ribose
* 记住“2′位少一个 OH”就是脱氧核糖。

### 4. 键合方式

* **β-N-糖苷键 (β-N-glycosidic bond)：**连接碱基和糖；嘌呤是 N-9 连 C-1′，嘧啶是 N-1 连 C-1′。
* **酸酐键 / 磷酸酐键 (acid anhydride bond)：**在糖的 C-5′ 上连 1~3 个磷酸，形成 NMP、NDP、NTP（如 AMP, ADP, ATP）。

### 5. 常见核苷酸表示

* DNA 型：dAMP, dGMP, dCMP, dTMP
* RNA 型：AMP, GMP, CMP, UMP
* **环核苷酸 (cyclic nucleotides)：**cAMP, cGMP —— 第二信使。

**关键词：** nucleotide, nucleoside, purine, pyrimidine, ribose, deoxyribose, β-N-glycosidic bond, phosphate, AMP/ADP/ATP, cAMP, cGMP

---

## 四、多核苷酸与方向性（Polynucleotides）

1. 核苷酸通过**3′,5′-磷酸二酯键（3′,5′-phosphodiester bond）**连接。
2. 链具有方向性：一端是 **5′-end**（有游离或被磷酸化的 5′-OH），一端是 **3′-end**（有游离 3′-OH）。
3. 序列书写通常从 5′ → 3′。
4. 骨架是**糖-磷酸骨架**，碱基“伸在外面”。

**关键词：** phosphodiester bond, 5′ end, 3′ end, backbone, oligonucleotide, polynucleotide

## 五、DNA 的结构（Structure of DNA）

### 1. 一级结构（Primary structure）

* 就是**核苷酸序列（base sequence）**，是遗传信息的直接载体，常用 bp、kb、nt 表示长度。
* 稳定因素：3′,5′-磷酸二酯键。

### 2. 二级结构（Secondary structure）

**Chargaff’s rules 查加夫法则：**

* DNA 中 A ≈ T，G ≈ C
* 嘌呤总量 = 嘧啶总量

**Watson–Crick 双螺旋模型要点：**

1. 两条多核苷酸链**反向平行 (antiparallel)**，都是右手螺旋。
2. 外侧是糖-磷酸骨架，内侧是碱基配对。
3. **碱基互补配对 (complementary base pairing)**：A=T（2 条氢键），G≡C（3 条氢键，故 GC 含量越高，越稳定、Tm 越高）。
4. 每一圈约 10 bp，螺距 3.4 nm，直径 2 nm，一个碱基间距 0.34 nm。
5. 存在**大沟（major groove）**和**小沟（minor groove）**，蛋白可在沟内识别序列并调控基因表达。
6. 稳定因素：氢键 + **碱基堆积力（base stacking）**。

### 3. 不同构象

* B-DNA：生理条件下最常见
* A-DNA：较宽、较扁
* Z-DNA：左手螺旋

### 4. 三级结构（Tertiary structure）

* **超螺旋 (supercoil)**：闭合环状 DNA 被进一步扭转，可正可负，有拓扑异构酶（topoisomerase）调节。
* 真核细胞中 DNA 缠绕组蛋白（histone）形成**核小体（nucleosome）**：

  * 核心颗粒：八聚体 (H2A, H2B, H3, H4 各 2) + ~146 bp DNA
  * 连接区：H1 + ~60 bp DNA
  * 逐级压缩成 30 nm 纤维 → 染色质 → 中期染色体，可达 10⁴~5×10⁴ 倍压缩。

### 5. DNA 的功能

* 遗传信息的化学基础
* 复制模板（replication template）
* 转录模板（transcription template）

**关键词：** Chargaff’s rule, complementary base pairing, antiparallel, right-handed double helix, major groove, minor groove, B-form DNA, A-form, Z-form, supercoiling, nucleosome, histone, chromatin

## 六、RNA 的结构与种类（RNA Structure and Function）

### 1. 与 DNA 的比较

* 糖：RNA 是 ribose；DNA 是 deoxyribose
* 碱基：RNA 用 U 替代 T
* 链数：RNA 多为单链，可形成二级结构（stem-loop, hairpin）
* RNA 不遵守 Chargaff 法则
* RNA 较易被碱水解，稳定性差，半衰期短
* 含量和种类因细胞而异

### 2. 真核 RNA 的分类

* **编码 RNA (coding RNA)：**mRNA
* **非编码 RNA (non-coding RNAs, ncRNAs)：**tRNA, rRNA, snRNA, snoRNA, miRNA, siRNA, piRNA, lncRNA, circRNA 等

### 3. mRNA

* 异质性最大，大小、稳定性差别大
* 5′ 端有 **7-methylguanosine cap (5′ cap)**，3′ 端多有 **poly(A) tail**（20~250 nt）
* 真核 mRNA 为**单顺反子 (monocistronic)**，原核常为多顺反子
* 来源于 hnRNA，经剪接、加帽、加尾成熟

### 4. tRNA

* 长度 74~95 nt
* 二级结构像三叶草，含有多处不寻常碱基（修饰碱基）
* 3′ 端统一是 **CCA-OH**，是氨基酸受纳部位
* 中间有 anticodon loop，可识别 mRNA 上的 codon
* 是翻译中的“adapter”

### 5. rRNA & 核糖体

* 核糖体是核糖核蛋白颗粒，是翻译机器
* 原核：70S = 50S(23S rRNA, 5S rRNA) + 30S(16S rRNA)
* 真核：80S = 60S(28S rRNA, 5.8S rRNA, 5S rRNA) + 40S(18S rRNA)

**关键词：** mRNA, 5′ cap, poly(A) tail, hnRNA, splicing, monocistronic, tRNA, anticodon, CCA 3′ end, rRNA, ribosome, 70S, 80S

## 七、核酸的理化性质（Nucleic Acid Chemistry）

1. **紫外吸收 (UV absorption)：**

   * 含氮碱基在 260 nm 有特征吸收，常用 A₂₆₀ 定量
   * A₂₆₀ = 1.0 时：dsDNA ≈ 50 μg/mL，ssDNA or RNA ≈ 40 μg/mL
   * 纯度：DNA A₂₆₀/A₂₈₀ ≈ 1.8；RNA ≈ 2.0

2. **变性 (denaturation, melting)：**

   * 提高温度或降低盐浓度可使双链 DNA 分离成单链
   * 氢键断开，但共价键（磷酸二酯键）不断
   * 伴随有**高变色效应 (hyperchromic effect)** —— A₂₆₀ 上升

3. **复性 (renaturation, annealing)：**

   * 温度、pH 恢复适宜后互补的单链可重新配对
   * 伴随**低变色效应 (hypochromic)**

4. **融解温度 Tm：**一半 DNA 分子变性的温度
   影响因素：

   * GC 含量 ↑ → Tm ↑
   * 盐浓度 ↑ → Tm ↑
   * 链越长 → Tm 越高

5. **杂交 (hybridization)：**

   * 不同来源的互补核酸单链在适宜条件下也能配对形成杂化双链
   * 是 Southern blot (DNA-DNA), Northern blot (RNA-DNA), PCR 引物设计的理论基础

6. **应用：**PCR、DNA sequencing、Southern / Northern blotting

**关键词：** UV absorption, A260, hyperchromic effect, melting temperature (Tm), denaturation, renaturation, hybridization, Southern blot, Northern blot, PCR

## 八、核苷酸的功能与消化（Functions & Digestion）

1. **功能：**

   * DNA/RNA 前体 (precursors)
   * 能量货币：ATP, GTP
   * 辅酶成分：NAD, FAD
   * 活化中间体：UDP-glucose, CDP-diacylglycerol, SAM
   * 第二信使：cAMP, cGMP

2. **消化：**

   * 食物中核蛋白 → 胃酸+胃蛋白酶 → 核酸
   * 小肠内：核酸 → RNase/DNase → 核苷酸 → 核苷 → 碱基 + 核糖
   * 人体能自己合成嘌呤和嘧啶，所以“核苷酸非必需营养素（dietarily nonessential）”

**关键词：** ATP, GTP, NAD, FAD, UDP-glucose, cAMP, nucleases, RNase, DNase, nucleotidase, nucleosidase, dietarily nonessential

## 九、嘌呤核苷酸的从头合成（De novo synthesis of purine）

### 1. 总体特点

* 在 **核糖-5-磷酸 (ribose-5-phosphate)** 上“搭建”嘌呤环
* 关键活化中间体：**PRPP (5-phosphoribosyl-1-pyrophosphate)**
* 需要多种供一碳单位的叶酸形式（N¹⁰-formyl-THF）
* 产物先是 **IMP (inosine monophosphate)**，再分支成 AMP、GMP
* 共 **11 步左右**反应

### 2. 嘌呤环原子来源（要背）

* N-1：aspartate
* C-2, C-8：formate (via N¹⁰-formyl-THF)
* N-3, N-9：amide N of glutamine
* C-4, C-5, N-7：glycine
* C-6：CO₂

### 3. 三个阶段

1. **IMP 合成阶段**：R5P → PRPP → … → IMP

   * PRPP synthase：限速之一
   * PRPP glutamyl amidotransferase：也易受反馈调节
2. **IMP → AMP / GMP：**

   * IMP + Aspartate + GTP → Adenylosuccinate → AMP + fumarate
   * IMP → XMP (IMP dehydrogenase, NAD⁺) → GMP (uses glutamine, ATP)
3. **单磷酸 → 三磷酸：**AMP/GMP → ADP/GDP → ATP/GTP（各自的 nucleoside monophosphate kinase + nucleoside diphosphate kinase）

### 4. 调控（Feedback inhibition）

* PRPP synthase 受 AMP, GMP 抑制
* PRPP amidotransferase 受 IMP, AMP, GMP 抑制
* AMP 合成需要 GTP；GMP 合成需要 ATP —— 形成平衡

**关键词：** PRPP, de novo, IMP, adenylosuccinate, IMP dehydrogenase, AMP, GMP, feedback inhibition, rate-limiting enzyme

---

## 十、嘌呤的补救合成（Salvage pathways of purine）

1. 利用游离的嘌呤碱基 + PRPP → 相应的 NMP，更省能量
2. 关键酶：

   * **APRT (adenine phosphoribosyl transferase)：**Adenine → AMP
   * **HGPRT (hypoxanthine-guanine phosphoribosyl transferase)：**Hypoxanthine → IMP；Guanine → GMP
3. 生理意义：

   * 节能
   * 一些组织（脑、骨髓）主要靠补救合成
4. **HGPRT 缺陷 → Lesch–Nyhan syndrome**：X 连锁隐性，尿酸增高 + 严重神经精神症状 + 自残

**关键词：** salvage pathway, APRT, HGPRT, Lesch–Nyhan syndrome

---

## 十一、嘧啶核苷酸的从头合成（De novo synthesis of pyrimidine）

### 1. 总体特点

* 嘧啶是**先合成环，再挂到 PRPP 上**，跟嘌呤相反
* 关键限速酶：**CPS II (carbamoyl phosphate synthase II)**，在胞质，用 **glutamine**供氮，受 UMP 反馈抑制
* 第二关键酶：**aspartate transcarbamoylase (ATCase)**

### 2. 四个阶段

1. CO₂ + glutamine + ATP → **carbamoyl phosphate (by CPS II)**
2. carbamoyl phosphate + aspartate → carbamoyl aspartate → dihydroorotate → **orotate**
3. orotate + PRPP → **OMP (orotidine monophosphate)** → **UMP**
4. UMP → UDP → UTP → **CTP**（由 CTP synthase，用 glutamine 供 N）

   * UMP 也可还原成 dUDP，再变成 dUMP，为后续 dTMP 合成准备

### 3. CPS I vs CPS II 对比（易考）

* CPS I：在线粒体，尿素循环，用 NH₃，激活剂是 N-acetylglutamate
* CPS II：在胞质，嘧啶合成，用 glutamine，受 UMP 反馈抑制

### 4. dTMP 的生成

* dUMP → (thymidylate synthase) → dTMP
* 需要 N⁵,N¹⁰-methylene-THF 供 **一个 C 和两个 H**，同时叶酸被氧化成 DHF，要靠 DHFR 再生
* 所以叶酸代谢药、胸苷合成药能抑制 DNA 合成

**关键词：** CPS II, ATCase, orotate, OMP, UMP, UTP, CTP, ribonucleotide reductase, thymidylate synthase, DHFR, de novo pyrimidine synthesis

---

## 十二、脱氧核苷酸的形成（Formation of deoxynucleotides）

* 由 **ribonucleotide reductase** 把 **NDP → dNDP**（注意是二磷酸水平）
* 需要 **thioredoxin** / **thioredoxin reductase** / **NADPH**
* dUDP → dUTP → (dUTPase) → dUMP → dTMP

**关键词：** ribonucleotide reductase, thioredoxin, NADPH, dUMP, dTMP

## 十三、抗代谢物（Antimetabolites）

1. **定义：**结构类似核苷酸合成底物或中间产物的化合物，通过竞争/抑制关键酶来**阻断核酸合成**，多用于肿瘤化疗或免疫抑制。
2. **嘌呤类似物：**6-mercaptopurine (6-MP), 6-thioguanine, azathioprine

   * 6-MP 可通过 HGPRT 转成毒性核苷酸，抑制 PRPP amidotransferase、IMP 转 AMP/GMP 等多个位点 → 嘌呤合成受阻
3. **嘧啶类似物：**5-fluorouracil (5-FU)、cytarabine (ara-C)

   * 5-FU → F-dUMP，**特异抑制 thymidylate synthase** → dTMP 不能合成 → DNA 合成受阻
4. **叶酸类似物：**methotrexate (MTX)、aminopterin —— 抑制 DHFR，间接阻断胸苷和嘌呤的合成

**关键词：** antimetabolite, 6-MP, 5-FU, methotrexate, DHFR, thymidylate synthase, chemotherapy

## 十四、核苷酸的分解代谢（Catabolism）

### 1. 嘌呤的分解

* AMP → adenosine → inosine → hypoxanthine → xanthine → **uric acid**
* GMP → guanosine → guanine → xanthine → uric acid
* 关键酶：**xanthine oxidase**
* 人类嘌呤的最终产物是**尿酸（uric acid）**，**水溶性差** → 易沉积
* 尿酸排泄或生成异常 → **高尿酸血症、痛风 (gout)**
* 治疗：**allopurinol（别嘌醇）**抑制 xanthine oxidase，减少尿酸生成；配合饮食控制

### 2. 嘧啶的分解

* U, C → dihydrouracil → β-ureidopropionate → β-alanine + CO₂ + NH₃
* T → β-aminoisobutyrate
* 这些产物水溶性好，一般**不致病**

**关键词：** xanthine oxidase, uric acid, gout, hyperuricemia, allopurinol, β-alanine, β-aminoisobutyrate
