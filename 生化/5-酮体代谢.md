## 一、上节回顾：酮体（Ketone bodies）

### 1）一句话八字总结（老师原意）

* **“肝内合成，肝外利用”**（8个字）

### 2）酮体的生成与去路

* **合成部位：肝脏线粒体**
* **原料：乙酰辅酶A（acetyl-CoA）**，主要来自**脂肪酸β-氧化**
* **输出：肝脏把酮体释放入血 → 外周组织（肌肉、心肌、脑等）摄取 → 再转回乙酰辅酶A进入三羧酸循环供能**

### 3）为什么会“失控”（酮症酸中毒）

触发条件本质是：**糖不够用 → 被迫大量动员脂肪 → 肝大量产酮体**

* **糖绝对不足**：真的没糖（饥饿/长期禁食等）
* **糖相对不足**：有糖但用不了（典型：糖尿病胰岛素不足/作用差）

### 4）酮体三种成分 & 酸中毒机制

* 酮体三兄弟：

  * **乙酰乙酸（acetoacetate）**：酸性
  * **β-羟丁酸（β-hydroxybutyrate）**：酸性
  * **丙酮（acetone）**：相对中性、挥发性强
* 大量乙酰乙酸/β-羟丁酸进入血 → **pH下降** → **代谢性酸中毒**
* 临床线索：**呼气/尿液“烂苹果味”（丙酮味）**；酮体也会随尿排（ketonuria）

### 5）缓冲对与“为什么碳酸氢盐最关键”

* 血液缓冲体系很多，但老师强调：

  * **HCO₃⁻/H₂CO₃（碳酸氢盐缓冲对）**能通过**肺排CO₂**快速调节（呼吸性代偿）
  * 缓冲容量有上限 → 超过上限就酸中毒

## 二、把酮体放进代谢地图：肝是“来料加工厂”

老师的逻辑主线是：**肝脏很多代谢 = 原料别处来，产品给别处用**

* 脂肪酸来源：**脂肪组织脂解（lipolysis）**

  * 激素敏感性脂肪酶 **HSL** 作用：甘油三酯 → 脂肪酸 + 甘油
  * 脂肪酸在血中靠**白蛋白（albumin）**运输 → 到肝
* 肝把脂肪酸主要“加工”为：**酮体**（更易在血中运输/被利用）

## 三、脂肪酸合成（Fatty acid synthesis）——以软脂酸为核心

### 1）合成什么、在哪合成

* 代表产物：**软脂酸（palmitate，C16:0）**
* **主要组织：肝脏（也可见于脂肪组织等）**
* **亚细胞定位：细胞质（cytosol）**
* 延长与去饱和主要在：

  * **内质网（ER）**：延长到C18~C24、去饱和
  * **线粒体**也可做部分“反β-氧化样”的延长（老师点到为止）

### 2）和β-氧化的“像”与“绝不一样”

**像：**都以“两碳”为单位改造碳链
**不一样（高频考点）：**

* 部位：合成在**细胞质**；β-氧化在**线粒体**
* 载体：合成用**ACP**（酰基载体蛋白）；分解用**CoA**
* 还原力：合成用**NADPH**；分解产**NADH + FADH₂**
* 酶体系：合成多为**脂肪酸合成酶复合体（FAS）**；分解是一串独立酶

### 3）乙酰辅酶A怎么从线粒体出来？——柠檬酸穿梭

乙酰辅酶A在**线粒体内**生成，但合成在**细胞质**进行 → 需要“搬运”

* 线粒体：乙酰-CoA + 草酰乙酸 → **柠檬酸（citrate）**
* 柠檬酸出线粒体 → 细胞质 **ATP-柠檬酸裂解酶（ATP-citrate lyase）**裂解：

  * 柠檬酸 → 乙酰-CoA + 草酰乙酸（耗ATP）
* 这是老师强调的控制思路：
  **“把乙酰-CoA留在线粒体＝倾向燃烧；把它运到细胞质＝倾向合成/储存”**

### 4）NADPH从哪来（合成脂肪酸必须）

两大来源（老师重点）：

* **磷酸戊糖途径（PPP）**
* **细胞质异柠檬酸脱氢酶（IDH1，NADP⁺依赖）**
  老师还顺带提到：某些**异柠檬酸脱氢酶突变**与肿瘤相关（课上当作“批判性思维案例”听就行，考试更可能考“同工酶/定位/NADPH来源”这一层）

### 5）脂肪酸合成三阶段（老师按流程划分）

1. **活化**：乙酰-CoA → **丙二酰-CoA（malonyl-CoA）**
2. **延长循环**：以丙二酰-CoA为“2C供体”，每轮加2个碳
3. **延长/去饱和**：C16后转ER/线粒体继续加工

### 6）关键限速酶：乙酰-CoA羧化酶（ACC）

* 反应：乙酰-CoA + CO₂ + ATP → 丙二酰-CoA
* **辅酶：生物素（biotin）**（“所有羧化酶的老朋友”）
* **需要ATP，基本不可逆**（能量驱动）
* 调控（老师把两条调控思路讲得很清楚）：

  * **别构调节（allosteric regulation）**

    * 柠檬酸 ↑：激活ACC（底物前馈/构象促进）
  * **共价修饰调节（covalent modification）**

    * 胰岛素：促进去磷酸化 → **激活ACC**（合成脂肪、降血糖）
    * 胰高血糖素：PKA途径磷酸化 → **抑制ACC**（升血糖、抑制合脂）

## 四、脂肪酸合成酶复合体（FAS）：7轮循环为什么变C16？

### 1）复合体 vs 多功能酶（原核/真核对比）

* 原核：多功能酶/多酶系统组织方式不同（老师用来说明“进化把相关功能凑一块提高效率”）
* 真核：**脂肪酸合成酶复合体**，核心在**ACP**携带中间体跑“流水线”

### 2）循环反应四步（每轮都一样）

* **缩合（condensation）**
* **还原（reduction，NADPH）**
* **脱水（dehydration）**
* **再还原（reduction，NADPH）**

### 3）为什么是7轮？

* 启动时先“放入”一个**乙酰基（2C）**作引物
* 后续每轮用一个**丙二酰基（提供2C，脱CO₂推动反应）**
* 目标C16：已经有2C引物，还差14C → **每轮+2C → 7轮**

### 4）总反应式（老师的“最后一口气总结”）

合成1分子软脂酸大意需要：

* **1乙酰-CoA + 7丙二酰-CoA + 14NADPH**
* 产物：**软脂酸 + 7CO₂（“过河拆桥”放掉）+ …（水、NADP⁺等）**
  （考试更爱考“乙酰引物 + 7次延长 + 每轮2个NADPH”这种结构性结论）

## 五、延长与去饱和：必需脂肪酸怎么来的？

### 1）延长（elongation）

* **内质网**：用**丙二酰-CoA**继续延长（C18~C24常见）
* 软脂酸（C16:0）→ **硬脂酸（stearate，C18:0）**
  老师用“硬/软”帮助记溶解/凝固差异

### 2）去饱和（desaturation）与电子传递

* 人体去饱和能力有限（只能做某些位置的双键，引出“必需脂肪酸”概念）
* 去饱和过程需要电子传递链（老师点名）：

  * **NADH → 细胞色素b5还原酶 → 细胞色素b5 → 去饱和酶**

### 3）必需脂肪酸（Essential fatty acids）

* 动物体**不能合成**某些多不饱和脂肪酸 → 必须从食物获得
* 这些脂肪酸还是**花生四烯酸（arachidonic acid）**等炎症介质前体（前列腺素、血栓素、白三烯等）

## 六、甘油三酯合成与运输：谁“可进可出”，谁“只进不出”？

### 1）合成部位三大类

* **小肠黏膜**：利用食物消化产物就地合成TG → 组装成**乳糜微粒（chylomicron, CM）**入淋巴/血
* **肝脏**：合成TG → 组装成**极低密度脂蛋白（VLDL）**入血
* **脂肪组织**：也能合成TG，但**主要是储存，不直接把TG整包输出到血里**

### 2）脂肪组织要“出货”怎么出？

* 不是出TG，而是激素诱导脂解：
  **TG → 游离脂肪酸 + 甘油**（HSL主导）
* 小分子就不需要载脂蛋白“打包整箱”

### 3）脂肪肝的老师版逻辑

* 肝是加工厂，不是仓库
* 若VLDL装配/分泌障碍（营养不良、中毒、必需脂肪酸缺乏等可影响载脂蛋白/脂蛋白合成）
  → **脂肪运不出去 → 堆在肝里 → 脂肪肝**

### 4）两条合成TG的“路”

* **小肠：单甘油途径（monoacylglycerol pathway）**
  单甘油 + 脂酰-CoA → TG（因为小肠里脂酰-CoA“原料浓度高”，反应推动得动）
* **肝/脂肪等：磷酸甘油途径（glycerol-3-phosphate pathway）**
  用**甘油-3-磷酸**（更“活化”）做骨架更容易反应

## 七、磷脂（Phospholipids）：膜、信号、肺表面活性物质

### 1）为什么磷脂“到处都要合成”

* 磷脂是细胞膜/细胞器膜基本材料 → **全身广泛合成、持续更新**

### 2）两大类骨架

* **甘油磷脂（glycerophospholipids）**：骨架是甘油
* **鞘磷脂（sphingomyelin 等）**：骨架是鞘氨醇（老师说这节不细讲）

### 3）磷脂的结构与膜流动性

* 常见特点：一个脂肪酸链更“直”（饱和），另一个更“弯”（多不饱和如花生四烯酸）
* 弯折让膜不至于像“猪油”一样冬天冻硬 → **维持膜流动性**

### 4）磷脂分类的“X头基”思路（记法最值）

同一骨架，换头基X：

* **PC**（phosphatidylcholine，卵磷脂）
* **PE**（phosphatidylethanolamine）
* **PS**（phosphatidylserine）
* **PI**（phosphatidylinositol）
* **PG**（phosphatidylglycerol）等

### 5）第二信使：PI被PLC切开

* **磷脂酶C（PLC）**切PI衍生物（PIP₂等）→

  * **DAG（二酰甘油）**
  * **IP₃（三磷酸肌醇）**
* DAG/IP₃都是经典第二信使（这块很像“名词解释+机制题”）

### 6）肺表面活性物质（超高频临床点）

* 特殊磷脂：**二棕榈酰磷脂酰胆碱（DPPC）**
* 由**Ⅱ型肺泡上皮细胞**分泌
* 作用：降低肺泡表面张力，防止肺泡塌陷
* 不足可导致顺应性下降/通气受限（老师把它类比到慢性呼吸问题）

### 7）磷脂运输：磷脂交换蛋白

* 内质网合成磷脂后，要发往各类膜系统
* **磷脂交换蛋白（phospholipid transfer/exchange proteins）**承担“细胞内物流”

### 8）磷脂酶分类（知道“按切哪条键命名”即可）

* **PLA、PLC、PLD**等
* 老师强调：**PLC最关键**（第二信使）

## 八、胆固醇（Cholesterol）：从结构到合成开篇

### 1）是什么、为什么叫这个名

* 最早从胆汁中发现，常温下**针状结晶**，又属于“醇”类 → **胆固醇**

### 2）性质与分布（老师给的数字逻辑）

* 体内总量高（老师强调“人没胆固醇活不了”）
* **约1/4在脑/神经系统**（强调其结构与功能重要性）
* 肝、肾上腺、性腺含量也高（类固醇激素合成相关）

### 3）功能三大块

* **膜结构成分**：调膜流动性（“味精/调味剂”类比）
* **胆汁酸前体**：参与脂肪消化吸收（占胆固醇去路大头）
* **类固醇激素 & 维生素D前体**

  * 糖皮质激素、盐皮质激素、雄/雌/孕激素
  * 维生素D与钙磷代谢相关

### 4）是不是“必需胆固醇”？

* **没有必需胆固醇**：人体可自行合成
* 老师给的比例口径：体内胆固醇来源大头来自**内源合成**

### 5）合成概述（老师刚开始铺垫到HMG-CoA还原酶）

* 关键原料：**乙酰-CoA**
* 合成早期步骤与“酮体合成”前两步相似（老师故意串联）：

  * 乙酰-CoA → **乙酰乙酰-CoA（acetoacetyl-CoA）**（硫解酶 thiolase）
  * → **HMG-CoA**（HMG-CoA合成酶）
  * 关键分叉：不裂解去产酮体，而是走：

    * **HMG-CoA还原酶（HMG-CoA reductase）** + **NADPH** → **甲羟戊酸（mevalonate）**

> 这一步是胆固醇合成的经典“限速/关键酶”，临床降脂药（他汀类）就盯它（后面课大概率会展开）。
