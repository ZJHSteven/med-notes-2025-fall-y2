# 剩余价值学说：货币如何转化为资本

## 1）两个流通公式：为什么“有钱≠资本”

* **简单商品流通公式：** **C—M—C**
  目的：用商品换货币，再用货币换自己需要的商品（满足使用价值）。
* **资本的总公式：** **M—C—M′**，其中 **M′ = M + ΔM**
  目的：用货币买商品，最终得到**更多货币**（追求价值增殖）。
* 关键问题：**ΔM（货币增量）从哪里来？**
  交换领域遵循等价交换，**流通本身不能创造价值**；因此增殖秘密必在**生产过程**中。

# 劳动力成为商品：资本增值的“特殊商品”

## 2）劳动力与劳动：必须分清

* **劳动力：** 人的劳动能力（体力+脑力的总和）。
* **劳动：** 劳动力的使用（把劳动能力“用起来”的过程）。

## 3）劳动力成为商品的两个基本条件

1. **劳动者是自由人**：能把自己的劳动力当作商品支配、出卖（形式上自由）。
2. **劳动者“自由得一无所有”**：没有生产资料与生活资料，只能靠出卖劳动力维生（实质上被迫）。

> 由此理解那句经典话：
> **奴隶有“有形锁链”，雇佣工人有“无形锁链”**——表面自由选择雇主，实质必须进入资本关系才能活。

---

# 劳动力商品的价值与使用价值

## 4）劳动力商品的价值（怎么“算工资”）

劳动力价值由**生产、维持、延续劳动力所必需的生活资料价值**决定，包含：

* 劳动者本人衣食住行的基本生活资料
* 维持劳动者家庭所必需的生活资料（劳动力再生产）
* 教育与训练成本
* 还具有**历史与道德因素**（不同社会/时期不一样，不是固定常数）

## 5）劳动力商品的使用价值：它为什么“特殊”

一般商品：使用价值被消费时，价值要么消失、要么转移到新产品中。
**劳动力的特殊性：**

* 它不仅能创造出**等于自身价值**的价值，
* 还能创造出**超过自身价值**的价值
  → 这“超过的部分”就是**剩余价值的来源**。

# 剩余价值：定义、必要劳动与剩余劳动

## 6）剩余价值的定义

* **剩余价值：** 雇佣工人在生产过程中创造的、**超过劳动力价值的那部分价值**，被资本家**无偿占有**。

## 7）必要劳动 vs 剩余劳动

* **必要劳动（时间）：** 用来再生产劳动力价值（工资）的那部分劳动。
* **剩余劳动（时间）：** 超过必要劳动的那部分劳动，其创造的价值形成**剩余价值**。

---

# 例子（课堂算例）：一眼看懂“剥削从哪来”

设定（为计算方便）：

* 工人劳动 **1小时创造1元新价值**
* 工人工资（劳动力价值）= **6元/天**
* 生产资料：棉花、机器磨损等价值会“转移”到产品中

### 情况A：工人劳动6小时

* 新创造价值：6元
* 若棉花10元 + 机器磨损2元
* 产品价值：10 + 2 + 6 = **18元**

### 情况B：资本家把劳动日延长到12小时（工资仍6元）

* 新创造价值：12元
* 若棉花20元 + 机器磨损4元
* 产品价值：20 + 4 + 12 = **36元**
* 扣除：棉花20（转移）+磨损4（转移）+工资6（必要劳动对应）
* 剩下：36 − (20+4+6) = **6元**
  → 这6元就是**剩余价值**。

# 资本的本质：不是“物”，而是生产关系

## 8）资本为什么不是“钱/机器/厂房”本身

* 资本常以物表现（货币、机器、厂房、原料），但其本质是：
  **资本家对雇佣劳动的支配与剥削关系（社会关系）**。
* “不幸的皮尔先生”故事要点：
  他把钱和生产资料带到澳大利亚，也带了工人；但当地土地富饶、工人不必依附雇主谋生，于是工人纷纷离开——他**无法建立雇佣劳动关系**，因此“资本”运作不起来。
  核心：**缺的不是物，是资本主义生产关系。**

---

# 不变资本与可变资本

## 9）按在剩余价值生产中的作用划分

* **不变资本 c**：用于购买生产资料（厂房、机器、原料等）
  特点：其价值在生产中**只转移**到新产品，不发生增殖。
* **可变资本 v**：用于购买劳动力（工资）
  特点：通过劳动力使用，能创造新价值并带来增殖，**是剩余价值唯一源泉**。

> 易错点：可变不是“工资忽高忽低”，而是指这部分资本在生产中能引起**价值增殖**。

---

# 剩余价值率：衡量剥削程度的科学公式

## 10）三种等价表达

* **剩余价值率：**
  [
  m' = \frac{m}{v}
  ]
* 等价于：
  [
  m' = \frac{\text{剩余劳动}}{\text{必要劳动}}
  ]
* 用时间表述：
  [
  m' = \frac{\text{剩余劳动时间}}{\text{必要劳动时间}}
  ]

举例（纠正口误版）：

* 必要劳动4小时、工作日8小时 → 剩余4小时
  [
  m' = 4/4 = 100%
  ]
* 必要劳动4小时、工作日10小时 → 剩余6小时
  [
  m' = 6/4 = 150%
  ]
* 必要劳动2小时、工作日8小时 → 剩余6小时
  [
  m' = 6/2 = 300%
  ]

# 绝对、相对、超额剩余价值

## 11）绝对剩余价值生产

* **在必要劳动时间不变**的前提下，靠**延长工作日/提高劳动强度**延长剩余劳动时间。
* 局限：人的生理极限、社会斗争与法律限制（如8小时工作制的争取）。

## 12）相对剩余价值生产

* **工作日长度不变**，通过**缩短必要劳动时间**相对延长剩余劳动时间。
* 机制链条（背诵版）：

  * 提高劳动生产率 → 生活资料价值下降
  * 劳动力价值下降 → 必要劳动时间缩短
  * 剩余劳动时间相对延长 → 相对剩余价值增加
* 注意：这里强调“全社会（或关键部门扩散到全社会）劳动生产率提高”。

## 13）超额剩余价值：相对剩余价值的“特殊表现”

* **超额剩余价值：** 个别资本家通过改进技术、提高劳动生产率，先于社会平均水平降低个别价值，从而在竞争中获得超额收益。
* 关系：

  * 超额剩余价值是**相对剩余价值的特殊形式**
  * 全体资本家相对剩余价值的获得，常以个别资本家追求超额剩余价值为路径扩散实现。

# “到底谁养活谁”：用理论反击错觉

## 14）结论（按课堂逻辑）

* **工人养活资本家。**
* 理由：劳动是价值的唯一源泉；资本家占有的是工人创造的**剩余价值**。
  没有工人劳动，生产资料只是“死物”，不能自我增殖。

# 资本积累：剩余价值的资本化

## 15）概念

* **资本积累：** 把剩余价值转化为资本（剩余价值的资本化）。
* 与“资本原始积累”区分：
  原始积累强调暴力与迅速集中；资本积累是资本主义运行中的常态机制。

## 16）资本家为何要积累（两动力）

1. **内在动力：** 追求剩余价值（永无止境的增殖冲动）
2. **外在压力：** 市场竞争（不扩张就被吞并）

## 17）简单再生产 vs 扩大再生产

* **简单再生产：** 剩余价值全部用于资本家个人消费，下一轮仍按原规模生产。
* **扩大再生产：** 剩余价值一部分消费、一部分转化为追加资本（买更多生产资料、雇更多工人），生产规模扩大。
* 实质：资本主义再生产不仅是物质再生产，更是**资本主义劳资关系的再生产**。

---

# 资本积累的后果：两极分化与失业

## 18）贫富两极分化

* 资本积累 → 财富集中在少数资本家手里
* 工人与资本家“富/贫”是**相对概念**：资本越集中，差距越拉大。

## 19）失业的根源：资本有机构成提高 → 相对过剩人口

* 技术进步常表现为：更多投入机器设备（不变资本）+ 相对减少雇工（可变资本）。
* **资本有机构成：** 通常用 **c/v** 表示（由技术构成决定并表现为价值构成）。
* 后果：形成**相对过剩人口（产业后备军）**
  不是“社会不需要人”，而是“资本增殖不需要这么多人”。

### 相对过剩人口三种形态

1. **流动的过剩人口**：时有工、时失业
2. **潜伏的过剩人口**：看似“潜在失业”（如毕业难就业等）
3. **停滞的过剩人口**：长期失业/半失业、极不稳定就业

### 产业后备军对资本主义的“功能”

* 适应资本主义经济周期波动（高涨/危机/萧条/复苏）
* 对在业工人形成压力（压工资、强化纪律、增加可替代性）

# 资本主义基本矛盾与历史命运（课堂口径）

## 20）基本矛盾

* **生产的社会化**（大生产、分工协作、全球化联系增强）
  vs
* **生产资料私人占有**（由资本家按私利决定生产什么、生产多少、怎样生产）

课堂表述的归结：当生产资料集中与劳动社会化程度超出资本主义外壳所能容纳，就会走向制度更替（“剥夺者被剥夺”的逻辑）。

# 资本的循环与周转：资本靠“跑起来”增值

## 21）资本循环：一次“从出发点回到出发点”的运动

* 定义：资本从一种形式出发 → 经历形式变化 → 回到原出发点（但带来增殖）。
* 产业资本三阶段：

  1. **购买阶段**：货币资本 → 买劳动力+生产资料
  2. **生产阶段**：生产资本 → 生产商品并创造剩余价值
  3. **销售阶段**：商品资本 → 卖出实现价值与剩余价值 → 回到货币资本（M′）

## 22）空间并存、时间继起（抓关键词就行）

* **空间并存：** 三种资本形态（货币资本/生产资本/商品资本）必须按一定比例同时存在，否则链条断裂。
* **时间继起：** 三阶段按顺序连续推进，不能跳跃；任何一段卡住都可能出现“资金链断裂”。

## 23）资本周转：循环的反复

* **周转 = 循环的反复进行**
* **一次循环 = 一次周转**

### 周转速度为什么重要

* 周转越快，同一预付资本一年内可实现越多次增殖 → **年利润量上升**
  （课堂用“清仓/甩卖为了回笼现金流、加速周转”的例子说明）

# 固定资本与流动资本：别和不变/可变搞混

## 24）固定资本 vs 流动资本（按价值转移方式划分）

* **固定资本**：厂房、机器等劳动资料
  特点：价值**多次、逐步转移**（折旧）。
* **流动资本**：原材料、燃料、辅助材料，以及**工资**
  特点：价值在一次生产中**一次性转移/一次性预付并回收**。

> 关键辨析：
>
> * **可变资本 v**（买劳动力）通常属于“流动资本”的一部分；
> * **不变资本 c**既包含“固定资本”（机器厂房）也包含“不变的流动资本”（原材料等）。
>   所以：
>   **流动资本 ≠ 可变资本**；
>   **不变资本 = 固定不变资本 + 流动不变资本**。

# 社会总资本再生产：两大部类与比例关系（本段到你录音结尾处）

## 25）核心问题：社会总产品的实现

* **价值补偿：** 产品卖出去实现货币价值，用于补偿 c+v+m 的价值构成。
* **实物替换：** 用实现的货币去购买下一轮再生产需要的生产资料与消费资料。
  总结成一句话：**卖得出去 + 买得回来**，再生产才能继续。

## 26）两大部类（物质形态划分）

* **第一部类：生产资料的生产**（煤、电、钢铁、机械、原料等）
* **第二部类：消费资料的生产**（食品、衣物、生活消费品等）

## 27）比例失调 → 实现困难 → 可能走向危机

两大部类必须保持一定比例，否则会出现：

* 该卖的卖不出去（实现受阻）
* 该买的买不回来（再生产资料或消费资料断供）
  进而导致社会总产品实现困难，并可能诱发经济危机
