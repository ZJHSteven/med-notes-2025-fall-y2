# 第五章回顾：垄断资本向世界扩展（资本输出）与“矛盾分析法”

* **方法论强调**：看问题要坚持
  1）**从客观事实出发（物质观）**；
  2）**用矛盾观点看问题（两面性）**：同一现象往往“有利/有弊”并存。
* **资本输出/输入的两面性**（输出国、输入国都一样）：既可能促进发展，也可能带来代价与矛盾加深。

## 资本输出对输出国的影响（老师口径）

* **利**：获得巨额利润；带动并扩大商品输出；通过跨国公司等**控制发展中国家经济命脉**、巩固垄断地位。
* **弊**：可能导致**产业空心化**；加深与发展中国家/其他国家之间的矛盾。

## 资本输入对输入国的影响（以中国改革开放为例）

* **利**：引进资金与技术；优化产业结构；促进外贸；推动经济发展。
* **弊**：付出较大经济代价（如**环境污染**）；产业结构与布局可能受制于外资战略；冲击民族工业、影响经济控制权；加重债务负担；对国际资本依赖增强→更易受外部经济波动冲击（老师举了金融危机冲击的感受）。

> 老师举例（用于记忆“外资冲击民族工业”）：活力28、金鸡鞋油等“民族品牌被挤压/被收购后消失”的案例（点到为止即可）。

## 国际垄断同盟：作用与局限

* **积极**：加快资本国际流动与贸易服务；一定程度延缓国际经济领域矛盾；推动全球化。
* **消极/局限**：治理问题凸显，“加强全球治理势在必行”。

## 垄断资本主义（帝国主义）的实质：列宁概括（课堂版要点）

1. **垄断组织**在经济生活中起决定作用。
2. **金融资本**形成并在此基础上出现**金融寡头统治**（工业垄断资本 + 银行垄断资本 → 金融资本）。
3. **资本输出**具有特别重要的意义。
4. **瓜分世界的资本主义国际同盟**形成（跨国公司/国际托拉斯等）。
5. **最大资本主义国家瓜分世界领土基本完成**（老师口径：通过大战后格局重整，瓜分完成）。

* **垄断利润来源**：凭借垄断地位获取高额垄断利润，常用方式概括为**“垄断低价 + 垄断高价（低买高卖）”**。

# 经济全球化及其影响（教材第3部分：单列一讲）

## 背景脉络（老师的“世界市场”时间线）

* 二战前：殖民扩张推动世界市场形成（“血与火”）。
* 冷战时期：两大阵营对立、两个“平行世界”。
* 冷战结束后：对立格局弱化、相互依存增强 → **经济全球化加速演化**（世界格局走向多极化）。

## 经济全球化的三大表现（必背）

1. **生产全球化**：生产分工跨国展开（老师用波音飞机“多国部件+最终组装”作例子）。
2. **贸易全球化**：商品与劳务在全球范围更自由流动；通信/运输条件改善、贸易手段进步、各国更开放政策 → 全球贸易快速发展（重在“趋势上升”）。
3. **金融全球化**：各国金融政策协调与渗透，金融市场更开放、体系更融合、金融交易更自由。

## 全球化的“真正动因”（老师强调：不是人为阴谋，是客观结果）

* **科学技术进步与生产力发展**：提供物质基础与根本动力（人工智能、大数据、量子信息、生物技术等带来新产业/新业态/新模式）。
* **跨国公司**：提供适宜的企业组织架构，推动要素全球流动。
* **各国经济体制变革 + 国际组织发展**：提供制度与政策保障（如世贸组织等）。
* **冷战结束**：提供国际环境条件，使商品、技术、资本更广泛流动。

## 全球化是“双刃剑”（矛盾两面：对发展中国家）

* **积极作用**：带来先进技术与管理经验；更多就业机会；推动国际贸易发展；促进跨国公司发展。
* **消极作用（资本主义主导的全球化）**：

  * 发达国家与发展中国家**地位与收益不平等**（受益者更多是发达国家）；
  * 资源短缺与环境破坏加速（高耗能、高污染产业可能转移）；
  * 经济风险加剧（外部冲击、产业结构不平衡等）。

## 逆全球化：表现与典型（老师举例口径）

* **经济上**：贸易保护主义抬头（加征关税、贸易摩擦等）。
* **政治上**：极端保守倾向、民粹主义上升。
* **社会上**：反移民、排外主义盛行。
* 典型现象：**英国脱欧**、**美国“退群”**、贸易摩擦与加税等。
* 老师观点：逆全球化是“现象”，本质上是**经济基础矛盾的反映**（生产力—生产关系矛盾在现实政治中的折射），但**全球化方向总体未改**。

## 中国应对逆全球化（老师给的“答题模板”）

* **创新驱动**：打造富有活力的增长模式。
* **协同联动、开放共赢**：打造合作模式。
* **公平包容、平等普惠**：让各国人民共享全球化成果。
* 实践抓手：**“一带一路”**、**中欧班列**、更高水平开放布局等。
* 老师例子：以**海南自由贸易港封关**（作为开放平台与政策优势）说明“在逆流中走自己的路”（记“政策+区位+平台”三件套）。

# 当代资本主义的新变化（战后五点变化，按老师顺序）

## 1）生产资料所有制的变化（主导形式的演变）

* 资本主义早期：**私人资本**为主 → 所有权与控制权较统一。
* 19世纪末20世纪初：**私人股份资本** → 所有权与控制权分离（职业经理人等）。
* 二战后：**法人资本**成为重要形式 → 通过集中股权等使所有权/控制权趋于“再合一”。
* 二战后新增（老师强调两种）：

  * **国家资本所有制**：国家占有生产资料但服务于垄断资本（性质仍属资本主义）。
  * **法人资本所有制**：企业法人/机构法人通过股权参与或干预治理，本质仍是雇佣劳动统治下的“集体资本”形式。

## 2）劳资关系与分配关系变化

* **劳资关系缓和举措**：工会作用增强、**职工参与决策**等。
* **分配关系变化**：除工资外，出现**职工持股/分红**等（老师提醒：容易制造“人人都是资本家”的假象，本质上股份很小，但确能一定程度缓和矛盾）。
* 福利制度倾向：从“摇篮到坟墓”的社会福利制度扩展（用于缓和矛盾）。

## 3）社会阶层与阶级结构变化

* 企业实际控制者更多表现为**高级职业经理人**；资本家更多体现为“收益/分红获取者”。
* 产业结构变化：知识型、服务型劳动者增多，**白领比例上升**，传统产业工人占比下降。

## 4）经济运行机制与经济危机形态变化

* 古典危机：以**商品过剩**为典型表现。
* 战后：国家干预（凯恩斯主义等）加强。
* 70年代：出现**滞胀**（老师口径：货币供给过剩等）。
* 之后：私有化浪潮与**新自由主义**（大市场、小政府）。
* 结果：爆发**2008金融危机**（老师强调其严重性与影响面）。

## 5）政治制度变化

* 多元化趋势；公民权利有所扩展；法治建设加强；加强对社会经济生活干预；改良主义政党受关注（用于缓和社会矛盾）。

# 如何正确认识当代资本主义：性质没变，但“自我调节/更新”存在

* **结论（老师口径）**：当代资本主义的变化**没有改变其剥削性质**，也**没有解决基本矛盾**；更多是制度允许范围内的自我调整与改良。
* **同时**：资本主义也不是“马上灭亡”，社会主义代替资本主义是**长期过程**（后面还会再强调）。

## 变化原因（录音能整理出的“能答题版”）

* **科学技术与生产力发展**是根本推动力：产业结构、劳动组织、新经济形态（数字/智能/共享经济等）发展。
* **工人阶级争取权益的斗争**推动调整（罢工等）。
* （录音此处略有断裂）可用总括句：变化根源仍要从**社会基本矛盾（生产力—生产关系、经济基础—上层建筑）**中找。

# 世界大变局下：资本主义矛盾冲突的集中表现（老师列点）

## 经济层面

* **虚拟经济与实体经济失衡**；福利风险加剧；债务负担加重（危机后治理仍困难）。

## 政治层面：政治体制“失灵”

* 选举难以产生“贤能治理”；党派利益可能凌驾于国家利益；公投等“民主陷阱”影响治理；传统精英政治衰落→民粹主义泛滥。

## 社会层面：社会融合机制失效

* 利益群体分化；社会流动性下降（阶层固化）；贫富差距扩大；群体性事件/游行示威频发（老师举“占领华尔街”等作为现象例子）。

# 资本主义的历史地位与变化趋势：坚持矛盾观点（进步性 + 局限性）

## 进步性（为什么它曾推动社会前进）

* 将科学技术转化为强大生产力（从工场手工业到机械大工业；多次工业/科技革命推动生产力）。
* 追求剩余价值的内在动力 + 竞争外在压力 → 推动改进技术、改善经营、提高劳动生产率。
* 上层建筑在一定时期内对资本主义生产方式起到保护与促进作用（如从自由竞争到垄断、再到国家干预调节等）。

## 局限性（为什么它必然被更高制度取代）

* **基本矛盾**：生产社会化 vs 资本主义私人占有（内部无法根本解决）。
* 财富两极分化、经济危机反复、社会冲突加剧。
* 阶级对立：无产阶级与资产阶级对立，矛盾不断激化。
* 国家垄断资本主义对社会化的调节，在某种意义上成为社会主义的“前奏/物质准备”（老师原话风格：社会主义的一个入口/前奏）。

## 关键判断

* 社会主义代替资本主义是**长期过程**（课堂问答里老师明确：短期内难以“在我们这一代看到完全实现”）。

# 第六章导入：社会主义理论（社会主义500年进程）——从“理想”到“科学”到“实践”

## 为什么会出现社会主义思想（老师的答案框架）

* 人类文明进化与对美好生活的向往 → 各种“理想社会观”。
* 古代思想家的理想设计（如孔子的“大同”、柏拉图“理想国”）可作为“理想社会”例子，但**不等同于社会主义**（受时代限制，缺可行方案与现实道路）。

## 社会主义500年六阶段（老师明确列的“时间线”）

1. **1516《乌托邦》**（托马斯·莫尔）——空想开端。
2. **1848《共产党宣言》发表**——社会主义由空想到科学。
3. **1917十月革命**——第一个社会主义国家诞生。
4. **1936苏联宣布建成社会主义**（苏联模式兴衰过程）。
5. **1949新中国成立**——社会主义力量壮大。
6. **1978改革开放/中国特色社会主义开创发展**（十一届三中全会）。

# 空想社会主义：三阶段 + 评价（老师给的“可背版”）

## 三阶段（按老师划分）

1. **16—17世纪：早期空想社会主义**

   * 代表：托马斯·莫尔、康帕内拉、（老师还提到）文采尔。
   * 典型主张（以莫尔为例）：反对“羊吃人”式原始积累弊端；设想无私有、无剥削、城乡无对立、有计划生产，按需分配等。
   * 康帕内拉《太阳城》：强调消灭私有、人人平等、法律严明、劳动光荣等。
2. **18世纪：空想的平均共产主义**

   * 代表：莫莱里、马布利、巴贝夫。
   * 老师提醒：这部分偏“法条/制度论述”，课堂只需掌握阶段与代表人物（不要细抠文本）。
3. **19世纪上半叶：批判的空想社会主义（顶峰）**

   * 代表：圣西门、傅立叶、欧文。
   * 共同点：直面资本主义矛盾尖锐化与劳动人民苦难，提出改造方案并有实践尝试（如欧文的新和谐公社、缩短工时、禁童工、办教育与互助组织等）。

## 评价（矛盾两面）

* **进步性**：批判旧制度，揭示其弊端；描绘新制度蓝图，提出许多有价值见解。
* **局限性**：陷入“理性支配世界”的唯心史观；找不到现实的破旧立新力量与道路；理论体系不成熟。
* **根本原因**：不成熟理论对应不成熟资本主义与不成熟阶级状况（时代局限）。
* **历史地位**：成为科学社会主义的**直接理论来源**之一。

# 科学社会主义：形成、标志与实践线索（课堂串讲版）

* **思想来源**：德国古典哲学、英国古典政治经济学、英法空想社会主义。

* **诞生标志**：**1848《共产党宣言》**（社会主义由空想到科学）。

* **论证基础**：唯物史观、剩余价值学说（老师说“细节不展开”，答题点到即可）。

* **组织与运动线索**：

  * 共产主义者同盟；
  * 1864国际工人协会（第一国际）；
  * 巴黎公社：失败但经验教训（要武装革命、打碎旧国家机器、建立新政权、需要无产阶级政党领导）；
  * 1889第二国际（后因修正主义等问题走向解体）。

* **十月革命**：提出“帝国主义薄弱环节首先胜利”，建立世界第一个人民当家作主的社会主义国家；此后社会主义实践发展、也经历曲折（东欧剧变等），中国走出中国特色社会主义道路并继续发展。

# 科学社会主义基本原则（十条，按老师讲到的顺序整理）

## 1. 两个必然 + 两个绝不会（辩证统一）

* 两个必然：资本主义必然灭亡；社会主义必然胜利。
* 两个绝不会：旧制度在其能容纳的生产力充分发展前不会灭亡；新生产关系在物质条件成熟前不会出现（强调“不会一蹴而就”）。

## 2. 无产阶级是最先进、最革命的阶级

* 是先进生产力代表；组织性纪律性强；受剥削压迫最深→革命最坚决彻底。
* 肩负推翻资本主义、建设社会主义/共产主义新世界的历史使命。

## 3. 无产阶级革命是斗争最高形式：以建立无产阶级专政国家政权为目的

* 斗争形态：经济斗争、政治斗争、思想斗争。
* 关键点：解放必须夺取并建立属于自身阶级的国家政权（上层建筑的最高表现）。

## 4. 在生产资料公有制基础上组织生产：以满足全体社会成员需要为根本目的

* 私有制被视为资本主义罪恶根源之一；公有制是社会主义经济制度根基。
* 可探索公有制实现形式，但根本制度不变；强调经济效益与社会效益统一。

## 5. 对社会生产实行有计划指导与调节；分配实行按劳分配

* “有计划组织生产”是一般原则，但要与国情与生产力水平匹配。
* 老师解释计划经济局限：没有相应生产力与信息条件（类比“大数据不成熟”）难以完全覆盖社会需求。
* 社会主义第一阶段仍存在分工与差别 → 按劳分配是历史进步但有阶段局限。

## 6. 遵循自然规律改造与利用自然：实现人与自然和谐共生

* 人来源于自然、应敬畏自然；改造自然必须以遵循规律为前提，保持动态平衡。

## 7. 坚持科学理论指导并大力发展社会主义先进文化

* 坚持马克思主义指导地位；先进文化是凝聚与激励人民的重要力量、综合国力标志。
* 重视意识形态领域领导权/管理权/话语权；教育塑造价值观（老师举“历史叙事与教育影响认知”的例子用来说明）。

## 8. 必须坚持无产阶级政党领导

* 无产阶级政党是先锋队：先进理论武装、理想信念坚定、民主集中制、统一纲领与严格纪律 → 形成强大组织力量。
* 巴黎公社经验也强调“需要政党领导”。

## 9. 解放和发展生产力：消灭剥削、消除两极分化，实现共同富裕与社会全面进步，推动向共产主义过渡

* 社会主义根本任务落在“生产力”上；以共同富裕为方向（老师对应到邓小平相关表述作为记忆点）。

## 10. 共产主义是人类最美好社会制度：实现共产主义是共产党人最高理想

* 共产主义特征与展开：老师提示“第七章重点再讲”。

# 如何把握科学社会主义原则（答题常用三句话）
