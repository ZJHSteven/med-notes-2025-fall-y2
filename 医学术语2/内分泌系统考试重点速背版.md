# 内分泌系统考试重点速背版（那那老师划重点）

## 核心：腺体 + 激素 + 功能 = 必出题

---

## 一、所有内分泌腺体（都得知道、都要会写）

**Pituitary（垂体）/ Pineal（松果体）/ Thyroid（甲状腺）/ Parathyroid（甲状旁腺）/ Adrenal（肾上腺）/ Thymus（胸腺）/ Pancreas（胰腺）/ Testes（睾丸）/ Ovaries（卵巢）**

---

## 二、甲状腺（Thyroid Gland）——老师强调要会写

### 激素 + 功能

| 激素 | 功能 |
|------|------|
| **Thyroxine（T4）** | 调节体内能量和热量产生→调整代谢率 |
| **Triiodothyronine（T3）** | 调节体内能量和热量产生→调整代谢率 |
| **Calcitonin（降钙素）** | **高钙血症**时分泌 → 促进钙向骨沉积 → **降血钙** |

---

## 三、肾上腺（Adrenal Glands）——老师重点讲解

### 肾上腺皮质（Adrenal Cortex）三层对应激素

| 层次 | 激素类别 | 代表激素 | 功能 |
|------|--------|--------|------|
| **球状带（外层）** | **Mineralocorticoids**（盐皮质激素） | **Aldosterone（醛固酮）** | 调节 **Na⁺** 和 **K⁺** → 影响**电解质与体液容量** |
| **束状带（中层）** | **Glucocorticoids**（糖皮质激素） | **Cortisol（皮质醇）** | 调节**糖、脂肪、蛋白质代谢** → 强效**抗炎** |
| **网状带（内层）** | **Steroid sex hormones**（性类固醇） | **Androgens（雄激素）/ Estrogen（雌激素）/ Progesterone（孕酮）** | 调节**第二性征**与**生殖** |

### 肾上腺髓质（Adrenal Medulla）

| 激素 | 功能 |
|------|------|
| **Epinephrine（肾上腺素） = Adrenaline** | ↑心率 / 扩张支气管 / 促进肝糖原分解 → 产生葡萄糖 |
| **Norepinephrine（去甲肾上腺素）** | 血管收缩 → **升高血压** |

**生理意义：应激反应（fight or flight）**

---

## 四、垂体前叶激素（Anterior Pituitary）

| 激素 | 功能 |
|------|------|
| **GH（Growth Hormone = Somatotropin）** | 促进全身细胞增大与分裂 → **体生长** |
| **TSH（Thyroid-Stimulating Hormone）** | 调节**甲状腺**功能 |
| **ACTH（Adrenocorticotropic Hormone）** | 调节**肾上腺皮质**功能 |
| **PRL（Prolactin）** | 妊娠及分娩后 → **乳汁分泌** |
| **FSH（Follicle-Stimulating Hormone）** | 女：促进卵泡&卵子发育 / 男：促进精子发生 |
| **LH（Luteinizing Hormone）** | 调节**性腺功能** → 参与排卵&性激素分泌 |
| **MSH（Melanocyte-Stimulating Hormone）** | 刺激黑素细胞 → 生成 **melanin** → **皮肤变深** |

---

## 五、垂体后叶激素（Posterior Pituitary）

| 激素 | 功能 |
|------|------|
| **ADH（Antidiuretic Hormone = Vasopressin）** | 促进肾小管**水重吸收** → 减少尿量 / 收缩小动脉 → **升血压** |
| **Oxytocin（OT）** | 分娩时：**子宫收缩** / 产后：刺激**乳腺排乳** |

---

## 六、松果体（Pineal Gland）

| 激素 | 功能 |
|------|------|
| **Melatonin（褪黑素）** | 调节**昼夜节律（circadian rhythm）** → 管理睡眠与清醒周期 |

---

## 七、甲状旁腺（Parathyroid Glands）

| 激素 | 功能 |
|------|------|
| **PTH（Parathyroid Hormone）** | **低血钙**时分泌 → 促进**骨分解** → 释放钙到血中 → **升血钙** |

---

## 八、胸腺（Thymus Gland）

| 激素 | 功能 |
|------|------|
| **Thymosin（胸腺素）** | **免疫系统发育** → 尤其是 **T细胞（T lymphocytes）** 的生长与成熟 |

---

## 九、胰腺（Pancreas）——胰岛激素

| 激素 | 分泌细胞 | 功能 |
|------|--------|------|
| **Insulin（胰岛素）** | **β细胞** | 促进体细胞摄取**葡萄糖** → **降血糖** / 促进肝糖原合成 |
| **Glucagon（胰高血糖素）** | **α细胞** | **低血糖**时分泌 → 促进肝分解葡萄糖 → **升血糖** |

**重点对比：Insulin ↓血糖 / Glucagon ↑血糖**

---

## 十、生殖腺（Gonads）

### 卵巢（Ovaries）

| 激素 | 功能 |
|------|------|
| **Estrogen（雌激素）** | 女性第二性征 / 调节月经周期 |
| **Progesterone（孕酮）** | 维持**子宫环境**→利于妊娠 |

### 睾丸（Testes）

| 激素 | 功能 |
|------|------|
| **Testosterone（睾酮）** | 促进**男性第二性征** / 调节**精子发生（sperm production）** |

---

## 十一、其他器官分泌激素

| 器官 | 激素 | 功能 |
|------|------|------|
| **Kidney（肾）** | **Erythropoietin（促红细胞生成素）** | 刺激**骨髓**造血 → 红细胞生成 |
| **Gastrointestinal tract（胃肠道）** | **Gastrin / Secretin / Cholecystokinin（CCK）** | 促进消化酶&胆汁分泌 |
| **Skin（皮肤）** | **Vitamin D** | 促进**小肠钙吸收** → 维持骨骼和血液钙含量 |

---

## 十二、必背的对比与拮抗激素

### 血糖调节

- **Insulin**（↓血糖）vs **Glucagon**（↑血糖）→ "拮抗双胞胎"

### 血钙调节

- **PTH（升血钙）** vs **Calcitonin（降血钙）**

### 血压调节

- **ADH（升血压）** + **Epinephrine（升血压）** vs Vasodilator

### 应激反应

- **Epinephrine + Norepinephrine** → **Fight or Flight Response**

## 十三、常见症状表述快速对应

| 症状组合 | 对应疾病/激素异常 |
|--------|----------------|
| **Polyuria（多尿）+ Polydipsia（多饮）** | ↑Glucose（高血糖，DM）/ ↓ADH（diabetes insipidus） |
| **Polyphagia（多食）+ 体重↓** | **Hyperglycemia（高血糖，DM）** |
| **Hypercalcemia（高钙血症）** | ↑PTH / ↓Calcitonin |
| **Hypocalcemia（低钙血症）** | ↓PTH / ↑Calcitonin / ↓Vitamin D |
| **心率快 + 出汗 + 消瘦 + 眼突** | **Hyperthyroidism（甲亢）** / **Graves' disease** |
| **心率慢 + 肥胖 + 皮肤干 + 嗜睡** | **Hypothyroidism（甲减）** |
| **肌肉抽搐/痉挛** | **Tetany**（↓血钙，甲旁腺疾病） |

## 十四、老师特别强调的黑体重点（会出选择题）

✅ **考试题型：给一个激素名，选它的功能/来自哪个腺体**

### 快速识别卡

**看到这些激素，你需要知道：**

1. **Insulin** = β细胞 = 降血糖
2. **Glucagon** = α细胞 = 升血糖
3. **PTH** = 甲状旁腺 = 升血钙
4. **Calcitonin** = 甲状腺 = 降血钙
5. **Cortisol** = 肾上腺皮质（束状带） = 代谢/抗炎
6. **Aldosterone** = 肾上腺皮质（球状带） = Na⁺/K⁺/血压
7. **Epinephrine/Adrenaline** = 肾上腺髓质 = 应激反应
8. **TSH** = 垂体前叶 = 调节甲状腺
9. **ACTH** = 垂体前叶 = 调节肾上腺皮质
10. **ADH/Vasopressin** = 垂体后叶 = 升血压/减尿量
11. **Oxytocin** = 垂体后叶 = 子宫收缩/乳汁排出
12. **GH/Somatotropin** = 垂体前叶 = 促进生长
13. **T4/Thyroxine + T3/Triiodothyronine** = 甲状腺 = 代谢/能量/热量
14. **FSH + LH** = 垂体前叶 = 调节生殖（卵/精）
15. **PRL** = 垂体前叶 = 乳汁分泌
16. **Testosterone** = 睾丸 = 男性第二性征/精子生成
17. **Estrogen + Progesterone** = 卵巢 = 女性第二性征/月经/妊娠
18. **Melatonin** = 松果体 = 睡眠/昼夜节律
19. **Thymosin** = 胸腺 = T细胞发育（免疫）
20. **Erythropoietin** = 肾 = 红细胞生成
